## 四、安全与权限模型

### 4.1 权限最小化原则

```
飞书应用权限分级:
  P0 必需: im:message:send_as_bot (机器人消息)
  P1 常用: drive:readonly, bitable:readonly, calendar:readonly
  P2 按需: meeting:readonly, approval:readonly
  P3 禁止: contact:write, admin:write, 任何 delete 权限
```

### 4.2 安全纵深 (五层)

```
L1: Token HMAC-SHA256 签名校验
L2: IP 白名单 (飞书开放平台配置)
L3: 请求频率限制 (10 QPS 上限)
L4: 行为审计日志 (全量记录 + 飞书文档双备份)
L5: 异常熔断 (连续5次失败 → 暂停5分钟 → 自动恢复)
```
