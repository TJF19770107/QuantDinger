### 5 大自动化场景 SOP

1. **AI 调研 → 飞书文档**：搜索 → 提炼 → Markdown → `lark-cli docs +create`
2. **批量数据 → 飞书 Base**：CSV/JSON → 解析 → `lark-cli base record-create`
3. **群消息智能总结**：获取消息 → LLM 提炼 → 发送总结 / 创建文档
4. **日程智能管理**：查忙闲 → 找空档 → 创建日程 → 邀请参会
5. **运营素材批量生成**：选题表 → 批量生成 → 飞书表格 → Canva 导出
