| 优先级 | 优化项 | 说明 |
|--------|--------|------|

```
Hermes Agent (Windows原生部署)

    ├── 调度层 → 豆包Agent (交互/推理)
```

## 四、Skill Bundles 机制引入（v0.14）

### 4.1 概念对齐

Hermes Agent v0.14 的 Skill Bundles (YAML聚合多技能) 与龙虾体系的技能库目录对应：

```
Hermes Skill Bundle (YAML)     ←→     龙虾技能库 (技能清单.json)
    skill-1                         →   技能库/auto-file-scanner-v1.0.md
    skill-2                         →   技能库/memory-os-v2.0.md
    skill-3                         →   技能库/desktop-controller-v2.0.md
```

### 4.2 引入方案

1. 在技能库目录新增 `skill-bundles.json`，定义技能组合
2. 按场景预定义Bundle（如"文件运维Bundle"、"迭代闭环Bundle"）
3. Hermes Agent调度时按Bundle批量加载相关技能
