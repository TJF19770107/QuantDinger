```
(99 + 98 + 92 + 95 + 99 + 97 + 93 + 93 + 91 + 98 + 91 + 96 + 94 + 94 + 97 + 92 + 86) / 17
= 1595 / 17 = 93.82

(95 + 93 + 98 + 96 + 86 + 98 + 95 + 91 + 92 + 88 + 90) / 11
= 1022 / 11 = 92.91

综合得分 = 核心得分 × 0.70 + 扩展得分 × 0.30
= 93.82 × 0.70 + 92.91 × 0.30
= 65.67 + 27.87
= 93.55

最终综合得分 = 93.55 × 1.04 ≈ 97.3
```
