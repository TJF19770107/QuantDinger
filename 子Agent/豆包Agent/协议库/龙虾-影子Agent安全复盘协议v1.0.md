# 龙虾-影子Agent安全复盘协议 v1.0

> **协议编号**: 118 | **生效范围**: 全域 / 永久 / 永恒
> **版本**: v1.0 | **依赖**: SafeGuard v3.0 + 协议117 L1引擎 + 协议106锁屏无人值守
> **对标**: Hermes影子Agent六层舱壁隔离 + ICLR 2026误进化研究 + A-Evolve五阶段Gate + Autogenesis AGP双层协议

---

## 一、设计哲学

复盘不可干扰业务，异步不可影响体验，隔离不可产生风险。影子Agent以最小权限、最窄视野、最强审计执行复盘。

---

## 二、六层舱壁隔离架构

### Layer 1: 权限隔离

| 控制项 | 影子Agent | 主Agent |
|--------|----------|---------|
| 文件写入 | 仅技能库 | 全量 |
| 系统命令 | 禁止 | 授权范围内 |
| 网络访问 | 仅内网 | 全量 |
| 跨Agent通信 | 禁止 | 允许 |
| 用户交互 | 禁止 | 允许 |
| 配置文件修改 | 禁止 | 授权范围内 |

### Layer 2: 数据隔离

| 控制项 | 策略 |
|--------|------|
| 输入数据 | 仅注入会话摘要（非原始对话） |
| 上下文窗口 | 独立上下文，不污染主Agent缓存 |
| Token预算 | 固定上限8000 tokens |
| 记忆访问 | 只读，不允许修改长期记忆 |
| 敏感字段脱敏 | API Key/Credential自动替换为占位符 |

### Layer 3: 网络隔离

| 控制项 | 策略 |
|--------|------|
| 外网访问 | 全部阻断 |
| MCP连接 | 禁止建立新连接 |
| WebSocket | 禁止 |
| HTTP请求 | 仅本地回环 |

### Layer 4: 文件隔离

| 控制项 | 策略 |
|--------|------|
| 可读范围 | 技能库 + 配置库（只读） |
| 可写范围 | 仅技能库 |
| 禁止路径 | C:\Windows、C:\Program Files、系统注册表 |
| 禁止操作 | 删除、覆盖、移动、重命名 |

### Layer 5: 进程隔离

| 控制项 | 策略 |
|--------|------|
| 启动方式 | fork独立子进程 |
| 主进程阻塞 | 绝不阻塞主Agent |
| 超时机制 | 120秒无进展→强制终止 |
| 资源限制 | CPU 20%上限 / 内存 512MB上限 |

### Layer 6: 审计隔离

| 控制项 | 策略 |
|--------|------|
| 操作日志 | 影子Agent独立日志文件 |
| 审计路径 | E:\龙虾AI主控中心\我的AI分身\子Agent\豆包Agent\审计日志\ |
| 日志格式 | JSON结构化，含操作/时间/结果 |
| 保留期限 | 90天滚动归档 |
| 防篡改 | 写入后只读，追加模式 |

## 三、脏计数器精准触发

```
触发条件: 工具迭代次数 ≥ 8 (可配置)
重置条件: Agent主动调用skill_manage/写入技能
避免场景: 简单问答(工具迭代<8)→不触发复盘
适配原则: 工具迭代数与经验沉淀价值正相关
```

| 场景 | 工具迭代 | 触发？ | 原因 |
|------|---------|--------|------|
| 简单问答 | 0-2 | 否 | 无有效经验 |
| 文件读取 | 3-5 | 否 | 仅有信息获取 |
| 代码生成 | 6-7 | 否 | 边界场景，可调阈值 |
| 复杂部署 | 8-15 | 是 | 含方案/排查/修复 |
| 多工具协同 | 15+ | 是 | 高价值经验 |

## 四、误进化断路器

对标ICLR 2026四条误进化路径：

| 路径 | 龙虾检测机制 | 应对 |
|------|------------|------|
| 模型误进化 | 复盘前后技能质量对比 | 退步≤5%→接受；退步>5%→拒绝 |
| 记忆误进化 | 语义一致性校验 | 冲突记忆→标记审查 |
| 策略误进化 | 任务成功率追踪 | 连续3次↓→熔断 |
| 安全误进化 | 协议合规性自动扫描 | 违规→立即回滚 |
| 技能误进化 | 覆盖场景回归测试 | 退化→拒绝合并 |

**熔断规则**：
- 连续3次迭代异常 → 断路器打开 → 人工确认
- 30分钟冷却期 → 半开状态 → 试运行1次
- 试运行成功 → 闭合恢复
