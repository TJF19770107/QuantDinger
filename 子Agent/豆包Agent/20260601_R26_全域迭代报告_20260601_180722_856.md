### 2.4 MindStudio自改进Agent架构（情报#263）

```
输入 → Executor → 输出
         ↓
    Logger (存储运行记录)
         ↓
    Evaluator (评分输出)
         ↓
    [定时: Optimizer读取近日志]
         ↓
    Optimizer生成改进Prompt
         ↓
    Prompt版本化更新
         ↓
    Executor使用新Prompt下一轮
```

四组件 + 双循环：
- **任务循环**（高频）：执行实际工作
- **改进循环**（低频）：回顾日志、优化Prompt
- **被动改进**：出错时自动恢复重试
- **主动改进**：定时分析日志模式，提出/实施优化

### 3.3 协议#87详解：四组件自改进Agent架构协议 v1.0

```
四大组件：
1. Executor（执行器）：接收输入→运行当前Prompt/模型→产出输出+结构化日志
2. Logger（日志器）：持久化存储每条运行记录（输入/输出/模型/版本/延迟/成功标记）
3. Evaluator（评估器）：独立LLM调用→评分输出质量→追加质量分数到日志
4. Optimizer（优化器）：批量读取日志→识别低质运行→提取失败模式→生成改进Prompt

双循环机制：
- 任务循环：高频（每小时/每天/事件驱动）
- 改进循环：低频（每周/完成N次任务后）
```

→ 轮换（自动化双模式：Backend/Front-door）
