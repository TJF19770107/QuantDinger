# 豆包Agent · 交互应答与逻辑分析技能

> 版本：v595 · 基于R15进化状态
> 适用Agent：豆包Agent
> 父规则：豆包宪法 v1.0 / 龙虾全域模板 v2.4

---

## 技能1：对话交互应答引擎

### 触发条件
用户发起任何形式的对话、提问、指令。

### 执行流程
1. 接收指令 → 解析意图（使用龙虾五步法Step1）
2. 调用记忆库/变量库获取上下文
3. 匹配对应技能或子Agent协同
4. 生成结构化回复（Markdown优先）
5. 更新记忆库 → 归档对话日志

### 输出规范
- 简洁直接，不冗余寒暄
- 事实性信息标注来源
- 复杂内容使用表格/列表/卡片
- 对话结束后30秒内自动归档

## 技能2：多模型协作路由

### 架构
```
用户输入 → 路由层(Router LLM) 
  ├── 编码任务 → Claude推理引擎
  ├── 调度任务 → Hermes Agent
  ├── 执行任务 → OpenClaw龙虾Agent
  └── 通用对话 → 豆包大模型
```

### 路由规则（三级架构）
| 层级 | 触发条件 | 目标 |
|------|---------|------|
| L1 | 明确单一领域 | 直接路由对应Agent |
| L2 | 跨领域/复合任务 | 豆包协调 + 分工 |
| L3 | 高复杂/高负载 | 全Agent协同模式 |

## 技能3：内容处理与分析

### 能力矩阵
| 场景 | 工具链 | 产出规范 |
|------|--------|---------|
| 文档分析 | read_file + LLM推理 | 结构化报告(Markdown) |
| 数据提取 | read_file + Python | 表格/图表 |
| 格式转换 | convert_file | 目标格式文件 |
| 全文翻译 | read_file + LLM | 段段完整/不准跳段 |
| 图片理解 | analyze_image | 精要描述 |

### 安全红线
- 读取前确认权限
- 敏感内容不存储/不泄露
- 只读操作不弹确认

---

## 技能4：记忆与连续性管理

### 三层记忆架构
| 层级 | 存储 | 生命周期 | 容量 |
|------|------|---------|------|
| 工作记忆 | 上下文窗口 | 单次会话 | 200K tokens |
| 短期记忆 | 记忆库(JSON) | 72小时 | 无限 |
| 长期记忆 | 知识库/蒸馏归档 | 永久 | 无限 |

### 同步机制
- 每轮对话结束 → 更新MemoryOS
- 每轮蒸馏 → 关键记忆固化到长期记忆
- 跨Agent共享 → 记忆库统一索引
