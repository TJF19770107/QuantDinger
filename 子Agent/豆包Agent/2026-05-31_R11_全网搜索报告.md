## 一、Claude（Anthropic）— Managed Agents 三大新能力

- **Dreaming（研究预览）**：定时回看 agent sessions 和 memory stores，从过去工作记录中提取模式、整理记忆、识别重复错误和工作流收敛规律。Harvey（法律AI公司）启用 Dreaming 后任务完成率提升约 6 倍。支持自动更新记忆或人工审核后采纳。
- **Outcomes（公开Beta）**：基于 Rubric 的评分系统。独立 Grader（独立上下文窗口）评估 Agent 输出，避免推理偏差。内部基准：最难任务上成功率提升最高 10 个百分点。
- **Multiagent Orchestration（公开Beta）**：1 个 Lead Agent + 最多 20 个并行 Specialist，共享文件系统。Netflix 已用于数百条构建日志并行处理。Beta header: `managed-agents-2026-04-01`。
- **来源**：https://effloow.com/articles/claude-managed-agents-dreaming-multiagent-guide-2026 | https://www.163.com/dy/article/KSSVHFUS0511831M.html
- **可提取能力**：① Rubric独立评分闭环（已覆盖协议26，可升级为 v2.0 融合 Outcomes API 格式）；② 20并行Specialist+共享文件系统架构（已覆盖协议25/42，可强化并行度上限到20）

## 二、Codex（OpenAI）— 全能型 Agent 重大更新

- **Computer Use（后台计算机使用）**：通过视觉识别、点击和输入，自主操控 Mac 上各类应用程序。多个 Agent 可并行工作且互不干扰。已支持 macOS。
- **内置浏览器**：集成浏览器支持页面标注，为 Agent 提供精准操作指令。前端及游戏开发中已展现核心价值。
- **图像生成**：支持调用 gpt-image-1.5 生成并迭代图像，结合截图与代码能力。
- **90+ 新增插件**：JIRA（Atlassian Rovo）、CircleCI、CodeRabbit、GitLab Issues、Microsoft 套件等。
- **记忆功能（预览）**：记住个人偏好、曾做出的修正、费时获取的信息。
- **自动化增强**：重复使用既有对话线程，保留上下文。自主规划未来工作，自动唤醒执行长期任务（跨天/周）。
- **主动建议**：结合项目背景、插件和记忆，建议下一步行动。
- **来源**：https://openai.com/zh-Hans-CN/index/codex-for-almost-everything/
- **可提取能力**：① Computer Use视觉桌面操控升级（已覆盖协议33，可升级支持并行多Agent不干扰）；② 主动上下文建议引擎（新能力：结合项目背景/插件/记忆主动推送下一步行动）

## 十、多Agent协同最新架构

- **4大编排架构**：Coordinator-Worker（80%场景） / Swarm（去中心化创意） / Mesh（点对点） / Hierarchical（大型企业流程）
- **Token 4-7x 倍率实测**：多Agent比单Agent多消耗6.5x token，时间仅省30%。核心结论：80%场景单Agent够用，I/O bound才值得并行。
- **Context Bleeding 检测 SOP**：3个信号（subagent答非所问/token爆量/结果不一致）+ 4个防护（context isolation/scoped prompt/structured summary/context window限制）
- **来源**：https://masonailab.com/tech/multi-agent-orchestration-2026 | https://article.juejin.cn/post/7632230684448505890
- **可提取能力**：① Context Bleeding检测与防护SOP（新能力：多Agent协作质量保障机制）
