## 五、R43 关键里程碑

### 5.1 Hermes Kanban Swarm — 多Agent任务持久化的工程答案

Hermes Kanban Swarm 是目前最工程化的多Agent持久化协作方案：
- **SQLite作为协调原语**：WAL模式+BEGIN IMMEDIATE事务保证多进程安全
- **CAS并发控制**：无需分布式锁，SQLite序列化写入者天然解决竞争
- **Board隔离**：多项目同时运行互不干扰
- **Dispatcher自动依赖提升**：父任务done自动将子任务从todo→ready
- **熔断保护**：Worker崩溃后超时检测→自动回收→其他Worker重新领取
- **三种交互入口**：CLI + Web Dashboard + Agent Tools

### 5.2 AI Agent记忆栈标准化 — 从混沌到三层固化

2026年记忆层成为兵家必争之地：
- **Letta (22K★/$10M种子)** / **Mem0 (55K★/$24M融资)** / **Zep Graphiti (20K★)**
- **Context Rot正式命名**：大上下文窗口反而导致性能退化
- **结构化提取 > 全量上下文**：Mem0用7K Token达到91.6%准确率，Full-Context需26K+且分数更低
- **三层固化**：工作记忆(RAM) ↔ 短期记忆(会话) ↔ 长期记忆(外部存储)

### 5.3 Darwin Gödel Machine — 自进化Agent的理论突破

- **Archive基因多样性**：不追求单点最优，维护多样化Agent种群

- **跨模型泛化**：生成的Agent不仅在一个模型上有效
