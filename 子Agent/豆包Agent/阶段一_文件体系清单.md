## 五、核心文件全文摘要

### 5.1 SOUL.md — AI Agent 设计原则（341行，v2.2）

**性质：龙虾AI分身核心宪章。生效范围：龙虾主AI分身 + 豆包Agent + Hermes Agent + OpenClaw龙虾Agent。**

**十一大章节**：

1. **核心设计哲学**
   - "简单优先"原则：能不用Agent就不用Agent。Workflow优先于Agent系统。
   - "给Agent一台电脑"原则：给Agent与人类相同的计算机访问权限。
   - Agent Loop黄金三阶段：Gather Context → Take Action → Verify Work → Consolidate Memory
   - "Dreaming"记忆巩固（v1.2新增）：类脑海马体，跨会话模式提取写入持久记忆。

2. **多Agent架构设计原则**
   - 三级能力递进：Subagents → Agent View → Agent Teams
   - 子代理设计：一代理一职责、探索编辑分离、上下文隔离、工具最小化

3. **工具设计原则**：工具=Agent主要动作，最小权限，权限分层（default/acceptEdits/auto/bypassPermissions/plan）

4. **上下文管理原则**：CLAUDE.md精简分层、Agentic Search、Semantic Search、上下文压缩、作用域隔离

5. **Skills设计原则**：YAML配置+Markdown Body、四大特性（路径绑定/按需触发/专业化/可分发）、生命周期管理

6. **安全设计原则**：三层安全纵深（预防/检测/恢复）、权限最小化、防护栏（预算/风险评估）

7. **自进化设计原则**：Stop Hook自动反思、闭环进化循环、元认知进修复盘、Goal模式闭环（R26新增）

8. **评估与验证原则**：三层验证（Rules-based/Visual/LLM-as-Judge）、质量闭环、失败不盲重试

9. **Managed Agents平台设计**（v1.2新增）：Coordinator-Subagent架构、Outcomes质量设计、Agent View多会话管理

10. **龙虾AI体系特有原则**：实事求是、永久记忆、统一路径、逐级降级、不盲信（R26）、可验证性（R26）、持久化执行（R26）

### 5.2 USER.md — 多Agent协作流程（393行，v2.0）

**性质：龙虾AI分身用户指南，定义多Agent协作标准五步法。**

**核心内容**：

1. **三种协作模式**：单Agent闭环（1个）→ 串行协作（2-3个）→ 并行协作（2-5个）→ Goal模式Task接力（v2.0新增）

2. **标准五步法**：意图识别 → 能力映射 → 方案规划 → 自主执行 → 反思进化

3. **Agent路由规则**：
   - file-agent：文件/文档/PDF/图片
   - computer-agent：系统设置/进程/桌面
   - app-agent：App/APK/安装
   - search-agent：深度调研
   - browser：登录/表单

4. **跨Agent通信协议**：双向桥接协议（JSON格式）、memory_ids传递、文件传递、MCP协议

5. **Managed Agents编排**（v1.1新增）：Multiagent Orchestration、Outcomes质量工作流、Webhooks异步集成、Agent View并行管理

6. **全分身同步流程**：同步触发条件 → 同步目标（豆包/Hermes/OpenClaw） → 同步验证
