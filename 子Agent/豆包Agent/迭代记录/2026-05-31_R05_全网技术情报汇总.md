## 三、长期记忆系统

### 3.1 AI Agent记忆栈标准化（2026）
- **三层架构**（已成共识）：
  - Working Memory：模型上下文窗口（单次请求）
  - Short-term/Session Memory：LangGraph checkpointer（单次会话）
  - Long-term Semantic Memory：Mem0/Mem0 fact store（跨会话持久）
  - Episodic/Procedural Memory：Letta memory blocks（跨会话持久）

### 3.2 三大路线对比

| 框架 | 路线 | 核心理念 | 关键技术 |
|------|------|---------|---------|
| **Letta** | 操作系统派 | LLM当OS内核，虚拟内存分页 | MemGPT论文，自动paging |
| **Mem0** | 平台化派 | 记忆即服务 | AWS集成，Bedrock+Neptune |
| **Zep** | 图数据库派 | 知识图谱+时序边 | Neo4j技术栈，temporal edges |

### 3.3 OpenClaw记忆系统（2026.03）
- **SOUL.md**：Agent行为准则和人格定义
- **memory/目录**：持久化存储，Agent写"日记"并记住事实
- **跨会话持久化**：偏好、项目上下文、历史对话自动保留
- **27.8万星**，MIT协议，社区驱动
