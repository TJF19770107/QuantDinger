## 四、SkillForge v3.0 增强详情

### 技能自动萃取流水线

```
执行日志 → 模式识别 → 质量评估 → 模板生成 → 入库审查 → 激活
```

| 萃取模式 | 触发条件 | 产出 |
|---------|---------|------|
| 成功模式 | 同类任务3次+成功 | 最优执行路径+参数组合 |
| 失败模式 | 2次+同类失败 | 失败原因+绕行方案 |
| 高效模式 | 执行耗时<历史平均50% | 加速技巧+快捷路径 |
| 协作模式 | 多Agent协同完成 | Agent编排模板 |

## 五、SafeGuard v3.0 增强详情

### 自动回滚规则

| 规则ID | 触发条件 | 动作 | 冷却 |
|--------|---------|------|------|
| ARR_001 | error_rate > 50% AND nodes > 3 | rollback_to_last_stable | 1h |
| ARR_002 | memory > 2048MB | compress_and_continue | 10min |
| ARR_003 | skill_success_rate < 30% AND count > 10 | deactivate_and_rollback | 2h |
| ARR_004 | checksum_mismatch_on_critical | restore_from_snapshot | 即时 |
