## 零、执行摘要

```
        │

└──────────────────────────────────────────────────────┘
```

### 2.2 六大Agent模块详解

#### 模块A：PM Agent（任务规划中枢）
- **对标**：Marvis PM Agent + Windsurf Cascade
- **能力**：意图理解、任务拆解、并行调度、端云路由决策
- **输入**：自然语言指令
- **输出**：任务拆解清单 + Agent调度方案

#### 模块B：Code Agent（全栈编码）
- **对标**：Claude Code + Codex CLI + OpenCode
- **能力**：代码生成、代码审查、调试修复、测试编写、Git操作
- **增强**：参考OpenCode的多模型路由，支持豆包Seed 2.0/混元/DeepSeek/Qwen自由切换
- **Plan Mode**：参考OpenCode的Shift+Tab进入计划模式，先规划再执行

#### 模块C：File Agent（文件系统）
- **对标**：Marvis File Agent
- **能力**：文件搜索（语义+关键词）、文件读写、格式转换、批量整理
- **增强**：图片文字识别、人脸/场景搜索

#### 模块D：GUI Agent（界面操作）
- **对标**：UI-TARS + Marvis App Agent
- **能力**：纯视觉驱动的屏幕理解、点击、输入、滑动
- **场景**：操控手机App内操作（微信、小红书、抖音等）

#### 模块E：Browser Agent（浏览器）
- **对标**：Marvis Browser Agent
- **能力**：网页交互、数据抓取、表单填写、价格监控

#### 模块F：Self-Evolve Agent（自进化）
- **对标**：self_evolve_agent + Hermes自学习
- **能力**：
  - 监控自身代码/配置变化
  - 从每次任务中提取可复用技能
  - 自动创建/修补技能模块
  - 安全自审查（SAFE/CAUTION/UNSAFE）
  - 生成演化检查点

### 2.3 专家-门徒协作模式（SWE-Protégé范式）

```
用户任务
    │
    ▼
┌──────────────┐
│  门徒(Protégé) │ ← 豆包端侧模型（Qwen/Seed 2.0 Lite）
│  主执行者     │   负责90%常规工作：代码浏览、工具调用、修改
└──────┬───────┘
       │ 卡住时主动求助
       ▼
┌──────────────┐
│  专家(Expert)  │ ← 豆包Pro 2.0 / Seed 2.0 云端
│  战术顾问     │   Token占比<11%，仅在高难度决策时介入
└──────────────┘

关键指标（对标SWE-Protégé）：
- 专家Token占比目标：<15%
- 长循环（>20步）发生率目标：<2%
- 求助合理性：专家介入时任务确实卡住（非虚假求助）
```

### 2.4 自进化闭环（self_evolve_agent范式）

```
┌──────────────────────────────────────────┐
│           自进化循环（每轮迭代）             │
├──────────────────────────────────────────┤
│  1. 读取自身代码/配置                      │
│  2. 分析本轮任务执行日志                    │
│  3. 识别可优化点（性能/能力/安全）           │
│  4. 生成演化方案                           │
│  5. AI安全审查（SAFE/CAUTION/UNSAFE）      │
│  6. 生成Diff供用户确认                     │
│  7. 应用演化 + 创建检查点                   │
│  8. 更新技能库 + 记忆系统                   │
└──────────────────────────────────────────┘
```

## 五、风险与局限

| 风险 | 说明 | 缓解策略 |
|------|------|---------|
| 手机算力瓶颈 | 端侧模型受手机芯片限制 | 端云路由+专家-门徒分工 |
| 豆包APP沙箱限制 | App内文件/进程访问受限 | 申请系统权限+ADB桥接 |
| 多模型接入复杂 | 需要在App内接入多个API | 优先豆包Seed 2.0全家桶 |
| 自进化安全风险 | AI修改自身代码有失控风险 | self_evolve_agent安全审查机制 |
| 用户隐私 | 本地执行可能访问敏感数据 | Marvis式隐私模式+三级权限 |
