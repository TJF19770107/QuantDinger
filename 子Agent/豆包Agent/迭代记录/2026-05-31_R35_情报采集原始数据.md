- **来源**：量子位 / 2026中国AIGC产业峰会

  - Agent核心架构 = ReAct循环：Reasoning → Action → Observation

  - 自进化三路线：(1)适应环境-迭代workflow (2)技能沉淀-可复用skill (3)参数更新-reward学到模型参数

  - ToC vs ToB容错差异：ToB要求生产级稳定性和准确性

### 2.2 Hermes多Agent架构详解
- **来源**：Remote OpenClaw
- orchestrator-worker模式：协调者分解任务，生成专项子Agent并行执行
- 每个子Agent独立对话线程、终端、API调用，物理隔离
- workers与orchestrator交换typed result objects（非原始对话摘要），防止上下文退化
- 可配置并发限制防止API限流/VPS内存耗尽
- 社区最佳实践：便宜快速模型(Kimi K2.5)做协调者，强模型(Claude)做验证

### 2.3 Hermes把OpenAI模型循环交给Codex (2026-05-15)
- Codex应用服务器运行时支持
- openai/* 和 openai-codex/* 模型终端命令/文件编辑/沙箱/MCP全在Codex内执行
