## 一、核心对标对象最新进展

### 1.1 Marvis Workbody（腾讯）- 最新深度解析
- **定位**：操作系统级AI中间层，不是独立应用而是嵌入系统底层的AI中间层
- **架构**：1 PM Agent + 5 专业 Agent（File/Computer/App/Browser/Search）
- **端云双模式**：效率模式（云端）+ 隐私模式（纯端侧Qwen），自动路由
- **安全三级分层**：低风险→AI自主执行 / 中风险→L2硬垂询 / 高风险→禁止AI执行
- **跨端协同**：Windows↔Mac↔Android↔iOS，支持PC操控安卓App
- **定价**：每天1000万Token免费
- **局限**：不可编程扩展、无长时间自主任务、依赖腾讯生态、Model Lock-in

### 1.3 Hermes Agent - 自进化Agent新突破
- **GitHub星标**：突破10.1万（Nous Research）
- **协议**：MIT完全开源
- **核心差异化**：自学习——记住教给它的技能，越用越聪明
- **基准测试**：11项CLI基准6:5击败OpenAI Codex
- **本地部署**：6GB GTX 1660Ti即可运行（+Ollama）
- **记忆系统**：SQLite + 全文检索 + LLM压缩 + 用户建模，跨会话自动持久化
- **执行环境**：纵深防御，多层沙箱（本地/Docker/SSH/云/HPC）
- **模型支持**：200+模型，对话中一条命令随时切换
- **技能系统**：技能即程序记忆，Agent从经验中自动创建修补，真正自我生长
- **多Agent模式**：基于OpenClaw的多Agent引擎，每Agent独立profile+记忆+会话

### 1.4 OpenClaw
- **架构**：Hub-and-Spoke，Gateway统一管控多Agent
- **入口**：25+渠道 + Mac/iOS/Android客户端
- **技能市场**：ClawHub，5700+技能，有完整治理流程
- **记忆**：基于工作区文件，偏手动管理
- **执行环境**：信任模型，非主会话进Docker沙箱
- **互通**：Hermes支持从OpenClaw一键导入

### 1.5 Windsurf (Codeium)
- **Cascade Agent**：深度融合代码库理解+高级工具+实时操作感知
- **Devin云端Agent**：独立机器运行，用户可关闭笔记本等结果
- **模式**：Plan→Devin云端执行+本地继续编码
- **Tab系统**：单键多动作（导入/移动光标/完成）
- **用户量**：100万+用户，4000+企业客户，94% AI编写代码占比

### 1.6 self_evolve_agent (GitHub开源)
- **核心理念**：AI完全控制自己的代码演化，自主决定演化策略
- **演化流程**：展示当前代码 → 用户确认 → 备份 → AI自主执行 → 检查点 → Diff → 安全审查 → 确认 → 应用
- **能力范围**：多Agent系统、记忆系统、工具创建、自分析、涌现行为
- **安全系统**：AI驱动的安全审查，三级判决（SAFE/CAUTION/UNSAFE）
- **多Provider**：Google/OpenAI/Anthropic/Hyperbolic

## 二、突破性技术发现

### 2.1 SWE-Protégé：专家-门徒协作范式
- **来源**：Meta+密歇根大学+斯坦福大学，2026年2月发布
- **核心**：7B小模型作为唯一执行者 + Claude等大模型作为战术顾问
- **专家Token占比**：仅11%，绝大多数推理在本地完成
- **SWE-bench Verified**：42.4%解决率，超越32B开源模型SOTA
- **成本**：单任务成本直降8.2倍
- **长循环根治**：超过20步的长循环从31%降至0.8%
- **训练**：SFT（监督微调）+ GRPO（在线强化学习）

### 2.2 Eve Agent V2U - 完全本地运行AI编程助手
- **双层架构**：Soul Layer（本地GPU微调模型）+ Worker Layer（Qwen3 Coder 480B云端）
- **能力**：40轮工具调用循环、完整文件系统访问、bash执行、网页搜索、git操作
- **特点**：无需云账号、无订阅费、代码数据留在本机

### 2.3 豆包2.0原生Agent架构
- **核心突破**：从"被动问答"到"主动执行"的范式转变
- **Agent能力**：自主任务拆解、多角色协同、端到端闭环交付
- **推理效率**：整体推理效率提升43%，工具调用准确率99.2%
- **成本**：token定价相比GPT-5.2/Gemini 3 Pro降低约90%
- **TRAE整合**：与TRAE开发平台深度整合，5轮提示词完成全流程
- **UI-TARS GUI Agent**：纯视觉驱动，GitHub 26k Star，豆包手机核心技术

### 2.4 Agent Runners (Netlify)
- **概念**：AI Agent直接在Netlify Dashboard运行，拥有完整生产环境上下文
- **支持的Agent**：Claude Code、Gemini CLI、Codex
- **隔离**：每个Agent在独立沙箱中运行
- **零本地配置**：无需本地开发环境
