## 一、Claude Code — 终端原生 AI 编码 Agent

| 维度 | 详情 |
|------|------|
| 厂商 | Anthropic |
| 发布时间 | 2025年2月预览，2025年5月GA |
| 开源 | 是 (GitHub: anthropics/claude-code, 73.9k stars) |
| 架构 | 本地终端通过API调用云端Claude模型推理 |
| 上下文 | **1M token 上下文窗口**（碾压级优势） |
| 模型支持 | Claude全系列 (Opus/Sonnet/Haiku) |

**核心特性**：
- **ReAct模式**：Thought → Action → Observation 循环
- **Hooks系统**：18种事件钩子，工具调用前后可执行自定义脚本
- **Custom Slash Commands**：封装可复用工作流 (如 /commit、/review-pr)
- **Agent Teams**：多Agent会话协作，共享任务列表和直接通信
- **Auto Memory**：跨会话记住构建命令、调试经验
- **Checkpoints**：追踪编辑历史，可回退到任意状态
- **IDE深度集成**：VS Code原生扩展（内联diff）+ JetBrains 插件
- **Channels**：接收Telegram、Discord等事件推送
- **Remote Control**：手机或其他设备远程控制终端会话

**豆包可借鉴**：
1. 1M上下文 → 豆包需要突破上下文限制，支持长文档全量理解
2. Hooks系统 → 豆包工具调用前后可插入自定义逻辑
3. Checkpoints → 豆包编码Agent需要版本回溯能力
4. Agent Teams → 豆包需要多Agent协作机制

## 四、Hermes Agent — 自进化 AI Agent（最核心对标）

| 维度 | 详情 |
|------|------|
| 厂商 | Nous Research |
| 开源 | 是 (GitHub: NousResearch/hermes-agent, MIT, **150k stars**) |
| GitHub排名 | **全球第47位** |
| 版本 | v0.2.0 ~ v0.15.1 (13个正式版本) |
| 硬件需求 | **6GB显卡可跑** |
| 贡献者 | 1100+ |

**核心特性 — 豆包最需要学习的部分**：

### 1. 自学习Skill闭环（核心差异化）
```
执行复杂任务 → 分析执行轨迹 → 提取可复用步骤 → 保存为.md Skill文件 → 下次自动调用
```
- 内置Skill市场: agentskills.io
- Skill自我改进：同一Skill多次调用后自动优化执行步骤
- 社区评测：重复任务时间减少40%

### 2. 跨会话记忆（FTS5持久化）
- SQLite + FTS5全文检索
- 记住所有历史上下文、项目偏好
- 重启不丢失

### 3. 40+内置工具
网页搜索、文件操作、终端命令、代码执行、浏览器自动化等

### 4. 多平台接入（15+）
CLI、Telegram、Discord、Slack、WhatsApp、飞书、钉钉等

### 5. 6种运行后端
本地、Docker、SSH、Daytona、Singularity、Modal

### 6. 技术架构
```
hermes-agent/
├── run_agent.py       # AIAgent核心类 ~12k LOC
├── model_tools.py     # 工具编排与函数调用
├── cli.py             # HermesCLI ~11k LOC
├── hermes_state.py    # SessionDB SQLite存储
├── agent/memory_manager.py  # 多记忆提供者编排
├── agent/curator.py   # 技能生命周期管理
├── tools/registry.py  # 工具注册表(自动发现)
├── gateway/platforms/ # 20+平台适配器
├── plugins/           # 插件系统
├── skills/            # 内置技能
└── optional-skills/   # 可选技能
```

### 7. CLI基准测试：Hermes 6:5 击败 Codex
在11项基准测试中以6:5领先OpenAI Codex

**豆包可借鉴**：
1. **自学习Skill机制是豆包最需要的能力** — 用户教一次，以后自动执行
2. FTS5记忆系统 — 豆包目前每次对话独立，需要跨会话记忆
3. 40+内置工具 — 豆包需要丰富工具库
4. 多平台接入 — 豆包可从手机APP扩展到多平台
5. 低硬件门槛 — 证明本地Agent不需要顶级GPU

## 六、Gemini 2.5 + LangGraph — 深度研究 Agent

| 维度 | 详情 |
|------|------|
| 厂商 | Google |
| 开源 | 是 (Apache-2.0) |
| 架构 | React + FastAPI + LangGraph + Gemini 2.5 |
| 核心理念 | "让AI不只是生成回答，而是提供有据可依的见解" |

**核心特性**：
- **动态搜索策略**：根据用户提问实时生成搜索词，迭代优化检索路径
- **信息反思能力**：基于初步结果识别"知识盲区"，主动追加搜索
- **引用溯源**：最终回答包含明确的网页来源，增强可信度
- **热重载开发体验**：支持前后端热更新
- **结构化搜索循环**：Search → Reflect → Gap Detection → Search Again → Synthesize

**豆包可借鉴**：
1. 反思循环 — 豆包回答问题后应自我检查是否完整准确
2. 知识缺口检测 — 发现不足时主动补充搜索
3. 引用溯源 — 信息来源可追溯
4. 结构化推理图 — LangGraph的图结构推理可提升复杂问题处理能力
