## 一、Claude Code 51万行源码泄露深度分析

### 1.1 事件背景
- **时间**：2026年3月31日
- **原因**：npm包误含source map文件，泄露51万行TypeScript源码
- **发现者**：安全研究员Chaofan Shao

### 1.2 五层架构全貌

| 层级 | 代码量 | 核心功能 | 关键技术 |
|------|--------|---------|---------|
| 入口层 | ~8,000行 | CLI/IDE/API多端路由 | Node.js + Bun/Zig |
| 运行层 | ~12,000行 | TAOR循环状态机 | Think-Act-Observe-Repeat |
| 引擎层 | ~46,000行 | 动态提示词组装 | 数百个提示碎片动态拼装 |
| 工具层 | ~15,000行 | 40个隔离能力单元 | 文件/Bash/浏览器/搜索/Git |
| 基础设施层 | ~10,000行 | 缓存断点+Worktree | 14个断点+Git Worktree |

### 1.3 安全机制三件套

| 机制 | 描述 | 目的 |
|------|------|------|
| 卧底模式 | 非内部仓库剥离AI标识，匿名贡献 | 防止代码被标记为AI生成 |
| 反蒸馏机制 | 注入假工具定义+加密签名摘要 | 防止API流量蒸馏学习 |
| 原生认证 | Bun/Zig层计算哈希，JS层无法绕过 | 强制身份验证，关闭遥测也生效 |

### 1.4 泄露影响
- 韩国开发者24小时完成Python重写版claw-code，获5万GitHub star
- 硬编码Token、44个未发布功能flag及内部模型代号暴露
- 分析师认为真正护城河在模型权重/训练数据/对抗测试积累

### 1.5 技术关键词
- TAOR循环（Think-Act-Observe-Repeat）
- Plan Mode + Coordinator Mode
- Agent Teams辩论模式
- 14个缓存断点（Checkpoint）
- Git Worktree多Agent隔离
- 动态提示词碎片组装（Fragment Assembly）
