## 二、核心收获

### 2.1 子代理 (Subagents) 最佳实践
| 要点 | 详情 |
|------|------|
| 上下文隔离 | 每个子代理独立上下文窗口，主Agent只接收精炼结果 |
| 委派标准 | 可独立完成 + 结果可验证 + 值得开销 |
| 精准回报 | 子代理只返回关键信息，不返回完整执行过程 |
| Skills协同 | Skills注入自定义子代理实现专家级任务委派 |

### 2.2 Claude Code 五大定制手段
```
CLAUDE.md → Subagents → Skills → MCP Servers → Hooks
```
- **CLAUDE.md**：项目级记忆，跨会话保持约定
- **Subagents**：隔离上下文执行专项任务
- **Skills**：可复用Markdown指令，自动触发
- **MCP Servers**：连接外部系统（Tools/Resources/Prompts三层）
- **Hooks**：确定性检查点（PreToolUse/PostToolUse/PreMessage/PostMessage）

### 2.3 MCP 三层架构
| 原语 | 功能 | 示例 |
|------|------|------|
| Tools | 执行操作 | 函数调用、API请求 |
| Resources | 读取数据 | 文件、数据库、API |
| Prompts | 预构建指令 | 模板化交互 |

### 2.4 Agent 设计模式
- **确定性工作流**：步骤固定、结果可预测
- **灵活Agent系统**：自主决策复杂任务
- **并行 vs 链式**：根据任务依赖关系选择
- **条件路由**：基于中间结果动态决策
