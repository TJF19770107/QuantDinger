### 4.1 自主编码Agent四组件架构（Cadence 2026）

```
┌─────────────────────────────────────────────────┐
│           Autonomous Coding Agent Loop           │
│                                                  │
│  INGEST → PLAN → ACT → OBSERVE → REFLECT       │
│    ↓                                    ↓        │
│  DECIDE → VERIFY → SUBMIT (PR)          │        │
│       ↑_________________________________|        │
│                                                  │
│  + Tool Layer: fs / shell / git / browser        │
│  + Eval Harness: SWE-bench Verified + Internal   │
│  + Human-in-the-Loop Boundary                    │
└─────────────────────────────────────────────────┘
```

**五大架构决策**（决定SWE-bench 20分差距）:
1. Retrieval: BM25+Embedding+Code Graph > Naive RAG
2. Action Surface: CodeAct (Python执行) > JSON tool calling
3. Verification: 每次变更后验证 > 仅结尾验证（16分差距）
4. Memory & Scope: 小工作内存+一次性子Agent > 全仓库进上下文
5. Stopping Condition: 测试通过+Diff够小+可总结 > 仅测试通过
