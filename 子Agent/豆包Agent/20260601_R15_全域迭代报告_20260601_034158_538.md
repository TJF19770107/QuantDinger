## 三、R15 新增技能协议（3项）

### 协议53：Windows桌面视觉操控协议 v1.0

- **对标来源**：Codex Windows Computer Use + Locked Computer Use + AppShots
- **核心价值**：将桌面视觉操控能力从单一平台扩展至 Windows 全生态，支持锁屏后台运行、截图上下文注入、键鼠语义模拟
- **关键设计**：
  - 三层桌面操控：前景视觉操控（Screenshot→Perceive→Act）+ 锁屏后台操控（Locked Mode）+ 快照注入（AppShots）
  - Windows 平台适配：PowerShell/WSL2/Windows Sandbox 原生集成
  - 安全边界：锁屏模式仅限活跃可信回合解锁；检测本地输入自动重锁
- **文件**：[龙虾-Windows桌面视觉操控协议v1.0.md](E:\龙虾AI主控中心\我的AI分身\技能库\龙虾-Windows桌面视觉操控协议v1.0.md)

### 协议54：JS脚本百级并行子Agent调度协议 v1.0

- **对标来源**：Claude Dynamic Workflows + Antigravity 2.0 93-Agent 协作
- **核心价值**：将任务编排逻辑外置为 JS 脚本，上下文仅保留最终答案；支持百级并行子 Agent + DAG 拓扑分解 + 脚本变量中间存储
- **关键设计**：
  - 脚本化编排：用户描述任务→Agent 编写 JS 编排脚本→运行时后台执行→上下文仅保留最终答案
  - 并发模型：单次 16 并行，总数上限 1000；中间结果存脚本变量不污染上下文
  - 断点续传：子 Agent 失败自动重建+状态恢复
- **文件**：[龙虾-JS脚本百级并行子Agent调度协议v1.0.md](E:\龙虾AI主控中心\我的AI分身\技能库\龙虾-JS脚本百级并行子Agent调度协议v1.0.md)

### 协议55：Mermaid无限画布记忆压缩协议 v1.0

- **对标来源**：TencentDB Agent Memory 上下文卸载 + Mermaid 结构化图表示
- **核心价值**：通过外部文件系统卸载+Mermaid 结构化图将长任务过程压缩为可导航记忆，节省 61% Token，超长 Session 通过率 +52%
- **关键设计**：
  - 双存储：完整信息→外部文件系统；关键状态→Mermaid 流程图（高密度上下文）
  - 分层索引：Palace/Wing/Room/Drawer 四层记忆架构
  - 自动触发：Token 阈值触发卸载；空闲时触发记忆策展
- **文件**：[龙虾-Mermaid无限画布记忆压缩协议v1.0.md](E:\龙虾AI主控中心\我的AI分身\技能库\龙虾-Mermaid无限画布记忆压缩协议v1.0.md)
