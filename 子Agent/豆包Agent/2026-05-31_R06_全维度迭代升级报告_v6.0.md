## 三、本轮能力注入：7大系统精华提取

### 3.1 Codex `/goal` → 豆包「持久目标引擎」

**Codex策略**：`/goal` 将目标持久化到数据库，Agent持续追踪直到完成/暂停/预算耗尽/卡住。

**豆包注入方案**：
```
持久目标引擎 (PersistentGoalEngine)
├── GoalStore (SQLite) → 目标持久化
├── ProgressTracker → 进度实时追踪
├── BudgetManager → Token/时间预算管理
├── StallDetector → 卡住检测与自动恢复
└── HandoffProtocol → 跨轮次上下文传递
```

### 3.2 Hermes Kanban → 豆包「任务看板系统」

**Hermes策略**：SQLite持久化 + 原子认领 + 崩溃恢复 + 熔断

**豆包注入方案**：
```
任务看板系统 (KanbanTaskBoard)
├── TaskQueue (SQLite) → todo/ready/active/done/blocked
├── AtomicClaim → 多Agent竞争认领
├── Watchdog → 进程存活检测 → 自动回收
├── CircuitBreaker → 3次失败熔断
├── DependencyGraph → 父子任务依赖
└── WebSocket Dashboard → 实时状态推送
```

### 3.3 Claude Checkpoints → 豆包「检查点快照」

**Claude策略**：自主运行检查点，崩溃后从快照恢复。

**豆包注入方案**：
```
检查点快照系统 (CheckpointSnapshot)
├── SnapshotEngine → 上下文快照（每N步自动保存）
├── CrashRecovery → 崩溃检测 → 自动恢复
├── DiffTracker → 代码变更追踪
├── Rollback → 一键回滚到任意检查点
└── SnapshotGC → 过期快照清理
```

### 3.4 OpenClaw ACP → 豆包「Agent通信协议」

**OpenClaw策略**：ACP (Agent Communication Protocol) 标准化跨平台协作。

**豆包注入方案**：
```
Agent通信协议 (Doubao-ACP)
├── MessageBus → 发布/订阅消息总线
├── CapabilityDiscovery → Agent能力自动发现
├── TaskDelegation → 标准化任务委托格式
├── Heartbeat → Agent存活检测
└── ProtocolBuffer → 高效序列化
```

### 3.5 OpenCode LSP → 豆包「代码智能感知」

**OpenCode策略**：自动加载LSP，为LLM提供代码智能感知。

**豆包注入方案**：
```
代码智能感知 (CodeIntelligence)
├── LSPLoader → 按语言自动加载LSP
├── SymbolIndex → 符号索引与跳转
├── DiagnosticCollector → 编译/语法错误收集
├── ReferenceFinder → 引用查找
└── CodeContextBuilder → 智能上下文构建
```

### 3.6 Evolver + HyperAgents → 豆包「自进化3.0」

**Evolver策略**：GEP基因组演化协议（基因+胶囊+SHA-256内容寻址）

│   └── GenomeAssembler → 基因/胶囊组合生成

│   ├── PerformanceObserver → 执行质量监控
