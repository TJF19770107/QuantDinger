### 4.1 协议78：长时域Goal任务推进协议 v1.0

```
来源：Codex Goal Mode (GA, 2026-05-21)
覆盖：Codex App + IDE Extension + CLI

七要素：
1. Goal定义：可验证的持续目标（含验收条件）
2. 进度持久化：专用存储记录进度状态
3. 自动规划：Agent自主判断下一步+何时完成
4. 中途补充：可随时追加约束/调整方向
5. 跨会话持续：数小时/数天跨会话推进
6. 验收自检：完成后自验证是否满足验收条件
7. 预算软停止：Token/时间预算预警机制

对标豆包：已有Goal追踪（协议11）+ 心跳调度（协议40），
需升级为持久化进度存储 + 验收条件自检闭环。
```

### 4.2 协议79：Appshots上下文快照注入协议 v1.0

```
来源：Codex Appshots (macOS, 2026-05-21)

核心机制：
- 快捷键截图+可获取文本，一键发送Agent
- 替代手动复制报错/描述页面状态/整理上下文
- CLI可读取线程中已有Appshot

安全约束：
- 敏感页面（密码/支付/个人数据）慎用
- 截图和文本均进入Agent上下文，不可撤回
- 建议结合权限profiles控制可截取应用范围

对标豆包：已有桌面视觉操控（协议53/72），
需增加快捷键截图+文本提取+一键注入Agent上下文的快捷通道。
```

### 4.3 协议80：Python架构优先Agent开发协议 v1.0

```
来源：Hermes Python击败Codex Rust (2026-05-27)

核心主张：
- Agent赛道：架构决策 > 语言原始速度
- Python优势：可编辑 + 实时迭代 + 社区贡献
- Rust劣势：编译壁垒 + 迭代慢 + 贡献门槛高

五大优先原则：
1. 可编辑性优先：Agent框架必须支持热修改
2. 迭代速度优先：开发→测试→部署循环≤分钟级
3. 社区友好优先：降低贡献门槛，利用开源加速
4. 性能定位：LLM延迟主导，框架开销优化有上限
5. 架构进化优先：CLL闭环学习 > 语言级性能优化

对标豆包：已有Python执行环境，但需强化：
- 技能协议热加载（无需重启Agent）
- 自进化代码热替换
- 社区技能贡献流水线
```
