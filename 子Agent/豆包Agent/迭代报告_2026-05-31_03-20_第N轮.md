### 1.2 MCP / A2A / ACP 三层协议栈 (2026标准)

```
ACP（顶层）：长周期多Agent工作流、持久状态、监督与审计
├── A2A（中层）：Agent间调用、Agent Card发现、任务原语
└── MCP（底层）：Host-to-Tool调用、能力协商、OAuth 2.1
```

关键结论：三者不竞争，分层互补。企业级实践路径：先MCP封装内部API → 逐步添加A2A端点 → 仅在需要持久化工作流时引入ACP。

### 1.3 Hermes自进化闭环四大组件

1. **技能自创建**：复杂任务完成后自动提取工作流 → 固化为Skill文件（Markdown + 变量模板）
2. **技能自改进**：使用中评估效果 → 持续优化（GEPA算法驱动）
3. **周期性记忆推送（Nudge）**：每15轮对话强制反思提炼
4. **跨Session检索**：FTS5全文索引 + LLM摘要，无需向量数据库

### 1.4 GEPA进化算法

- 全称：Genetic-Pareto Prompt Evolution
- 来源：UC Berkeley × Stanford 联合开发
- 优势：训练效率比GRPO高35倍以上，无需GPU，纯API调用
- 机制：反思性变异 → 帕累托前沿选择 → 自然语言反馈 → PR审查合并
