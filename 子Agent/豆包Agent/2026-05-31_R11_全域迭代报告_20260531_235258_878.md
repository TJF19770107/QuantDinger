## 三、协议详情

### 协议46：Codex Agent全栈闭环协议 v1.0

**对标**：Codex 2026年5月重大更新

**五大能力闭环**：
1. **Computer Use**：视觉识别→点击→输入，多Agent并行互不干扰（macOS首发）
2. **内置浏览器**：页面标注→精准操作指令→前端/游戏开发核心
3. **记忆功能**：记住偏好/修正/费时信息→加速后续任务
4. **自动化增强**：线程复用+上下文保留+跨天/周自主唤醒
5. **主动建议引擎**：项目背景+插件+记忆→主动推送下一步行动

**豆包融合方案**：
- 将协议33（视觉桌面操控）升级为并行多Agent不干扰模式
- 新增主动建议模块：绑定豆包Agent上下文→记忆→任务历史→推送下一步
- 插件生态参照Codex 90+插件扩展路线

### 协议49：Context Bleeding检测防护协议 v1.0

**对标**：Mason AI Lab 2026多Agent编排实践

**三层检测信号**：
1. Subagent答非所问（偏离任务域）
2. Token消耗异常爆量（上下文污染）
3. 多个Agent结果不一致（信息串扰）

**四层防护**：
1. Context Isolation：子Agent独立上下文窗口
2. Scoped Prompt：任务域限定注入
3. Structured Summary：结构化摘要替代原始上下文传递
4. Context Window限制：硬性窗口上限防膨胀

**豆包融合方案**：
- 多Agent协作场景自动启用检测SOP
- 异常信号触发自动隔离+重试
- 集成到协议42（Swarm拓扑调度）的质量保障层
