## 三、R13 新增技能协议（5项）

### 协议51：金字塔式Agent-as-Tool分解协议 v1.0

- **对标来源**：InfiAgent (ICLR 2026)
- **核心机制**：
  - DAG金字塔拓扑 + Router顶层重定向
  - Agent-as-Tool：每个高层Agent将低层Agent视为工具调用
  - 分支因子约束 K_max=5，确保单Agent协调复杂度有界
  - 四层上下文结构：系统提示/长期记忆索引/短期共享内存/压缩环境交互
  - 三层自演化：模型级(Git风格merge) → Agent级(持续训练) → 拓扑级(DAG动态重构)
- **豆包Agent适配**：将dispatch_task升级为支持金字塔式agent-as-tool调用链，高层Agent自动识别子Agent并路由

### 协议52：持久化看板多Agent编排协议 v1.0

- **对标来源**：Hermes SWARM v2.1 Kanban TaskBoard
- **核心机制**：
  - SQLite驱动的持久化任务看板，跨会话状态保持
  - CAS并发控制 + Board隔离 + 熔断保护
  - 任务状态机：triage → in_progress → review → done
  - Workspace策略：Scratch/Dir/Worktree三种隔离级别
  - 三种交互入口：CLI / Web Dashboard / Agent Tools
- **豆包Agent适配**：为多Agent协作引入持久化任务状态表，支持跨dispatch_task调用链的状态追踪与异常恢复

### 协议53：双层自改进闭环协议 v1.0

- **对标来源**：Hexo Labs SIA + Autogenesis AGP SEPL
- **核心机制**：
  - 双层自改进：Harness层（行为逻辑） + 模型层（权重微调）
  - Core Loop：任务→Harness→模型推理→结果评估→Harness修改→权重微调→再部署
  - SEPL闭环：Propose(提出改进) → Evaluate(评估有效性) → Commit(提交变更)
  - 可审计血缘追溯 + 版本化回滚
- **豆包Agent适配**：升级自进化闭环，从仅修改提示词/记忆schema扩展至可修改路由逻辑与调用编排

### 协议54：超大规模并行子Agent调度协议 v1.0

- **对标来源**：Antigravity 2.0 (93子Agent并行构建OS)
- **核心机制**：
  - 主Agent动态生成专用子Agent，自动分解任务并并行执行
  - 异步任务管理 + 后台调度（Cron/定时触发）
  - 上下文隔离：子Agent独立上下文窗口，避免主Agent污染
  - 动态工作流：Agent A→B→C 链式传递，支持条件分支
  - 成本控制：100子Agent级别任务成本<$1000
- **豆包Agent适配**：dispatch_task 支持批量并行派发（当前单次调用），引入子Agent上下文隔离与异步回调汇总

### 协议55：知识库MCP原生接入协议 v1.0

- **对标来源**：Obsidian+MCP + Claude Code Files MCP
- **核心机制**：
  - MCP Server注册本地知识库目录为可读取资源
  - Markdown原生格式：Agent直接搜索、读取、交叉引用、综合
  - 四类场景：研究综合 / 写作辅助 / 决策支持 / 学习路线
  - 描述性文件名 + 结构化笔记优化AI可读性
- **豆包Agent适配**：File Agent 升级支持 Obsidian 知识库目录的 MCP 协议接入，实现跨笔记智能检索与知识综合
