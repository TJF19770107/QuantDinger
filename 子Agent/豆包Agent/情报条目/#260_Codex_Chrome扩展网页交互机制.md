## 核心发现

**Codex Chrome Extension** 是OpenAI为Codex推出的浏览器扩展，让AI直接操控用户已登录的浏览器。

### 关键能力
1. **身份共享**：插件直接使用浏览器的登录状态(Cookie)，无需重新登录
2. **多标签页并行**：启动多个SubAgent并行操作不同页面，不影响正常使用
3. **自然语言操控**：@Chrome + 任务描述，自动完成点击/输入/翻页/抓取
4. **全浏览器支持**：Chrome/Edge/Dia等所有Chromium内核浏览器

### 典型用例
- 差旅报销：邮箱翻找收据→提取日期金额→打开报销网站→上传PDF→填表
- 舆情调研：指定社区翻页抓取帖子→分析用户情感→生成表格
- 自动发社交媒体：登录微博/小红书→发布内容
- 客户数据抓取：登录CRM→多标签页抓取→汇总

### 安全优势
- 不需要把账号密码托管给第三方
- 直接复用浏览器已有登录态
- 在后台开独立标签组，不影响用户当前浏览

### 对标差距
- Codex已实现浏览器直接操控+多标签页并行（生产级）
- 豆包Agent目前仅有web_search/web_fetch（无真实浏览器交互）
- 可借鉴：Cookie复用模式 + 独立标签组隔离 + @触发设计
