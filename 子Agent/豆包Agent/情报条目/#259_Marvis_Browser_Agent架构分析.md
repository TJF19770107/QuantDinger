## 核心发现

**Marvis Browser Agent 定位**：1+5智能体中作为"网页交互专员"，专注于需要多步交互的网页场景。

### 职责边界
- **与Search Agent的区别**：Search Agent负责"搜索并总结"，Browser Agent负责"在网页上执行操作"
- **适用场景**：需要登录认证、多步表单填写、多页跳转数据提取、网页按钮点击、下拉选择
- **不适用场景**：简单网页内容抓取（由Search Agent+web_fetch完成）

### 技术栈
- 浏览器接管 + DOM解析
- 自动处理弹窗关闭、Cookie提示等常见障碍
- 遇到登录墙或验证码时提示用户介入
- GUI视觉识别+模拟操作

### 安全架构
- L2级安全兜底机制
- 敏感操作强制用户确认
- 涉及隐私/安全/支付时交回用户控制权

### 对标差距
- Marvis Browser Agent已产品化运行在Windows/Mac/Android
- 豆包Agent目前缺少该能力，浏览器搜索维度82分（-18%）
- 对标可借鉴：DOM解析 + 浏览器接管 + 用户介入断点设计
