## 一、L2市场深度核心概念

### 1.1 L2 vs L1 vs Tick

| 数据层级 | 包含信息 | 样本频率 | 应用场景 |
|---------|---------|---------|---------|
| **L1（Level 1）** | 最新价、买一价、卖一价、成交量 | 实时 | 基本价格观察 |
| **L2（Level 2）** | 五档/十档买卖挂单（所有可见挂单） | 每次变化 | 深度市场分析 |
| **Tick（逐笔）** | 每一笔实际成交的价、量、方向 | 每笔成交 | 微观订单流分析 |
| **Time & Sales** | 成交流：时间、价格、数量、买卖方向 | 每笔成交 | 速度分析 |

### 1.2 订单流分析核心框架

```
L2 订单簿（挂单意图） + Time & Sales（已成交动作）
            ↕ 交叉验证
      真实市场动态画像

确认框架四步法：
1. 在L2上识别显著深度位置
2. 查看Time & Sales上该价位的块单成交（股票≥1000股/期货≥10手）
3. 监控大单是否吸收卖压/买压而价格不突破
4. 在3笔以上确认后，沿吸收方向入场

该框架在确认信号上可达63-67%胜率，而仅靠L2信号只有52-55%。
```

## 二、订单流足迹图（Footprint Chart）

### 2.1 核心概念

订单流足迹图将L2和Time & Sales数据合并到单一可视化图表中：

```
每个K线蜡烛精确显示：
┌────────────────────┐
│ 买量 | 价格 | 卖量 │
│ 500  | 12.58| 1200 │  ← 卖方主导（红色/Delta负）
│ 800  | 12.57| 900  │  ← 接近平衡（灰色）
│ 1500 | 12.56| 600  │  ← 买方主导（蓝色/Delta正）
└────────────────────┘
```

### 2.2 Delta足迹图

| 指标 | 计算 | 解读 |
|------|------|------|
| **Delta** | 主动买量 - 主动卖量 | + = 买方主导，- = 卖方主导 |
| **Cumulative Delta** | 时间段内Delta累加 | 趋势强度确认 |
| **Delta Divergence** | 价格新高但Delta萎缩 | 趋势衰竭信号 |
| **Volume Imbalance** | 单一价格买卖比≥3:1 | 主力挂单信号 |

## 三、订单流核心信号

### 3.1 三大核心信号

#### 信号1：吸收（Absorption）

| 特征 | 含义 | 交易意义 |
|------|------|---------|
| 大量挂单在某一价位被持续吞噬 | 主力在此价位积极成交 | **反转/突破前兆** |
| 价格不穿过该价位 | 强支撑/阻力确认 | 可考虑反向建仓 |
| 成交量远超平均水平 | 机构建仓/出货 | 跟随主力方向 |

```
示例：
卖盘挂10万手在12.58，买方持续吃掉这些卖单
但价格始终没有跌破12.58
→ 买方在吸收卖方压力，价格即将向上突破
→ 信号：BUY @ 12.58，止损 12.55
```

#### 信号2：堆积/撤单（Stacking/Pulling）

| 特征 | 含义 | 交易意义 |
|------|------|---------|
| 某一价位突然出现巨量挂单 | 主力展示意图 | **假突破预警** |
| 挂单在成交前被撤回 | 假挂单（Spoofing） | 反向操作 |
| 挂单被真实成交 | 真实意图 | 跟随方向 |

#### 信号3：失衡（Imbalance）

| 特征 | 含义 | 交易意义 |
|------|------|---------|
| 某价位买/卖量严重失衡（≥3:1） | 短期方向明确 | **顺势入场** |
| 持续性失衡 | 趋势强劲 | 加仓 |
| 失衡被快速填平 | 假方向 | 警惕逆转 |

### 3.2 进阶信号组合

```python
# 信号组合框架
SIGNAL_COMBOS = {
    "强买入": ["吸收买方", "Delta由负转正", "失衡买方≥3:1"],
    "强卖出": ["吸收卖方", "Delta由正转负", "失衡卖方≥3:1"],
    "假突破": ["堆积后撤单", "失衡快速填平", "价格回落原区间"],
    "趋势加速": ["连续失衡", "Cumulative Delta递增", "成交量递增"]
}
```

## 四、不同资产类别的L2差异

### 4.1 股票L2

| 特点 | 说明 | 交易建议 |
|------|------|---------|
| 多交易所挂单 | NYSE/NASDAQ/ARCA等 | 关注跨交易所大单 |
| 暗池交易 | 不显示在L2 | 大单消失可能是暗池 |
| 做市商义务 | 提供流动性 | 识别做市商假单 |

### 4.2 期货L2

| 特点 | 说明 | 交易建议 |
|------|------|---------|
| 中央限价订单簿（CLOB） | 单一订单簿，真实透明 | 信号更可靠 |
| 高频交易占比高 | 70%+成交量 | 关注微秒级速度 |
| 合约到期日效应 | 到期日L2异常 | 到期前降低仓位 |

### 4.3 A股L2特殊规则

| 特点 | 说明 | 对订单流分析的影响 |
|------|------|-------------------|
| T+1制度 | 当天买不能当天卖 | 日内信号需要T+0标的（ETF/可转债） |
| 涨跌停限制 | ±10%（主板） | 涨跌停时L2分析失效 |
| 集合竞价 | 9:15-9:25 | 集合竞价期间的虚假挂单 |
| Level-2收费 | 需购买Level-2行情 | 增加成本 |

## 五、订单流分析在量化策略中的应用

### 5.1 策略增强方向

| 策略类型 | L2增强点 | 提升效果 |
|---------|---------|---------|
| **趋势跟踪** | Delta确认趋势方向 | 减少假突破进场 |
| **均值回归** | 吸收信号确认支撑/阻力 | 提高反转准确率 |
| **突破交易** | 失衡判断真假突破 | 降低假突破损失 |
| **高频做市** | 订单簿不平衡做报价 | 提高利润因子 |
| **跨市场套利** | L2价差异常检测 | 提前发现套利机会 |

### 5.2 风控增强

| 风控维度 | 传统方法 | L2增强方法 | 效果 |
|---------|---------|-----------|------|
| **流动性风险** | 日成交量 | 实时L2深度 | 提前15秒预警 |
| **滑点控制** | 固定滑点假设 | 实时盘口深度估算 | 准确率+30% |
| **闪崩预警** | 价格波动率 | L2挂单急剧变化 | 提前5-10秒 |
| **主力出货检测** | 成交量放大 | 吸收卖方+价格不跌 | 关键反转信号 |
