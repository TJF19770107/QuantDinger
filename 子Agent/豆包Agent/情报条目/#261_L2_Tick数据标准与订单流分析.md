## 核心发现

### L2逐笔数据标准
- Level-2数据为沪深交易所高频精细化行情，区别Level-1（仅五档盘口、每3秒更新）
- L2包含：逐笔成交（毫秒级）、逐笔委托、十档盘口
- 时间精度达毫秒级，记录每一笔交易的原始细节

### 前沿因子方法论

**广发金工高频知情交易因子**（2026-05-14发布）：
- VPIN因子族：VPIN_vol(IC=10.05%) / VPIN_amt(IC=9.2%) / VPIN_cnt(IC=8.5%)
- DPIN因子族：36个因子（3行为特征×4时间特征×3统计特征），月度RankIC>8%
- VPIN_vol多头年化16.53%，相对中证全指超额8.72%

**国信证券/北大金工首席订单流Alpha**（2026-05-19讲座）：
- 订单口径（同委买/委卖ID成交量加总）捕捉机构行为
- 大单属性 + 漫长属性（Duration）交叉形成16种微观类型
- 纯净因子（正交剥离常见因子后）仍具稳健超额

### 数据接入
- QMT/MiniQMT：免费实时L2数据（券商端）
- Tushare Pro：付费API，支持历史回测
- 东方财富L2：免费3秒延迟

### 关键学术进展
- 传统PIN→VPIN→DPIN模型演进
- 微观结构因子：订单不平衡、成交量毒性VPIN、订单簿斜率
- 事件驱动：大单吞没、撤单潮模式捕捉
