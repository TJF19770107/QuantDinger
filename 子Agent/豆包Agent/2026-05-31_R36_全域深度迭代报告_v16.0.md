## 三、全网情报深度洞察

### 3.1 Claude Cowork：文件系统Agent新范式

2026年1月发布的Claude Cowork证明：Agent不需要full desktop control，只需文件夹级授权就能完成绝大多数知识工作任务。架构三层：
- **沙盒化执行引擎**：macOS App Sandbox，仅获授权文件夹访问
- **连接器中间件**：OAuth 2.0 + IPFS内容寻址，云端→本地VFS映射
- **Agent SDK任务编排**：自然语言→可序列化任务图(Task Graph)

对豆包Agent启示：桌面控制不需要full权限，文件夹级沙盒+授权模型更安全且足够。

### 3.2 Auto Skills技术全景（2023-2026）

| 阶段 | 代表工作 | 核心贡献 |
|------|---------|---------|
| 学术奠基(2023) | Voyager | Minecraft中首次验证Agent自主构建技能库 |
| 工具扩展(2024) | ToolLLM, LATM | 真实API工具的自助学习与使用 |
| 真实世界(2025) | ATLASS, Alita, Agent0 | 从游戏走向真实任务 |
| 工程落地(2026) | Claude Code Skills, EvoAgentX, MetaClaw | 商业产品+开源框架成熟 |

四条技术路线：轨迹蒸馏(Voyager) → 程序合成(LATM) → 进化搜索(GEPA) → 元认知(HyperAgents)

### 3.3 Hermes Curator v0.12：自主技能管理闭环

七个核心机制：使用频率追踪、每周自动运行、跳过已Pin技能、智能合并、转模板、归档(不删除)、tar.gz快照回滚。

关键差异化：Hermes在执行轨迹上进化(GEPA)，而非依赖Agent自我评价（Agent倾向于自我表扬）。

### 3.4 Claude Managed Agents：三层解耦架构

```
Brain(推理) ←→ Hands(执行) ←→ Session(状态)
   无状态         按需启动      append-only日志
```

独立容错：Brain挂→从Session事件日志恢复→新Brain继续，用户无感。

### 3.5 OpenClaw五层Gateway架构

用户接口层 → Gateway核心层 → 消息处理层 → 扩展插件层 → 基础设施层

本质是Agent Runtime而非聊天机器人，消息→协议适配→路由分发→会话构建→Agent执行→响应投递→状态持久化全链路标准化。

### 3.6 自我进化Agent综述（arXiv 2026-05）

统一四组件框架：
- **系统输入**：任务、环境反馈、用户指令
- **Agent系统**：模型、提示词、记忆、工具、工作流、通信
- **环境**：交互空间
- **优化器**：进化算法、RL、元学习

六大组件均可自主进化：基础模型、提示词、记忆、工具、工作流、Agent间通信。
