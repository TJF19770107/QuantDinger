# 动态联动博弈规则

> **核心原则**：敌不动我不动，敌一动我必先动  
> **适用场景**：A股黑马股交易  
> **版本**：V1.0  
> **更新日期**：2026-06-03

---

## 一、博弈总纲

### 1.1 博弈核心理念

```
┌─────────────────────────────────────────────────────────────────┐
│                    双向动态博弈模型                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│    主力行为                      我的行为                         │
│    ┌──────────┐                ┌──────────┐                     │
│    │ 吸筹     │ ──观察等待──→  │ 空仓/观察 │                     │
│    │ 洗盘     │ ──识别确认──→  │ 试探建仓  │                     │
│    │ 拉升     │ ──跟随加仓──→  │ 重仓持有  │                     │
│    │ 震荡     │ ──灵活应对──→  │ 滚动操作  │                     │
│    │ 出货     │ ──识别离场──→  │ 清仓观望  │                     │
│    └──────────┘                └──────────┘                     │
│         ↑                          │                            │
│         └──────── 反馈学习 ────────┘                            │
│                                                                 │
│    核心不等式：                                                  │
│    我的反应速度 > 主力的动作速度 > 市场的消化速度                  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 先手原则

> **敌不动我不动**：主力没有明确动作时，保持现有仓位，不做预判性操作。  
> **敌一动我必先动**：主力动作信号一旦确认，必须在市场多数人反应过来之前完成调仓。

**先手的三个层次**：

| 层次 | 速度要求 | 操作内容 | 成功率 |
|------|----------|----------|--------|
| 第一层：同步 | 与主力同步 | 在主力动作发生后30秒-2分钟内响应 | 高 |
| 第二层：预判 | 提前30秒-2分钟 | 基于盘口异动预判主力意图 | 中 |
| 第三层：布局 | 提前数小时/数天 | 基于阶段判断提前布局 | 中低 |

**先手操作铁律**：
- 预判型操作仓位不超过总仓位的20%
- 同步型操作可使用全部计划仓位
- 预判失败立即止损，不扛单

## 三、跟踪-拆解-学习-迭代 四步循环

### 3.1 Step1：跟踪 —— 盘口异动监控指标体系

```
┌──────────────────────────────────────────────────────────────┐
│               盘口异动实时监控指标（共15项）                     │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【大单流向指标】                                              │
│  ① 大单净流入/流出：单笔 > 50万元的买卖方向差额                 │
│     - 连续3笔大单同向 → 主力明确动作                           │
│     - 大单净流入 > 500万/日 → 主力积极买入                     │
│                                                              │
│  ② 特大单占比：单笔 > 100万元的成交量占总成交量比例             │
│     - 占比 > 30% → 主力活跃                                   │
│     - 占比 > 50% → 主力主导                                   │
│                                                              │
│  【量比突变指标】                                              │
│  ③ 量比：当日成交量 / 前5日同时段均量                          │
│     - 量比 > 2 → 异动，关注原因                               │
│     - 量比 > 5 → 强烈异动，判断主力意图                        │
│                                                              │
│  ④ 集合竞价比：开盘集合竞价量 / 前5日均量                      │
│     - 竞价比 > 10% → 主力开盘有动作                            │
│                                                              │
│  【挂单异常指标】                                              │
│  ⑤ 买卖盘失衡度：|买盘总量 - 卖盘总量| / (买盘总量 + 卖盘总量)  │
│     - 失衡度 > 0.3 → 主力在某一方布局                          │
│                                                              │
│  ⑥ 挂单撤单率：1分钟内撤单次数 / 总挂单次数                    │
│     - 撤单率 > 20% → 主力在诱导                               │
│                                                              │
│  ⑦ 异常挂单：单档超过前5档总量50%的挂单                        │
│     - 出现异常挂单 → 主力在测试或诱导                          │
│                                                              │
│  【分时图异动指标】                                            │
│  ⑧ 分时走势独立性：个股分时与大盘分时的相关系数                 │
│     - 相关系数 < 0.3 → 主力独立运作                            │
│                                                              │
│  ⑨ 脉冲式涨跌：30秒内涨跌幅 > 1.5% → 主力动作                 │
│                                                              │
│  ⑩ 尾盘异动：14:45-15:00 区间涨跌幅 > 2%                     │
│     - 尾盘偷袭是主力惯用手法                                   │
│                                                              │
│  【综合判断指标】                                              │
│  ⑪ 异动得分 = Σ(各指标触发权重)                               │
│     - 得分 > 5：轻度异动，关注                                 │
│     - 得分 > 10：中度异动，准备操作                            │
│     - 得分 > 15：重度异动，立即行动                            │
└──────────────────────────────────────────────────────────────┘
```

## 四、先手原则实施细则

### 4.1 何时抢跑（预判型先手）

| 场景 | 抢跑条件 | 操作 | 仓位限制 | 止损 |
