# 可落地执行的迭代交易策略

> **策略代号**：龙虾博弈 Alpha V1.0  
> **核心框架**：多时间框架 + 主力博弈 + 动态仓位 + 持续迭代  
> **适用市场**：A股（主板/创业板/科创板）  
> **版本**：V1.0 | 更新日期：2026-06-03

## 一、策略总览

### 1.1 多时间框架体系

```
┌──────────────────────────────────────────────────────────────┐
│                  多时间框架决策体系                            │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   日线 ────→ 定方向（趋势判断）                               │
│   ├─ 判断：上升趋势 / 下降趋势 / 震荡                         │
│   ├─ 工具：均线(MA20/MA60/MA120)、MACD、ADX(>25有趋势)       │
│   └─ 输出：多头区域 / 空头区域 / 中性区域                     │
│                                                              │
│   60分钟 ──→ 定节奏（阶段判断）                               │
│   ├─ 判断：吸筹 / 洗盘 / 拉升 / 震荡 / 出货                  │
│   ├─ 工具：量价关系、筹码分布、K线形态                        │
│   └─ 输出：可操作 / 谨慎操作 / 不可操作                       │
│                                                              │
│   15分钟 ──→ 定点位（精确入场/离场）                          │
│   ├─ 判断：精确买卖点                                        │
│   ├─ 工具：分时图、盘口挂单、大单流向                         │
│   └─ 输出：具体价格和仓位                                     │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 1.2 策略决策层级

```
决策流程（自上而下，每层都通过才执行）：

  Layer 1: 大盘环境检查
  ├─ 上证/创业板是否在MA60上方？
  ├─ 市场情绪（涨跌比 > 1:1？）
  └─ 不通过 → 空仓或轻仓（≤10%）

  Layer 2: 板块强度检查
  ├─ 目标板块是否在涨幅前10？
  ├─ 板块内是否有龙头涨停？
  └─ 不通过 → 最多试探仓（≤5%）

  Layer 3: 个股阶段判断
  ├─ 当前处于主力操盘哪个阶段？
  ├─ 是否符合入场条件？
  └─ 不通过 → 不操作

  Layer 4: 精确入场/离场
  ├─ 15分钟级别信号确认
  ├─ 仓位计算
  └─ 执行
```

## 二、入场规则

### 2.1 吸筹末期突破入场法

```
策略名称：吸筹末期突破入场法（Breakout-Entry）
适用阶段：主力吸筹末期，即将进入拉升阶段

【量化入场条件】（必须同时满足以下6项）：

  ☑ 条件1：横盘整理时间 ≥ 20个交易日
     - 计算方式：统计过去的交易日，区间内最高价/最低价 ≤ 1.25
  
  ☑ 条件2：地量确认
     - 最近5日平均换手率 ≤ 吸筹期间日均换手率的40%
     - 或：最近5日平均成交量 ≤ 吸筹区间日均成交量的35%
  
  ☑ 条件3：均线状态
     - MA5、MA10、MA20 三条均线中至少2条已经走平或向上
     - MA5与MA20之间的距离 ≤ 价格的3%（均线粘合）
  
  ☑ 条件4：突破信号
     - 当日收盘价突破横盘区间最高价的101.5%（至少1.5%的有效突破）
     - 或：盘中突破后回踩不破，收盘站稳突破位上方
  
  ☑ 条件5：放量确认
     - 突破当日成交量 ≥ 前20日均成交量的1.5倍
     - 且：突破当日换手率在 3%-10% 之间（不在极端范围）
  
  ☑ 条件6：大盘配合
     - 大盘（上证指数）当日收盘不得跌幅 > 1%
     - 大盘不在明显的下降趋势中（MA20不向下）

【仓位计算】：
  初始仓位 = 账户总资金 × 20%
  若突破后第2日继续收阳 + 放量 → 加仓至 30%
  若突破后第3日仍站稳突破位 → 加仓至 50%

【止损设置】：
  止损价 = 突破日最低价 × 0.97（3%止损空间）
  或 = 横盘区间下轨（取较高者）
```

### 2.2 洗盘结束反转入场法

```
策略名称：洗盘结束反转入场法（Washout-Reversal）
适用阶段：主力洗盘末期，即将恢复上升趋势

【量化入场条件】（必须同时满足以下5项）：

  ☑ 条件1：洗盘确认
     - 前期有明确的拉升（涨幅 ≥ 15%）
     - 当前回调幅度在前期涨幅的 30%-62% 之间（斐波那契回调区间）
  
  ☑ 条件2：回调缩量
     - 回调期间最大日成交量 ≤ 前一波拉升期间最大日成交量的60%
     - 回调最后3天平均成交量 ≤ 前一波拉升期间日均成交量的50%
  
  ☑ 条件3：止跌信号
     - 出现以下至少一种K线形态：
       · 锤子线（下影线 ≥ 实体2倍）
       · 启明星（先阴后阳，阳线实体包住阴线50%以上）
       · 缩量十字星后跟放量阳线
     - 且：当日最低价未跌破前低
  
  ☑ 条件4：指标底背离
     - MACD：价格创回调新低但MACD柱未创新低
     - 或 RSI：价格新低但RSI未新低（底背离）
  
  ☑ 条件5：支撑确认
     - 价格在以下至少一个支撑位获得支撑：
       · MA20/MA60均线
       · 前期筹码密集区
       · 斐波那契50%或61.8%回调位
       · 前低支撑

【仓位计算】：
  初始仓位 = 账户总资金 × 15%
  若次日涨幅 > 2% + 放量 → 加仓至 30%
  若突破前高 → 加仓至 50%

【止损设置】：
  止损价 = 反转信号当日最低价 × 0.98（2%止损空间）
```

### 2.3 拉升途中回踩加仓法

```
策略名称：拉升途中回踩加仓法（Pullback-Add）
适用阶段：主力明确拉升中，出现短暂回调

【量化入场条件】（必须同时满足以下5项）：

  ☑ 条件1：趋势确认
     - 价格在MA20上方运行
     - MA5、MA10、MA20呈多头排列（MA5 > MA10 > MA20）
     - ADX指标 > 25 且 +DI > -DI
  
  ☑ 条件2：回踩幅度
     - 回踩至MA5或MA10均线附近（价格与均线距离 ≤ 2%）
     - 回踩幅度在最近一波涨幅的 20%-38.2% 之间
  
  ☑ 条件3：回踩缩量
     - 回踩日成交量 ≤ 前5日平均成交量的70%
     - 缩量回踩 = 主力未出货，只是正常回调
  
  ☑ 条件4：支撑有效
     - 回踩过程中盘中最低价未跌破MA10（或跌破后快速收回）
     - 分时图呈现"V型"反转或尾盘回升
  
  ☑ 条件5：大盘配合
     - 大盘当日不处于暴跌状态（跌幅 < 1.5%）
     - 所属板块当日不在跌幅前5

【仓位计算】：
  已有仓位：维持底仓（50-70%）
  加仓仓位：账户总资金 × 15-20%
  总仓位上限：80%（极限行情下不超过此值）

【止损设置】：
  加仓部分止损价 = 回踩日最低价 × 0.98（2%止损空间）
  底仓止损价 = MA20均线（跌破MA20减半仓）
```

## 三、离场规则

### 3.1 分批止盈策略

```
策略名称：主升浪三段式分批止盈
核心理念：让利润奔跑，但不让利润全部回吐

【三段式止盈结构】：

  持仓结构       止盈触发条件              止盈比例
  ─────────────────────────────────────────────────
  底仓(50%)      趋势破坏信号（见3.3）      全部
  滚动仓(30%)    MA10跌破 或 MACD死叉      分批
  机动仓(20%)    短线超买信号               每次反弹

【具体执行规则】：

  第1批止盈（机动仓20%）：
  - 触发条件（任一满足）：
    · 单日涨幅 > 7%（涨停板除外，涨停次日高开执行）
    · RSI(14) > 80
    · 连续3根阳线且第3根为长上影（上影>实体）
  - 止盈比例：机动仓的100%

  第2批止盈（滚动仓30%）：
  - 触发条件（任一满足）：
    · 收盘价跌破MA10
    · MACD出现死叉
    · 高位放量滞涨（连续2天换手>15%但价格不涨）
  - 止盈比例：滚动仓的50%-100%

  第3批止盈（底仓50%）：
  - 触发条件（见3.3主力出货信号强制离场规则）
  - 止盈比例：底仓100%
```

### 3.2 动态止损策略

```
策略名称：ATR动态移动止损

【止损基准计算】：

  ATR(14) = 最近14根K线的平均真实波幅
  
  初始止损距离 = ATR(14) × 1.5
  
  对于价格50元的股票，当ATR=2元时：
  初始止损距离 = 2 × 1.5 = 3元
  止损价 = 入场价 - 3元

【移动止损规则】：

  移动条件：价格向有利方向移动 ≥ ATR × 2
  
  移动方式：将止损价移至盈亏平衡点（入场价）
  → 之后：止损价 = max(前止损价, 当前价 - ATR × 2)
  
  示例：
  入场价50元，ATR=2元
  初始止损 = 47元
  价格涨到54元时（涨了4元 = 2×ATR）
  → 止损移至50元（保本止损）
  价格涨到58元时
  → 止损上移至54元（58 - 2×2）

【关键支撑移动止损】：
  除ATR止损外，止损价不能低于最近的显著支撑位：
  - 前期高点（突破后变成支撑）
  - MA20/MA60均线
  - 筹码密集区下沿
  止损价取 ATR止损价 和 关键支撑-1% 两者中的较高者
```

### 3.3 主力出货信号强制离场规则

```
强制离场触发条件（满足任意1项 → 清仓，不犹豫）：

  🔴 一级强制离场（立即清仓）：
  
  ☑ 高位放量长阴（单日跌幅 > 5% + 成交量 > 前5日均量2倍）
  ☑ 高位天量（换手率 > 25% + 价格冲高回落收阴）
  ☑ 跌停出货（高位跌停 + 盘中反复打开后封死）
  ☑ 破位信号（放量跌破MA20或关键支撑位）
  ☑ MACD高位死叉 + 放量确认
  
  🟡 二级强制减仓（减至30%以下）：
  
  ☑ 高位放量滞涨（连续3天换手 > 10% + 价格涨幅 < 1%）
  ☑ 连续3根长上影（盘中冲高后回落 > 3%）
  ☑ 利好频出但不涨（3条以上利好 + 价格微涨或微跌）
  ☑ 股东减持公告
  ☑ 单日换手率 > 15% + 收阴线

【执行铁律】：
  - 一级信号触发 → 5分钟内完成清仓
  - 二级信号触发 → 30分钟内完成减仓
  - 不允许"再等等看" → 这是最大亏损来源
```

## 四、仓位管理模型

### 4.1 初始仓位计算公式

```
基于凯利公式变形的仓位计算：

  基础仓位% = (胜率 × 平均盈利比 - (1-胜率)) / 平均盈利比 × 风险系数

  参数说明：
  - 胜率：基于历史回测的实际胜率（默认使用50%作为保守估计）
  - 平均盈利比：平均盈利 / 平均亏损（目标 ≥ 1.5）
  - 风险系数：0.25-0.50（凯利公式的分数应用，保守取0.25）

  示例计算：
  假设胜率=50%，平均盈利比=2.0，风险系数=0.30
  
  基础仓位% = (0.5 × 2.0 - 0.5) / 2.0 × 0.30
            = (1.0 - 0.5) / 2.0 × 0.30
            = 0.25 × 0.30
            = 7.5%
  
  这是初始单笔风险暴露，实际仓位 = 基础仓位% × 杠杆倍数

【简化版仓位计算公式（日常使用）】：

  单笔仓位% = 2% / 预估止损比例

  示例：
  - 止损设为3% → 单笔仓位 = 2% / 3% × 100 = 66.7%（含杠杆的总风险暴露）
  - 无损止损设为5% → 单笔仓位 = 2% / 5% × 100 = 40%
  
  规则：单笔理论最大亏损不超过账户的2%
```

### 4.2 加仓条件与比例

```
加仓金字塔模型：

  价格 →
    ↑
    │                        ▲ 第4次加仓 ×0.5份 (趋势极强)
    │                    ▲ 第3次加仓 ×1份 (突破前高)
    │                ▲ 第2次加仓 ×2份 (回调确认)
    │            ▲ 第1次加仓 ×2份 (突破确认)
    │        ▲ 初始仓位 ×3份 (突破入场)
    │    ▲ 试探仓位 ×1份 (提前布局)
    │
    └──────────────────────────────────────→ 时间

加仓条件：
  第1次加仓：突破日次日继续收阳 + 放量（量>前日80%）
  第2次加仓：回踩MA5/MA10获得支撑 + 缩量
  第3次加仓：突破前高 + 放量确认
  第4次加仓：趋势加速段 + ADX > 35 + 缩量上涨（极限行情）

加仓铁律：
  - 每次加仓必须设置独立止损
  - 加仓后整体仓位不超过80%
  - 前一笔加仓盈利后才允许下一次加仓
  - 加仓部分止损被触发 → 只平掉加仓部分，底仓不动
```

## 五、选品种过滤池

### 5.1 四层过滤模型

```
候选股票池 → [量能过滤] → [趋势过滤] → [筹码过滤] → [基本面过滤] → 交易标的

【量能过滤】
  条件：
  ① 近5日日均换手率 > 1%（排除僵尸股）
  ② 近5日日均成交量 > 5000万元（排除流动性差的品种）
  ③ 近20日出现过至少1次放量（量>均量1.5倍，说明有主力活动）

【趋势过滤】
  条件：
  ① 收盘价 > MA20（中期趋势向上）
  ② MA20 > MA60 或 MA20走平即将上穿MA60
  ③ ADX > 20（趋势存在，不是随机游走）
  ④ 近20个交易日涨幅在 -10% 到 +30% 之间（排除暴涨暴跌）

【筹码过滤】
  条件：
  ① 筹码集中度（90%筹码区间 / 当前价） < 30%
  ② 低位筹码锁定良好（底部筹码峰 > 30%且未显著上移）
  ③ 获利盘比例 < 80%（排除获利盘过多的跟风风险）

【基本面过滤】
  条件：
  ① 非ST、非*ST、非退市整理期
  ② 流通市值在 20亿-500亿 之间（太小易被操纵，太大难拉升）
  ③ 近1个月无重大利空（立案调查/大额减持/业绩暴雷等）
  ④ 近1个月无大额解禁（解禁量 < 流通盘的5%）
```

### 5.2 过滤结果分级

```
过滤通过率 → 标的池分级：

  全部通过(4/4) → ★★★ 核心标的池 → 重点交易
  通过3/4    → ★★  候选标的池 → 可交易，仓位降低20%
  通过2/4    → ★   观察标的池 → 仅限试探仓(≤5%)
  通过<2/4   → 排除
  
  每日开盘前更新一次过滤结果
```

## 六、每日交易流程SOP

### 6.1 盘前准备清单（8:30-9:00）
