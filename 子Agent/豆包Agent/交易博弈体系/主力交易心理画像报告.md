### 2.2 主力吃货手法库

#### 手法一：压单吸筹

```
盘口特征：
  卖一：5000手 (压单)
  卖二：3000手
  卖三：2000手
  ─────────────────
  买一：200手 (散户卖单)
  买二：300手
  买三：500手

主力操作：在卖一挂大压单制造抛压假象 → 散户恐慌卖出
        → 主力用小单在买盘悄悄吃货 → 压单撤掉 → 重新挂上

识别信号：
- 大压单反复出现-消失-出现，但股价不跌
- 分时成交明细中反复出现"小单买入"
- 日线呈现缩量横盘或微涨
```

#### 手法二：跌停板吸筹

```
操作流程：
1. 利用利空消息或大盘大跌，将股价打至跌停
2. 跌停板上挂巨量卖单，制造恐慌
3. 散户跟风挂卖单
4. 主力撤掉自己的卖单，排在散户后面
5. 用另一个账户在跌停板上吸纳散户的筹码

风险信号：
- 跌停板反复打开 → 有人在吃货
- 跌停板封单突然变小 → 主力撤单
- 次日不创新低 → 昨日为诱空
```

#### 手法三：对倒吸筹

```
手法描述：主力用A账户卖给B账户，制造放量假象
目的：激活股性，吸引市场关注，为后续出货做铺垫

识别要点：
- 买卖盘口均有大单
- 成交价格在买卖之间（对倒价）
- 股价不涨或微涨（不是真拉升）
- 换手率突然放大但股价波动小
```

### 2.3 成本区间估算方法

```
主力成本估算公式：

  主力成本 ≈ (吸筹区间最高价 + 吸筹区间最低价 × 2 + 吸筹区间均价 × 3) / 6

简化版：
  主力成本 ≈ 吸筹箱体的2/3位置

举例：
  吸筹区间：10元-15元，箱体均价12.5元
  主力成本 ≈ (15 + 10×2 + 12.5×3) / 6 ≈ 12.08元

验证方法：
  - 吸筹末期的最低价不应持续跌破此成本
  - 拉升初期回踩不低于此成本的105%
```

### 2.4 隐蔽性特征总结

| 隐蔽手段 | 操作方式 | 暴露信号 |
|----------|----------|----------|
| 分仓操作 | 使用数百个账户分散持仓 | 股东户数持续减少但前十大股东不变 |
| 压单隐藏 | 大压单制造卖压假象 | 压单反复挂撤，股价不跌 |
| 尾盘偷袭 | 收盘前15分钟悄悄吸筹 | 尾盘成交量突增 |
| 借利空吸 | 利用利空消息制造恐慌 | 利空不跌或跌幅远小于合理值 |
| 对倒放量 | 自买自卖制造量能 | 放量不涨，盘口买卖均有大单 |

```
│ 最大跌幅       │ 10-15%          │ 20-30%          │ 5-8%     │

└───────────────┴─────────────────┴─────────────────┴─────────┘
```

### 3.2 洗盘深度与时长判断

```
洗盘结束的信号组合（需同时满足至少3项）：

  1. 成交量萎缩至极值（"地量"）：
     日成交量 < 吸筹阶段日均成交量的30%

  2. 价格波动收窄：
     连续3天日内振幅 < 2%

  3. 均线粘合：
     5日/10日/20日均线间距 < 1%

  4. KDJ/MACD底背离：
     价格新低但指标未新低

  5. 浮筹清洗度估算：
     洗盘期间累计换手率 > 吸筹期间日均换手率 × 洗盘天数 × 2
     → 表示浮筹已被充分清洗

  6. 支撑位确认：
     价格在关键支撑位（前低/均线/筹码密集区）获得2次以上有效支撑
```

### 3.3 清洗目标分析

```
主力在洗盘阶段要清除的三类资金：

  ┌─────────────────────────────────────────┐
  │         洗盘清除目标金字塔               │
  │                                         │
  │         ╱ 跟风盘 ╲                      │
  │        ╱  (30%)   ╲                     │
  │       ╱─────────────╲                    │
  │      ╱   技术派      ╲                   │
  │     ╱    (25%)        ╲                  │
  │    ╱───────────────────╲                 │
  │   ╱      浮筹/散户      ╲                │
  │  ╱       (45%)           ╲               │
  │ ╱─────────────────────────╲              │
  └─────────────────────────────┘            │

  浮筹清洗判断：
    连续3天换手率累计 < 5% → 浮筹基本清空

  技术派清洗判断：
    关键均线/支撑位被短暂击穿后收回 → 技术止损盘出局

  跟风盘清洗判断：
    冲高回落长上影 → 追高盘止损出局
```

### 3.4 真假洗盘辨别

| 特征 | 真洗盘（拉升前） | 假洗盘（出货前） |
|------|----------------|-----------------|
| 下跌速度 | 快速急跌 | 缓慢阴跌 |
| 反弹速度 | 快速收复 | 反弹无力 |
| 成交量 | 跌时缩量 | 跌时放量 |
| 关键支撑 | 不破或假破后快速收回 | 有效跌破 |
| 大盘环境 | 常借大盘下跌顺势洗 | 大盘平稳时独自下跌 |
| 消息面 | 无利空或有小利空 | 利空开始增多 |
| 主力筹码 | 锁定良好 | 开始松动 |

## 四、拉升阶段深度拆解

### 4.1 三种拉升节奏

```
┌────────────────────────────────────────────────────────────────┐
│                     拉升节奏对比                                │
├──────────────┬─────────────────┬─────────────────┬─────────────┤
│    特征       │  台阶式拉升      │  推土机式拉升    │  连板式拉升  │
├──────────────┼─────────────────┼─────────────────┼─────────────┤
│ 形态          │ 拉升→横盘→拉升   │ 持续小阳线上攻    │ 连续涨停板   │
│ 单日涨幅       │ 3-7%            │ 1-3%            │ 10%        │
│ 持续时间       │ 4-8周           │ 2-4周            │ 1-2周      │
│ 成交量         │ 阶梯式放大       │ 温和持续放大      │ 爆发式放大  │
│ 换手率         │ 5-15%           │ 3-8%            │ 15-30%     │
│ 主力风格       │ 稳健型/机构型    │ 技术流/游资型     │ 凶狠型/敢死队│
│ 参与难度       │ 中等(有上车机会) │ 较难(需追涨)      │ 极难(秒板)  │
│ 出货难度       │ 容易(有出货空间) │ 中等            │ 困难(需对倒) │
└──────────────┴─────────────────┴─────────────────┴─────────────┘
```

### 4.2 量价配合特征

```
健康拉升的量价关系（可参与）：

  阶段1：放量突破 — 成交量 > 前期均量的2倍，突破关键压力位
         ↓
  阶段2：缩量上涨 — 成交量 < 突破日的60%，但价格持续上行
         （缩量上涨 = 主力控盘度高，筹码锁定好，最健康）
         ↓
  阶段3：高位放量 — 成交量突然再次放大 > 前日均量2倍
         （高位放量 = 主力开始出货信号，减仓！）

不健康拉升需警惕：

  - 放量滞涨：量大但价格不动 → 主力出货
  - 无量空涨：涨停但几乎无成交 → 主力对倒拉板，无真实买盘
  - 天量天价：单日换手 > 30%，价格冲高回落 → 大概率见顶
```

### 4.3 消息配合节奏

```
主力消息运作时间线：

  T-2周：媒体开始出现"行业利好"相关报道（铺垫）
  T-1周：行业研报发布，给出"买入"评级（造势）
  T日：  公司发布利好公告（定增/收购/业绩预增）（点火）
  T+3日：各大财经平台推送，散户开始关注（扩散）
  T+1周：股价已涨30-50%，散户追涨（收割）
  T+2周：利好消息兑现完毕，主力开始出货（收网）

博弈要点：
  看到利好时判断：
  - 如果股价已经涨了 > 30% → 利好是出货信号
  - 如果股价刚启动 < 10% → 利好可能是真实拉升信号
  - 如果股价未涨 → 可能是主力布局信号，关注
```

## 五、震荡阶段深度拆解

### 5.1 震荡目的分类

| 震荡类型 | 位置 | 目的 | 量能特征 | 持续时间 | 后续方向 |
|----------|------|------|----------|----------|----------|
| 洗盘震荡 | 拉升初期 | 清除短线获利盘 | 缩量 | 1-2周 | 向上突破 |
| 换手震荡 | 拉升中期 | 提高市场平均成本 | 温和放量 | 2-3周 | 继续向上 |
| 出货震荡 | 拉升末期 | 分批派发筹码 | 放量 | 2-4周 | 向下破位 |
| 混合震荡 | 任何位置 | 洗盘+换手+试盘 | 不稳定 | 不确定 | 需观察 |

### 5.2 箱体识别方法

```
箱体识别规则：

  上轨确定：至少2次触及未突破的高点连线
  下轨确定：至少2次触及未跌破的低点连线
  箱体幅度：上轨/下轨 - 1 = 10%-20%为健康箱体

  有效性验证：
  ┌─────────────────────────────┐
  │ 上轨 ← 第3次触及不破 = 确认 │
  │         │                   │
  │     (箱体内部运行)          │
  │         │                   │
  │ 下轨 ← 第3次触及不破 = 确认 │
  └─────────────────────────────┘

  操作策略：
  - 箱体下轨附近缩量 → 买入信号
  - 箱体上轨附近放量 → 卖出或观望
  - 突破上轨带量 → 追涨（箱体突破）
  - 跌破下轨放量 → 止损（箱体破位）
```

## 六、出货阶段深度拆解

### 6.1 三大出货手法

#### 手法一：拉高出货

```
操作流程：
  1. 早盘快速拉高3-5%，制造强势假象
  2. 吸引跟风盘追涨买入
  3. 主力在高位分批派发筹码
  4. 尾盘回落，次日低开

盘口特征：
  - 拉升时量能集中，但持续时间短（< 30分钟）
  - 高位横盘时卖盘压力持续增加
  - 尾盘出现跳水式下跌

散户心理利用：
  "再不买就涨停了" → 追高被套
  "只是正常回调" → 第二天低开，深度套牢
```

#### 手法二：震荡出货

```
操作流程：
  1. 在高位建立箱体(10-15%区间)
  2. 下轨附近买入少量维持价格
  3. 上轨附近大量派发
  4. 反复操作，每次高点越来越低

识别信号：
  - 箱体低点逐步下移（每次下轨都比上次低）
  - 反弹高点也逐步下移
  - 成交量整体萎缩（主力筹码减少）
  - "放量下跌，缩量反弹"特征明显
```

#### 手法三：跌停出货

```
触发条件：
  - 突发重大利空
  - 主力资金链紧张需快速回笼
  - 监管风险（如被立案调查）

操作方式：
  1. 开盘直接跌停板挂单
  2. 跌停板上排单卖出
  3. 若无人接盘，次日继续跌停
  4. 直到有足够的接盘资金

规避方法：
  - 高位出现跌停 → 无条件清仓
  - 不要幻想"跌停板补仓做T"
```
