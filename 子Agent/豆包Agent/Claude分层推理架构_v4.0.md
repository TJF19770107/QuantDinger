## 三、三级缓存上下文系统 v4.0

### 3.1 缓存架构

| 层级 | 名称 | 容量 | 命中延迟 | 压缩策略 | 内容 |
|------|------|------|---------|---------|------|
| L1 | 热缓存 | 最近5轮对话(12K tokens) | <10ms | 无压缩，原始保留 | 当前会话最近上下文 |
| L2 | 温缓存 | 当前会话全量(64K tokens) | <50ms | 语义压缩，关键实体保留 | 会话全量摘要 |
| L3 | 冷缓存 | 历史会话摘要(256K tokens) | <200ms | 时间衰减+重要性加权 | 跨会话模式提取 |

### 3.2 上下文窗口管理策略

| 策略 | 方法 | 触发条件 |
|------|------|---------|
| 语义压缩 | 保留关键决策点+产物路径，删除冗余细节 | tokens > 阈值 |
| 分片加载 | 大文件分段读取(offset+limit) | 文件 > 10K行 |
| 过期归档 | 超过24h非关键对话→MemoryOS持久化 | 定时任务 |
| 优先级排序 | 安全规则 > 技能定义 > 任务上下文 > 对话历史 | 始终 |
| 跨会话注入 | Dreaming模式提取→下一次会话预加载 | 会话间 |

## 四、推理回溯增强 v4.0

### 4.1 多级回溯策略

```
Layer 1失败 → 重新解析(切换意图分类策略)
Layer 2失败 → 扩展条件分支(增加假设条件)
Layer 3失败 → 切换推理路径(并行→串行，Lead→Arena)
Layer 4失败 → 降级工具链(专用→通用→executor)
Layer 5失败 → 降级评分标准(放宽阈值)，记录失败模式
```

### 4.2 Checkpoint快照增强

| 快照时机 | 内容 | 恢复策略 |
|---------|------|---------|
| 每Layer完成 | 任务状态+上下文+产物清单 | 从该Layer重新开始 |
| 高风险操作前 | 完整系统状态快照 | 精确回滚+确认 |
| 每5次工具调用 | 增量快照 | 跳过失败工具，切换备用工具 |
| 异常检测触发 | 异常前完整状态 | Overseer异步监察判定 |

### 4.3 回溯限制

| 参数 | 值 | 说明 |
|------|-----|------|
| 最大回溯次数 | 3 | 超过则降级为人工确认 |
| 回溯冷却期 | 30秒 | 避免死循环 |
| 路径探索上限 | 5条 | 并行推理路径上限 |
| 回溯记录 | 全量 | 用于经验沉淀 |

## 五、工具联动推理 v4.0

### 5.1 增强工具选择矩阵

| 任务特征 | 工具选择 | 推理依据 | 降级方案 |
|---------|---------|---------|---------|
| 文件操作 | file-agent | 本地文件读写/搜索/整理 | python_executor |
| 系统配置 | computer-agent | Windows系统设置/管理 | shell_executor |
| 应用操作 | app-agent | App安装/打开/操作 | computer-agent |
| 网页内容 | web_fetch | 无交互的网页抓取 | browser(自动升级) |
| 网页交互 | browser | 登录/点击/多页跳转 | 通知用户手动 |
| 深度搜索 | search-agent | RAG总结的复杂搜索 | web_search+web_fetch |
| 推理增强 | Claude推理引擎 | 复杂推理任务 | Main Agent五步法 |

### 5.2 工具联动回环

```
执行 → 结果分析 → 推理调整 → 新工具选择 → 再执行
  ↑_______________________________________________↓
            (最多3轮回环，超限则输出当前最优)
```

### 5.3 降级链 v4.0

```
Sub Agent(专用) → Skill(封装) → Tool(通用) → executor(兜底) → 用户确认(最终)
```
