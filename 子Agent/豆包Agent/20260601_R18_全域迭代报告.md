#### 协议63：Hermes-Codex任务派发协议 v1.0

**对标来源**：Hermes Orchestrator-Worker + dispatch_task 标准化

**核心定义**：
规定 Hermes 向 Codex 派发编码任务的标准化格式、参数规则、并行调度策略。

```
派发格式三要素：
1. <overall_goal>：用户原始需求（直接复述或等价压缩）
2. <current_task>：本次委托具体任务（自包含、可独立执行、结果导向）
3. 辅助参数：memory_ids（历史上下文）+ inherit_agent_id（续接任务）

并行调度规则：
- 无数据依赖 → 同批并行派发（如 Codex + File Agent 同时执行）
- 有数据依赖 → 顺序派发（如 Codex 生成脚本 → File Agent 用脚本处理文件）
- 同批并行上限：5 个 Agent
```

---

#### 协议64：结构化摘要返回协议 v1.0

**对标来源**：Codex Structured Output

**核心定义**：
规定 Codex 完成任务后向 Hermes 返回结构化摘要的标准格式和字段语义。

```json
{
  "status": "done|partial|failed",
  "agent_id": "sa-xxx",
  "artifacts": [
    {"file": "绝对路径", "type": "code|data|report|config", "description": "说明"}
  ],
  "tool_trace": ["工具调用追踪"],
  "gaps": ["未完成部分描述"],
  "suggestions": ["后续建议"],
  "confidence": 0.0-1.0,
  "budget_used": "N/15 rounds"
}
```

验收规则：
- confidence ≥ 0.9 → 直接验收
- 0.7 ≤ confidence < 0.9 → 查看 reasoning 手动判断
- confidence < 0.7 → 重新派发或降级

---

#### 协议65：Codex工具链自动切换协议 v1.0

**对标来源**：Codex Tool Use + 龙虾工具路由规则

**核心定义**：
规定 Codex 在编码场景下的工具选择优先级和自动切换规则。

```
工具优先级（从高到低）：
1. read_file / read_text（文件内容读取，按类型路由）
2. write_file / edit_file（文件内容写入）
3. convert_file（格式转换）
4. delete（文件删除，自带确认UI）
5. search_file / search_chunk（索引检索）
6. fs_search_file / fs_search_content（兜底检索）
7. python_executor（Python 脚本执行）
8. shell_executor（Shell 命令执行）

禁止越级：1-6 能覆盖的场景，不得降级到 7-8
自动降级：上层失败 2 次后，自动降级到下一层
```

#### 协议66：多Agent编码协作协议 v1.0

**对标来源**：龙虾多Agent协同看板 + Hermes Swarm v2.1

**核心定义**：
规定编码场景下多 Agent 并行协作的模式、隔离机制、结果仲裁规则。

```
协作模式：
1. 独立编码模式：多个 Codex 同时编码不同模块 → Hermes 合并
2. 编码+审查模式：Codex 编码 + Review Agent 审查 → Codex 修正
3. 竞技场模式：2+ Codex 同时编码同一需求 → Hermes 择优 → 融合
4. 流水线模式：Codex A 生成框架 → Codex B 填充实现 → Codex C 测试

隔离机制：
- 每个 Agent 独立会话 + 独立产物目录
- 共享只读文件系统（技能库/知识库）
- 写入隔离（各自的 output/ 子目录）

结果仲裁：
- 一致性校验：2 Agent 结果一致 → 通过
- 分歧仲裁：启动仲裁 Agent 裁决
- 融合策略：择优融合 + 标注来源
```

#### 协议67：Agent互联互通域协议 v1.0

**对标来源**：龙虾AI体系全域架构

**核心定义**：
建立 6 大 Agent 统一域名空间，实现能力注册与互通路由。

```
统一域名空间：

Agent Domain Registry:
┌──────────────┬─────────────────────┬──────────────────┐
│ Agent        │ Domain              │ 注册能力           │
├──────────────┼─────────────────────┼──────────────────┤
│ Hermes       │ orchestrator.local  │ 任务分解/调度/聚合  │
│ Codex        │ codex.local         │ 编码/测试/重构     │
│ File Agent   │ file.local          │ 文件搜索/读写/转换  │
│ Computer Agt │ computer.local      │ 系统设置/桌面控制   │
│ App Agent    │ app.local           │ 应用操作/APK管理   │
│ Search Agent │ search.local        │ 深度搜索/调研      │
└──────────────┴─────────────────────┴──────────────────┘

互通路由规则：
- Hermes → 所有 Agent：dispatch_task()
- Codex → File Agent：文件操作请求（通过 Hermes 中转）
- File Agent → Hermes：搜索结果返回
- 禁止：Agent 间直接调用（必须经过 Hermes 中枢）
```
