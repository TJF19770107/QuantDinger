### 生态一：Claude Code源码泄露与Agent架构收敛
- 2026年3月31日，Claude Code 51.2万行TypeScript源码因npm source map失误泄露
- 三巨头核心架构收敛：**ReAct Loop + Tool System + Context Manager + Permission Layer**
- 竞争从"模型战"转向"系统战"，Harness Engineering成为差异化核心
- 六大工程维度曝光：缓存经济学/记忆系统/安全加固/多Agent协调/成本控制/渲染优化
- 同一Opus模型不同Harness性能差16个百分点

### 生态二：Hermes Agent (138K⭐) 崛起
- Nous Research开发，自我进化AI代理，内置Closed Learning Loop
- 七大核心能力：CLL技能自产 / FTS5全文搜索 / 6平台消息网关 / 200+模型无锁定 / 6种终端后端 / 并行子Agent / Atropos RL
- OpenClaw精神继承者，一键迁移工具

### 生态三：Agent Skills生态爆发
- GitHub 446仓库 / 70.7万⭐
- agentskills.io开放标准，文件级可插拔模块化
- Skills从Prompt Engineering转向Harness Engineering的关键节点

### 生态四：OpenCode/Claude Code/Hermes三方对比
- 三种范式：开源协议化 / 模型厂商一体化 / 自托管学习型
- 记忆系统四层架构（Claude Code）：会话上下文→MEMORY.md索引→完整记忆→AutoDream
- Hermes三文件：SOUL.md / MEMORY.md / USER.md

### 生态五：中国AI产业化加速

- 微信Agent化 / 腾讯QClaw公测 / 小红书Dots一级AI部门
