## 三、与R04三层架构的融合映射

| R04 模块 | R05 整合能力 | 协同方式 |
|----------|------------|---------|
| 端云路由层 | AutoWake优先级队列 | P0安全审查→云端、P1-P3→本地执行 |
| 本地执行层 | DesktopController + AutoFileScanner | 桌面操作+文件扫描合并为执行层 |
| 专家-门徒层 | Marvis专家 + SkillForge门徒 | 专家审核技能、门徒执行生成 |
| 自进化闭环 | AutoWake+MemoryOS+SkillForge+SafeGuard | 4模块串联形成完整闭环 |
| 6Agent模块 | 6大自主能力 | 1:1映射补全 |
| 多Agent协作 | AutoWake任务队列 | 多任务排队执行，优先级抢占 |

## 四、技能依赖图

```
AutoWake（核心调度）
  ├── MemoryOS（记忆，AutoWake唤醒时加载）
  │     └── AutoFileScanner（文件感知，MemoryOS需目录索引）
  ├── SkillForge（技能锻造，依赖AutoWake调度）
  │     └── SafeGuard（安全审查，SkillForge产出需审查）
  └── DesktopController（桌面控制，独立模块）
        └── SafeGuard（操作审查，桌面操作需安全审查）

SafeGuard（全局守护）
  └── 审查所有模块的变更和操作
```

## 六、启动与执行时序

```
T=0   AutoWake.trigger()
T+1   MemoryOS.auto_load()           → 上下文就绪
T+2   AutoFileScanner.build_tree()  → 环境感知就绪
T+3   SafeGuard.pre_check()         → 安全状态确认
T+4   任务队列逐项执行                → 迭代/搜索/扫描/锻造
T+N   SafeGuard.create_checkpoint() → 创建检查点
T+N+1 MemoryOS.persist()            → 记忆持久化
T+N+2 AutoWake.sleep()              → 休眠，等待下次唤醒
```
