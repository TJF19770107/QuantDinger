## 三、数据流 v4.0

```

    │
    ▼
Marvis 主脑 (Layer 1)
    │ 理解意图 → 拆解任务 → 安全检查
    ▼
MissionControl v2.0 (Layer 5)
    ├── 创建 Kanban Task (SQLite)
    ├── 分配 Agent Profile
    ├── 设置超时和熔断
    └── 启动异步执行
    │
    ├──→ AutoWake v2.0 (Layer 3)
    │       ├── PES拆分
    │       └── 优先级抢占
    │
    ├──→ MemoryOS v2.0 (Layer 3)
    │       ├── 三层记忆检索
    │       ├── WISE-Flow提取
    │       └── Obsidian MCP同步 → Layer 7
    │
    ├──→ CodeAgent v1.0 (Layer 4)
    │       ├── LSP感知
    │       └── 代码理解
    │
    ├──→ DesktopController v3.0 (Layer 3)
    │       ├── OmniParser V2视觉感知
    │       ├── pywinauto UI自动化
    │       └── 进程安全白名单

    └──→ SafeGuard v3.0 (Layer 6)
            ├── 反蒸馏检查
            ├── ACP指令溯源
            ├── 七级权限验证
            └── 检查点快照
    │
    ▼
结果聚合 → MemoryOS持久化 → SkillForge模式提取 → 用户交付
```

## 六、反蒸馏协议数据流（对标 Claude Code）

```
SkillForge 生成技能
    │
    ▼
AntiDistillation.watermark_injection()
    ├── 注入加密签名摘要（SHA-256 + RSA）
    ├── 嵌入不可见水印到代码注释
    └── 记录到 ACP 溯源日志
    │
    ▼
SafeGuard.pre_check()
    ├── 检测仓库类型：内部/外部
    ├── 内部仓库 → 保留完整AI标识
    └── 外部仓库 → 卧底模式 (剥离AI标识)
    │
    ▼
ACP 指令溯源
    ├── 每行指令 trace_id → 源Agent → 生成时间 → 权限级别
    ├── 审计日志结构化存储
    └── 支持全链路回溯
```

## 七、模块间接口协议 v4.0

```python
# 新增接口

# MissionControl → KanbanBoard
class IKanbanBoard:
    def create_task(profile, params) -> str
    def dispatch_ready() -> list
    def complete_task(task_id, handoff) -> None
    def recover_timeout(task_id) -> None

# MissionControl → AgentTeams
class IAgentTeams:
    def debate(task, agents=3) -> dict
    def score(results) -> dict
    def select_best(results, scores) -> dict

# SafeGuard → AntiDistillation
class IAntiDistillation:
    def stealth_mode(repo_type) -> dict
    def watermark_injection(skill_code) -> bytes
    def acp_trace(instruction_id) -> list

# CodeAgent → LSPIntelligence
class ILSPIntelligence:
    def detect_language(file_path) -> str
    def load_server(language) -> LSP
    def code_understanding(repo) -> dict

# MemoryOS → ObsidianBridge
class IObsidianBridge:
    def sync_vault(vault_path) -> None
    def markdown_index() -> dict
    def cross_reference(query) -> list
```
