# 端云智能路由引擎 + 专家-门徒调度器
> 版本：v1.0  
> 参考来源：Marvis端云双模式 + SWE-Protégé专家-门徒 + Windsurf Cascade/Devin  
> 归属：豆包Agent v4.0 · Layer 2-3

---

## 一、端云路由决策树

```
用户自然语言指令
    │
    ▼
PM Agent 意图理解 + 复杂度评估
    │
    ├── 简单任务（纯端侧）
    │   条件：代码补全、文件读写、简单搜索、单步GUI操作
    │   执行：端侧模型（Qwen/Seed Lite）
    │   延迟：<500ms
    │   成本：0 Token费用
    │
    ├── 中等任务（端侧执行 + 云端顾问）
    │   条件：代码生成、多文件编辑、复杂GUI操作、中等推理
    │   执行：端侧模型主执行 + 云端Pro模型顾问（Token占比<15%）
    │   延迟：<2s
    │   成本：少量Token费用
    │
    └── 复杂任务（云端主导）
        条件：长文本理解、深度推理、多Agent复杂协作、大规模代码重构
        执行：云端Pro模型主导 + 端侧辅助执行
        延迟：<5s
        成本：标准Token费用
```

## 二、复杂度评估维度

| 维度 | 权重 | 简单(0) | 中等(1) | 复杂(2) |
|------|------|---------|---------|---------|
| 代码行数 | 20% | <50行 | 50-500行 | >500行 |
| 文件数量 | 15% | 1个 | 2-5个 | >5个 |
| 推理深度 | 25% | 单步推理 | 多步推理 | 链式推理 |
| 上下文长度 | 15% | <4K tokens | 4K-32K | >32K |
| 工具调用数 | 10% | 0-1个 | 2-5个 | >5个 |
| 多Agent协作 | 15% | 单Agent | 2-3个Agent | >3个Agent |

**评分公式**：总分 = Σ(维度得分 × 权重)
- 总分 < 0.5 → 简单任务 → 纯端侧
- 0.5 ≤ 总分 < 1.2 → 中等任务 → 端侧+云端顾问
- 总分 ≥ 1.2 → 复杂任务 → 云端主导

## 三、专家-门徒调度流程

### 门徒（Protégé）职责（端侧）
- 接收用户指令
- 执行常规操作（90%工作量）
- 监控自身执行状态
- 在以下情况主动求助专家：
  - 连续3次操作失败
  - 推理置信度低于阈值
  - 遇到未见过的新模式
  - 需要长文本理解
  - 需要多源信息整合

### 专家（Expert）职责（云端）
- 接收门徒求助请求
- 提供高维度指导和决策
- Token占比控制：<15%
- 不直接执行操作，仅输出建议
- 返回建议后立即退出

### 协作示例

```
[用户] 帮我用Python写一个带JWT认证的用户管理系统

[门徒-端侧] 开始分析需求...
  → 拆解为：数据库设计、API接口、JWT中间件、测试
  → 开始设计数据库模型...

[门徒-端侧] JWT token刷新策略不确定，求助专家

[专家-云端] 建议：使用access_token(15min)+refresh_token(7d)双token模式
  → refresh_token存数据库，支持吊销
  → 使用Redis缓存黑名单提升性能
  (Token消耗：~500 tokens)

[门徒-端侧] 收到建议，继续实现...
  → 生成User模型、Auth接口、JWT中间件
  → 编写单元测试
  → 输出完整代码
```

## 四、与Windsurf Cascade/Devin模式对比

| 维度 | Windsurf | 豆包v4.0 |
|------|----------|---------|
| 本地Agent | Cascade | Code Agent(端侧) |
| 云端Agent | Devin | PM Agent + Expert(云端) |
| 分工方式 | Plan→Devin执行+本地继续 | 端云自动路由 |
| 离线能力 | 需联网 | 简单任务可离线 |
| 成本 | 订阅制 | 按Token计费 |

## 五、隐私模式

对标Marvis隐私模式：
- **触发条件**：用户声明"隐私模式"或系统检测到敏感文件路径
- **行为**：所有推理走端侧模型，数据零上云
- **限制**：无法使用云端Pro模型作为专家顾问
- **适用**：财务/法务/HR等敏感场景
