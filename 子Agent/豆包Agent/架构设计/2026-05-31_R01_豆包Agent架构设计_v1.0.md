## 二、核心模块设计

### 2.1 PM Agent（对标 Marvis 主 Agent + Claude Code 意图理解）

```
职责：
- 接收用户自然语言输入
- 7类任务自动分类: 编码/搜索/创作/分析/操作/问答/系统
- 复杂度评分(1-10分)，>5分自动启动Plan Mode
- 拆解子任务并调度专业Agent
- 汇总执行结果，验证完整性
```

### 2.2 三环思考引擎（对标 Claude ReAct + Hermes 自学习 + Gemini 反思）

```
┌─────────────────────────────────────────────┐
│ 外环：反思循环 (Gemini 2.5 模式)              │
│  知识缺口检测 → 追加搜索 → 来源验证 → 迭代优化  │
│ ┌─────────────────────────────────────────┐ │
│ │ 中环：规划执行 (Claude Code ReAct模式)    │ │
│ │  Thought → Plan → Action → Observation   │ │
│ │ ┌─────────────────────────────────────┐ │ │
│ │ │ 内环：自学习 (Hermes模式)            │ │ │
│ │ │  轨迹分析 → 模式识别 → Skill提取     │ │ │
│ │ │  → 经验固化 → 自动复用              │ │ │
│ │ └─────────────────────────────────────┘ │ │
│ └─────────────────────────────────────────┘ │
└─────────────────────────────────────────────┘
```

**实现伪代码**：
```python
class TripleLoopThinkingEngine:
    def process(self, user_input):
        # 内环：检查是否有已学Skill可复用
        cached_skill = self.skill_matcher.match(user_input)
        if cached_skill and cached_skill.confidence > 0.8:
            return self.execute_skill(cached_skill)
        
        # 中环：ReAct 规划执行
        plan = self.planner.decompose(user_input)
        for step in plan:
            observation = self.execute_step(step)
            plan.adjust(observation)
        
        # 外环：反思验证
        gaps = self.reflector.detect_gaps(result, user_input)
        if gaps:
            result = self.fill_gaps(gaps)
        
        # 内环：学习保存
        if plan.complexity > 5:
            self.skill_extractor.save(user_input, plan, result)
        
        return result
```

### 2.3 模型路由器（对标 OpenCode 75+ providers）

```
路由策略：
用户任务 → 分类器
  ├─ 简单对话/闲聊      → 本地小模型 (Qwen2.5-7B / Llama3-8B)
  ├─ 代码生成/调试       → 豆包Coder模型 / DeepSeek-Coder

```

### 2.5 自进化引擎（对标 Hermes Agent 完整设计）

```python
class SelfEvolutionEngine:
    """
    对标 Hermes Agent 的自学习闭环
    核心理念: "The agent that grows with you"
    """
    
    def __init__(self):
        self.trajectory_db = SQLiteFTS5("doubao_evolution.db")
        self.skill_curator = SkillCurator()
        self.memory_manager = MemoryManager()
    
    def learn_from_task(self, task_input, execution_plan, result):
        """从任务中学习"""
        # ① 执行追踪：记录完整轨迹
        trajectory = {
            "input": task_input,
            "steps": execution_plan.steps,
            "tool_calls": execution_plan.tool_calls,
            "result": result,
            "success": result.success,
            "duration": result.duration,
            "timestamp": now()
        }
        self.trajectory_db.insert(trajectory)
        
        # ② 模式识别：分析成功模式
        if result.success and execution_plan.complexity > 3:
            pattern = self.pattern_analyzer.extract(trajectory)
            if pattern.is_reusable():
                # ③ Skill提取：保存为可复用技能
                skill = self.skill_curator.create_skill(
                    name=pattern.generate_name(),
                    description=pattern.summarize(),
                    steps=pattern.extract_steps(),
                    metadata=pattern.get_metadata()
                )
                self.skill_curator.save(skill)
        
        # ④ 记忆固化：更新长期记忆
        self.memory_manager.consolidate(
            key_facts=result.key_insights,
            user_preferences=result.user_patterns,
            project_context=execution_plan.context
        )
    
    def optimize_skill(self, skill_name):
        """⑤ 自我优化：分析Skill调用成功率并自动改进"""
        usage_stats = self.trajectory_db.get_skill_stats(skill_name)
        if usage_stats.success_rate < 0.8 and usage_stats.attempts > 10:
            optimized_steps = self.optimizer.improve(skill_name, usage_stats)
            self.skill_curator.update(skill_name, optimized_steps)
    
    def upgrade_capabilities(self):
        """⑥ 能力升级：定期全网扫描新技术"""
        new_tech = self.web_scanner.scan_topics([
            "AI Agent", "Coding Agent", "LLM Tools",
            "MCP Protocol", "Agent Architecture"
        ])
        for tech in new_tech:
            self.skill_curator.absorb_technology(tech)
```

### 2.8 安全三层架构（对标 Marvis L2硬垂询 + Codex沙箱）

```
低风险(自动执行)：
  - 读文件、搜索信息、显示内容
  - 代码分析、代码建议
  - 非破坏性查询

中风险(确认后执行)：
  - 写文件、修改代码
  - 执行Shell命令
  - 修改系统设置

高风险(禁止AI执行/强制人工)：
  - 支付、转账
  - 删除重要文件
  - 修改核心系统配置
```
