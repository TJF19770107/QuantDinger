## 三、DGM演化树设计（SkillForge v2.0核心）

```
                     Root Skill (初始技能)
                           │
              ┌────────────┼────────────┐
              │            │            │
          v1.0-A        v1.0-B      v1.0-C     ← 第1代: 基础变体
              │            │            │
          ┌───┴───┐    ┌───┴───┐    ┌───┴───┐
          │       │    │       │    │       │
       v2.0-A  v2.0-B v2.0-C v2.0-D v2.0-E ← 第2代: 交叉变异
          │       │      │       │      │
          └───┬───┘      └───┬───┘      └───┐
              │              │              │
           v3.0-A        v3.0-B        v3.0-C ← 第3代: 融合进化

采样策略:
- 精英保留: Top 20% 技能直接进入下一代
- 轮盘赌: 剩余 80% 按质量评分加权采样
- 变异率: 20% 概率引入新特性
- 交叉率: 30% 概率融合两个技能
- 淘汰率: 连续10轮未使用 → 休眠 → 50轮 → 淘汰
```

## 五、检查点体系数据流

```
迭代开始
    │
    ▼
SafeGuard.create_checkpoint()
    ├── 计算所有文件MD5
    ├── 生成快照JSON
    ├── 写入 checkpoints/
    └── 更新 stable_checkpoint.json
    │
    ▼
执行迭代任务
    │
    ├──成功──→ SafeGuard.validate()
    │           ├── 冒烟测试通过
    │           ├── 核心功能验证
    │           └── stable_checkpoint 指向新版本
    │
    └──失败──→ SafeGuard.rollback()
                ├── 定位上一个stable检查点
                ├── 对比Diff确认回滚范围
                ├── 执行文件还原
                ├── 记录 rollback_history.json
                └── 用户通知
```

## 六、模块间接口协议

```python
# 标准模块接口
class IModule:
    def init(self) -> bool:        # 初始化
    def execute(self, task) -> dict:  # 执行任务
    def status(self) -> dict:      # 状态查询
    def shutdown(self) -> bool:    # 安全关闭

# 模块间通信协议
# AutoWake → MemoryOS: wake(task_context) → memory_context
# MemoryOS → AutoFileScanner: query_index(pattern) → file_list
# SkillForge → SafeGuard: submit_skill(skill) → review_result
# DesktopController → SafeGuard: pre_check(operation) → safe/blocked
```

## 七、启动时序 (auto_start.py)

```
T=0    AutoWake.start()                    ← 加载任务队列
T+1    MemoryOS.init()                     ← 恢复上次会话快照
T+2    AutoFileScanner.build_tree()        ← 扫描目录+构建索引
T+3    SafeGuard.create_checkpoint()       ← 创建R06初始检查点
T+4    AutoWake.execute_next()             ← 逐项PES执行任务
  T+4.1  任务1: 4小时迭代 (P1)
  T+4.2  任务2: 文件扫描 (P2)
  T+4.3  任务3: 日志归档 (P3)
T+N    SafeGuard.validate()                ← 验证本轮变更
T+N+1  MemoryOS.persist()                  ← 持久化记忆
T+N+2  AutoWake.sleep()                    ← 休眠，等待下次唤醒
```
