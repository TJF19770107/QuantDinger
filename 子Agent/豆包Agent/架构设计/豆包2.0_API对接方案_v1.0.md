## 二、豆包Agent → 豆包2.0 对接架构

### 2.1 模型分层策略

```
豆包Agent 决策层（龙虾五步法）
  │
  ├─ 意图识别 → Doubao-Seed-2.0-Lite (快速/低成本)
  ├─ 任务规划 → Doubao-Seed-2.0-Pro  (复杂推理)
  ├─ 代码生成 → Doubao-Seed-2.0-Code (编码优化)
  ├─ 日常对话 → Doubao-Seed-2.0-Lite (平衡)
  └─ 端侧推理 → Doubao-Seed-2.0-Mini (R12规划，本地部署)
```

### 2.2 API 对接方案

```python
# 模型适配器接口（参考 OpenCode 75+ 模型抽象）

class DoubaoAdapter:
    """豆包2.0 API适配器"""
    
    MODELS = {
        "pro": "doubao-seed-2.0-pro-250215",
        "lite": "doubao-seed-2.0-lite-250228",
        "code": "doubao-seed-2.0-code-250315",
        "mini": "doubao-seed-2.0-mini-250315"
    }
    
    def route(self, task_type: str) -> str:
        """根据任务类型路由到最佳模型"""
        routing = {
            "code_generation": self.MODELS["code"],
            "complex_reasoning": self.MODELS["pro"],
            "task_planning": self.MODELS["pro"],
            "daily_chat": self.MODELS["lite"],
            "quick_search": self.MODELS["lite"],
            "local_inference": self.MODELS["mini"]  # R12
        }
        return routing.get(task_type, self.MODELS["lite"])
```
