## 二、核心能力提取

### 2.1 Codex 移动端远程操控（对标：跨平台）
- **锁定后操控**：Mac锁定后Codex通过受信通道临时解锁，手机远程操控，本地用户被阻止
- **Appshots**：自动捕获前台应用窗口，无需手动截图
- **SubagentStart Hook**：子Agent启动时触发自定义脚本注入
- **Triggers全自动流水线**：GitHub事件→Codex读取→修复→开PR→手机审批

### 2.2 Claude Opus 4.8 Dynamic Workflows（对标：多Agent/自主规划）
- **百级并行子Agent**：单会话内拆解→分发→并行→汇总→交叉验证
- **对抗Agent**：内置证伪Agent交叉验证，直到答案收敛
- **断点恢复**：中途打断支持从断点继续
- **Effort Control**：Low/High/Extra/Max/Ultra Code五档思考深度
- **Messages API**：任务进行中插入系统指令，Prompt Cache不失效
- **诚实度跃升**：缺陷漏报率降至4.7的1/4，过度自信降至1/10
- **实战验证**：Bun 75万行Zig→Rust移植，11天，99.8%通过率

### 2.3 Hermes v0.15.0 工程化革命（对标：工具调用/任务编排）
- **核心瘦身**：run_agent.py 16083→3821行（-76%），14个高内聚模块
- **session_search**：30s→20ms（4500x），零成本
- **Kanban Swarm**：一键创建协调者+并行worker+验证器+合成器+共享黑板
- **任务级模型覆盖**：每个任务可选不同模型
- **Promptware防御**：三道关卡（威胁模式库+记忆扫描+工具输出分隔符）
- **Skill Bundles**：一条命令加载整组技能

### 2.4 ReVeal 自验证编码Agent（对标：自进化/编码能力）
- **生成-验证多轮循环**：20+轮自进化，仅3轮训练数据
- **TAPO信用分配**：轮次级信用分配，促进代码与测试协同进化
- **Pass@k提升**：更强的探索能力扩展推理边界
