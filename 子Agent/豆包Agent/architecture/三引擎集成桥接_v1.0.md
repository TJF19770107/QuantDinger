## 三、事件总线（三引擎通信协议）

三引擎通过统一事件总线通信，基于发布-订阅模式实现松耦合：

| 事件ID | 事件名 | 发送者 | 携带数据 | 接收者 |
|--------|--------|--------|----------|--------|
| EVT_001 | REASONING_COMPLETE | Claude推理引擎 | `{plan_json, confidence, intent_graph, constraints}` | 工作流引擎 |
| EVT_002 | WORKFLOW_PROGRESS | 工作流引擎 | `{node_id, status, metrics, progress_pct}` | 状态看板 |
| EVT_003 | WORKFLOW_COMPLETE | 工作流引擎 | `{result, trajectory, metrics, errors}` | 自进化引擎 |
| EVT_004 | EVOLUTION_PROPOSAL | 自进化引擎 | `{target_engine, patch_type, patch_content, confidence}` | 工作流引擎/推理引擎 |
| EVT_005 | ROLLBACK_TRIGGERED | 自进化引擎 | `{snapshot_id, reason, affected_skills, severity}` | 全域通知 |
| EVT_006 | SKILL_EXTRACTED | 自进化引擎 | `{skill_id, skill_spec, source_trajectory_id}` | SkillForge |
| EVT_007 | ANOMALY_DETECTED | 工作流引擎 | `{node_id, anomaly_type, severity, context}` | 自进化引擎/SafeGuard |
| EVT_008 | EVOLUTION_APPLIED | 自进化引擎 | `{skill_id, version, delta, test_results}` | 全域广播 |

## 四、统一入口API

```python
# integration_unified_api.py - 三引擎统一入口

class DoubaoAgentOrchestrator:
    """
    豆包Agent统一编排器
    集成 Claude推理v5.0 + 可视化工作流v5.0 + 深度自进化v6.0
    """
    
    def __init__(self):
        self.reasoning = ClaudeReasoningEngineV5()
        self.workflow = WorkflowVisualEngineV5()
        self.evolution = SelfEvolutionCoreV6()
        self.event_bus = EventBus()
        self._setup_event_handlers()
    
    def execute_with_full_cycle(self, user_input: str) -> dict:
        """
        完整三引擎执行循环：推理 → 编排 → 进化
        
        Args:
            user_input: 用户原始输入
        
        Returns:
            dict: {result, trajectory, evolution_applied}
        """
        # Phase 1: Claude推理引擎解析
        plan = self.reasoning.analyze(user_input)
        self.event_bus.emit("EVT_001", plan)
        
        # Phase 2: 工作流引擎编排执行
        result, trajectory = self.workflow.execute(plan)
        self.event_bus.emit("EVT_003", {
            "result": result,
            "trajectory": trajectory
        })
        
        # Phase 3: 自进化引擎沉淀
        evolution_result = self.evolution.absorb(trajectory)
        
        # Phase 4: 如果需要进化，触发SICA循环
        if self.evolution.should_evolve():
            evolution_result = self.evolution.evolve()
            self.event_bus.emit("EVT_004", evolution_result)
        
        return {
            "result": result,
            "trajectory": trajectory,
            "evolution_applied": evolution_result is not None
        }

    def execute_reasoning_only(self, user_input: str) -> dict:
        """仅推理模式：快速分析不执行"""
        return self.reasoning.analyze(user_input)
    
    def execute_workflow_only(self, plan: dict) -> dict:
        """仅编排模式：直接执行已有计划"""
        result, trajectory = self.workflow.execute(plan)
        return {"result": result, "trajectory": trajectory}

    def evolve_skills(self, trajectory_id: str) -> dict:
        """手动触发自进化"""
        return self.evolution.evolve_from_trajectory(trajectory_id)

    def _setup_event_handlers(self):
        """绑定事件处理器"""
        self.event_bus.subscribe("EVT_001", self.workflow.on_reasoning_complete)
        self.event_bus.subscribe("EVT_003", self.evolution.on_workflow_complete)
        self.event_bus.subscribe("EVT_004", self._on_evolution_proposal)
        self.event_bus.subscribe("EVT_005", self._on_rollback)
        self.event_bus.subscribe("EVT_007", self.evolution.on_anomaly)
    
    def _on_evolution_proposal(self, event):
        """处理自进化提议：决定是否应用到推理/工作流引擎"""
        if event.payload["target_engine"] == "reasoning":
            self.reasoning.apply_patch(event.payload["patch_content"])
        elif event.payload["target_engine"] == "workflow":
            self.workflow.apply_patch(event.payload["patch_content"])
    
    def _on_rollback(self, event):
        """处理回滚事件：通知所有引擎"""
        self.workflow.pause()
        self.evolution.rollback_to_snapshot(event.payload["snapshot_id"])
        self.workflow.resume()
```
