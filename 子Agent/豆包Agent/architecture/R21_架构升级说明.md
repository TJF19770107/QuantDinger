# 豆包Agent R21架构升级说明

> **版本**：R21 (2026-06-01)
> **升级范围**：全域架构
> **基于**：Hermes v0.8.0, Vera Rubin, AWS AgentCore

---

## 一、架构变更概览

### 1.1 R20 → R21 核心变更

```
R20架构层：
├── 应用层
│   ├── MUSE五阶段技能生成
│   ├── MOS源码级元重写
│   └── CASCADE双元技能
├── 平台层
│   ├── Google Managed Agents
│   └── MemPalace记忆
└── 基础设施层
    └── GenericAgent极简种子

R21架构层：
├── 应用层
│   ├── Hermes闭环学习（新增）    ← v0.8.0闭环学习循环
│   ├── Token经济调度（新增）     ← 按速度/智能分层定价
│   ├── MUSE五阶段技能生成（保留）
│   └── MOS源码级元重写（保留）
├── 平台层
│   ├── AWS三架构部署（升级）     ← Bedrock/AgentCore/Strands
│   ├── Vera Rubin平台（新增）    ← Agentic AI专属硬件
│   └── MemPalace+HyperMem（升级）
├── 安全层
│   ├── 机密计算（新增）          ← 硬件级可信执行环境
│   └── 视觉语义操控v2.0（升级）
└── 基础设施层
    └── 持续运行守护（升级）      ← 锁屏7×24 + 崩溃恢复5秒
```

---

## 二、核心能力矩阵

| 能力域 | R20实现 | R21升级 | 关键对标 |
|-------|---------|---------|---------|
| 技能生成 | MUSE五阶段 | MUSE + Hermes闭环 | Hermes v0.8.0 |
| 技能复用 | CASCADE双元 | CASCADE + 权重调整 | Hermes闭环 |
| 记忆系统 | MemPalace四层 | MemPalace + HyperMem | 长期记忆协议 |
| Agent调度 | 基础FIFO | Token经济预算驱动 | Vera Rubin |
| 部署架构 | 单体运行 | AWS三架构可选 | Bedrock/AgentCore/Strands |
| 安全机制 | 沙箱隔离 | 沙箱 + 机密计算 | Vera Rubin |
| 桌面控制 | 坐标定位v1.0 | 语义定位v2.0 | Codex CU |
| 持续运行 | 需要屏幕解锁 | 锁屏7×24 | Locked Agent |
| 平台兼容 | 单一平台 | 多云兼容 | AWS/Google/本地 |

## 三、技术债务清理

| 债务项 | 状态 | 说明 |
|-------|------|------|
| 坐标定位脆弱 | ✅ 已解决 | v2.0语义定位，分辨率无关 |
| 锁屏无法运行 | ✅ 已解决 | Locked Agent + 虚拟桌面 |
| 无预算控制 | ✅ 已解决 | Token经济 + 多级预算 |
| 单体架构 | ✅ 已解决 | AWS三架构可切换 |
| 恢复时间长 | ✅ 已解决 | Process Guardian 5秒恢复 |

## 四、迁移指南

### 4.1 升级步骤
1. 停用旧版坐标定位模块，启用语义定位v2.0
2. 集成Hermes闭环学习到任务执行流水线
3. 配置Token预算管理系统
4. 部署Process Guardian进程守护
5. 更新技能库索引格式

### 4.2 回滚方案
```
R21 → R20 回滚步骤：
1. 关闭Hermes闭环学习模块
2. 切换回坐标定位v1.0
3. 关闭Token预算管理
4. 恢复原有记忆存储格式
5. 重新加载v3.14模板
```
