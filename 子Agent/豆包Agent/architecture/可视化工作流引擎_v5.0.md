### 2.3 串行/并行/条件跳转规则引擎

```json
{
  "workflow_id": "wf_v5_example",
  "nodes": [
    {
      "id": "trigger_001",
      "type": "TRIGGER",
      "config": {"trigger_type": "schedule", "cron": "0 */2 * * *"}
    },
    {
      "id": "scan_001",
      "type": "ACTION",
      "config": {"tool": "AutoFileScanner", "params": {"path": "E:/workspace"}},
      "execution_mode": "sequential",
      "next": ["condition_001"]
    },
    {
      "id": "condition_001",
      "type": "CONDITION",
      "config": {
        "rules": [
          {
            "id": "rule_high_priority",
            "condition": {
              "type": "compound",
              "logic": "AND",
              "predicates": [
                {"field": "{{scan_001.output.file_count}}", "op": "GT", "value": 10},
                {"field": "{{scan_001.output.priority}}", "op": "EQUALS", "value": "high"}
              ]
            },
            "target": "parallel_group_001"
          },
          {
            "id": "rule_normal",
            "condition": {"type": "default"},
            "target": "agent_single_001"
          }
        ]
      }
    },
    {
      "id": "parallel_group_001",
      "type": "PARALLEL_GROUP",
      "execution_mode": "parallel",
      "max_parallel": 5,
      "nodes": ["agent_a", "agent_b", "agent_c"],
      "merge_strategy": "all_success",
      "next": ["terminal_001"]
    }
  ]
}
```

**条件跳转规则语法：**

| 运算符 | 含义 | 示例 |
|--------|------|------|
| EQUALS | 等于 | `field EQUALS "success"` |
| NOT_EQUALS | 不等于 | `field NOT_EQUALS null` |
| GT / LT | 大于/小于 | `count GT 10` |
| GTE / LTE | 大于等于/小于等于 | `score GTE 0.8` |
| CONTAINS | 包含 | `tags CONTAINS "urgent"` |
| REGEX | 正则匹配 | `email REGEX ".*@company.com"` |
| EXISTS / NOT_EXISTS | 字段存在性 | `error EXISTS` |

**复合逻辑：** AND / OR / NOT 任意嵌套组合

### 4.2 日志聚合查询

```sql
-- 查询某工作流全部日志（按时间排序）
SELECT * FROM workflow_logs 
WHERE trace_id = 'wf_R15_a3f2' 
ORDER BY timestamp;

-- 查询所有失败节点日志
SELECT node_id, level, message, context 
FROM workflow_logs 
WHERE level = 'ERROR' AND trace_id = 'wf_R15_a3f2';

-- 查询特定节点性能日志
SELECT node_id, 
       AVG(execution_time_ms) as avg_time,
       PERCENTILE(execution_time_ms, 0.95) as p95
FROM node_metrics
WHERE node_type = 'AGENT'
GROUP BY node_id;
```

## 五、v5.0 多Agent任务分发适配层

### 5.1 DAG拓扑自动分解

```
输入: 大型DAG工作流
  ↓
拓扑分析:
├─ 识别独立子图（可并行分发）
├─ 识别串行依赖链（单Agent顺序执行）
├─ 识别数据依赖（需Agent间通信）
└─ 计算最优Agent分配方案
  ↓
输出: Agent任务分配表
```

### 5.2 智能负载均衡

```
分发决策引擎:

1. Agent 能力画像:
   ├─ 计算能力: 推理速度(TPS) / 内存 / GPU
   ├─ 工具覆盖: 可用工具列表
   ├─ 当前负载: 排队任务数 / 活跃连接数
   └─ 历史表现: 同类任务成功率 / 平均耗时

2. 任务匹配:
   ├─ 能力匹配: 任务需求 ∩ Agent能力
   ├─ 负载均衡: 加权最小连接数算法
   ├─ 亲和路由: 同类型任务归集到同Agent
   └─ 容错: 任务失败自动重分配到备用Agent

3. 跨Agent流水线:
   ├─ Agent A → 数据预处理
   ├─ Agent B → 核心计算
   ├─ Agent C → 结果验证
   └─ Agent D → 格式化输出
```

### 5.3 结果聚合策略

| 策略 | 描述 | 适用场景 |
|------|------|---------|
| ALL_SUCCESS | 所有子任务成功才通过 | 刚性依赖 |
| ANY_SUCCESS | 任意一个成功即通过 | 冗余容错 |
| MAJORITY | 超过半数成功通过 | 投票决策 |
| WEIGHTED | 加权聚合 | 质量评分 |
| CONCAT | 结果拼接 | 独立子任务 |
| MERGE_SORTED | 排序合并 | 搜索结果聚合 |
