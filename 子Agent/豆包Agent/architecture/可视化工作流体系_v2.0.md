| 节点类型 | 标识 | v2.0新增 | 功能 |

| SUB_WORKFLOW | 子工作流 | ✅ | 嵌套子工作流，支持递归 |

| NOTIFY | 通知节点 | ✅ | 推送通知/邮件/消息 |

### 条件路由增强

```json
{
  "condition": {
    "type": "compound",
    "logic": "AND",
    "rules": [
      {"field": "{{node_001.output.score}}", "operator": "GREATER_THAN", "value": 0.7},
      {"field": "{{node_001.output.status}}", "operator": "EQUALS", "value": "valid"}
    ],
    "true_branch": "node_high_quality",
    "false_branch": "node_fallback"
  }
}
```

支持复合条件：AND / OR / NOT 逻辑组合

## 三、执行引擎增强

### 超时熔断与降级

```
节点执行:
  ├─ 开始 → 计时器启动
  ├─ 正常完成 → 结果传递
  ├─ 超时(30s) → 黄色告警 → 重试(最多3次)
  │   └─ 重试失败 → 降级策略：
  │       ├─ 有fallback_node → 切换到降级节点
  │       ├─ 有default_value → 使用默认值继续
  │       └─ 无降级 → 标记FAILED，跳过(若允许)
  └─ 超时(60s) → 红色告警 → 熔断 → 记录+终止
```

### 循环迭代增强

```
LOOP模式:
  ├─ max_iterations: 10
  ├─ convergence_check: 连续2轮结果差异<1% → 提前终止
  ├─ stall_detection: 连续3轮无变化 → 警告+终止
  └─ iteration_timeout: 单轮<30s
```

## 七、多Agent分发增强

### 分发策略矩阵

| 策略 | 描述 | 适用场景 |
|------|------|---------|
| ROUND_ROBIN | 轮询分发 | 同质多任务 |
| CAPACITY_AWARE | 容量感知 | 异构Agent负载均衡 |
| AFFINITY | 亲和性 | 同类型任务归集 |
| BROADCAST | 广播 | 全Agent通知 |

### Agent健康检查

```
dispatch前:
  ├─ Agent心跳检测 (最近30s内有响应)
  ├─ Agent负载评估 (当前任务队列深度)
  ├─ Agent能力匹配 (capability标签)
  └─ 决策 → 选择最优Agent
```
