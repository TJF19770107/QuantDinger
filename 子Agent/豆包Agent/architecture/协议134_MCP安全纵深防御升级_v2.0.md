## 三、纵深防御四层架构

```
Layer 4: 自进化层 (SecurityEvolution v1.0)
  └─ 攻击→抗体Skill自动生成 → NRP持续提升

Layer 3: 运行时沙箱层 (MCP Sandbox Node)
  └─ 隔离执行 → 响应安全检测 → 实时阻断

Layer 2: 调用前验证层 (Tool Signature & Parameter Check)
  └─ 工具名验证 → 描述审计 → 参数越权检测

Layer 1: 注册时审核层 (Tool Registry Audit)
  └─ 工具来源验证 → 签名校验 → 权限最小化
```

## 四、NRP指标集成

### 4.1 核心公式

```
NRP = PUA × (1 - ASR)

PUA (Performance Under Attack): 攻击环境中完成用户任务的比例
ASR (Attack Success Rate): 攻击成功率

豆包Agent NRP目标:
  R33 (v1.0): NRP = 0.72  (基础防御，仅Layer 1-2)
  R38 (v2.0): NRP = 0.88  (+Layer 3沙箱层)
  R40 (v3.0): NRP > 0.95  (+Layer 4自进化层全效)
```

### 4.2 NRP vs ASR vs PUA 三维平衡

```
关键反直觉发现 (MSB ICLR 2026):
  "能力越强的模型，反而越容易受到攻击"
  高PUA的模型同时有高ASR → 必须引入NRP平衡
  
豆包Agent策略:
  不降低PUA (保持高性能) + 降低ASR (四层防御) → NRP最大化
```
