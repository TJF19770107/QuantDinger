### 3.2 模式挖掘算法

```python
# 多模态模式挖掘
class PatternMiner:
    def mine(self, logs):
        patterns = []

        # 1. 频繁序列模式 (PrefixSpan)
        sequences = self._extract_tool_sequences(logs)
        freq_patterns = prefixspan(sequences, min_support=3)

        # 2. 关联规则 (Apriori)
        itemsets = self._extract_tool_itemsets(logs)
        rules = apriori(itemsets, min_confidence=0.6)

        # 3. 时序因果模式 (Granger)
        time_series = self._extract_metrics(logs)
        causal = granger_causality(time_series)

        # 4. 错误恢复模式 (异常→恢复配对)
        error_recovery = self._pair_errors_with_recovery(logs)

        return self._merge_patterns(freq_patterns, rules, causal, error_recovery)
```

### 4.1 四步进化循环

```
SICA v6.0 = Generate → Test → Evaluate → Select

┌─────────────────────────────────────────────────┐
│  Step 1: Generate (生成)                         │
│  ├─ 基础变异: 参数调整/步骤重排/条件增强        │
│  ├─ 交叉变异: 多Skill片段重组                    │
│  ├─ 反思变异: LLM分析失败原因定向改进            │
│  ├─ 创新变异: 引入新工具/新策略                  │
│  └─ 输出: N个候选变体 (默认10个)                 │
├─────────────────────────────────────────────────┤
│  Step 2: Test (测试)                             │
│  ├─ 沙箱隔离执行                                 │
│  ├─ 回归测试套件 (历史用例自动重跑)              │
│  ├─ AB对比测试 (新旧方案并行)                    │
│  └─ 输出: 每个变体的测试结果                     │
├─────────────────────────────────────────────────┤
│  Step 3: Evaluate (评估)                         │
│  ├─ 三维效用函数: U = α·E + β·S + γ·C           │
│  │   E=效能(成功率/耗时/Token效率)               │
│  │   S=安全(风险等级/合规性/鲁棒性)              │
│  │   C=成本(计算资源/存储/时间)                  │
│  ├─ 帕累托前沿筛选                               │
│  └─ 输出: 排序后的候选列表                       │
├─────────────────────────────────────────────────┤
│  Step 4: Select (选择)                           │
│  ├─ 效用值 > 接受阈值 (0.75) → 部署              │
│  ├─ 效用值 ∈ [0.4, 0.75] → 继续优化             │
│  ├─ 效用值 < 拒绝阈值 (0.4) → 丢弃               │
│  └─ 部署前: 版本快照 → 部署 → 验证 → 确认        │
└─────────────────────────────────────────────────┘
```

### 4.2 三维效用函数

```python
def utility_function(efficacy, safety, cost, weights=None):
    """
    U = α * efficacy + β * safety - γ * cost

    efficacy: 效能 = success_rate * 0.4 + speed_score * 0.3 + token_efficiency * 0.3
    safety:   安全 = (1 - risk_level) * 0.5 + compliance * 0.3 + robustness * 0.2
    cost:     成本 = compute_cost * 0.4 + storage_cost * 0.3 + time_cost * 0.3
    """
    w = weights or {"alpha": 0.45, "beta": 0.35, "gamma": 0.20}
    return w["alpha"] * efficacy + w["beta"] * safety - w["gamma"] * cost
```

### 4.3 自适应变异算子

```
变异算子选择策略 (UCB1):
├─ 每个变异算子维护: 成功次数/总次数
├─ UCB选择: argmax(成功率 + sqrt(2*ln(N)/n_i))
├─ 冷启动: 所有算子等概率
├─ 热运行: 偏向历史成功率高的算子
└─ 动态调整: 每10轮重新计算UCB值

变异算子池:

├─ LLM_REFLECT:   LLM反思变异 (成功率: 0.82)
```
