## 三、全双工交互标准

### 3.1 半双工 vs 全双工

```
传统半双工:
  User: [说] → Agent: [听→想→说] → User: [说] → ...
  单向交替，阻塞式

ELLSA全双工:
  User: [说+做手势] ←→ Agent: [同时听+看+想+说+做]
  双向同时，非阻塞
  支持: 打断/插话/并行操作/实时反馈
```

### 3.2 豆包Agent全双工实现

## 四、跨模态融合策略

### 4.1 融合时机决策

| 融合策略 | 适用场景 | 延迟 | 精度 |
|---------|---------|------|------|
| Early Fusion | 模态高度相关（语音+口型） | 低 | 中 |
| Late Fusion | 模态独立（图片+文本描述） | 高 | 高 |
| Hybrid Fusion | 复杂多模任务 | 中 | 高 |
| Dynamic Fusion | 自适应（默认） | 中 | 高 |

### 4.2 SA-MoE路由配置

```yaml
sa_moe_routing:
  text_expert:
    models: [claude-opus-4.8, claude-sonnet-4, deepseek-v3.1]
    context_window: 1M
  
  vision_expert:
    models: [claude-opus-4.8]
    resolution: [1080p, 4K]
    modalities: [image, video_frame, screenshot]
  
  speech_expert:
    models: [whisper-large-v3, ELLSA-speech]
    languages: [zh-CN, en-US, zh-dialect-22]
    mode: [transcription, synthesis, understanding]
  
  action_expert:
    models: [claude-opus-4.8 + Marvis工具层]

  fusion_expert:
```
