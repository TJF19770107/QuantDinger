## 五、AI on UI 实战集成

### UI操作→技能萃取管道

```
DesktopController截获UI操作序列
        │
        ▼
  序列规范化（去噪/去重/合并）
        │
        ▼
  SkillForge模式提取器
        │
        ▼
  生成 UI操作Skill (含控件树路径+操作序列+验证步骤)
        │
        ▼
  入库 → DesktopController下次直接调用Skill
```

### 多模型协作UI感知

| 模型 | 职责 | 触发条件 |
|------|------|---------|
| 主LLM | 理解用户意图 | 每次 |
| 视觉模型 | UI截图分析/控件识别 | 涉及UI操作时 |
| 轻量分类器 | 控件类型判定 | 每次UI交互 |
| OCR引擎 | 文本提取 | 需要读取界面文字时 |

