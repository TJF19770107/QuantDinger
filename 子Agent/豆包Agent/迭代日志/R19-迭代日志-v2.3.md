## 变更详情

### 新增：协议68 — 五层上下文压缩协议

- 对标 Claude Code v2.1 五层压缩
- GSM8K消融实验：准确率96.3%→95.1%（-1.2pp），上下文-77.3%
- 每次交互成本$0.27→$0.062（-77%）
- 第5层轻量模型1.5B蒸馏长程依赖

### 新增：协议69 — 动态子Agent工作区隔离协议

- 对标 Antigravity 2.0 动态子Agent + Claude Code 并行子Agent
- 最大并行：Claude 7个（生产）→ Antigravity 93个（演示）
- 隔离级别：文件系统独立、上下文独立、权限≤父级
- HumanEval：28.3s→4.7s（6.0x）

### 新增：协议70 — 事件驱动自主触发器协议

- 对标 Codex Triggers + Antigravity Scheduled Tasks + Hermes定时启动
- 支持4种触发源：cron定时、GitHub事件、Webhook、文件变更
- Codex全自动流水线：Issue→扫描→修改→测试→PR
- 高危操作禁止无人值守

### 新增：协议71 — 分层本地推理路由协议

- 对标 Ollama v0.17.7 vs vLLM v0.17.0
- 决策：1-4用户→Ollama / 5+用户→vLLM / 边缘→llama.cpp
- 50并发：vLLM 920 tok/s vs Ollama ~140 tok/s（6.6x）
- RTX 4090 70B：基准4→优化后41 tok/s（10.3x）

### 新增：协议72 — 三层GUI感知行动协议

- 对标 GUI Agent 三层架构 + Codex Appshots
- 两种路线：Cloud+Screenshot vs Local+Accessibility API
- 元素定位三级优先级：文本 > 布局 > 图像
- 4项安全约束：沙箱、脱敏、审计、人机闸门
