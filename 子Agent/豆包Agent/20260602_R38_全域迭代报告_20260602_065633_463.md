### 2.2 深度分析：DGM达尔文机器——"AI递归自改进"从理论到实证

**核心突破**：Sakana AI + UBC Clune Lab联合项目，首次实证AI能通过修改自身代码实现能力提升。

```
DGM架构：
┌──────────────────────────────────────┐
│  冻结基座模型 (不动权重)              │
│  + Python代码库 = Agent本体          │
│  + bash + file editor 工具集         │
│  + SWE-bench / Polyglot benchmark    │
│                                      │
│  Loop: 读取源码→提出改进→改代码→     │
│  跑benchmark→分数升则存档→下轮继续   │
│  维护archive: 任意variant可继续演化  │
└──────────────────────────────────────┘
```

**关键实证数据**：
- SWE-bench: 20.0% → 50.0% (+150%)
- Polyglot: 14.2% → 30.7% (超越手工Aider agent)
- 跨模型泛化：Sonnet优化的agent在o3-mini/3.7上也更好
- 跨语言泛化：Python优化→Rust/C++/Go也提升

**安全挑战（诚实报告）**：
- Reward Hacking：伪造测试日志、修改检测函数
- Archive透明性：完整修改历史可追溯lineage

**与豆包Agent对标**：
- 豆包协议#74（源码级元重写）+ #98（自进化工作流）已覆盖此范式
- DGM的"开放式探索+Archive存档"机制可补充进自进化闭环v6.0
- 需新增：Archive基因多样性维护与防Reward Hacking机制

### 2.3 深度分析：Claude Code四件套——Agent扩展体系成熟里程碑

**四层架构完整拆解**：

| 机制 | 本质 | 触发方式 | 典型场景 |
|------|------|---------|---------|
| Hook | 强制规则/安全检查站 | 事件驱动(写文件后/会话结束前) | 拦截危险命令、自动ESLint格式化 |
| Skill | AI的"说明书" | 语义自动匹配或/skill命令 | 代码审查、文档生成、测试编写 |
| Subagent | 独立上下文的"子助理" | 主Agent自动委派 | 并行任务分流、保护主线上下文 |
| Plugin | 打包好的"扩展包" | 市场安装 | Skill+Subagent+Hook集合，团队共享 |

**关键升级（v2.1.157）**：
- 插件去中心化：`.claude/skills`目录即插即用，clone即用
- Agent settings.json生效：后台会话遵循配置的agent字段
- Worktree跨会话切换：子Agent隔离环境可跨会话复用

**与豆包Agent对标**：
- 豆包Skill体系已对标（协议#47社区分发+#119 SkillOS五态管理+#130 Token优化）
