## 二、核心情报详情

### 情报 #1: BayesianPersuasion — 多Agent框架架构原语统一分析

**来源**: https://bayesianpersuasion.com/posts/architectural-primitives-multi-agent-frameworks
**长度**: 44,612字符
**价值等级**: ⭐⭐⭐⭐⭐

**核心发现**:
- 12+框架收敛为4个不可再分原语：LLM推理引擎、工具调用接口、while-loop执行器、上下文窗口管理器
- 三大主流框架：OpenClaw (138K GitHub Stars)、Hermes Agent (81K Stars)、Claude Agent SDK
- OpenClaw核心理念：agents are config, not code。Agent = SOUL.md + workspace + model + memory + tools
- Hermes核心：self-improving learning loop (Execute→Evaluate→Extract→Refine→Retrieve)
- Claude SDK核心：subagent isolation（子Agent不能嵌套，严格通信边界）
- MCP已收敛为标准化层，ReAct loop为规范执行模式
- 三个本质分歧：代码即行动 vs JSON工具调用、图编排 vs 对话编排、集中式 vs 去中心化
- OpenClaw Gateway: WebSocket ws://127.0.0.1:18789，23+渠道，确定性Binding Rules（零LLM参与路由）
- 记忆子系统五层架构：对话历史→结构化记忆→语义/向量记忆→情节/长期记忆→元记忆
- ClawHub: 5,400+社区技能，VirusTotal安全扫描，独占槽位插件系统
- 模型Provider: 30+ Provider, vLLM一等公民, failover链, cost tracking
- 多Agent协调: sub-agent spawning (maxDepth 1-2, maxConcurrent 8), P2P messaging, addressable sessions, Lobster YAML工作流, Octopus编排器

### 情报 #2: Brightlume — 长周期AI Agent调度/持久化/恢复模式

**来源**: https://brightlume.ai/blog/long-running-ai-agents-scheduling-durability-recovery
**长度**: 28,735字符
**价值等级**: ⭐⭐⭐⭐⭐

**核心发现**:
- 长任务Agent与聊天机器人的本质区别：状态持久化、异步调度、部分故障处理、可观测性、合规治理
- 三种调度模式：事件驱动（SQS/PubSub/RabbitMQ）、定时调度（Cron）、混合模式
- 三层持久化：检查点状态管理（执行状态+工具结果+Agent记忆+时间戳）、幂等工具调用（UUID+状态验证+结果缓存）、优雅降级（失败模式定义+短超时+备选方案+全量日志）
- 三种恢复模式：指数退避（1s→2s→4s→8s→16s，5次上限）、熔断器（Closed→Open→Half-Open，3次失败触发）、死信队列（全量重试耗尽→入死信→修复后重放）
- 生产环境Agent架构：Agent Runtime + State Store (PostgreSQL/DynamoDB) + Message Queue + 工作节点池
- 幂等性关键设计：Stripe/AWS/Google Cloud原生支持幂等键
- Healthcare/Finserv/Hospitality三个行业实战案例

### 情报 #3: Marvis架构深度分析

**来源**: CSDN (https://blog.csdn.net/2401_87961121/article/details/161323432) + 腾讯云 + 腾讯网 + 网易
**价值等级**: ⭐⭐⭐⭐

**核心发现**:
- 1主Agent + 5副Agent：PM(任务拆解/调度/汇总) + File(文件搜索/识别/OCR) + Computer(Windows API直调) + App(GUI视觉识别+模拟操作) + Browser(DOM解析) + Search(网络搜索)
- 端云双模自动路由：效率模式(混元+DeepSeek V4云端推理) vs 隐私模式(Qwen端侧+Intel OpenVINO)
- OS级AI中间层：用户→自然语言→操作系统API→文件/设置/应用/硬件
- 端侧能力：本地文件索引+语义搜索(图片文字/人脸/场景识别)
- 跨端协同：Windows/Mac/Android/iOS同账号，端到端加密
- L2级安全兜底：删除/系统核心配置/支付 → 硬垂询确认
- 日1000万Token免费额度

### 情报 #4: HyperAgents深度解析

**来源**: https://cloud.tencent.com.cn/developer/article/2650918
**价值等级**: ⭐⭐⭐⭐

**核心发现**:
- Meta FAIR开源，双层架构：Task-Agent(执行) + Meta-Agent(观察/生成patch/修改)
- 5代进化：准确率 0% → 80% (claude-opus-4.6)
- Archive档案库：不淘汰任何成员，维持种群多样性
- 5种父代选择策略：best/latest/score_child_prop/uniform/tournament（默认score_child_prop）
- 分阶段评估（Staged Eval）：10%快速验证→达阈值才跑全量
- Docker容器隔离执行
- 跨域迁移：代码→论文审稿→机器人控制→数学证明
- 模型越强进化效果越好 → "强者恒强"
