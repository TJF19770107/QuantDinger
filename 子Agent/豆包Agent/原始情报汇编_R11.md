**① 编程式工具调用 (Programmatic Tool Calling)**
- LLM输出TypeScript代码直接编排多个工具
- 支持for循环、条件语句、变量处理
- Token消耗减少30-50%
- 通过allowed_callers白名单授权

- 中间层代码在HTML进入上下文窗口前过滤
- Token消耗减少24%
- 仅提取相关内容

**③ 可扩展工具搜索 (Tool Search)**
- 500 token工具搜索替代全量加载
