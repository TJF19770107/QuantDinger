## 二、功能节点拆分 v4.0

### 2.1 完整节点类型（扩容至15种）

| 类型 | 标识 | 功能 | 输入 | 输出 |
|------|------|------|------|------|
| 触发节点 | START | 工作流入口 | 用户指令/定时信号/事件心跳 | 任务对象 |
| 意图解析节点 | PARSE | 意图识别+实体提取+难度分级 | 原始输入 | TaskObject v4.0 |
| 上下文注入节点 | CONTEXT | 三级缓存上下文注入 | TaskObject | 增强TaskObject |
| 条件判断节点 | IF | 条件分支路由 | 任意数据 | TRUE/FALSE分支 |
| 多路分支节点 | SWITCH | 多条件多路分支 | 任意数据 | N条分支路径 |
| 任务执行节点 | EXEC | 调用工具/Agent执行 | 任务参数 | 执行结果 |
| 数据转换节点 | TRANSFORM | 格式转换/清洗/聚合 | 原始数据 | 转换后数据 |
| 并行分叉节点 | FORK | 拆分并行子任务 | 任务列表 | 多路并行 |
| 并行汇聚节点 | JOIN | 等待所有并行任务 | 多路结果 | 合并结果 |
| 循环节点 | LOOP | 条件循环 | 循环体+条件 | 最终结果 |
| 人工确认节点 | CONFIRM | 暂停等待用户确认 | 确认内容 | 确认/取消 |
| 自进化注入节点 | EVOLVE | SICA变异测试注入 | 当前状态 | 变异方案 |
| 产物输出节点 | OUTPUT | 最终产出物声明 | 产物路径 | yyb-product卡片 |
| 异常处理节点 | CATCH | 捕获异常并降级 | 异常对象 | 降级方案 |
| 终止节点 | END | 工作流结束 | 最终状态 | 完成信号 |

## 三、串行/并行/条件跳转规则 v4.0

### 3.1 串行执行增强

```
触发: 节点间存在数据依赖
标识: "next": ["node_002"]
增强: 
- 流水线模式: A完成即触发B(A输出流式传递给B)
- 检查点模式: A完成后保存快照再触发B
- 事务模式: A→B原子执行(A失败则B不执行)
```

### 3.2 并行执行增强

| 策略 | v3.0 | v4.0增强 |
|------|------|---------|
| 最大并行数 | 固定5 | 动态(根据系统负载: 2~8) |
| 批次间隔 | 100ms | 自适应(负载低→50ms, 负载高→200ms) |
| 超时 | 300s固定 | 分级(L1:60s/L2:120s/L3:300s) |
| 优先级 | 无 | FIFO+优先级抢占(高优任务插队) |
| 资源隔离 | 无 | 每并行任务独立沙盒(协议36) |

**动态并行度算法**:
```
parallel_degree = max(2, min(8, base * cpu_factor * memory_factor))
cpu_factor = 1.0 - (cpu_usage - 0.5)  # CPU>50%开始降并行
memory_factor = 1.0 - (mem_usage - 0.6)  # 内存>60%开始降并行
```

### 3.3 条件跳转增强

| 特性 | v3.0 | v4.0增强 |
|------|------|---------|
| 条件类型 | ==, !=, >, <, in, contains | + regex_match, semantic_match, confidence>threshold |
| 分支数量 | 2路(IF) | 2~N路(SWITCH新增) |
| 多条件组合 | 无 | AND/OR/NOT逻辑组合 |
| 条件缓存 | 无 | 重复条件缓存(相同条件跳过计算) |
| 默认分支 | 无 | default_fallback节点 |

**SWITCH多路分支示例**:
```json
{
  "type": "SWITCH",
  "on": "result.domain",
  "cases": {
    "file": "node_file_handler",
    "system": "node_system_handler",
    "app": "node_app_handler",
    "search": "node_search_handler"
  },
  "default": "node_unknown_domain"
}
```

## 五、节点监控 v4.0

### 5.1 增强监控指标

| 指标 | 采集方式 | v4.0告警阈值 | 自动动作 |
|------|---------|-------------|---------|
| 节点耗时 | 时间戳diff | >60s告警 / >120s熔断 | 降级或切换备用工具 |
| 连续失败 | 状态计数 | 3次→熔断(10min) / 5次→永久跳过 | 通知SICA启动变异探索 |
| 内存占用 | psutil | >500MB告警 / >1GB熔断 | 释放缓存+降低并行度 |
| 工具调用频率 | 调用计数 | >100次/min限流 | 批次合并+冷却 |
| 产出物大小 | 文件大小 | >50MB告警 | 分段输出 |
| 推理tokens | 估算 | >上下文预算80%告警 | 触发压缩/分片 |
| 用户等待时间 | 端到端 | >30s告警 | 发送进度通知 |

### 5.2 增强熔断机制

```
连续失败3次 → 自动熔断(10分钟)
熔断期间 → 跳过该节点，执行fallback降级
SICA自动探索 → 生成变异方案替代熔断节点
10分钟后 → 半开状态，允许1次试探
试探成功 → 恢复 + 变异方案入库
试探失败 → 再次熔断(30分钟) + 标记高风险
```
