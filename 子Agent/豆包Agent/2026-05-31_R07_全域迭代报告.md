## 二、重点框架深度分析

### 2.1 Autogenesis Protocol (AGP) — 自进化操作系统

**核心架构**：双层协议解耦

```
RSPL (Resource Substrate Protocol Layer)     → 定义"什么可以进化"
  ├── Prompt   → 可注册/检索/更新/回滚/审计
  ├── Agent    → 一等注册实体
  ├── Tool/MCP/Skill → 版本化工具资源
  ├── Environment → 沙箱环境资源
  └── Memory   → 持久记忆资源

SEPL (Self-Evolution Protocol Layer)         → 定义"如何安全进化"
  └── Reflect → Select → Improve → Evaluate → Commit
```

**关键数据**：
- GAIA Validation: 93.33%
- GAIA Test: 89.04%（vs Vanilla 79.07%，提升12.61%）
- HLE全量: 59.6%（排名第二，仅次于Claude Mythos Preview）
- LeetCode C++: 接近满分

**豆包Agent可借鉴点**：
- RSPL的资源注册/版本管理机制 → 升级SafeGuard的检查点系统
- SEPL的五步自进化闭环 → 整合到SkillForge v4.0
- 资源治理理念：从"代码工程"迈向"资源治理"

### 2.2 HyperAgents — 递归自修改进化

**核心架构**：
```
meta-agent (观察者/改造者)
    ↓ 读取代码库+历史评分 → 输出diff/patch
task-agent (被进化对象)
    ↓ 执行任务 → 返回评分
Archive (种群记忆) → 维护多样化agent集合
```

**递归自修改亮点**：`select_next_parent.py` 本身也在可修改范围内，系统可以进化出"更聪明的父代选择策略"。

**豆包Agent可借鉴点**：
- Archive多样化种群维护 → 升级SkillForge的技能生成策略
- 父代选择5种策略（best/latest/random/score_prop/score_child_prop）
- 分阶段评估（Staged Eval）节省API成本

### 2.3 Claude Managed Agents — 持久化执行容器

**核心能力**：
- 长时间运行（数分钟到数小时）
- 持久文件系统 + 对话历史
- 内置工具：Bash/Read/Write/Edit/Glob/Grep/WebFetch/WebSearch/MCP
- 容器沙箱隔离
- SSE流式事件

**豆包Agent可借鉴点**：
- WebFetch+WebSearch内置能力 → 对应已有web_search/web_fetch
- 持久化会话设计 → 对应MemoryOS长期记忆
- 工具配置控制粒度 → 升级DesktopController

## 三、R07新增技能协议（2项）

### 协议25: AGP式双层资源治理协议 v1.0

**对标来源**: Autogenesis Protocol (NTU/Stanford/Princeton, 2026.05)

**核心价值**: 将智能体内部组件（Prompt/Agent/Tool/Environment/Memory）全部抽象为协议注册资源，配备显式状态、生命周期、版本接口和可演化标记，实现可追踪/可回滚/可审计的闭环自进化。

**关键规范**：
1. **RSPL资源注册**: 所有组件必须通过统一接口注册，获得唯一资源ID
2. **版本管理**: 每次修改生成新版本号，保留完整版本链
3. **SEPL进化闭环**: Reflect→Select→Improve→Evaluate→Commit 五步不可跳过
4. **回滚机制**: 任意版本可一键回滚，回滚操作本身也是版本化记录
5. **审计追踪**: 所有资源变更自动记录who/when/what/why

**与现有协议关系**:
- 升级协议24（自愈回滚检查点）→ 增加资源级版本管理
- 升级协议21（CASCADE技能习得）→ 增加SEPL闭环控制
- 升级SafeGuard v3.0 → 增加资源变更审计

### 协议26: HyperAgents式种群进化协议 v1.0

**对标来源**: HyperAgents (Meta, 2026.03)

**核心价值**: 采用进化算法思想，维护多样化Agent种群（Archive），meta-agent观察task-agent表现自动生成代码补丁，支持递归自修改（进化"如何进化"）。

**关键规范**：
1. **Archive种群**: JSONL格式维护所有历史版本，不做淘汰，保持多样性
2. **父代选择**: 5种策略（best/latest/random/score_prop/score_child_prop），默认score_child_prop
3. **分阶段评估**: 先用10%样本快速评估，达标才展开完整评估
4. **递归自修改**: 选择策略本身也在可进化范围内
5. **隔离执行**: 每代在独立Docker容器中运行

**与现有协议关系**:
- 升级协议21（CASCADE）→ 引入Archive种群多样化
- 新独立协议，补充SkillForge v3.0的生成策略
