## 四、供应商无关LLM抽象

核心概念：**Route路由**

```
用户请求 → Route选择器
  ├─ GPT-5 路由 → OpenAI
  ├─ Claude 路由 → Anthropic
  ├─ Gemini 路由 → Google
  └─ 本地模型路由 → Ollama/LocalAI
```

75+供应商统一接口，自由切换无锁定。

## 五、多代理编排 (v1.3.0+)

- 背景子代理：后台异步执行独立任务
- 并行工作树：隔离git worktree，无合并冲突
- 代理间通信：通过共享状态层

## 六、LSP自动集成

根据项目语言自动启用对应的Language Server Protocol：
- TypeScript → tsserver
- Python → pyright
- Rust → rust-analyzer
- Go → gopls

## 七、可融合要点

1. **Effect风格DI**：Marvis工具/模型层解耦，支持热插拔
2. **供应商无关路由**：模型选择与业务逻辑分离
3. **LSP自动加载**：编码场景自动语言感知
4. **TUI界面**：终端友好的交互体验
5. **权限系统**：Shell命令白名单，安全沙箱
