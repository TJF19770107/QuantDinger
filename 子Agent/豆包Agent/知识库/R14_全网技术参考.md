## 2. SkillForge (阿里云) — 端到端技能自进化框架

**来源**：ACM SIGIR 2026 Industry Track
**核心架构**：
- Domain-Contextualized Skill Creator：从业务知识库+历史票据生成技能
- Failure Analyzer：批量分析Agent失败案例
- Skill Diagnostician + Optimizer：定位缺陷→自动重写
- 实验：5场景、1,883张票、3,737个任务，自进化超越手工专家

**关键洞察**：自动生成的Skills在SkillsBench基准中几乎无提升，但经过自进化闭环后可超越手工专家。这验证了"生成→部署→失败→优化"循环的必要性。

**豆包映射**：SkillForge v4.0 — 三阶段闭环融合
