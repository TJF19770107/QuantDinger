### 3.2 协议详情

#### 协议#101: AI劳动力市场代理接入协议 v1.0

**来源**: Workfoz (2026-05-26) + OpenClaw Skill生态
**核心机制**:

```
雇主发布任务 → AI Agent自动读取需求
    ↓
AI Agent竞标 (Bid + 价格 + 交付时间)
    ↓
协商与确认 (智能合约锁定)
    ↓
自主完成交付 (文件/API/部署)
    ↓
验收与评分 (信誉系统积累)
```

**豆包Agent适配路径**:
- 接入Workfoz API，豆包Agent作为Worker注册
- OpenClaw Skill一键部署为市场适配层
- 信誉系统与豆包自进化评分体系双向绑定
- 市场任务作为自进化训练数据源

#### 协议#102: 自指元Agent深度进化协议 v2.0

**来源**: HyperAgents DGM-H (arxiv 2603.19461, Meta FAIR + UBC + Vector Institute)
**升级**: 在协议#28（SICA元Agent编程）基础上叠加DGM-H机制

**核心增强**:
| 机制 | SICA (协议#28) | DGM-H增强 |
|------|---------------|----------|
| 元级自修改 | 元Agent独立存在 | Task+Meta同一可编辑程序 |
| 父代选择 | 单一选择策略 | 5种选择策略(best/latest/score_child_prop/uniform/tournament) |
| 基因多样性 | 不保证 | Archive保留所有历史版本 |
| 评估效率 | 全量评估 | 分阶段评估(10%→全量) |
| 跨域迁移 | 不支持 | 代码→审稿→机器人→数学 |

#### 协议#103: 多后端沙箱弹性部署协议 v2.0

**来源**: OpenClaw v2026.3.22 Breaking Change
**升级**: 在协议#23（桌面Agent工作区隔离）基础上叠加多后端支持

**三后端架构**:
```
Sandbox Backend Layer
├── Docker Backend: 容器隔离，适合Linux/macOS
├── SSH Backend: 远程执行，secret-backed密钥，适合企业内网
└── OpenShell Backend: 轻量级，支持mirror/remote workspace，适合Windows
```

**安全增强**: 可插拔后端 + per-agent执行环境注入限制 + secret-backed认证

#### 协议#104: Agent意图市场标准接口协议 v1.0

**来源**: Workfoz Marketplace API + OpenClaw openclaw.json声明式
**标准接口定义**:

```json
{
  "market": {
    "endpoint": "https://api.workfoz.com/v1",
    "agent_id": "doubao-r29",
    "capabilities": ["coding", "writing", "analysis", "automation"],
    "bid_strategy": "auto",
    "max_concurrent_jobs": 5,
    "price_range": {"min": 10, "max": 500}
  }
}
```
