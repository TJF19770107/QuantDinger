## 二、R28 新技能协议提取

### 协议 #96：Multi-Agent Team协作协议 v1.0

**对标来源**: 扣子3.0 + Antigravity 2.0 Dynamic Subagents

**核心架构**:
```
项目空间 (Project Space)
  ├── 目标定义层: 任务目标 + 验收条件 + 成员角色
  ├── Agent注册层: 本地Agent(Claude Code/Codex/OpenClaw) + 云端Agent
  ├── 任务分配层: 主Agent拆解 → 子Agent认领 → 并行执行
  ├── 上下文共享层: 文件/产出物/记忆 统一项目空间共享
  └── 结果聚合层: 子Agent结果 → 主Agent Review → 最终产出
```

**关键能力**:
- Agent Team组建：多Agent同项目空间、不同职能分工协作
- 本地+云端混合：Claude Code/Codex CLI/OpenClaw本地接入 + 云Agent长期运行
- 项目空间：独立任务管理、目标/成员/Agent/文件/产出统一整合
- 跨Agent上下文共享：文件系统和记忆统一命名空间
- 三端同步：Web/Desktop/Mobile全端Agent可接入同一项目

**豆包Agent融合方案**:
- 豆包Agent主控中心升级为"项目空间"模式
- 支持同时接入Codex/Claude/Hermes作为子Agent
- 统一产出物目录 + 共享记忆库
- 子Agent互发现：Agent A的产出自动被Agent B感知

### 协议 #97：Native Windows Agent零依赖部署协议 v1.0

**对标来源**: Hermes Agent Windows原生支持

**核心架构**:
```
Windows 10/11 原生运行栈
  ├── 免WSL/Cygwin/Docker → 零依赖启动
  ├── Git Bash Shell引擎 → 跨平台命令兼容
  ├── PortableGit 45MB → 无感捆绑启动
  ├── UTF-8自动配置 → CP_UTF8(65001)控制台
  ├── 计划任务自启 → 免管理员权限开机自启
  └── Python I/O重构 → 原生stdin/stdout流
```

**关键能力**:
- 零依赖：不需要WSL、Cygwin、Docker任何一层
- PortableGit嵌入：45MB轻量Git Bash环境，自动检测系统Bash.exe路径
- 字符集自动适配：控制台代码页自动切换UTF-8
- 计划任务集成：Windows Task Scheduler实现开机自启，避免管理员权限
- 15+ IM网关：微信/Telegram/Discord等多平台消息接入

**豆包Agent融合方案**:
- 豆包Agent Windows版免WSL/Docker直接运行
- 集成PortableGit实现跨平台Shell兼容
- UTF-8字符集自动适配模块
- 计划任务实现后台常驻 + 定时唤醒

### 协议 #98：Agent-as-Infrastructure范式协议 v1.0

**对标来源**: 黄仁勋GTC Taipei 2026 + Gemini Spark 7x24

**核心论点**:
> "每家公司都需要Agent战略，如同当年必须有Linux、互联网、云战略。" — 黄仁勋, GTC Taipei 2026

**架构转型**:
```
旧范式: 计算机运行应用程序
  └── App → 用户操作 → 完成任务

新范式: 计算机运行AI Agent  
  └── Agent → 自主规划 → 自主执行 → 自主交付
```

**关键能力**:
- Agent定位升级：从"工具"到"基础设施"
- 7x24持久运行：Gemini Spark云端VM不间断服务
- 端侧部署：数据主权优先，敏感数据不出本地
- 按效付费：商业模型从按调用付费转向按结果付费
- 行业技能包：投研/法务/科研/自媒体等垂直领域预置Agent

**豆包Agent融合方案**:
- 豆包Agent从"助手"定位升级为"基础设施层"
- 本地7x24后台常驻模式
- 数据主权保护：敏感操作100%本地执行
- 行业技能包体系：预置垂域Agent模板

### 协议 #100：Agent Relay任务接力协议 v1.0

**对标来源**: 飞书Multi-Agent接力 + Antigravity Dynamic Subagents

**核心架构**:
```
任务接力链:
  Agent A (任务拆解) → 产出: 结构化任务简报
    ↓ 自动@交接
  Agent B (专业处理) → 产出: 领域分析结果
    ↓ 自动@交接
  Agent C (结果聚合) → 产出: 最终交付物
    ↓ 自动通知
  用户 (审核确认)
```

**关键能力**:
- 自动任务交接：Agent A完成后自动@Agent B，无需人工中转
- 结构化交接对象：任务简报包含来源/产出/下一步/负责人
- 接力链追踪：完整记录每个Agent的输入→处理→输出
- 失败回传：子Agent失败时自动回传上游重分配
- 并行+串行混合：部分子Agent并行执行，依赖节点串行

**豆包Agent融合方案**:
- 豆包Agent子任务系统支持自动@交接
- 结构化任务简报格式标准化
- 接力链可视化追踪
- 失败自动回传 + 重分配机制
