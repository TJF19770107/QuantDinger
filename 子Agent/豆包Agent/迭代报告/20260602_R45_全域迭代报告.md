### 协议#164：SkillOpt文本空间技能优化协议 v1.0

**对标来源**：Microsoft Research SkillOpt（arXiv:2605.23904 / GitHub 3.3K Stars）

**核心能力**：
- **技能=可训练参数范式**：冻结Agent模型权重，仅优化技能文档文本（300-2000 tokens）
- **五组件训练闭环**：Rollout（采样轨迹）→ Reflect（分析成功/失败）→ Bounded Edit（有界编辑，cosine学习率调度）→ Validation Gate（验证门控）→ Export（导出最佳技能）
- **52/52全优战绩**：7个目标模型×6个基准×3种执行环境，全部52组合取得最优或并列最优
- GPT-5.5 Direct Chat +23.5分 / Codex +24.8分 / Claude Code +19.1分
- **防退化机制**：有界编辑（文本编辑预算cosine衰减）+ Validation Gate（低于基线拒绝更新）
- 与深度学习对等映射：Rollout=Forward Pass / Reflection=Backward Pass / Bounded Edit=Parameter Update / Validation Gate=Early Stopping

**价值**：从"手工写技能→一次性生成→无约束自我修订"三步手工艺，升级到"和神经网络训练同等纪律"的工程化路径。Agent技能首次拥有学习率、验证集、负反馈约束。

### 协议#165：GUI Agent记忆增强自进化协议 v1.0

**对标来源**：SE-GA ICML 2026（天津大学+上海交大 / arXiv:2605.16883）

**核心能力**：
- **分层记忆结构**：L1短期轨迹缓存 + L2关键帧抽取 + L3语义模式压缩，三层记忆逐步抽象
- **迭代自我改进**：从失败轨迹中识别因果链→提炼可复用动作模板→注入下次执行上下文
- **上下文窗口突破**：关键信息通过分层记忆跨窗口保留，解决多步骤任务中"早期信息丢失→误差累积→连锁失败"的致命问题
- **静态→动态范式转换**：GUI Agent从"使用固定数据集训练的静态策略"进化为"从经验中持续学习的动态学习者"
- ICML 2026正式接收，多个基准验证有效

**价值**：解决当前GUI Agent两大核心短板——"记不住"（上下文窗口受限导致关键信息丢失）和"学不会"（静态策略无法从经验迁移）。为桌面Agent长程任务执行提供记忆基础。
