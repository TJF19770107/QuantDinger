#### 情报1：OpenClaw 2026六层纵深隔离体系

| 层 | 名称 | 技术 | 特点 |
|----|------|------|------|
| L0 | 硬件信任根 | AMD SEV-SNP / Intel TDX + TPM 2.0 远程证明 | 宿主机/云厂商不可读内存 |
| L1 | 微虚拟机 | Firecracker Nano-VMs / Kata Containers | 非共享内核，攻击面减90% |
| L2 | 用户态内核 | gVisor Sentry 系统调用拦截 | 所有syscall在用户态执行 |
| L3 | 内核观测 | eBPF行为异常检测 | 实时监控fork炸弹/异常文件访问，秒级杀容器 |
| L4 | 只读文件系统 | 不可变Root + COW内存交换 | 任何系统目录写入失败；停止后内存粉碎清零 |
| L5 | 零信任网络 | eBPF mTLS Sidecar + 出口白名单 | C2通联内核级拦截；蜜罐陷阱 |
