## 四、情报融合分析

### 4.1 Live-SWE-agent（情报#578）

**核心创新**：运行时自演化（Runtime Self-Evolution）—— Agent在解决软件工程问题的过程中，动态扩展和修改自身驱动逻辑和工具，而非部署后能力固定。

**与豆包对标**：
- 豆包自进化闭环v6.0已覆盖"执行→反思→沉淀→升级"的事后循环
- Live-SWE-agent补充了"执行中实时扩展工具"的视角
- **行动**：新建协议#185 龙虾-Agent运行时自演化协议 v1.0

### 4.2 AI工作流范式迁移（情报#579）

**核心变化**：Coding Agent从"被调用的功能"→"可运行/可观察/可恢复/可管理的执行单元"。

**关键概念**：
1. playbook固化协作模式（已有协议#124 ACE上下文工程覆盖）
2. 日志复盘积累组织记忆（已有协议#29 Dreaming+#107分层记忆覆盖）
3. 权限清单管理边界（已有协议#118影子Agent安全复盘覆盖）

**行动**：新建协议#186 龙虾-Agent工作流托管协议 v1.0，将三者系统化整合。

### 4.3 Coze 3.0 Agent Team（情报#580）

**核心验证**：本地Agent（Claude Code/Codex CLI/OpenClaw）可直接接入扣子项目空间，与云端原生Agent协同完成同一项目。

**与豆包对标**：已有协议#141/161覆盖Coze 3.0 Agent Team生态对接。**无需新建协议**，但可触发协议#161 v3.0升级（增加"本地Agent资源隔离"条款）。

1. **playbook固化**：成功协作模式写入项目级playbook，新人可直接复用

3. **权限清单**：白名单（允许Agent执行的命令）+黑名单（禁止执行的命令）+人工审核节点
