## 三大协议深度解析

### 协议117：三层自进化引擎

```
L1 实时反思引擎（脏计数触发）
  ├─ 工具迭代≥8 → 自动fork影子Agent
  ├─ 异步复盘对话轨迹
  └─ 提取技能/记忆/模板写入技能库

L2 延迟统计引擎（边车文件）
  ├─ 毫秒级技能使用数据埋点
  ├─ 活性状态自动流转（活跃→陈旧→归档）
  └─ 数据驱动决策，避免LLM主观偏差

L3 定期合并引擎（Curator馆长）
  ├─ 7天周期自动巡检
  ├─ 语义相似度+使用热度+场景覆盖率三维评分
  ├─ 伞状合并碎片化窄技能→通用主技能
  └─ 归档过期技能、复活有效技能

双向联动：正向（L1→L2→L3）+ 反向（L3↔L2↔L1）
```

### 协议118：影子Agent安全复盘

六层舱壁隔离：
1. **权限隔离**：影子Agent只有最小只读权限
2. **数据隔离**：仅注入摘要，不注入原始会话数据
3. **网络隔离**：禁止外联网访问
4. **文件隔离**：只能写入技能库，不能读写其他文件
5. **进程隔离**：fork独立子进程，与主会话完全解耦
6. **审计隔离**：全操作日志独立记录，不污染主会话审计

| 安全机制 | 对标来源 | 龙虾落地 |
|---------|---------|---------|
| 脏计数精准触发 | Hermes Dirty Counter | 工具迭代≥8触发阈值 |
| 误进化断路器 | ICLR 2026四条误进化路径 | 连续3次异常→熔断→人工确认 |
| git回滚 | A-Evolve五阶段Gate | 每次迭代打tag，退步自动回滚 |
| 心跳检测 | Hermes Goal模式 | 15秒心跳，30秒超时→僵死标记 |

### 协议119：SkillOS五态管理

```
新生(NEW) → 活跃(ACTIVE) → 休眠(DORMANT) → 归档(ARCHIVED)
                ↑                                    │
                └────────── 复活(REVIVE) ←───────────┘

策展周期：7天自动评分 → 合并 → 清理
保护机制：pin固定技能 → bundled受保护 → hub源不可修改
质量门控：模型评分(40%) + 使用热度(30%) + 场景覆盖率(30%)
```
