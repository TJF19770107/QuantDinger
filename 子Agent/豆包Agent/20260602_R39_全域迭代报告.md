**核心能力**:

**协议状态**: ✅ 已落地

**对标来源**: Microsoft Work IQ A2A协议(IETF草案) + Copilot Studio A2A GA + Google A2A

**核心能力**:

- 混合部署互通：豆包Agent ↔ Copilot Studio Agent ↔ Gemini Agent 无需自定义适配器
- 组织级上下文共享：跨Agent共享用户画像+任务上下文+安全凭证

**协议状态**: ✅ 已落地

### 协议 #138: 龙虾-多模型动态路由调度协议 v2.0

**对标来源**: Microsoft Copilot多模型路由 + OpenCode Zen 75+Provider

**核心能力**:
- 任务特征→模型能力映射：编码→Codex/Claude，推理→Gemini，本地执行→Llama
- 成本感知路由：Token单价×预期消耗量实时优化，目标成本-70%
- 模型降级链：主模型不可用时自动切换备选模型

**协议状态**: ✅ 已落地 (升级协议#77)

### 协议 #139: 龙虾-全模态统一生成协议 v1.0

**对标来源**: Gemini Omni全模态生成 + Seedance 2.0视频生成

**核心能力**:

- 跨模态一致性：单一模型替代多管线，消除拼接伪影
- API可编程：开发者通过统一接口调用

**协议状态**: ✅ 已落地
