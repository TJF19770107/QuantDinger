## 三、全域能力融合方案

### 3.1 Agent间通信协议设计（对标OpenClaw sessions_send）

```
豆包Agent ←→ 龙虾主控中心 ←→ 子Agent(Codex/Claude/Hermes/...)
     ↑                        ↑
  双向桥接协议v2.0        Agent间消息通道
```

**通信协议核心字段**：
- source_agent / target_agent：源和目标Agent标识
- message_type：task_delegate | result_return | state_query | sync_checkpoint
- payload：任务上下文和数据载荷
- trace_id：全链路追踪UUID
- priority：normal | high | critical
- retry_policy：max_retries=3, backoff=exponential
