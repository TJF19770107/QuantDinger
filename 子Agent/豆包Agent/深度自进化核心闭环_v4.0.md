## 二、技能自动萃取引擎

### 2.1 引擎架构

```
执行日志 + 产物 → 模式识别 → 标准化封装 → 入库评审 → Skill注册
```

### 2.2 萃取流程

| 阶段 | 输入 | 处理 | 输出 |
|------|------|------|------|
| 采集 | 工具调用日志、执行记录、产物文件 | 日志聚合，去噪过滤 | 结构化操作序列 |
| 识别 | 操作序列 | 模式匹配：重复模式/成功模式/高频模式 | 候选Skill模板 |
| 标准化 | 候选模板 | 自动填充Skill元数据(name/version/input/output) | Skill草案 |
| 评审 | Skill草案 | Rubric自动评分(协议26)，低于60分→废弃 | 评分+建议 |
| 入库 | 通过评审的Skill | 写入技能库目录，更新技能清单 | 注册完成 |

### 2.3 萃取触发条件

| 触发方式 | 条件 |
|---------|------|
| 自动触发 | 同一操作模式重复≥3次 / 任务完成后复盘发现新可复用模式 |
| 定时触发 | 每3小时定时任务自动扫描日志(全域缺口专项补全迭代) |
| 手动触发 | 用户明确指令"萃取技能"/"生成Skill" |

### 2.4 Skill标准化模板

```markdown
# 技能名称 v1.0

> **来源**: 自动萃取 / 手动定义
> **创建时间**: YYYY-MM-DD HH:MM
> **触发模式**: 关键词匹配 / 条件触发

## 功能描述
[一句话描述技能功能]

## 输入
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|

## 输出
| 字段 | 类型 | 说明 |
|------|------|------|

## 执行步骤
1. [步骤1]
2. [步骤2]

## 关联协议
- 协议XX
```

## 三、SICA自进化逻辑接入

### 3.1 SICA四步进化循环

```
┌─────────────────────────────────────────┐
│  Step 1: 自发变异 (Spontaneous Mutation) │
│  随机探索新的行为模式、参数组合           │
├─────────────────────────────────────────┤
│  Step 2: 变异测试 (Mutation Testing)     │
│  评估变异效果，计算效用函数               │
├─────────────────────────────────────────┤
│  Step 3: 效用选择 (Utility Selection)    │
│  选择效用最高的变异，淘汰低效用变异        │
├─────────────────────────────────────────┤
│  Step 4: 固化沉淀 (Crystallization)      │
│  将优秀变异固化为Skill或规则，更新基因     │
└─────────────────────────────────────────┘
```

### 3.2 三维效用函数

| 维度 | 权重 | 计算公式 |
|------|------|---------|
| 成功完成率 | 50% | 成功次数/总执行次数 |
| 资源效率 | 25% | 1 - (实际耗时/基线耗时) |
| 用户满意度 | 25% | 用户修改/否定次数取反 |

**综合效用**: U = 0.5×P_success + 0.25×E_efficiency + 0.25×S_satisfaction

### 3.3 GenericAgent轻量化接入

| GenericAgent特性 | 豆包Agent映射 |
|-----------------|-------------|
| ≤10原子工具 | 读/写/删/搜/执行/派发/询问/展示/图片分析/网页抓取 |
| 自主生长Skill | SkillForge自动萃取引擎 |
| 五层记忆路由 | MemoryOS：热/温/冷/经验/元记忆 |
| 最小化依赖 | 仅依赖shell_executor + python_executor兜底 |
| 自我修正 | Rubric自纠正 + 回溯重试 |
| 上下文压缩 | 历史摘要 + 分段加载 + 过期归档 |

## 四、版本快照与异常回滚

### 4.1 版本快照机制

| 快照类型 | 触发时机 | 内容 | 存储 |
|---------|---------|------|------|
| 定时快照 | 每轮迭代完成后 | 能力注册表、技能清单、GAP_BACKLOG | checkpoints/ |
| 里程碑快照 | 版本号升级时(X.0) | 全量配置文件 | stable_checkpoint.json |
| 异常快照 | 检测到异常时 | 异常前状态 + 上下文 | checkpoints/ |

### 4.2 版本号规范

```
v{主版本}.{次版本}(_R{迭代轮次})
示例: v3.0_R11, v4.2_R15

主版本: 重大架构变更
次版本: 功能新增/协议扩展
R轮次: 迭代轮次编号
```

### 4.3 异常自动回滚

```
异常检测 → 加载最近稳定快照 → 重试(最多3次) → 降级(跳过失败节点) → 人工介入
```

| 异常类型 | 检测方式 | 回滚策略 |
|---------|---------|---------|
| 技能执行失败 | 工具返回错误 | 回滚到任务开始前，切换技能重试 |
| 配置损坏 | JSON解析失败 | 回滚到上一个稳定配置快照 |
| 内存溢出 | OOM检测 | 回滚并释放资源，降低并行度 |
| 无限循环 | 超时(300s) | 强制终止，回滚，标记节点为高风险 |

### 4.4 回滚历史

回滚记录存入 [rollback_history.json](E:\龙虾AI主控中心\我的AI分身\子Agent\豆包Agent\checkpoints\rollback_history.json)，格式：
```json
{"timestamp":"","rollback_to":"","reason":"","restored":true}
```

## 六、AI on UI联动

### 6.1 桌面控制深度集成

```
用户桌面
    │
    ├─ DesktopController ──→ 窗口管理/键鼠模拟/剪贴板
    │
    ├─ 视觉桌面操控 ────────→ 截图→感知→推理→行动 (协议33)
    │
    └─ 应用操作 ───────────→ app-agent 启动/操作App
```

### 6.2 联动场景

| 场景 | 实现 |
|------|------|
| 打开桌面应用 | DesktopController.start_app("notepad") |
| 窗口分屏 | DesktopController.arrange_windows("split") |
| 文件拖拽 | DesktopController.drag_drop(src, dst) |
| 剪贴板读写 | DesktopController.clipboard_read/write |
| 屏幕截图分析 | DesktopController.screenshot + analyze_image |

### 6.3 安全约束

- 系统核心路径豁免（C:\Windows等）
- 高风险操作必须用户确认
- 操作审计日志全量记录
