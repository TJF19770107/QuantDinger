## 二、模块详细说明

### 2.1 Claude分层推理引擎 v2.0
**文件**: `architecture/claude_reasoning_enhanced_v2.0.py` (620行)

**增强维度**:

1. **三级上下文缓存** (TieredContextCache)
   - L1热缓存(最近3轮/12K tokens/<10ms)
   - L2温缓存(语义压缩/64K tokens/<50ms)
   - L3冷缓存(历史摘要/256K tokens/<200ms)
   - 命中统计 + 自动分层膨胀

2. **增强推理回溯** (EnhancedReasoningBacktrack)
   - 检查点保存/恢复 (ReasoningCheckpoint)
   - 回溯决策树 (decide_backtrack)
   - 多路径评估 (置信度→切换→合并重试→全量重启)

3. **工具联动推理回环** (ToolReasoningLoop)
   - 预判→路由→执行→反馈→迭代→收敛
   - 收敛窗口检测(连续N轮一致)
   - 改进幅度阈值(IMPROVEMENT_THRESHOLD=0.05)

4. **中文全场景适配** (ChineseContextAdapter)
   - 多义词消歧(全局语义场+局部上下文窗口)
   - 语气层级识别(formal/casual/technical/general)
   - 中文长文档分段推理(8K tokens/chunk)
   - 多引擎搜索路由(知乎/CSDN+B站/百度)

**性能目标**: 
- 上下文加载效率: +40%
- 推理回溯准确率: 95%
- 工具联动收敛率: 87%

### 2.2 可视化工作流引擎 v2.0
**文件**: `architecture/visual_workflow_engine_v2.0.py` (560行) + `architecture/workflow_dashboard_v2.0.html`

**增强维度**:

1. **超时熔断降级** (CircuitBreaker)
   - 黄色告警(30s) / 红色熔断(60s)
   - 自动重试(最多3次)
   - 降级结果返回 + 自动恢复(5min)

2. **节点全维度监控** (NodeMonitor)
   - p50/p95/p99性能基线

   - Agent健康检查(30秒心跳)
   - 最优Agent选择(负载分)

4. **增强节点类型**: SUB_WORKFLOW / DYNAMIC / WAIT / NOTIFY

5. **HTML暗色看板** (workflow_dashboard_v2.0.html)
   - GitHub暗色主题 (#0d1117)
   - 五维统计卡片 + 进度条 + 节点列表

   - 实时日志流 + 动态刷新动画
   - 响应式移动端适配
