# 龙虾-移动端远程控制协议 v1.0

> **对标来源**：Codex 移动端远程连接（2026年5月14日预览）
> **版本**：v1.0 · 2026-05-31 · R06
> **状态**：ACTIVE

---

## 一、协议目标

将手机/平板等移动设备作为豆包Agent的**远程控制台**，实现跨设备的Agent监控、审批和管理。

---

## 二、核心能力

### 2.1 远程控制台功能

| 能力 | 说明 |
|------|------|
| 查看输出 | 实时查看Agent任务执行输出 |
| 批准命令 | 对需要人工确认的操作进行Approve/Reject |
| 切换模式 | 切换Effort模式（Low/Medium/High） |
| 发起任务 | 从手机端发起新任务 |
| 查看进度 | Kanban看板实时状态 |
| 异常通知 | 任务阻塞/失败时推送通知 |

### 2.2 架构

```
手机App ←→ 豆包Agent主机（保持运行）←→ 任务执行环境
   ↑              ↑
   远程连接         本地Agent核心
```

### 2.3 安全约束

- 连接需身份认证（扫码或设备标识）
- 敏感操作仍需在手机上二次确认
- 传输加密（TLS 1.3）
- 超时自动断开（默认30分钟无操作）
- 可设置IP白名单限制连接来源

---

## 三、适用场景

| 场景 | 操作 | 频率 |
|------|------|------|
| 外出Review | 查看长任务输出，决定是否继续 | 偶尔 |
| 会议间隙Approve | 批准等待中的危险操作 | 偶尔 |
| 监控夜间任务 | 查看自动化流水线进度 | 每日 |
| 应急响应 | 远程终止异常任务 | 罕见 |

---

## 四、与Marvis对标

Marvis作为操作系统层级AI助手，已实现三端同步（Windows/Mac/Android）。豆包Agent的移动端远程控制协议从Marvis的跨端架构中提取灵感：

- Marvis：操作系统层级Agent，天然跨端
- 豆包Agent：采纳远程控制台模式，轻量实现跨端管理

---

## 五、与其他协议的关系

- 与「事件驱动自动化流水线协议v2.0」协同：流水线中等待审批的步骤可在手机端Approve
- 与「定时任务调度协议v1.0」协同：定时任务执行状态可在手机端监控
- 与「SafeGuard v3.0」协同：高风险操作在手机端二次确认
