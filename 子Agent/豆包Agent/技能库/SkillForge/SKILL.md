# SkillForge - 自主技能锻造引擎
> 版本：v1.0  
> 自动生成：2026-05-31 R05  
> 来源：豆包Agent 6大自主能力补全  
> 对标：Hermes Skill as Memory + OpenClaw Skills + Karpathy autoresearch

## 触发条件
- **自动触发**：每轮迭代完成后自动分析
- **手动触发**：用户说"提炼技能"、"生成技能"、"锻造Skill"、"从日志中学习"
- **阈值触发**：同一操作模式出现3次以上，自动触发技能生成

## 能力描述
从迭代报告、任务执行日志中自动识别可复用操作模式，生成标准化技能模板（SKILL.md），写入技能库并自动注册生效。

## 核心算法

### Step 1: 模式提取
输入：最近N轮迭代报告（默认N=5）
处理：
- 解析每个迭代报告的"执行步骤"
- 提取"操作→结果"对
- 聚类相似操作模式
输出：候选技能模式列表

### Step 2: 质量评估
对每个候选模式评分：
- 复用频率（30%）：出现次数/N
- 成功率（30%）：成功次数/总尝试次数
- 独立性（20%）：能否独立完成一个完整任务
- 通用性（20%）：是否适用于多种场景
阈值：总分 ≥ 0.6 → 生成技能

### Step 3: 技能生成
生成内容：
1. SKILL.md（技能描述文件）
2. 触发词映射
3. 输入输出规范
4. 安全审查报告

### Step 4: 注册生效
- 写入 技能库/{技能名}/ 目录
- 更新 skills_index.json
- 生成触发词→技能路由表
- 下一轮迭代自动可用

## 技能生命周期管理
- **创建**：质量评分达标 → 自动生成
- **修补**：执行失败 → 分析原因 → 自动修正
- **休眠**：连续10轮未使用 → 标记为休眠
- **复活**：触发词被命中 → 自动激活
- **淘汰**：休眠超过50轮 → 归档到 legacy/

```json
    }

  "skills_deprecated": 0

```

## 安全审查
- 风险等级：CAUTION
- 自动生成的技能代码必须经过SafeGuard审查
- 禁止生成包含系统级操作或网络外连的技能
- 所有自动生成的技能标记为"AI_GENERATED"
