# 协议77：Marvis式OS级Agent中间层协议 v1.0

> **协议编号**：77
> **版本**：v1.0
> **对标来源**：腾讯 Marvis Workbody（2026-05-20上线）
> **核心价值**：1个主Agent+5个专业Agent的OS级中间层架构，端云双模式，每人每天1000万免费Token
> **关联协议**：协议72（Marvis式操作系统级操控协议）、协议23（桌面Agent工作区隔离协议）

---

## 一、背景

2026年5月20日，腾讯上线操作系统级AI助手Marvis（马维斯），Windows/Mac/Android三端全量开放。区别于传统AI对话工具，Marvis定位为"OS级AI中间层"，将终端系统、文件、应用、算力和跨端连接整合，用户一句话即可触发多Agent并行执行。每人每天1000万免费Token。

## 二、核心价值

- **操作系统级中间层**：不是跑在OS上的应用，而是嵌入系统底层的AI中间层
- **1+5 Agent架构**：PM主Agent理解需求拆解任务，5个专业Agent并行执行
- **端云双模式**：效率模式（端云协同）+ 隐私模式（端侧模型完全本地）
- **L2安全兜底**：敏感操作强制硬垂询，删除文件/修改系统配置前必须用户确认
- **每人每天1000万Token免费**：面向普通用户和职场人群的大规模普及

## 四、实现规范

### 4.1 主Agent任务分解流程

```
1. 自然语言意图识别
2. 子任务拆解（DAG拓扑）
3. 并行度评估（无依赖→并行；有依赖→串行）
4. Agent分配（子任务→专业Agent映射）
5. 执行监控（进度追踪+异常处理）
6. 结果汇总（合并+格式化输出）
```

### 4.2 L2安全兜底机制

| 操作级别 | 触发条件 | 处理方式 |
|---------|---------|---------|
| L0 安全 | 只读操作 | 直接执行 |
| L1 提醒 | 非敏感写操作 | 执行后通知 |
| L2 硬垂询 | 删除文件/修改系统配置 | 先展示执行计划→用户确认→执行 |
| L3 禁止 | 支付/密码/格式化 | 必须用户本人完成 |

### 4.3 跨端协同协议

```
Windows PC ←→ Marvis云端同步 ←→ Android手机
    │                                  │
    │ 远程查看/操控                     │ 查看电脑屏幕
    │ 锁屏状态可解锁                    │ 远程输入密码
    │ 文件跨端访问                      │ 实时可视化操控
```

### 4.4 Token预算管理

```
日预算：1000万Token
├── 效率模式：云端推理消耗（大模型意图理解）
├── 隐私模式：不计云端Token（端侧模型运行）
├── 文件索引：端侧预处理减少云端消耗
└── 图片搜索：端侧特征提取+云端语义匹配
```
