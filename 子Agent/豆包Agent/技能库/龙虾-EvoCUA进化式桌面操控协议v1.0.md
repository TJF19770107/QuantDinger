# 龙虾-EvoCUA进化式桌面操控协议 v1.0

> **对标来源**：美团LongCat EvoCUA (OSWorld 2026榜首 · Apache-2.0)
> **核心突破**：摒弃"轨迹模仿"，实现自主进化学习
> **类型**：操作层 · 进化学习
> **状态**：ACTIVE

---

## 一、协议概述

传统桌面Agent依赖人类示范轨迹，面临三大困境：
1. UI变动即失效
2. 新应用无示范
3. 无法自我改进

EvoCUA协议通过"可验证数据合成 + 大规模并行沙盒 + 自主进化循环"，实现Agent从零开始自主学会桌面操作。

---

## 二、三层进化架构

### 2.1 可验证数据合成

不依赖人类标注，自动生成训练数据：

```
步骤1：任务生成器 → 根据应用UI结构自动生成操作任务
步骤2：自动执行 → 在沙盒中执行任务
步骤3：结果验证 → 通过可编程规则验证任务是否成功
步骤4：正负样本标记 → 成功轨迹标记为正样本
```

### 2.2 十万级并发沙盒

- 每个任务在独立沙盒中运行
- 支持万级并行探索
- 沙盒间互不干扰
- 失败不影响其他任务

### 2.3 自主进化循环

```
探索 → 执行 → 验证 → 筛选成功轨迹 → 更新策略 → 再探索
  ↑                                                    |
  └────────────────────────────────────────────────────┘
```

- 策略从成功轨迹中学习
- 新策略用于下一轮探索
- 持续迭代，越探索越强

## 三、豆包Agent集成方案

### 3.1 与DesktopController协议#6的差异化

| 维度 | DesktopController | EvoCUA增强 |
|------|------------------|------------|
| 操作方式 | 预定义技能驱动 | 进化学习驱动 |
| 应对UI变动 | 需人工更新技能 | 自动适应 |
| 能力边界 | 已知应用 | 可拓展到新应用 |
| 优化方式 | 人工优化 | 自动进化 |

### 3.2 与CASCADE协议#21的协同

- CASCADE负责"技能习得"（从文档/教程中学习）
- EvoCUA负责"操作习得"（从实际操作中学习）
- 两者互补：理论+实践

### 3.3 渐进式启用策略

```
阶段1（当前）：EvoCUA作为DesktopController的补充
阶段2（R10+）：EvoCUA接管简单重复任务
阶段3（R15+）：EvoCUA成为桌面操控主引擎
```
