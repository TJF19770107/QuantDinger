## 一、协议概述

当前Agent记忆系统面临三大问题：
1. **碎片化**：信息散落，无法形成完整认知
2. **静态化**：只记最新或全堆，不追踪演化
3. **低效化**：检索慢、Token消耗大

Hy-Memory协议定义六层记忆架构+双系统检索+三层演化底牌，实现"记得住、记得对、记得轻、更懂你"。

---

## 二、六层记忆架构

```
┌─────────────────────────────────────────┐
│ L6 元记忆层 (Meta Memory)                │ ← 记忆的记忆：知道我知道/不知道什么
├─────────────────────────────────────────┤
│ L5 关系图谱层 (Knowledge Graph)          │ ← 实体间关系网络
├─────────────────────────────────────────┤
│ L4 演化追踪层 (Evolution Tracking)       │ ← 偏好/知识变化轨迹（非覆盖非堆积）
├─────────────────────────────────────────┤
│ L3 偏好模型层 (Preference Model)         │ ← 用户偏好动态建模
├─────────────────────────────────────────┤
│ L2 事实抽取层 (Fact Extraction)          │ ← 结构化事实和知识
├─────────────────────────────────────────┤
│ L1 原始对话层 (Raw Dialogue)             │ ← 完整对话记录，不丢历史
└─────────────────────────────────────────┘
```

### 各层职责

| 层级 | 存储内容 | 检索方式 | 生命周期 |
|------|---------|---------|---------|
| L1 | 完整对话原文 | 时间/会话索引 | 永久 |
| L2 | 结构化事实(JSON) | 精确/模糊 | 永久 |
| L3 | 偏好向量 | 语义相似度 | 随演化更新 |
| L4 | 变化轨迹(时序) | 时间序列 | 追加不覆盖 |
| L5 | 实体关系图 | 图遍历 | 动态更新 |
| L6 | 能力边界描述 | 元查询 | 每次迭代更新 |

## 三、System1/System2双系统检索

```
用户查询
    │
    ├─ System1（快速直觉）──→ L1/L2/L3 快速匹配 → 50ms
    │
    └─ System2（深度推理）──→ L4/L5/L6 关系推理 → 200ms
                                  │
                                  └─ 发现演化趋势/隐藏关系
```

### System1 触发条件
- 精确事实查询（"我之前设置的那个参数是多少"）
- 偏好查询（"我喜欢的配色方案"）
- 最近对话摘要

### System2 触发条件
- 趋势分析（"我的技术偏好有哪些变化"）
- 关系推理（"这两个项目有什么关联"）
- 能力自省（"我擅长/不擅长什么"）

---

## 四、演化链三层底牌

```
底牌1：不覆盖 → 新偏好不覆盖旧偏好，记录完整演化轨迹
底牌2：不堆积 → 定期压缩冗余信息，保持高信息密度
底牌3：可回溯 → 任意时间点的偏好/知识状态可查询
```
