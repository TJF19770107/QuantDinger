# 龙虾-四层持久化记忆架构协议 v1.0

> 协议编号: 118 | 版本: v1.0 | 来源: Hermes四层记忆 + Workforce五层记忆模型
> 生效范围: 全域Agent + Obsidian知识库 | 依赖: MemoryMgr + KBArchiving

---

## 一、四层记忆架构

| 层级 | 名称 | 核心作用 | 存储内容 | 生命周期 | 存储方式 |
|------|------|---------|---------|---------|---------|
| L1 | 工作记忆 | 实时交互 | 当前会话上下文、临时数据 | 会话内有效 | 模型上下文窗口 |
| L2 | 情景记忆 | 事件回溯 | 历史对话、任务记录、时间线 | 长期存储 | SQLite+FTS5全文索引 |
| L3 | 语义记忆 | 事实沉淀 | 固定知识、用户偏好、行业规则 | 永久存储，自动更新 | 向量数据库(可选: Chroma/Pinecone/Qdrant) |
| L4 | 技能专用记忆 | 技能复用 | 自动提炼的Skill、工作流、操作步骤 | 永久存储，持续迭代 | Markdown文件 in 技能库/ |

## 二、各层实现机制

### L1 工作记忆
- 当前Marvis会话上下文窗口
- 动态压缩：去除冗余，保留核心信息
- 支持Anthropic Prompt Caching

### L2 情景记忆（待增强）
- 历史消息持久化存储
- 增强目标：SQLite+FTS5全文检索，跨会话历史秒级查询
- 自动压缩归档：会话结束后压缩工作记忆→情景记忆

### L3 语义记忆（待增强）
- 当前：长期记忆检索
- 增强目标：Obsidian PARA知识库向量化索引
- 跨笔记语义检索，自动关联相关知识点

### L4 技能专用记忆
- 当前：技能库+全域模板
- 增强：Agent完成任务后自动提取成功路径→生成Skill文件
- 遵循协议120 Spec as Code规范

## 三、记忆压缩与注入

### 压缩策略
1. 会话结束后自动将L1→L2压缩归档
2. 去除冗余重复内容，保留核心信息
3. 关键转折点、用户偏好、成功路径优先保留

### 注入策略
1. 新任务启动时检索L2+L3相关记忆
2. 摘要后注入当前L1上下文
3. 只带有用信息，不堆砌冗余
4. 避免上下文臃肿

## 四、与OpenClaw/Obsidian对比

| 记忆类型 | Hermes Agent | OpenClaw | Marvis+龙虾体系 | 龙虾差距 |
|---------|-------------|----------|----------------|---------|
| L1工作记忆 | 动态压缩+Prompt Caching | 依赖context window | 上下文窗口 | 对等 |
| L2情景记忆 | SQLite+FTS5全文检索 | 简单消息历史 | 消息历史持久化 | 缺全文检索 |
| L3语义记忆 | 插件式向量数据库 | 外部RAG集成 | 长期记忆检索 | 缺Obsidian向量化 |
| L4技能记忆 | 自动生成Skills ✨ | 人工编写static files | 技能库文件 | 缺自动生成引擎 |
