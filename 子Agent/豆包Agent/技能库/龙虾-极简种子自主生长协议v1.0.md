## 一、核心原理

GenericAgent挑战了"Agent需要复杂架构"的假设。仅3.3K行核心代码（Agent Loop约100行），≤10个原子工具，每次任务自动将执行路径结晶为技能存入Skill Tree，实现从"小种子"到"参天大树"的自主生长。

**核心突破**：Agent不是"设计出来"的，而是"长出来"的。最小种子（100行循环+10个工具）通过持续使用，自动结晶出复杂技能体系。

## 二、极简架构

### 2.1 原子工具（≤10个）

```
1. read_file      → 读取文件内容
2. write_file     → 写入文件内容
3. execute_shell  → 执行Shell/PowerShell命令
4. search         → 搜索文件/内容
5. browse_url     → 打开网页/API调用
6. remember       → 写入记忆层
7. recall         → 从记忆层检索
8. ask_user       → 向用户提问
9. spawn_subagent → 创建子Agent
10. self_modify   → 修改自身配置/行为
```

**设计原则**：每个工具语义清晰、功能原子、不可分割。组合使用覆盖所有任务。

### 2.2 Agent Loop（约100行）

```python
def agent_loop(task: str) -> str:
    """极简Agent循环：观察→思考→行动→观察"""
    context = load_context()  # 加载记忆层
    history = []
    
    while not task_complete:
        observation = observe(task, history, context)
        thought = think(observation)
        action = decide_action(thought)
        result = execute(action)
        history.append({"thought": thought, "action": action, "result": result})
        
        if should_crystallize(history):
            crystal = crystallize_skill(history)
            skill_tree.add(crystal)
    
    return summarize(history)
```

### 2.3 自主生长Skill Tree

```
每次任务完成后：
1. 提取执行路径（thought → action → result 序列）
2. 分析路径是否可复用（相似度>60% → 合并；独特性>80% → 新建）
3. 结晶为技能文件存入./skills/
4. 技能文件自动参与下次同类任务的决策
```

## 三、五层分层记忆路由

```
L1 会话内记忆（Chat Memory）
   → 当前对话的原始消息 + 工具调用结果
   → 生命周期：当前会话
   → 存储：内存

L2 跨会话记忆（Session Memory）
   → 跨会话的关键事件 + 用户偏好 + 项目上下文
   → 生命周期：永久（定期策展）
   → 存储：SQLite FTS5

L3 技能记忆（Skill Memory）
   → 结晶化的执行路径 + 成功/失败模式
   → 生命周期：永久（系统维护）
   → 存储：./skills/*.md + .memory.md

L4 经验池（Experience Pool）
   → 错误模式库 + 成功模板库 + 跨任务迁移学习
   → 生命周期：永久（定期去重）
   → 存储：SQLite + 向量索引

L5 元记忆（Meta Memory）
   → 自我监控数据：性能趋势/技能使用率/失败统计
   → 生命周期：永久（定期聚合）
   → 存储：.metadata.json 聚合
```

**路由规则**：
- 新任务 → L3技能检索（找相似技能）→ 找到→直接执行
- L3未命中 → L4经验池检索（找相似模式）→ 找到→参考执行
- L4未命中 → L2跨会话检索（找相似上下文）→ 找到→参考执行
- 全部未命中 → 从零执行→结晶为L3新技能

## 四、集成方式（接入龙虾五步法）

### 作为"极简模式"开关

龙虾当前运行在"全功能模式"（协议1-72），本协议提供"极简模式"切换：

```
全功能模式：12项官方技能 + 72项协议 + 复杂编排引擎
极简模式：  10个原子工具 + Agent Loop + Skill Tree + 5层记忆
```

**切换方式**：用户可通过命令切换模式：
- `龙虾 极简模式` → 激活本协议，最小化Agent
- `龙虾 全功能模式` → 恢复完整协议栈

**应用场景**：
- 资源受限环境（低配电脑/移动端）
- 简单任务（不需要复杂编排）
- 新用户入门（学习成本低）
- 快速原型验证

## 五、安全约束

1. **最小权限**：仅10个原子工具，每个工具权限精确控制
2. **记忆隔离**：极简模式的记忆与全功能模式记忆隔离存储
3. **工具白名单**：`execute_shell`/`self_modify`需要用户显式授权
4. **资源限制**：极简模式默认timeout=120s, max_memory=256MB
