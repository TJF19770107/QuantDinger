# AutoWake - 自主唤醒与执行引擎
> 版本：v1.0  
> 自动生成：2026-05-31 R05  
> 来源：豆包Agent 6大自主能力补全  
> 对标：Karpathy autoresearch 自动循环 + Claude Managed Agents 长时会话

## 触发条件
- **定时触发**：每4小时自动唤醒执行完整迭代
- **事件触发**：文件变化、外部API回调
- **手动触发**：用户说"开始迭代"、"执行任务队列"、"唤醒Agent"

## 能力描述
管理Agent的唤醒-执行-归档-休眠循环，维护任务优先级队列，自主判断任务优先级并按序执行。

## 核心循环

```
SLEEP（休眠）
  ↓ 定时器/事件触发
WAKE_UP（唤醒）
  ↓
CONTEXT_LOAD（加载上下文）
  ↓
PRIORITIZE（任务排序）
  ↓
EXECUTE（逐项执行）
  ↓
ARCHIVE（归档结果）
  ↓
SLEEP（保存快照 → 休眠）
```

## 任务优先级体系

| 优先级 | 类型 | 示例 | 抢占规则 |
|--------|------|------|---------|
| P0 | 紧急 | 安全修复、崩溃恢复、数据保护 | 中断所有 |
| P1 | 重要 | 4小时迭代、技能更新、记忆归档 | 中断P2/P3 |
| P2 | 常规 | 全网扫描、能力对标、报告生成 | 不中断 |
| P3 | 低优 | 文档整理、目录优化、日志清理 | 最后执行 |

## 执行控制
- 超时控制：每任务默认600秒超时
- 失败重试：最多3次，间隔递增
- 阻塞处理：P0/P1失败需人工介入→暂停车队
- 并发限制：同优先级最多并行2个任务

## 输出格式
每次唤醒执行完毕后生成 auto_exec_log_{timestamp}.md，包含：
- 唤醒时间/触发原因
- 任务执行摘要（完成/失败/超时）
- 新发现问题/发现
- 下次唤醒时间

## 安全审查
- 风险等级：SAFE
- 仅管理任务调度，不直接操作系统
- 任务执行走各自模块的安全审查
