## 二、MUSE 五阶段统一生命周期

### 阶段1：创建 (Create)
- Agent通过内置 `skill_create` 工具实时生成技能
- 输入：任务轨迹 + 失败案例 + 成功模板
- 输出：自包含技能包（含指令+测试用例+边界条件）

### 阶段2：记忆 (Memory)
- 两级自适应DAG压缩：
  - L1：对话历史组织为有向无环图（DAG）
  - L2：根据当前任务需求选择性展开节点
- 技能存入"技能银行"（Skill Bank）

### 阶段3：管理 (Manage)
- 动态评分：每条经验记录使用次数+成功次数
- 语义去重：相似技能自动合并
- 阈值裁剪：低于阈值自动废弃

### 阶段4：评估 (Evaluate)
- 新技能通过单元测试方可注册
- SkillsBench基准：87.94% vs 人类68.40%
- 评估维度：正确性、完整性、边界覆盖

### 阶段5：改进 (Improve)
- 从后续执行轨迹中收集反馈
- 自动修正技能边界条件
- 经验强化学习（GRPO）优化技能调用策略

## 三、EvolveR 经验蒸馏融合（v2.0新增）

### 四步闭环生命周期
```
在线交互 → 离线自蒸馏 → 经验库维护 → 强化学习更新
```

### 关键洞察
- **认知对齐**：Agent自己蒸馏的原则 > 外部教师总结的原则（3B+模型验证）
- **复合奖励函数**：结果奖励 + 格式奖励（思考步数+搜索多样性）
- **经验 ≠ Skill**：经验是"怎么用工具"的元认知，Skill是"工具本身"

### 融合策略
```
MUSE五阶段（技能资产全生命周期）
    ↓ 并行
EvolveR四步（经验认知沉淀）
    ↓
豆包Agent统一技能银行 = 技能包 + 经验库 + RL策略
```

## 四、两级自适应DAG压缩机制

### L1: 对话→DAG
- 每条对话历史转为DAG节点
- 边 = 因果关系 / 引用关系 / 时序关系
- 节点权重 = 与当前任务相关性评分

### L2: 选择性展开
- 根据当前查询反向检索相关节点
- 只展开top-k高权重节点
- Token节省 40-60%

## 五、技能可移植性验证

MUSE-Autoskill实验证明：自动生成的技能应用于其他Agent时同样显著提升性能。

豆包Agent技能库中的技能可通过此协议实现跨Agent迁移：
- 豆包 → Claude：技能模板导出 + 接口适配
- 豆包 → Gemini：功能语义映射 + 工具绑定
- 豆包 → Codex：技能包序列化 + MCP协议桥接

## 六、执行规范

1. 每次迭代完成后自动触发MUSE评估
2. 新业务场景自动触发技能创建
3. 技能评分低于0.3自动进入裁剪候选
4. 技能银行每4小时自动整理（去重+合并+评分）
5. 全新工具发现时自动生成包装技能
