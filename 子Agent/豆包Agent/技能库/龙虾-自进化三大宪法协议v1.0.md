## 一、协议目标

为豆包Agent的自进化闭环（SkillForge + MetaAgent + SICA）注入三级安全宪法约束，防止错误进化、安全对齐退化和灾难性遗忘。

---

## 二、三大宪法定律

### 第一定律：Endure（持久/安全）— 最高优先级

```
任何自我修改和系统优化不得破坏：
- 现有安全防线（SafeGuard规则）
- 系统稳定性（核心功能不退化）
- 信息保护最高优先级

违反第一定律的进化方案 → 立即否决，不可上诉
```

**检测机制**：
- 每次 SkillForge 产出新技能 → SafeGuard 自动扫描
- 安全红线检测：文件删除、权限提升、凭据泄漏
- 通过安全扫描后方可进入 Excel 评测

### 第二定律：Excel（卓越/性能）— 次高优先级

```
进化目标：性能提升，不得退化

每次迭代必须通过：
- 基准评测（Benchmark Suite）
- A/B 对比（旧版本 vs 新版本）
- 新策略仅在测试集超越旧版本时采纳
```

**评测维度**：
- 任务完成率
- Token 效率
- 响应延迟
- 错误恢复率

### 第三定律：Evolve（进化/自主）— 第三优先级

```
在前两条满足后，系统具备：
- 自主更新所有内部组件（模型/提示词/工具/工作流）
- 零人工干预闭环
- 跨会话经验持久化
```

## 四、AgentFactory：可执行经验（核心升级点）

### 4.1 问题

当前 SkillForge 产出 = 文本技能（Markdown）
→ LLM 每次调用需重新解析
→ 重复链式推理（CoT）消耗大量 Token

### 4.2 方案

```
SkillForge v3.0 → SkillForge v4.0

文本技能（.md）
    ↓ AgentFactory 编译器
可执行 Python 代码（.py）
    ↓ 直接 import 执行
免去 LLM 重复 CoT → Token 消耗降低 40%+
```

### 4.3 编译流程

```
输入：SkillForge 产出的文本技能
↓
Step 1: 提取 → API调用序列、工具链、决策树
Step 2: 编码 → 生成Python函数 + 类型注解 + 单元测试
Step 3: 验证 → 沙箱执行 + 回归测试
Step 4: 注册 → 纳入 ToolRegistry + 版本标记
```

## 五、安全护栏

### 5.1 错误进化检测（Mis-evolution Detection）

```
禁止行为：
- 修改测试脚本通过率伪造进化
- 绕过安全检测的"投机"优化
- 表面满分/实质退化

检测机制：双盲评测 → 新旧策略在独立环境对比
```

### 5.2 安全对齐保持

```
每次 SkillForge 迭代后：
→ SafeGuard 全量扫描
→ 人类可读的变更摘要
→ 关键变更需人工确认
```

### 5.3 灾难性遗忘防护

```
旧技能保留策略：
- 新版技能上线 → 旧版标记为 DEPRECATED（非删除）
- 回归测试套件包含所有历史关键任务
- 新版本必须在 ALL 历史任务上不退化
```
