## 二、核心架构

### 2.1 语义定位引擎
```
传统坐标定位：
截屏 → 解析像素坐标(1234,567) → 点击 → ❌ 分辨率变化失效

语义定位（v2.0）：
截屏 → 语义理解"登录按钮" → 转换为坐标 → 点击 → ✅ 分辨率无关
```

### 2.2 四项核心组件
```python
class SemanticDesktopController:
```

## 三、视觉语义定位

### 3.1 定位流程
```python
async def locate_element(self, description):
    """
    语义定位UI元素
    """
    # 1. 截取当前屏幕
    screenshot = await self.screen_capture.capture()
    
    # 2. 语义分析当前界面
    ui_tree = await self.semantic_analyzer.analyze(screenshot)
    """
    返回的UI树结构：
    {
        "window": "文件资源管理器",
        "elements": [
            {
                "type": "button",
                "text": "新建文件夹",
                "position": {"x": 120, "y": 45, "width": 100, "height": 30},
                "state": "enabled",
                "attributes": {"aria-label": "新建文件夹按钮"}
            },
            {
                "type": "input",
                "label": "搜索框",
                "position": {"x": 300, "y": 10, "width": 200, "height": 25},
                "state": "focused"
            }
        ]
    }
    """
    
    # 3. 语义匹配目标元素
    matches = self.semantic_analyzer.match(
        ui_tree, 
        description,  # e.g. "登录按钮" / "搜索框" / "关闭窗口"
        threshold=0.8
    )
    
    # 4. 选择最佳匹配
    best_match = self.select_best_match(matches, description)
    
    # 5. 返回语义坐标
    if best_match:
        return SemanticPosition(
            element=best_match,
            center_x=best_match.x + best_match.width // 2,
            center_y=best_match.y + best_match.height // 2,
            confidence=best_match.score
        )
    
    return None
```

### 3.2 语义匹配策略
| 描述 | 匹配策略 | 优先级 |
|------|---------|--------|
| "登录按钮" | 文本匹配 > ARIA标签 > 类型推断 | text > label > type |
| "搜索框" | 标签匹配 > 占位符匹配 > 位置推断 | label > placeholder > position |
| "关闭窗口" | 文本匹配 > 位置匹配(右上角) | text > position |
| "保存文件" | 快捷键优先 > 菜单栏 > 工具栏 | shortcut > menu > toolbar |
| "滚动到底部" | 快捷键 > 滚动条操作 > 鼠标滚轮 | shortcut > scrollbar > wheel |

## 四、Locked持续运行

### 4.1 锁屏运行架构
```
用户锁屏 / 无操作
    ↓
Locked Agent 激活
    ↓
虚拟桌面会话创建
    ↓
Agent任务执行 (屏幕不可见但可操作)
    ↓
任务完成 → 虚拟桌面会话销毁
    ↓
进程守护 → 心跳检测 → 异常自动恢复
```

### 4.2 Process Guardian实现
```python
class ProcessGuardian:
    def __init__(self, heartbeat_interval=5, max_consecutive_failures=3):
        self.heartbeat_interval = heartbeat_interval
        self.max_consecutive_failures = max_consecutive_failures
        self.processes = {}
        self.health_status = {}
    
    async def register_process(self, process_id, process_info):
        """注册进程到守护系统"""
        self.processes[process_id] = {
            "info": process_info,
            "last_heartbeat": time.time(),
            "consecutive_failures": 0,
            "restart_count": 0,
            "total_uptime": 0
        }
        self.health_status[process_id] = "HEALTHY"
    
    async def heartbeat_check(self):
        """定期心跳检测"""
        while True:
            for pid, proc in self.processes.items():
                alive = await self.check_process_alive(pid)
                
                if alive:
                    proc["last_heartbeat"] = time.time()
                    proc["consecutive_failures"] = 0
                    proc["total_uptime"] += self.heartbeat_interval
                    self.health_status[pid] = "HEALTHY"
                else:
                    proc["consecutive_failures"] += 1
                    
                    if proc["consecutive_failures"] >= self.max_consecutive_failures:
                        # 触发自动恢复
                        self.health_status[pid] = "RECOVERING"
                        await self.auto_recover(pid)
                    else:
                        self.health_status[pid] = "DEGRADED"
            
            await asyncio.sleep(self.heartbeat_interval)
    
    async def auto_recover(self, process_id):
        """自动恢复进程"""
        proc = self.processes[process_id]
        start_time = time.time()
        
        # 1. 尝试温和关闭
        await self.graceful_shutdown(process_id)
        
        # 2. 等待资源释放
        await asyncio.sleep(2)
        
        # 3. 重新启动
        success = await self.restart_process(process_id)
        
        recovery_time = time.time() - start_time
        
        if success and recovery_time <= 5:
            proc["restart_count"] += 1
            proc["consecutive_failures"] = 0
            self.health_status[process_id] = "HEALTHY"
            
            # 记录恢复日志
            log_recovery(process_id, recovery_time, proc["restart_count"])
        else:
            # 恢复失败，通知管理员
            self.health_status[process_id] = "FAILED"
            await self.notify_admin(process_id, recovery_time)
```

```python
class AuditLogger:
```

## 六、执行流程

### 6.1 完整操作流程
```
Step 1: 屏幕捕获
  ├── 截取当前屏幕
  └── 计算屏幕哈希（用于去重）

Step 2: 语义分析
  ├── 构建UI元素树
  ├── 识别所有可交互元素
  └── 评估界面状态

Step 3: 目标定位
  ├── 语义匹配目标元素
  ├── 计算坐标位置
  └── 验证元素状态（可点击/可见/聚焦）

Step 4: 操作执行
  ├── 模拟人类操作轨迹（带随机延迟）
  ├── 执行点击/输入/拖拽
  └── 等待操作响应

Step 5: 结果验证
  ├── 再次截屏
  ├── 对比前后变化
  ├── 验证操作是否成功
  └── 失败则自动重试或降级

Step 6: 审计记录
  ├── 记录操作日志
  ├── 保存前后截屏
  └── 更新任务进度
```

### 6.2 错误恢复矩阵
| 错误类型 | 检测方式 | 恢复策略 | 最大重试 |
|---------|---------|---------|---------|
| 元素未找到 | 语义匹配失败 | 滚动/切换Tab后重试 | 3次 |
| 元素不可点击 | 状态检测 | 等待500ms后重试 | 3次 |
| 弹窗遮挡 | 检测遮挡元素 | 关闭弹窗后重试 | 2次 |
| 页面加载慢 | 检测加载状态 | 延长等待时间至10秒 | 2次 |
| 系统弹窗 | 检测系统对话框 | 按Enter/Esc尝试关闭 | 1次 |
| 进程崩溃 | 守护进程检测 | 自动重启进程 | 无限 |
