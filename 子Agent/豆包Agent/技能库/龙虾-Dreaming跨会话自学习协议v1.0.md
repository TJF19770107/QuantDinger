# 龙虾-Dreaming跨会话自学习协议 v1.0

> **对标来源**：Claude Managed Agents Dreaming（2026年5月6日研究预览）
> **版本**：v1.0 · 2026-05-31
> **所属轮次**：R07

---

## 一、协议目标

让Agent在会话间隙（"睡眠"期间）自动审查历史执行记录，提取失败模式、成功模板、共享偏好，并将学习成果沉淀为持久化记忆，实现"越用越聪明"的跨会话自我改进。

---

## 二、核心机制

### 2.1 Dreaming三阶段循环

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  审查阶段     │ ──→ │  提取阶段     │ ──→ │  沉淀阶段     │
│  扫描历史会话  │     │  识别模式     │     │  更新记忆库    │
└──────────────┘     └──────────────┘     └──────────────┘
```

### 2.2 三类可提取模式

| 模式类型 | 说明 | 示例 |
|---------|------|------|
| 重复错误 | 跨多次会话反复出现的失败模式 | "处理CSV文件时总忘记处理BOM头" |
| 收敛工作流 | 多次任务中自然形成的最优路径 | "发票整理→OCR→分类→Excel→汇总" |
| 共享偏好 | 团队/用户跨任务一致的偏好 | "所有报告使用A4横向排版" |

### 2.3 记忆结构化重组

Dreaming不仅添加新记忆，还会主动重组已有记忆：
- 合并重复/冲突的记忆条目
- 按主题/领域自动分类
- 标记过期/不再适用的记忆
- 保持记忆库高信噪比

---

## 三、可控性分级

| 级别 | 模式 | 说明 |
|------|------|------|
| L1 全自动 | 自动更新记忆 | 高置信度模式直接写入 |
| L2 半自动 | 审阅后落地 | 生成变更建议，等用户确认 |
| L3 仅报告 | 仅输出分析报告 | 不做任何自动变更 |

---

## 四、实际效果参考

- **Harvey法律Agent**：Dreaming启用后任务完成率提升约6x
- **关键因素**：Agent记住了文件类型兼容性问题和工具特定使用模式
- **多Agent协同**：一个Agent学到的经验自动共享给团队所有Agent
