## 一、核心原理

MUSE（Memory-Utilizing Skill Evolution）将技能从"静态文件"升级为"活的资产"。AI不再依赖人类手写技能，而是通过五阶段闭环自主创建、测试、修复、注册和维护技能。

**核心突破**：技能的完整生命周期由AI自主管理，人类只需在关键节点审批。

## 二、五阶段闭环

### 阶段1：Create（创建）
- **触发条件**：AI遇到新任务，当前技能库无匹配技能
- **执行动作**：
  1. 分析任务需求（输入类型/输出类型/工具依赖/安全边界）
  2. 生成技能包骨架：SKILL.md + scripts/ + tests/ + resources/ + .memory.md
  3. SKILL.md包含：自然语言使用说明 + 代码示例 + 前置条件 + 错误处理策略
  4. scripts/包含核心逻辑（Python/Shell/PowerShell按任务选择）
  5. tests/自动生成单元测试（覆盖正常路径+边界条件+异常路径）

### 阶段2：Test（测试）
- **触发条件**：Create完成后立即触发
- **执行动作**：
  1. 运行pytest/unittest完整测试套件
  2. 收集覆盖率报告（目标≥80%）
  3. 记录通过率到.metadata.json
- **结果分支**：
  - 通过率≥95% → 进入阶段4（Register）
  - 通过率<95% → 进入阶段3（Fix）

### 阶段3：Fix（修复）
- **触发条件**：Test未通过
- **执行动作**：
  1. 逐条分析失败用例，定位根因
  2. 修改scripts/中对应逻辑
  3. 更新tests/补充边界用例
  4. 重新运行完整测试套件
- **循环限制**：最多3轮Fix→Test，超过则标记为"需人工介入"
- **记录**：每次修复写入.memory.md（失败模式+修复方案）

### 阶段4：Register（注册）
- **触发条件**：Test通过
- **执行动作**：
  1. 写入技能库（`E:\龙虾AI主控中心\我的AI分身\技能库\`）
  2. 注册到.metadata.json（创建时间/准确率/使用次数/最后修改时间）
  3. .memory.md标记为"已注册"
  4. 通知记忆层（协议21 CASCADE三级沉淀）索引新技能

### 阶段5：Maintain（维护）
- **触发条件**：系统定期巡检（每次AutoWake）
- **执行动作**：
  1. **评分**：根据最近N次使用正确率+Token效率+用户反馈，更新.metadata.json
  2. **合并**：检测相似技能（功能重叠>60%）→ 评估合并可行性 → 自动合并+通知用户
  3. **修剪**：连续30天未使用且评分低于阈值 → 标记"候选删除" → 用户确认后归档
  4. **重训练**：评分持续下降 → 触发阶段1重新生成 → 新技能注册后旧版本归档

## 四、集成方式（接入龙虾五步法）

### Step 1：意图识别
- 用户请求 → AI判断是否需要新技能
- 检查技能库：`search_file(query="<任务关键词>", file_types=['md'])`限定技能库目录

### Step 2：能力映射
- 如技能库无匹配 → 触发MUSE Create
- 如技能库有匹配但评分<阈值 → 触发MUSE Maintain（重训练）

### Step 3：方案规划
- AI生成技能包 → 写入中间产物目录（temp）
- 运行测试 → 记录结果

### Step 4：自主执行
- 测试通过 → 自动注册到技能库
- 测试失败 → 自动修复（最多3轮）

### Step 5：反思进化
- 执行完成后，将本次执行结果写入.memory.md
- 触发记忆策展（协议29 Dreaming→提取模式→蒸馏原则）

## 五、安全约束

1. **文件写入范围**：仅限技能库目录，禁止写入系统目录
2. **代码审查**：第一次注册的技能需人工审批scripts/内容（防恶意代码）
3. **测试覆盖率**：必须≥80%，关键模块≥95%
4. **原子性**：技能注册失败→清理临时文件，不留半成品
5. **版本管理**：每次重训练生成新版本，旧版本归档（不直接覆盖）
