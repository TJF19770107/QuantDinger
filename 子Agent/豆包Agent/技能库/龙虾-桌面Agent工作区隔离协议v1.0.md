## 一、协议目标

赋予豆包Agent在隔离环境中安全执行桌面操作的能力。Agent在独立桌面会话中运行，与用户主桌面完全隔离，支持自然语言驱动的文件整理、格式转换、应用操作等桌面任务，同时提供审计日志和用户随时接管能力。

## 二、三层隔离架构

```
┌──────────────────────────────────────────────────┐
│               L3：审计与接管层                      │
│                                                    │
│  ┌──────────┐  ┌──────────┐  ┌──────────────┐    │
│  │ 全量审计 │  │ 用户接管 │  │ 操作预览确认  │    │
│  │ 日志     │  │ 一键中断 │  │ (高风险操作)  │    │
│  └──────────┘  └──────────┘  └──────────────┘    │
│                                                    │
│  ┌──────────┐                                     │
│  │ 会话回放 │  (事后追溯)                          │
│  └──────────┘                                     │
├──────────────────────────────────────────────────┤
│               L2：应用隔离层                        │
│                                                    │
│  每个应用/任务在独立Agent Workspace中运行           │
│  ┌────────┐  ┌────────┐  ┌────────┐              │
│  │ 文件   │  │ 格式   │  │ 预订   │              │
│  │ 整理   │  │ 转换   │  │ 票务   │              │
│  └────────┘  └────────┘  └────────┘              │
│  应用间不可交叉访问 | 异常应用不影响其他应用         │
│  文件操作限定授权目录                               │
├──────────────────────────────────────────────────┤
│               L1：桌面会话隔离层                     │
│                                                    │
│  Agent运行在独立桌面会话中                          │
│  与用户主桌面完全隔离                                │
│  无法访问/干扰用户个人桌面                           │
│  会话结束后自动清理                                  │
└──────────────────────────────────────────────────┘
```

## 三、授权目录白名单

Agent在隔离会话中只能操作以下授权路径：

```yaml
authorized_paths:
  - "E:\\龙虾AI主控中心\\"           # 龙虾主控中心（全局）
  - "E:\\龙虾AI主控中心\\我的AI分身\\" # AI分身目录
  - "E:\\龙虾AI主控中心\\Obsidian\\"   # Obsidian知识库
  - "C:\\Users\\{user}\\Downloads\\"   # 下载目录（整理任务）
  - "C:\\Users\\{user}\\Desktop\\temp\\" # 桌面临时目录

blocked_paths:
  - "C:\\Windows\\"
  - "C:\\Program Files\\"
  - "C:\\Users\\{user}\\AppData\\"（除Marvis工作目录外）
  - "C:\\Users\\{user}\\Documents\\"
  - "C:\\Users\\{user}\\Desktop\\"（除temp外）
```

## 四、自然语言→桌面自动化映射

### 4.1 文件整理类

| 自然语言 | Agent动作 | 隔离会话操作 |
|---------|----------|-------------|
| "帮我整理下载文件夹" | 扫描→分类→归档 | 在L1隔离会话中执行文件移动 |
| "把所有PDF移到文档目录" | 查找PDF→移动 | 仅操作授权目录内文件 |
| "删除临时文件" | 扫描temp→确认→删除 | 二次确认后才执行 |

### 4.2 格式转换类

| 自然语言 | Agent动作 | 隔离会话操作 |
|---------|----------|-------------|
| "把这个PDF转成Word" | 定位文件→调用转换→保存 | 原文件只读，输出新文件 |
| "把图片全转成PNG" | 扫描图片→批量转换 | 保留原始文件 |

### 4.3 应用操作类

| 自然语言 | Agent动作 | 隔离会话操作 |
|---------|----------|-------------|
| "打开Obsidian" | 启动应用→确认成功 | 在新桌面会话中启动 |
| "用Excel打开这个CSV" | 启动Excel→加载文件 | 不触碰用户已有Excel实例 |

### 4.4 信息提取类

| 自然语言 | Agent动作 | 隔离会话操作 |
|---------|----------|-------------|
| "从这些PDF中提取发票信息" | 批量读取→OCR→提取 | 只读操作，提取结果写回 |
| "统计这个文件夹里所有文件大小" | 递归扫描→汇总 | 只读操作 |

## 六、用户接管机制

### 6.1 接管触发条件

| 场景 | 触发方式 | Agent响应 |
|------|---------|----------|
| 高风险操作前 | 操作预览弹窗 | 等待用户确认或取消 |
| 用户主动中断 | 点击"接管"按钮 | 立即暂停所有操作，释放控制 |
| 异常检测 | SafeGuard自动触发 | 冻结当前会话，通知用户 |
| 操作超时 | 单步操作>60s | 暂停并询问是否继续 |

### 6.2 接管后状态

```
接管模式：
├─ 暂停模式：Agent暂停执行，保留当前状态，等待用户指令
├─ 继续模式：Agent从中断点恢复执行
├─ 回滚模式：撤销本次会话的所有操作，恢复初始状态
└─ 终止模式：结束会话，清理临时资源
```

## 八、执行约束

1. **会话生命周期**：每次桌面操作创建独立会话，完成后自动销毁
2. **文件操作限制**：仅限授权路径白名单，越界操作立即拦截
3. **并发限制**：同时最多1个桌面操作会话，防止资源冲突
4. **超时机制**：单次会话最长运行5分钟，超时自动终止
5. **资源清理**：会话结束后清理临时文件、关闭Agent启动的应用
