# 沙箱多层级隔离协议 v1.0

> **创建时间**：2026-05-31 R06
> **对标来源**：OpenClaw Sandbox (2026-05-10)
> **类型**：安全层 · 执行隔离
> **状态**：ACTIVE

---

## 一、协议目标

为豆包Agent的代码执行、Shell调用、MCP工具调用提供多层级沙箱隔离，限制Prompt Injection攻击爆炸半径，确保宿主系统安全。

---

## 二、三层运行时选择矩阵

| 层级 | 隔离强度 | 启动时间 | 适用场景 | 触发条件 |
|------|---------|---------|---------|---------|
| **L1 Docker容器** | 进程+命名空间 | ~200ms | 用户自有脚本、信任代码 | 默认 |
| **L2 gVisor** | 用户态内核拦截 | ~300ms | LLM生成代码、混合信任 | 代码来源含外源输入 |
| **L3 Firecracker microVM** | 硬件虚拟化 | ~1-2s | 不可信第三方Agent、公网内容 | 第三方Agent接入/公开issue |

## 三、六条沙箱铁律

### 3.1 默认即抛（Ephemeral by Default）
```
每个任务 = 新容器 → 执行完成 → 立即销毁
仅 /workspace 目录持久化
禁止跨任务复用容器
```

### 3.2 无宿主机网络（No Host Network）
```
独立网络命名空间
出站白名单：仅允许模型API端点 + 包注册表
DNS 经过滤器
```

### 3.3 无宿主机密钥（No Host Secrets）
```
Agent主进程持有API密钥
沙箱仅获取当前任务所需短期环境变量
密钥不在容器文件系统/环境变量中持久化
```

### 3.4 只读根目录（Read-Only Root）
```
容器文件系统除 /workspace 和 /tmp 外只读
禁止 write→chmod→execute 路径
```

### 3.5 资源配额（Resource Caps）
```
CPU: 按任务配置上限
内存: 按任务配置上限
磁盘IO: 限制写入速率
进程数: 硬上限128
Agent死循环 → 撞配额墙 → 自动终止
```

### 3.6 一任务一容器（One Task, One Container）
```
禁止复用长生命周期Shell
长生命周期Shell累积状态 = 免费提权原语
每个新Prompt = 全新沙箱环境
```

---

## 四、MCP安全规则

### 4.1 每个MCP Server = 不可信代码
```
社区MCP Server → 与Agent同等沙箱隔离
"A helpful community MCP server" = 一次Prompt距离的工具投毒向量
```

### 4.2 MCP工具权限按任务最小化
```
Agent只需要读文件 → 不暴露 shell.exec
Agent只需要查数据库 → 不暴露文件系统写入
能力式范围控制 → 被劫持工具列表无法提权
```

---

## 五、审计日志规则

```
每个命令执行 → 记录：命令原文 + 输入 + 退出码
日志写入Agent进程无法改写的存储位置
沙箱执行不可信代码 ✓
沙箱无法审计 = 只做了半份工作 ✗
```

## 六、参考Docker调用模板

```bash
docker run --rm \
  --read-only \
  --tmpfs /tmp:size=512M \
  --network=agent-sandbox \
  --cap-drop=ALL \
  --security-opt=no-new-privileges \
  --pids-limit=128 \
  --memory=2g --cpus=2 \
  -v "$WORKSPACE":/workspace \
  agent-runtime:latest \
  bash -c "$TASK_COMMAND"
```
