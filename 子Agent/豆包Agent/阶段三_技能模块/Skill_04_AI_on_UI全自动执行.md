# Skill_04：AI on UI 全自动执行

**版本号**：v1.0  
**创建日期**：2026-06-02  
**所属体系**：龙虾全域AI Agent执行层  
**挂载点**：全域调度中枢 → GUI自动化引擎

---

## 一、核心能力

1. **感知-决策-执行三层GUI自动化架构**：感知层（截图+OCR+元素树解析）→ 决策层（操作序列规划+状态机驱动）→ 执行层（键鼠模拟+操作验证）
2. **智能元素定位**：支持多模态定位策略——XPath/CSS选择器 + OCR文字匹配 + 图像模板匹配 + 坐标偏移，自动降级切换
3. **操作序列编排**：将自然语言任务指令解析为结构化的操作步骤序列（click / type / scroll / drag / wait / screenshot），含前置条件检查
4. **异常回退机制**：每步操作后执行"操作验证"（截图对比/元素状态检测），异常时自动回退至上一步并尝试替代定位策略
5. **跨应用编排**：支持多窗口切换、应用启动/关闭、剪贴板交互等跨应用自动化流程

---

## 二、输入规范

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| `task_description` | str | 是 | 自然语言任务描述，如"打开微信，给张三发一条'会议改到下午3点'" |
| `app_context` | JSON | 否 | 预知的应用上下文，含窗口句柄、进程名 |
| `max_steps` | int | 否 | 最大操作步数，默认50，防止无限循环 |
| `verification_mode` | str | 否 | 验证模式：`strict`（每步验证）/ `relaxed`（关键步骤验证）/ `none` |

---

## 三、输出规范

| 字段 | 格式 | 说明 |
|------|------|------|
| `action_plan` | JSON | 结构化操作序列，每步：`{step_id, action_type, target_element, parameters, precondition, expected_result}` |
| `execution_trace` | Markdown | 执行轨迹：每步截图路径、操作结果、耗时 |
| `final_status` | enum | `success` / `partial` / `failed` |
| `anomaly_report` | Markdown | 失败步骤的详细异常分析 |

---

## 四、执行协议

1. **任务解析**：LLM将自然语言指令分解为结构化子任务序列，标注每个子任务的前置条件
2. **环境感知**：截取当前屏幕 → OCR提取文字 + 控件树解析 → 匹配目标元素，生成候选定位策略列表（按置信度降序）
3. **步骤规划**：将子任务映射为具体操作步骤，含目标元素的多种定位 fallback
4. **逐步执行**：按序执行操作步骤，每步完成后执行验证（截图对比 / 元素存在性检测）
5. **异常处理**：验证失败 → 切换下一个定位策略 → 仍失败 → 回退至上一状态 → 超过3次失败则暂停并请求人工介入
6. **任务闭环**：全部步骤执行完毕 → 最终截图验证 → 生成执行轨迹报告

---

## 五、安全边界

- **禁止操作安全敏感界面**：不操作UAC弹窗、不输入凭据到未经验证的窗口
- **可见即所得**：仅操作当前屏幕可见的UI元素，不盲操隐藏控件
- **操作速率限制**：连续操作间隔 ≥ 200ms，模拟人类操作节奏
- **异常即停**：检测到意外弹窗（错误提示/更新提示/防火墙弹窗）立即暂停
