# Skill_06：自主技能生成

**版本号**：v1.0  
**创建日期**：2026-06-02  
**所属体系**：龙虾全域AI Agent自进化子系统  
**挂载点**：全域调度中枢 → 技能蒸馏引擎

---

## 一、核心能力

1. **六步蒸馏协议**：分析（Analyze）→ 计划（Plan）→ 转换（Transform）→ 构建（Build）→ 创建（Create）→ 更新（Update），完整闭环
2. **五道质量门控**：每步产出须通过对应质量门——完整性校验 / 格式合规 / 安全审计 / 对标一致性 / 可执行性验证，通过率目标100%
3. **技能模板自动填充**：基于龙虾全域官方模板v3.26的119项技能协议，自动匹配最适配的模板骨架并填充核心内容
4. **跨轮迭代追踪**：技能文件内置版本号与迭代日志，自动检测自上次生成以来的变更并生成增量更新
5. **安全红线注入**：任何技能生成时自动注入安全边界声明，确保所有产出技能自带安全防护

---

## 二、输入规范

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| `skill_spec` | JSON | 是 | 技能规格：`{name, domain, capabilities, reference_sources, template_type}` |
| `reference_materials` | list | 是 | 对标的源材料路径列表 |
| `output_dir` | str | 是 | 技能文件输出目录 |
| `version` | str | 否 | 目标版本号，默认v1.0 |
| `quality_gate_threshold` | float | 否 | 质量门通过阈值，默认1.0（全部通过） |

---

## 三、输出规范

| 字段 | 格式 | 说明 |
|------|------|------|
| `skill_file` | Markdown (.md) | 生成的标准化技能文件 |
| `quality_report` | JSON | 五道门控逐项评分与通过状态 |
| `iteration_log_entry` | JSON | 本次生成的迭代日志条目 |

---

## 四、执行协议

1. **分析（Analyze）**：解析 `skill_spec`，识别技能域 → 查询对标库 → 提取相关协议片段 → 门控G1：来源完整性 ≥ 3项对标
2. **计划（Plan）**：选择模板骨架 → 规划章节结构 → 标注需填充的变量字段 → 门控G2：模板合规性检查
3. **转换（Transform）**：将对标材料中的协议/方法论转写为结构化技能描述 → 门控G3：安全审计（确保无敏感信息泄露）
4. **构建（Build）**：填充所有章节（核心能力 / I/O规范 / 执行协议 / 安全边界 / 对标来源 / 迭代日志）→ 门控G4：对标一致性验证
5. **创建（Create）**：将完整内容写入 `.md` 文件至 `output_dir` → 自检文件编码（UTF-8）与Markdown语法
6. **更新（Update）**：若目标路径已有同名文件，执行增量合并：保留已有迭代日志 → 追加新版本日志条目 → 门控G5：可执行性验证（模拟挂载测试）

---

## 五、安全边界

- **禁止生成恶意技能**：自动检测技能描述中的恶意意图关键词（"绕过"、"提权"、"注入"），命中则拒绝生成
- **来源引用强制**：每个技能的对标来源必须包含至少1个已验证的本地文件路径
- **版本不可逆**：技能版本号只增不减，防止意外降级覆盖
- **敏感路径保护**：禁止将技能文件写入 `C:\Windows`、`C:\Program Files` 等系统目录
