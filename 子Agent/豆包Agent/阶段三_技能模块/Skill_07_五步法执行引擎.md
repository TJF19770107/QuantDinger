# Skill_07：五步法执行引擎

**版本号**：v1.0  
**创建日期**：2026-06-02  
**所属体系**：龙虾全域AI Agent执行框架  
**挂载点**：全域调度中枢 → 任务执行引擎

---

## 一、核心能力

1. **龙虾五步法v1.0闭环**：意图识别 → 能力映射 → 方案规划 → 自主执行 → 反思进化，五个阶段环环相扣
2. **ECC修正闭环**（Error Correction Cycle）：执行阶段出现偏差时，自动触发回退至"方案规划"阶段，重新规划后继续执行，无需人工介入
3. **意图消歧引擎**：接收自然语言指令后，通过上下文关联 + 历史记忆检索 + 反问澄清三个子模块，将模糊意图映射为精确任务描述
4. **能力匹配矩阵**：维护全域Agent能力-任务类型映射表，自动将子任务路由至最匹配的执行Agent
5. **MD5去重归档**：每次执行完成后，对任务+产出物做MD5哈希，自动检测重复任务并复用历史结果

---

## 二、输入规范

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| `user_intent` | str | 是 | 用户自然语言指令 |
| `context` | JSON | 否 | 上下文：`{session_id, history_ids, active_skills, environment}` |
| `max_iterations` | int | 否 | ECC修正最大迭代次数，默认3 |
| `execution_mode` | str | 否 | 执行模式：`auto`(全自动) / `interactive`(关键步骤确认) / `dry_run`(仅规划不执行) |

---

## 三、输出规范

| 字段 | 格式 | 说明 |
|------|------|------|
| `intent_analysis` | JSON | 意图解析结果：`{primary_intent, sub_intents, confidence, clarification_needed}` |
| `execution_plan` | Markdown | 五步法完整执行计划，含每步的Agent分配与预估耗时 |
| `execution_result` | JSON | 执行结果摘要：`{steps_completed, steps_failed, ecc_cycles, final_status}` |
| `reflection_report` | Markdown | 反思报告：偏差分析、改进建议、知识沉淀条目 |

---

## 四、执行协议

1. **意图识别（S1）**：接收 `user_intent` → 加载历史记忆 → 消歧推断 → 输出 `intent_analysis`；若置信度 < 0.7 且 `execution_mode=interactive`，触发反问澄清
2. **能力映射（S2）**：将确认后的意图分解为子任务列表 → 查询能力匹配矩阵 → 为每个子任务分配最佳Agent
3. **方案规划（S3）**：构建任务DAG（依赖关系 + 并行组） → 生成分步执行方案 → 若 `execution_mode=dry_run` 则到此终止
4. **自主执行（S4）**：按方案逐批执行 → 每批完成后做结果验证 → 若偏差超过阈值 → 触发ECC回退至S3重新规划（最多 `max_iterations` 次）
5. **反思进化（S5）**：汇总执行日志 → LLM分析偏差根因 → 生成改进建议 → 有价值的知识条目写入L3永久知识库；对所有产出物做MD5哈希，写入去重索引

---

## 五、安全边界

- **ECC上限保护**：同一任务的ECC回退次数 ≤ `max_iterations`（默认3），超出后标记为 `failed` 并输出详细异常报告
- **不可逆操作确认**：S4执行阶段如涉及🔴风险操作，强制暂停等待人工确认
- **去重防循环**：MD5去重机制防止同一任务被重复执行消耗资源
- **环境隔离**：S4执行在沙箱/独立工作目录中进行，不污染全局环境
