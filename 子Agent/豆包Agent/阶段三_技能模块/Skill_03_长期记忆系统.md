# Skill_03：长期记忆系统

**版本号**：v1.0  
**创建日期**：2026-06-02  
**所属体系**：龙虾全域AI Agent知识管理层  
**挂载点**：全域调度中枢 → 知识库引擎

---

## 一、核心能力

1. **三层记忆架构**：L1 实时缓存（会话级，自动过期）、L2 工作记忆（跨会话短期，7天保留）、L3 永久知识库（结构化持久存储），逐层蒸馏与衰减
2. **跨会话复用**：每次会话结束时，对L2工作记忆做关键信息抽取（用户偏好、决策结果、任务上下文），自动写入L3并在下次会话启动时注入
3. **向量检索接口**：L3层基于嵌入向量索引，支持语义检索（"上次关于XX的讨论"），召回率 ≥ 0.90
4. **记忆生命周期管理**：L1→L2蒸馏（会话结束触发）、L2→L3固化（7天周期触发）、L3过期清理（按用户定义的TTL策略）
5. **隐私分区**：敏感记忆（认证凭据、私钥、财务数据）与普通记忆物理隔离，敏感区写入需额外加密

---

## 二、输入规范

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| `memory_event` | JSON | 是 | 记忆事件：`{level, content, tags, ttl, sensitivity}` |
| `query` | str | 是（检索场景） | 自然语言检索查询 |
| `session_context` | JSON | 是（读/写） | 当前会话上下文标识 |
| `top_k` | int | 否 | 检索返回条数，默认10 |

---

## 三、输出规范

| 字段 | 格式 | 说明 |
|------|------|------|
| `write_result` | JSON | 写入确认：`{memory_id, level, stored_at, expires_at}` |
| `query_results` | list | 检索结果列表，每项含 `{content, relevance_score, source_level, created_at}` |
| `session_bootstrap` | Markdown | 会话启动时的L3注入摘要，含最近N条相关记忆 |

---

## 四、执行协议

1. **事件接收**：解析 `memory_event`，按 `sensitivity` 字段分流至普通区/敏感区
2. **分层路由**：`level=L1` → 写入会话级KV缓存（Redis/Memcached语义）；`level=L2` → 写入会话工作目录 `temp/memory_L2.json`；`level=L3` → 写入知识库持久存储
3. **蒸馏触发**：会话结束时，扫描L2中 `retention_score > threshold` 的条目，调用LLM做关键信息抽取，生成结构化摘要写入L3
4. **语义检索**：接收 `query` → 向量化 → 在L3向量索引中检索 → 按 `relevance_score` 降序返回
5. **会话启动注入**：新会话建立时，基于 `session_context` 自动检索L3中相关记忆，生成 `session_bootstrap` 注入提示词前缀

---

## 五、安全边界

- **敏感记忆加密存储**：`sensitivity=high` 的条目在写入L3前执行AES-256加密
- **禁止凭据明文存储**：检测到密码/API Key/Token模式时，仅存储 `{type: "credential", hint: "用户的XX凭据", location: "由用户保管"}` 元信息
- **TTL强制过期**：所有记忆条目必须有TTL，超期自动标记为 `expired`，7天后物理删除
- **不跨用户共享**：每个用户的L3知识库物理隔离
