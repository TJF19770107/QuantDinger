## 各Skill概要

### Skill_01 多Agent并行调度
**定位**：全域Agent任务编排层。基于Hermes SWARM协议的Kanban看板机制 + 龙虾调度体系的四模版（管道/扇出扇入/竞速/流水线），实现多Agent任务的优先级仲裁、并行调度与故障转移。核心输出为分批执行计划、看板状态快照与汇总执行报告。

### Skill_02 桌面安全自动化控制
**定位**：全域Agent安全审计层。融合Claude Agent OS的三级风险定级（🔴破坏性/🟡配置变更/🟢只读操作）与龙虾安全协议，实现指令深度审计、通配符穿透防护、敏感路径自动保护。所有高风险操作强制走显式确认回执。

### Skill_03 长期记忆系统
**定位**：全域Agent知识管理层。采用Obsidian三层架构（L1实时缓存 → L2工作记忆 → L3永久知识库），支持自动蒸馏、跨会话复用与向量语义检索。敏感记忆加密存储，所有条目强制TTL过期。

### Skill_04 AI on UI 全自动执行
**定位**：全域Agent GUI自动化执行层。基于感知-决策-执行三层架构，支持多模态元素定位（XPath/OCR/图像匹配）、操作序列编排与异常回退机制。每步操作后执行验证，异常自动切换替代策略。

### Skill_05 本地推理部署
**定位**：全域Agent推理基础设施层。基于Llama本地部署加速链（Ollama/vLLM分层路由 + AWQ量化 + FlashAttention-2），在RTX 4090上实现14.5x加速（4→58 tok/s）。预置三档配置方案，支持显存OOM自动降级。

### Skill_06 自主技能生成
**定位**：全域Agent自进化子系统。继承self-skill蒸馏协议R26版本（已迭代15轮）的六步流程（分析→计划→转换→构建→创建→更新），通过五道质量门控（完整性/格式合规/安全审计/对标一致性/可执行性）确保生成技能质量。

### Skill_07 五步法执行引擎
**定位**：全域Agent核心执行框架。实现龙虾五步法v1.0闭环（意图识别→能力映射→方案规划→自主执行→反思进化），内置ECC修正闭环与MD5去重归档。执行偏差自动回退重规划，最多3次修正。

### Skill_08 全域对标矩阵维护
**定位**：全域Agent质量保证层。基于龙虾全域模板v3.26的26维评估框架，维护龙虾体系与对标目标的逐维差距矩阵。自动计算对齐度分数、生成优先级追赶清单、输出版本趋势对比报告。
