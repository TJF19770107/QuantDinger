# Skill_02：桌面安全自动化控制

**版本号**：v1.0  
**创建日期**：2026-06-02  
**所属体系**：龙虾全域AI Agent安全子系统  
**挂载点**：全域调度中枢 → 安全审计层

---

## 一、核心能力

1. **三级风险定级引擎**：自动分类所有操作——🔴破坏性（格式化/清空/系统删除）、🟡配置变更（覆盖/卸载/注册表修改）、🟢只读操作（查询/读取/列目录），逐级匹配不同授权策略
2. **指令深度审计**：在执行任何 shell / python_executor 命令前，对命令字符串做关键词扫描（`del` / `rm` / `format` / `reg` / `kill` / `net stop`），命中则强制挂起并展示完整命令
3. **通配符/变量穿透防护**：检测到通配符（`*`, `?`）或环境变量（`$`, `%`）时，先执行模拟路径展开，告知用户受影响的具体文件路径及数量
4. **敏感路径自动保护**：硬编码保护区——`C:\Windows` / `C:\Program Files` / `C:\Program Files (x86)` / `C:\ProgramData` / `.git` / `.ssh` / `.aws` / `.kube` / `.env`，任何写入/删除操作自动拦截
5. **最小影响策略**：删除操作优先移入回收站；批量操作强制执行"1%试点 → 人工确认 → 全量执行"流程

| 字段 | 类型 | 必填 | 说明 |

## 四、执行协议

1. **操作捕获**：拦截所有 `shell_executor` / `python_executor` / `delete` / `write_file` / `edit_file` 调用
2. **风险定级**：解析命令语义，按三级标准定级——含 `rm -rf` / `format` → 🔴；含 `mv` / `cp -f` / 配置修改 → 🟡；纯 `cat` / `ls` / `dir` / `read` → 🟢
3. **深度审计**（仅🔴/🟡）：展开通配符，扫描路径前缀是否命中敏感路径保护区，列出所有受影响文件
4. **授权决策**：🔴 → 必须人工确认 + 建议备份；🟡 → AI自主提议时强制确认，用户主动要求时提示影响；🟢 → 直接放行
5. **执行监控**：操作执行过程中持续监听退出码和stderr，异常立即中断并回滚
6. **审计归档**：每次安全检查的结果写入 `temp/security_audit_{timestamp}.json`

---

## 五、安全边界

- **永不自行授权🔴操作**：即使用户在对话中口头授权，🔴操作也必须走 `ask_user(type="confirm")` 拿到显式确认回执
- **禁止隐蔽执行**：严禁通过 Base64 编码、Hex 编码、复杂脚本逻辑规避安全扫描
- **禁止静默变更**：禁止修改系统启动项、防火墙规则、注册表键值而不告知用户
- **凭据禁造**：禁止编造/猜测任何认证凭据，需要时向用户索取
