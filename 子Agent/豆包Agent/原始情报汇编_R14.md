## 情报源3: Dev.to — How to sandbox AI agents in 2026

**URL**: https://dev.to/manveer_chawla_64a7283d5a/how-to-sandbox-ai-agents-in-2026

**核心发现**：

1. 2026年共识：Docker/runc共享内核隔离已不足以执行LLM生成代码，需视为敌对代码

3. 三层市场格局：原语层(自建) / 嵌入式运行时(E2B/microsandbox) / 托管平台(Daytona/Modal/Northflank)
4. Google Agent Sandbox: 为K8s团队提供开源沙箱，含温池
5. AWS/Azure/GCP全部选择最强隔离原语指向AI，无一选容器

**对豆包价值**：Firecracker MicroVM集成应作为P1级行动项，同步评估E2B作为嵌入式运行时方案。
