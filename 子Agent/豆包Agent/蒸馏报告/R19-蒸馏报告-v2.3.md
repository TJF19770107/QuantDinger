## 三、步骤2：知识结构化提取

### 3.1 六大核心洞察

#### 洞察1：多Agent范式从理论走向工程化 — 2026年是"军团指挥"元年

- Hermes SWARM v0.15.0：747 PR、28万行变动，Orchestrator+Kanban实现"1个Orchestrator，0个人类干预"
- Antigravity 2.0：93个Agent并行构建OS，<12小时，<$1000
- Claude Code v2.1：7子Agent并行，HumanEval加速6.0x，错误传播率-89%
- 关键数据：session_search从30s→20ms（4500x），run_agent.py从16083→3821行（-76%）

#### 洞察2：上下文压缩成为规模化的关键技术瓶颈

- Claude Code五层压缩：84.7K→19.2K token（4.4x），成本$0.27→$0.062
- 准确率仅下降1.2pp（96.3%→95.1%），ROI极高
- 第5层用1.5B轻量模型蒸馏长程依赖，开辟了"小模型压大模型"范式
- Hermes v0.15.0每轮函数调用从399K→213K（-47%），同向印证

#### 洞察3：事件驱动自动化让Agent从"工具"变为"工作者"

- Codex Goal Mode：任务跨度数小时到数天，无人值守
- Codex Triggers：GitHub Issue→自动修复→开PR，全自动
- Antigravity Scheduled Tasks：cron定时唤醒Agent
- Hermes定时启动+过期检测+自动重试
- OpenAI内部Codex Agent已在自主运营数据平台

#### 洞察4：MCP已成为2026年工具集成事实标准

- OpenClaw：任意MCP Server即插即用，"USB for AI"
- ACP协议：跨Agent标准化通信，统一调度Claude Code/Codex/Gemini CLI等10+编码Agent
- OpenCode ACP-next：会话生命周期、事件路由、流式推送
- Gateway五位一体架构：多渠道接入、协议转换、智能调度、消息总线、运维管理

#### 洞察5：本地推理分层化 — 不再是一刀切

- Ollama：62 tok/s单用户，开发原型
- vLLM：920 tok/s（50并发），6.6x吞吐优势，Blackwell上16.6x
- Speculative Decoding：2-3x加速，RTX 4090上41 tok/s
- 量化栈：Q4_K_M（40GB→12GB）+ FP8（Hopper近无损30%加速）
- 成本对比：GPT-4o API $7500/月 vs A100+vLLM $1600/月（-78%）

#### 洞察6：GUI Agent从自动化到智能化跨越

- Codex Appshots：窗口视觉+文本上下文，手机远程控制Mac
- 三层架构确立：感知层（OCR+CV+Accessibility API）→决策层（规则+LLM）→执行层
- Accessibility API路线：数据不出设备，毫秒级响应，语义确定性定位
- 关键反模式明确：禁止无许可自动执行高影响操作
