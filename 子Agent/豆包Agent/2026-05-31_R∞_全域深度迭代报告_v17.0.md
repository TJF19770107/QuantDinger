## 三、架构变更

### 3.1 版本号：v6.0 → v7.0（主版本+1）

**变更理由**：新增"自进化层(EVOL)"作为独立架构层，从原工具层(TOOL)中剥离并提升为与执行层平级的核心层。

```
旧架构(v6.0)：                 新架构(v7.0)：
思考层(THINK)                  思考层(THINK)
  ↓                              ↓
规划层(PLAN)                    规划层(PLAN)
  ↓                              ↓
执行层(EXEC)                    执行层(EXEC)
  ↓                              ↓
工具层(TOOL)      ←→           自进化层(EVOL)  ← 新增独立层
  ↓                              ↓
基础设施层(INFRA)               工具层(TOOL)
                                  ↓
                                基础设施层(INFRA)
```

### 3.2 自进化层(EVOL)架构设计

```
EVOL 自进化层（对标 Autogenesis + ANNEAL + MUSE）
├── EVOL-OBSERVE：执行日志采集 + 模式识别引擎
│   └── 对标：Autogenesis 执行层采集 + SkillEvolver 策略多样化探索
├── EVOL-REFLECT：根因分析 + 改进候选生成
│   └── 对标：ANNEAL 符号补丁生成 + MUSE 创建阶段
├── EVOL-VALIDATE：沙箱验证 + 独立审计
│   └── 对标：Autogenesis 测试环境验证 + SkillEvolver 独立审计
├── EVOL-INTEGRATE：安全集成 + 检查点快照
│   └── 对标：MOSS 代码层集成 + Autogenesis 部署
└── EVOL-UPDATE：能力注册表更新 + 记忆归档
    └── 对标：MUSE 记忆/管理阶段 + Hermes KEPA
```
