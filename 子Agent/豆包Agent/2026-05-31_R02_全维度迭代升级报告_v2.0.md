## 三、本轮迭代优化方案

### 优先级 🔴 P0（本轮立即实施）

#### P0-1：引入长期记忆系统（对标 Claude Managed Agents Memory + Dreaming）

```
实现方案：
1. 每轮迭代结束后，自动归档本轮情报/决策/产出到记忆存储
2. 下一轮启动时，自动加载前N轮记忆摘要作为上下文注入
3. 建立"记忆压缩"机制：超过N轮的旧记忆自动摘要压缩
4. 引入"Dreaming"复盘：定期回顾历史迭代，发现模式/改进空间

存储路径：E:\龙虾AI主控中心\我的AI分身\子Agent\豆包Agent\memory\
文件格式：memory_R{轮次}_{日期}.json
```

#### P0-2：建立自改进闭环（对标 HyperAgents DGM-H）

```
实现方案：
1. 每轮迭代生成"改进建议"清单
2. 下一轮启动时加载上一轮建议，验证是否已落实
3. 建立"成功变体存档"：每个有效的优化方案保留为历史变体
4. 改进"改进过程本身"：定期评估迭代效率，优化迭代流程

存储路径：E:\龙虾AI主控中心\我的AI分身\子Agent\豆包Agent\evolution\

```

```
1. 每个任务定义明确的"成功标准"rubric
2. Agent围绕outcome工作，而非围绕prompt
3. 执行完成后自动对照rubric自评
4. 未达标的自动触发重试/修正
```
