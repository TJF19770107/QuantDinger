## 四、关键情报洞察

### 4.1 Agent架构共识收敛

业界对Agent核心架构达成三层共识：
```
Model（大脑）+ Harness（身体/工具）+ Shell（交互界面）
```
Harness竞争成为胜负手：Claude Code的Agentic Loop(gather→act→verify)被广泛借鉴，工具系统的"少而精+原子组合"设计哲学被验证有效。

### 4.2 自进化进入元认知阶段

从"AI会干活"到"AI会变强"再到"AI会越来越会变强"：
- DGM（2024）：仅在coding场景自进化
- HyperAgents（2026-04）：元认知自我修改，跨域通用
- GenericAgent（2026-04）：Token降10倍，经验复用
- MiniMax M2.7（2026-03）：70%-80% RL pipeline由AI完成

### 4.3 Swarm Scaling Law初步发现

港大黄超团队实验关键结论：3-5 Agent为最优规模，更多Agent边际递减甚至负收益。瓶颈不在沟通（零延迟），而在任务分解复杂度、冲突协调、上下文对齐——这些隐性成本随Agent数量指数增长。

### 4.4 CLI-Native交互范式兴起

从GUI Computer Use（让AI学人类）转向CLI-Native（让软件说AI语言）。黄超CLI-Anything Hub已有80软件31分类。本质是交互范式的根本重构。

### 4.5 开源Agent生态加速

- Hermes：Python击败Rust(Codex)，76%代码精减，Swarm模式
- OpenCode：4.6万Star，75+模型，MIT开源，月活65万
- nanobot：100天日更，20万下载，DeepSeek推荐全球15个Agent
