## 二、核心提取：5项新增技能协议

### R06-S01: 动态工作流编排协议 v1.0

**对标来源**：Claude Opus 4.8 Dynamic Workflows + Hermes SWARM v2.1

**核心价值**：
- 编排脚本机制：主Agent临时编写编排脚本，动态启动并行子Agent
- 并行子Agent池：coordinated subagents协同处理大规模任务
- Kanban看板管理：可视化任务分解/分配/追踪/汇总
- 适用场景：service-wide bug hunt / 大型迁移 / 设计压力测试

**文件**：`龙虾-动态工作流编排协议v1.0.md`

---

### R06-S02: 代价感知执行协议 v1.0

**对标来源**：Claude Opus 4.8 Effort Control + Token价格战趋势

**核心价值**：
- 三档 Effort 模式：Low（快省）/ Medium / High（深复杂，默认）
- Token 预算软停止：接近预算时优雅降级而非硬中断
- 成本回报率预估：复杂任务执行前预估Token消耗
- 适配 Agent 高消耗特性（Dynamic Workflows 官方提醒 "powerful but expensive"）

**文件**：`龙虾-代价感知执行协议v1.0.md`

---

### R06-S03: 不确定性自检协议 v1.0

**对标来源**：Claude Opus 4.8 判断力突破

**核心价值**：
- 代码缺陷未经提醒通过概率大幅降低
- 证据不足时主动暂停，等待用户补充信息
- "知道自己不知道"：在模糊需求/缺失参数/高风险场景主动亮红灯
- 反过度自信：降低 Agent "笃定地告诉你一切正常" 的幻觉风险

**文件**：`龙虾-不确定性自检协议v1.0.md`

---

### R06-S04: 事件驱动自动化流水线协议 v2.0

**对标来源**：Codex Triggers + Plugins（2026年5月GA）

**核心价值**：
- GitHub事件监听（Issue / PR / Label）→ 自动触发Agent任务
- 外部工具链接入（Sentry / Datadog / JIRA / CircleCI）
- MCP协议标准化插件接口
- 完整流水线：事件 → 分析 → 修复 → 测试 → 开PR → 等审批
- 移动端 Approve：手机远程审批（结合R06-S05）

**文件**：`龙虾-事件驱动自动化流水线协议v2.0.md`

## 五、行业趋势判断

### 5.1 5月关键信号：Agent已取代Chat成为主要赛道

2026年5月是一个分水岭。7大Agent几乎同步发布更新，核心不再是"模型更强"，而是"模型被允许做更多事"：

- **Claude**：从聊天模型 → 工程协作系统
- **Codex**：从代码补全 → 无人值守全自动Agent
- **Hermes**：从单兵Agent → 无限Agent军团指挥平台
- **Gemini**：统一迁移至多Agent平台Antigravity

### 5.2 Token价格战本质是Agent消耗战

Agent对Token的消耗是聊天的10-100倍。Dynamic Workflows官方明确提醒"powerful but expensive"。价格战不是为了让聊天更便宜，而是为了支撑Agent高频调用。

### 5.3 安全成为Agent化瓶颈

OpenClaw被中国NVDB和CNCERT同时警告；Codex Mac安全更新强制执行。Agent具备自主执行能力后，安全不再只是数据隐私问题，而是系统控制权问题。

### 5.4 Marvis的OS层级定位具有前瞻性

行业从"谁的模型更大"→"谁离操作系统更近"，Marvis的OS层级定位 + Intel/WinML底层优化符合这一趋势。
