### 1.2 人格双模态特征

历史数据显示出典型的 **「蚂蚁搬家 + 定时炸弹」双模态** 行为结构：

| 模态 | 特征 | 数据支撑 |
|------|------|----------|
| **蚂蚁搬家（常态）** | 大量微利交易，小赢即走 | 77.2%交易<50 USDT，均盈+5.68 USDT，胜率57.9% |

> **心理学解读**：这是一种典型的"损失厌恶不对称"——盈利时急于落袋为安（止盈过早），亏损时拒绝认错离场（止损缺失）。蚂蚁搬家积累的利润被定时炸弹一次性爆破。转型的核心不是提升胜率（57.9%已足够），而是**截断亏损、让利润奔跑**。

### 2.2 单笔交易情绪曲线

```
开仓前：期待/焦虑 ──→ 开仓后浮盈：兴奋/贪婪 ──→ 微利时：急于落袋（止盈过早）
                                           ──→ 开仓后浮亏：否认/侥幸 ──→ 扩大亏损：恐惧但拒绝止损
                                                                      ──→ 极端亏损：麻木/放弃（爆仓）
```

> **关键转折点**：浮盈阶段→"赚一点就跑"是盈亏比0.55的直接心理根源；浮亏阶段→"等回本就出"是止损缺失的心理根源。两者的共同基础是**以入场价为锚的锚定效应**。

> **v1.9优先级重构逻辑**：LAB从$8.70暴跌至$4.89后，市场环境剧变。止盈过早（在上涨趋势中过早平仓）在下跌趋势中不再是首要问题——当前你没有浮盈可止。**抄底冲动**和**报复交易**取而代之成为最危险的P0错误模式。历史数据显示，抄底失败是散户在暴跌中亏损的第二大来源（仅次于不止损）。

### 4.2 四大致命错误深度剖析

#### 错误#1：止损缺失 — 「等回本就出」

- **数据**：38个订单中止损设置率为0%，已导致1次爆仓（LAB $7.461）
- **心理链**：入场价成为心理锚点 → 浮亏时否认"这不是亏损，只是回调" → 亏损扩大时侥幸"还会回来的" → 极端亏损时麻木"已经这样了，拿着吧" → 爆仓
- **核心修复**：止损从"文档规则"升级为"代码强制"，开仓API中`stopLossPrice`为必填字段

#### 错误#2（新增）：抄底冲动 — 「跌了这么多该涨了」

- **触发条件**：LAB从$8.6953暴跌至$4.8935（约-44%），跌幅巨大引发"捡便宜"心理
- **心理链**：看到暴跌 → 锚定之前的高点$8.70 → "已经跌了44%，还能跌到哪？" → 急于抄底 → 若继续下跌 → 加仓（摊平成本） → 继续跌 → 爆仓
- **行为金融学解释**：这是典型的**锚定效应+均值回归错觉**。交易者不自觉地将$8.70作为"正常价位"锚点，认为$4.89是"打折价"。但在加密货币市场，跌44%后可以再跌50%（从$4.89跌到$2.45）。
- **核心修复**：抄底冷却期7天 + 底部结构确认条件（双底/W底/头肩底至少1项 + RSI脱离超卖 + 放量阳线确认）

#### 错误#3（新增）：报复交易 — 「把亏的赚回来」

- **触发条件**：LAB爆仓$7.461 + 后续暴跌，双重心理创伤
- **心理链**：爆仓创伤 → 愤怒/不甘 → "必须翻本" → 放大杠杆/仓位 → 非理性交易 → 更大亏损
- **核心修复**：爆仓后7天仓位5%/杠杆1x强制约束（代码层）；小仓位盈利重建信心

#### 错误#6：币种过度分散 — 「贪多嚼不烂」

- **数据**：126个币种，TOP5贡献+1,451.52 USDT（138.7%），其余121个整体净亏损-404.77
- **心理链**：看到新币种→怕错过机会（FOMO）→小仓位尝试→微利或微亏→换下一个。实质是把时间和精力浪费在大量无效交易上
- **核心修复**：币种白名单上限10个，聚焦TOP5盈利品种

### 4.3 错误模式关联图（v1.9更新）

```
止损缺失 ──→ 大额亏损失控 ──→ 回撤失控 ──→ 爆仓
    ↑                           ↑
    │                           │
过度交易 ←── 做空偏好偏执 ←── 确认偏误
    │                           │
    └──→ 止盈过早 ←──→ 盈亏不对称
              ↑
              │
币种过度分散 ←── FOMO ←── 看到机会就冲

爆仓 ──→ 报复交易 ──→ 更大亏损 ──→ 再次爆仓（死亡螺旋）
                ↑
                │
暴跌>40% ──→ 抄底冲动 ──→ 接飞刀 ──→ 加仓摊平 ──→ 爆仓
```

> **v1.9核心洞察**：止损缺失仍是所有致命错误的"根节点"。但在暴跌环境下，新增了两条致命路径——**爆仓→报复交易→死亡螺旋**和**暴跌→抄底冲动→接飞刀→爆仓**。这两条路径是当前交易心理画像的最高优先级防范目标。
