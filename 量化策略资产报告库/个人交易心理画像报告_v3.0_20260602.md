## 二、情绪波动图谱

### 2.1 情绪周期模型

```
盈利期:  自信膨胀 → 仓位放大 → 风险偏好飙升 → 回撤预警
         ↓
亏损期:  否认扛单 → 愤怒加仓 → 恐惧割肉 → 绝望停手
         ↓
恢复期:  冷静反思 → 小仓试水 → 信心重建 → 进入下一循环
```

### 2.2 关键情绪触发器

| 触发事件 | 情绪反应 | 行为后果 | 严重度 |
|----------|----------|----------|:---:|
| 连续盈利3+笔 | 过度自信 | 放大仓位、降低止损标准 | 🔴 |
| 单笔大亏（>5%） | 报复性交易 | 追回心态、频繁开仓 | 🔴 |
| 踏空行情 | 懊悔焦虑 | 追高入场、放弃等待 | 🔴 |
| 横盘震荡 | 无聊烦躁 | 强行交易、降低信号标准 | 🟡 |
| 浮盈回吐 | 贪婪抗拒 | 不止盈、幻想更高 | 🟡 |
| 浮亏扩大 | 恐惧否认 | 不止损、扛单加仓 | 🔴 |

### 2.3 情绪-决策偏差矩阵

| 偏差类型 | 具体表现 | 影响方向 |
|----------|----------|----------|
| **确认偏误** | 只看支持持仓的信息，忽略反向信号 | 持仓过久 |
| **损失厌恶** | 亏损时不愿止损，盈利时急于落袋 | 截断利润、放大亏损 |
| **锚定效应** | 以入场价/前高/前低为心理锚点 | 错误判断进出场 |
| **近期偏误** | 最近一笔交易结果严重影响下一笔决策 | 情绪连锁反应 |
| **过度交易** | 无信号时强行找理由入场 | 手续费损耗+情绪消耗 |

## 五、交易心理画像总结

### 5.1 人格类型定义

**类型**: **激进型技术交易者 — 情绪波动敏感期**

- 核心驱动力: 对市场的掌控欲 + 快速盈利的渴望
- 核心恐惧: 错过行情(FOMO) + 承认错误的痛苦
- 决策速度: 快 → 但质量不稳定
- 风险态度: 理论上保守 → 实践中激进

### 5.2 关键成长路径

```
当前阶段: 有技术基础但情绪管理不足
    ↓
近期目标: 建立铁律止损体系 + 仓位标准化
    ↓
中期目标: 情绪与决策解耦 + 机械化执行
    ↓
远期目标: 直觉与规则融合 → 交易大师
```

### 5.3 最需警惕的三大陷阱

1. **盈利后的狂妄**: 连续盈利后放大仓位 = 灾难前奏
2. **亏损后的报复**: 亏损后急于翻本 = 连环亏损
3. **信号饥渴**: 没有明确信号时强行交易 = 慢性失血
