## 四、风控执行SOP

### 4.1 六条风控规则（RM1-RM6）执行标准*

| 规则 | 内容 | 执行动作 | 违规处理 |
|------|------|----------|----------|
| **RM1** | 单币种最大亏损≤2% | 亏损达-2% → 强制平仓 | 违规 → 当日禁交易 |
| **RM2** | 总仓位最大亏损≤5% | 总浮亏达-5% → 减半仓位 | 违规 → 降级L2以下 |
| **RM3** | 同向信号间隔≥30分钟 | 同方向E1-E5信号 <30分钟 → 忽略 | 违规 → 记录"过度交易" |
| **RM4** | 追踪止损触发即执行 | 价格回撤达追踪止损位 → 立即平仓 | 违规 → 标记"不止损" |
| **RM5** | 禁战区不持L2以上仓位 | 23:00时段检测 → L2以上强制平仓 | 违规 → 策略重置 |
| **RM6** | 强平线≥保证金150% | 保证金比例<150% → 强制减仓 | 违规 → 停止所有交易 |

### 4.2 止损执行流程（标准化）

```
Step 1: 开仓同时挂止损单（不挂止损 = 不开仓）
Step 2: 价格触及止损位 → 系统自动平仓（不等待确认）
Step 3: 止损触发后记录 → 归类（正常止损/操作失误/判断错误）
Step 4: 连续止损≥2笔 → 暂停交易，复盘原因
```

### 4.3 止盈执行流程（阶梯式）

| 盈利阶段 | 操作 | 说明 |
|----------|------|----------|
| **盈利+3%** | 移动止损至开仓价 | 保证不亏 |
| **盈利+5%** | 平仓1/3，移动止损至+3% | 锁定部分利润 |
| **盈利+7%** | 平仓再1/3，移动止损至+5% | 扩大锁定 |
| **盈利+10%** | 全平或留1/3追踪止损 | 让利润奔跑 |
| **盈利+15%** | 全平 | 不贪最后5% |

## 六、道家心法实战卡片

### 6.1 四句心法对应交易场景

| 道家心法 | 交易场景 | 具体行动 |
|----------|----------|----------|
| **道可道，非常道** | 市场本质不可言说 | 策略保持弹性，不迷信固定模式；每周迭代 |
| **无名，天地之始** | 从混沌中发现规律 | 主力沉默期（吸筹/洗盘）保持观察，不急于下结论 |
| **有名，万物之母** | 从秩序中执行计划 | 主力信号明确（拉升/出货）果断执行，不犹豫 |
| **天之道，利而不害** | 顺势不逆势 | 只做顺势单；逆势单=害，不做 |
| **圣人之道，为而不争** | 不争一时盈亏 | 止损果断，不报复交易；长期复利>短期暴利 |

### 6.2 心法检查（每笔交易前默念）

```
① 这笔交易是"顺势"（天之道）还是"逆势"？
   → 逆势：放弃
② 这笔交易是在"争一时盈亏"还是"为长期复利"？
   → 争一时：放弃
③ 市场当前是"无名"（混沌）还是"有名"（有序）？
   → 无名：观望；有名：执行
④ 策略是否因近期盈亏而偏离原定规则？
   → 偏离：回归规则
```
