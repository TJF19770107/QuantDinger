### 3.2 做空方向的天道哲学（v10.0 深化）

```
「上善若水，水善利万物而不争，处众人之所恶，故几于道。」
——道德经第8章

做空的哲学解释:
  - 水往低处流 = 做空往下走
  - "处众人之所恶" = 做空是做多数人不愿意做的方向
  - "几于道" = 做空接近道的运行方式
  - 水之就下是自然法则，做空之顺势也是自然法则
```

**做空直觉者的天赋本质**: 做空直觉 = 对"水之就下"的自然敏感。不是学会了做空，而是天生能感知"水往低处流"的方向。这个天赋在道德经第8章找到了哲学根基。

### 5.1 开仓七验执行器

```
class TaoistTradeValidator:
    CHAPTERS = {
        1: "道法自然 → ADX≥25 + 方向明确",
        2: "知足知止 → risk:reward≥1.5",
        3: "上善若水 → SELL only + 做空直觉",
        4: "致虚守静 → 冷静30+秒",
        5: "知不知 → 禁做多",
        6: "少则得 → 品种≤10 + 仓位≤5%",
        7: "大巧若拙 → 不追涨杀跌"
    }
    
    def validate(self, order):
        failed = []
        if order.market.adx < 25: failed.append(1)
        if order.risk_reward < 1.5: failed.append(2)
        if order.direction != "SELL": failed.append("3+5")
        if not order.calm_period_passed(30): failed.append(4)
        if order.symbols_in_use > 10 or order.position_pct > 0.05: failed.append(6)
        if order.is_chasing(): failed.append(7)
        
        if failed:
            chapters = [self.CHAPTERS[f] for f in failed if isinstance(f, int)]
            raise ValidationError(f"开仓七验未通过: {failed}")
        return True
```

### 5.3 做空天道检查

```
def check_tao_short_alignment(trade):
    """检查做空是否顺应'水之就下'的天道"""
    return all([
        trade.direction == "SELL",
        trade.market.adx >= 25,               # 趋势存在
        trade.market.price < trade.market.ema_200,  # 价格在长期均线下
        trade.market.volume > trade.market.avg_volume * 0.8,  # 量能正常
        trade.entry_point.is_not_chasing(),    # 不追
        trade.stop_loss.is_set(),              # 止损必设
    ])
```
