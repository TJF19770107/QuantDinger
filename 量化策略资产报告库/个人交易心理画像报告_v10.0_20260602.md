### 2.1 周一盈利→周二亏损：盈利后过度自信的48小时动力学

**心理学机制**（v10.0深度拆解）：

| 阶段 | 时间 | 心理状态 | 行为表现 | 数据证据 |
|------|------|---------|---------|----------|
| 盈利高峰 | 周一收盘 | 欣快+自信膨胀 | 扩大仓位、降低标准 | 周二交易量维持高位 |

```

    reject("止损必填: 缺失stopLossPrice拒绝执行")
```

### 6.3 盈亏比硬约束（P0）

```
# 规则: 盈亏比≥1.5
risk = abs(order.entry_price - order.stopLossPrice)
reward = abs(order.takeProfitPrice - order.entry_price)
if reward / risk < 1.5:
    reject(f"盈亏比不合格: {reward/risk:.2f} < 1.5")
```

### 6.4 时段禁令（P0）

```

FORBIDDEN_HOURS = [4, 5, 22]  # 04-06 UTC, 22-23 UTC

    reject(f"时段禁令: {current_hour_utc}:00 UTC禁止开仓")
```
