## 零、道之总纲

> **道可道，非常道。名可名，非常名。**
> **无，天地之始；有，万物之母。**
> **故常无，欲以观其妙；常有，欲以观其徼。**
> **此两者同出而异名，同谓之玄。玄之又玄，众妙之门。**

本策略以《道德经》为底层操作系统，将道家智慧转化为可量化、可执行、可迭代的交易规则。五章心法对应交易全流程的五个核心环节。

## 第一章：守无 — 空仓等待之道

### 1.1 核心要义

> **"无"并非消极的空，而是最高级的积极。空仓不是不做，而是等待最佳时机。**

### 1.2 空仓触发规则

| 触发条件 | 执行 | 空仓级别 |
|----------|------|:---:|
| 主力阶段判定为"不明" | 维持空仓，不操作 | 🟢 常规 |
| 市场环境判定为"极端" | 清仓至空仓 | 🔴 强制 |
| 连续亏损3笔 | 强制空仓24小时 | 🔴 强制 |
| 重大宏观事件前4小时 | 减仓至空仓 | 🟡 预防 |
| 个人情绪评分<3分（满分10） | 当日禁止开仓 | 🔴 强制 |
| 周末/节假日低流动性时段 | 建议空仓或极轻仓 | 🟢 常规 |

### 1.3 "守无"纪律

```
守无三不:
  1. 不为了交易而交易——无信号则无动作
  2. 不做超出能力圈的交易——不懂不做
  3. 不在情绪波动时做决策——心不静不开仓

守无的好处:
  → 保存本金，活到真正机会出现
  → 保持客观，不受持仓偏见影响
  → 积蓄能量，一击必中的爆发力
```

## 第二章：观徼 — 趋势研判之道

### 2.1 核心要义

> **"常有，欲以观其徼"——当市场出现"有"（信号），就要观察它的边界和规律。**

### 2.2 趋势研判五层过滤

| 层级 | 研判内容 | 判断标准 | 权重 |
|:---:|------|------|:---:|
| 第一层 | **大周期方向** | 日线/周线EMA排列方向 | 30% |
| 第二层 | **主力阶段位置** | 吸筹/洗盘/拉升/出货判定 | 25% |
| 第三层 | **量价配合关系** | 量增价升=健康 / 量价背离=警惕 | 20% |
| 第四层 | **关键位博弈** | 支撑/阻力位的多空争夺结果 | 15% |
| 第五层 | **市场情绪共振** | 多品种、多时间框架的一致性 | 10% |

### 2.3 趋势判定矩阵

| 综合得分 | 趋势判定 | 操作倾向 |
|:---:|------|------|
| ≥80% | **强趋势** | 积极做多/做空 |
| 60%-79% | **趋势确立** | 标准仓位操作 |
| 40%-59% | **趋势不明** | 轻仓或观望 |
| 20%-39% | **趋势弱** | 不建议入场 |
| <20% | **无趋势** | 空仓等待 |

### 2.4 观徼实战清单

```
每日趋势研判 Checklist:
□ 大周期EMA排列: 多头排列/空头排列/缠绕 → 得分: __/30
□ 主力阶段判定: 吸筹/洗盘/拉升/出货/不明 → 得分: __/25
□ 今日量价关系: 配合/背离/异常 → 得分: __/20
□ 关键位状态: 突破/支撑/阻力/震荡 → 得分: __/15
□ 市场共振: 一致/分化/混乱 → 得分: __/10
────────────────────────────────
总分: __/100 → 趋势判定: _______
```

## 第三章：顺势 — 持仓操作之道

### 3.1 核心要义

> **"天之道利而不害"——顺应趋势去获利，而不是对抗趋势。**

### 3.2 顺势操作规则

#### 3.2.1 入场规则

| 入场类型 | 条件 | 仓位 | 止损 |
|----------|------|:---:|------|
| **试探入场** | 吸筹确认 + 趋势≥60% | 10% | 吸筹区间下沿-1% |
| **标准入场** | 拉升初期 + 趋势≥70% | 20% | 突破K线低点或ATR×2 |
| **加仓** | 拉升确认 + 趋势≥80% | +5%（最大25%） | 移动至新的支撑位 |

#### 3.2.2 持仓规则

```
持仓三守:
  1. 守止损——止损位绝不移动扩大，只能向有利方向移动
  2. 守趋势——只要趋势未反转，就继续持有
  3. 守仓位——不超过25%上限，不因浮盈而膨胀仓位

持仓三放:
  1. 放利润奔跑——趋势在就让利润跑，不加主观限制
  2. 放小的波动——日内的正常震荡不构成离场理由
  3. 放对的执念——如果发现自己判断错了，立即承认并改正
```

#### 3.2.3 离场规则

| 离场类型 | 触发条件 | 操作 |
|----------|------|------|
| **止损离场** | 价格触及止损位 | 无条件立即平仓 |
| **止盈离场** | 主力出货确认 + 高位滞涨 | 分批清仓 |
| **时间止盈** | 持仓超过预定周期无利润 | 减仓或清仓 |
| **信号反转** | 趋势判定从≥60%降至<40% | 逐步退出 |
| **强制离场** | 连续亏损3笔 → 强制空仓 | 全部平仓 |

## 第四章：制衡 — 多空博弈之道

### 4.1 核心要义

> **"圣人之道为而不争"——行动但不强求，在博弈中保持动态制衡而非正面对抗。**

### 4.2 博弈制衡策略

#### 4.2.1 与主力的制衡关系

```
我方定位: 不是主力的对手，而是主力的影子

主力的优势:            我方的制衡:
  资金大、控盘强    →   灵活、进出快
  信息不对称        →   主力行为分析能力
  可以操纵短期价格  →   只做趋势跟随，不逆势

制衡原则:
  → 不猜主力的底牌，只读主力的行为
  → 不在主力洗盘时硬扛，不在主力出货时接盘
  → 主力拉升我跟一段，主力出货我先走
  → 始终保持"我比主力更快"的优势
```

#### 4.2.2 诱多/诱空的制衡策略

| 主力手法 | 传统散户反应 | 我方制衡策略 |
|----------|------------|-------------|
| 假突破拉升 | 追涨买入 | 等待突破确认+回踩不破再入场 |
| 高位横盘诱多 | 认为还要涨 | 关注量能萎缩信号，提前减仓 |
| 假跌破洗盘 | 恐慌割肉 | 看破位后的收回速度和量能 |
| 恐慌砸盘 | 低位割肉 | 无实质利空不割，等企稳补仓 |
| 尾盘拉高 | 次日追高 | 次日开盘观察，不追涨 |
| 尾盘砸盘 | 次日恐慌 | 次日开盘观察，不跟跌 |

#### 4.2.3 多空力量博弈监控

| 监控指标 | 多头信号 | 空头信号 | 当前状态 |
|----------|----------|----------|:---:|
| 合约多空比 | <1.5偏多 | >2.5偏空 | 观察 |
| 资金费率 | 负值(多头弱) | 极高正值(空头弱) | 观察 |
| 大单流向 | 净买入 | 净卖出 | 观察 |
| 持仓量变化 | 价升仓增 | 价跌仓增 | 观察 |
| 盘口深度 | 买盘厚 | 卖盘厚 | 观察 |

## 第五章：迭代 — 进化升级之道

### 5.1 核心要义

> **"玄之又玄，众妙之门"——在不断的迭代进化中，打开交易智慧的无限之门。**

### 5.2 迭代进化机制

#### 5.2.1 日常迭代（日级别）

```
每日复盘 → 记录偏差 → 分析原因 → 微调参数 → 次日应用

每日必做三件事:
  1. 记录当日所有交易决策及依据
  2. 对照 Maris体系规则检查合规性
  3. 标记体系未覆盖的新情况
```

#### 5.2.2 策略迭代（周级别）

| 迭代项 | 内容 | 输出 |
|--------|------|------|
| 信号有效性回测 | 本周信号准确率统计 | 信号权重调整 |
| 主力画像更新 | 主力手法变化识别 | 主力画像小版本更新 |
| 盈亏归因分析 | 盈亏来源拆解 | 策略优化方向 |
| 情绪评分统计 | 本周情绪影响程度 | 情绪管理改进措施 |

#### 5.2.3 体系升级（月级别）

```
月度体系升级流程:

1. 汇总本月交易数据
     ↓
2. 计算核心指标: 胜率、盈亏比、最大回撤、夏普比率
     ↓
3. 对比上月指标，评估体系有效性
     ↓
4. 识别体系薄弱环节
     ↓
5. 制定升级方案
     ↓
6. 更新 Maris体系版本号 + 输出升级报告
     ↓
7. 新版本试运行 → 进入下一月度循环
```

### 5.3 关键迭代参数

| 参数 | 当前值 | 优化方向 | 调整频率 |
|------|:---:|------|:---:|
| 单笔最大仓位 | 25% | 根据胜率动态调整(±5%) | 月度 |
| 止损ATR倍数 | 2.0x | 根据波动率动态调整 | 周度 |
| 趋势判定阈值 | 60% | 根据市场环境微调 | 月度 |
| 冷却期时长 | 24小时 | 根据情绪评分调整 | 季度 |
| 加仓间隔 | ≥4小时 | 根据趋势强度调整 | 周度 |

## 六、执行落地操作手册

### 6.1 每日交易SOP

```
【盘前准备】(开市前30分钟)
  □ 阅读 Maris体系规则速查
  □ 完成趋势研判五层过滤打分
  □ 确认当日主力阶段判定
  □ 设定当日最大亏损限额
  □ 情绪自评(1-10分，<3分禁止交易)

【盘中执行】
  □ 每1小时检查主力行为变化
  □ 信号触发时严格按规则执行
  □ 不盯盘（用报警代替盯盘）
  □ 每笔交易记录决策依据
  □ 止损触发无条件执行

【盘后复盘】(收市后30分钟)
  □ 回顾当日所有交易
  □ 填写交易日志
  □ 计算当日盈亏比和胜率
  □ 标记体系不足和改进点
  □ 更新主力行为观察记录
```

### 6.3 紧急情况处理

| 紧急情况 | 处理流程 |
|----------|----------|
| 市场闪崩 | ① 立即检查止损单 ② 不手动加仓/抄底 ③ 等市场稳定 |
| 主力异动 | ① 暂停开仓 ② 观察30分钟 ③ 重新评估主力阶段 |
| 连续亏损 | ① 立即停止交易 ② 关闭交易终端 ③ 24小时后复盘 |
| 情绪失控 | ① 平掉所有仓位 ② 离开屏幕 ③ 明天再评估 |
| 重大消息 | ① 减仓至轻仓 ② 等待市场消化 ③ 重新研判趋势 |
