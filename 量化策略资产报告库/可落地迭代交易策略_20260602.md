## 一、策略执行总纲

### 1.1 六条铁律（代码强制，无例外）

```
1. 每笔交易必须设止损 → API stopLossPrice必填，否则拒绝开仓
2. 盈亏比必须≥2:1 → 止盈距离=止损距离×2，否则拒绝开仓
3. 单品种仓位≤账户15% → API仓位校验，超限拒绝
4. 同时持仓品种≤3 → 超出自动拒绝新开仓
5. 每日最大亏损≤账户3% → 日终自动检查，触发即熔断
6. 交易时段限定08:00-22:00 → 非窗口时段API拒绝开仓
```

### 2.1 多因子AND逻辑（全部满足才入场）

| # | 条件 | 参数 | 权重 |
|:---:|------|------|:---:|
| 1 | 布林带外溢 | 价格突破上轨且带宽>22%（做空则为下轨） | 必选 |
| 2 | RSI确认 | 55-72之间 | 必选 |
| 3 | 成交量 | 当前量>20日均量×1.3 | 必选 |
| 4 | 均线排列 | 5EMA>10EMA>20EMA（多头） | 必选 |
| 5 | 恐惧指数 | 20-60之间 | 强烈推荐 |
| 6 | ETF流向 | 近3日无连续净流出 | 强烈推荐 |

- **A级（≥4达标含1-4全部）**：标准仓位执行
- **B级（≥3达标但缺1-4之一）**：不入场，仅观察
- **C级（≤2达标）**：不入场

### 2.2 入场仓位（金字塔模式）

```
S1试仓: 首仓50%×总仓位上限20% = 账户10%
  ↓ 放量突破确认
S2加仓: 二仓30%×50% = 账户15% + 三仓20%×50% = 账户10% → 总仓位35%
  ↓ 趋势加速确认
S3持有: 趋势仓 = 账户15%（总仓位≤50%）
  ↓ 注意: 单品种总仓位上限 = 账户15%
```

### 2.3 禁止入场场景

- 恐惧指数<20或>80
- ETF连续3日净流出
- 已触发日亏损3%熔断
- 非允许交易时段（22:00-08:00）
- 品种不在Top10白名单内
- 布林带外溢>22%（极端超买超卖）
- LAB熔断联动激活（全BSC生态信号降级）
- 连续3笔亏损→强制暂停24小时

## 三、止盈止损精确参数表

### 3.1 止损（代码强制，API stopLossPrice必填）

| 品种类型 | ATR倍数 | 计算方式 | 单笔亏损上限 |
|------|:---:|------|:---:|
| 主流币（BNB等ETF标的） | 1.8 | 入场价 - ATR(14)×1.8 | ≤账户3% |
| 山寨币（其他） | 2.5 | 入场价 - ATR(14)×2.5 | ≤账户5% |
| LAB专属 | 2.2 | 入场价 - ATR(14)×2.2 | ≤账户5% |

### 3.2 止损移动规则

| 浮盈状态 | 止损位 | 说明 |
|------|------|------|
| 入场时 | 初始止损（ATR×2.5） | 最宽保护 |
| 浮盈>3% | 移动至成本价 | 保本止损 |
| 浮盈>8% | 移动至成本+3% | 保本+微利 |
| 浮盈>15% | 追踪止盈4% | 从最高点回撤4%平仓 |
| 浮盈>25% | 追踪止盈收紧至2% | 锁定大部分利润 |

### 3.3 止盈（阶梯式）

```
第一目标（50%仓位）: 止盈价 = 入场价 + (止损距离×2.0) → 到达即平50%
第二目标（30%仓位）: 追踪止盈4% → 从最高点回撤4%平仓
放飞仓（20%仓位）: 移动止损至成本+3% → 让利润奔跑，不设上限

数值示例:
  入场价: 10.00 USDT | ATR(14): 0.40 USDT
  止损价: 10.00 - 0.40×2.5 = 9.00 USDT（单笔亏损1.00，占仓位10%）
  第一止盈: 10.00 + 1.00×2.0 = 12.00 USDT → 平50%
  第二止盈: 开启追踪4%（最高点-4%触发平仓）
  放飞仓: 移动止损至10.30 → 最差情形保本+3%
```

### 3.4 特殊熔断止损

| 熔断类型 | 触发条件 | 止损动作 |
|------|------|------|
| 时间止损 | 持仓7天未盈利 | 强制平仓，不论盈亏 |
| 日亏损熔断 | 日亏损≥账户3% | 当日剩余时间禁止开仓，已有持仓可平 |
| 单品种暴跌 | 单日跌幅>ATR×3 | 立即全清该品种 |
| 黑天鹅 | 交易所异常/极端行情 | 全账户紧急平仓 |

## 四、仓位管理精确参数

### 4.1 账户资金分层

| 层级 | 占比 | 用途 | 限制 |
|------|:---:|------|------|
| 交易资金 | 80% | 日常六阶段状态机交易 | 按状态分配 |

### 4.2 状态→仓位映射

| 状态 | 仓位 | 止损 | 止盈 | 加仓规则 |
|:---:|:---:|------|------|------|
| S0 观望 | 0% | — | — | — |
| S1 试仓 | 10-20% | ATR×2.5 | — | 金字塔首仓50% |
| S2 加仓 | 25-50% | 移动至成本 | — | 金字塔二三仓 |
| S3 持有 | 15-100%* | 追踪4%→2% | 阶梯50/30/20 | 趋势仓 |
| S4 减仓 | 30%↓ | 成本+3% | 持续减 | 只减不加 |
| S5 清仓 | 0% | — | 全清 | — |

> *S3持有阶段100%指策略仓位，单品种绝对上限≤账户15%

### 4.3 动态调整规则

| 账户状态 | 仓位调整 |
|------|------|
| 月盈利>10% | 维持标准仓位，不放大（戒贪） |
| 月盈利0-10% | 维持标准仓位 |
| 月亏损0-5% | 仓位降至50%，只做确定性A级信号 |
| 月亏损5-10% | 仓位降至25%，暂停1周 |
| 月亏损>10% | 暂停1月，全面复盘+参数校准 |
| 连续3笔盈利 | 恢复标准仓位 |
| 连续3笔亏损 | 仓位降至1%，直到恢复盈利 |
