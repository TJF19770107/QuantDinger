## 零、体系哲学根基

> **道可道，非常道。名可名，非常名。**
> **无，天地之始；有，万物之母。**
> **天之道利而不害，圣人之道为而不争。**

本体系的底层逻辑根植于道家思想：
- **"无"** = 空仓等待状态，保持"无"的警觉，不被市场杂音干扰
- **"有"** = 入场信号出现，从"无"中生"有"，精准出击
- **利而不害** = 顺应市场趋势获利，不与市场对抗
- **为而不争** = 行动但不强求，不与主力正面硬刚，而是借势、顺势、驭势

## 二、三层博弈架构

### 2.1 第一层：主力行为实时跟踪（情报层）

| 跟踪维度 | 监控指标 | 数据源 | 更新频率 |
|----------|----------|--------|:---:|
| **资金流向** | 大单净流入/流出、主力资金动向 | 订单流+成交数据 | 实时 |
| **筹码分布** | 持仓集中度、筹码转移速率 | 链上数据+交易所数据 | 每4小时 |
| **量价关系** | 量价配合/背离、异常放量 | K线+成交量 | 每1小时 |
| **盘口语言** | 挂单密度、买卖盘比、撤单率 | Level2/Tick数据 | 实时 |
| **持仓变化** | 合约持仓量、多空比、资金费率 | 合约数据 | 每1小时 |
| **消息面** | 利好利空、项目进展、大V观点 | 社交媒体+新闻 | 持续 |

### 2.2 第二层：个人策略动态调整（决策层）

| 主力状态 | 我方状态 | 应对策略 | 核心原则 |
|----------|----------|----------|----------|
| **吸筹中** | 空仓等候 | 观察不参与，记录吸筹特征 | 敌不动我不动 |
| **吸筹尾声** | 轻仓试探 | 小仓位（10%）潜伏布局 | 敌将动我先备 |
| **洗盘** | 持仓不动或离场 | 若已入场 → 守止损；若未入场 → 等信号 | 不被震出去 |
| **拉升初期** | 标准仓位入场 | 加至标准仓位（20%） | 敌一动我必先动 |
| **拉升中期** | 阶梯加仓 | 确认趋势后加仓至（25%） | 顺势加码 |
| **拉升末期** | 减仓锁定利润 | 减至轻仓（10%） | 不贪最后一个铜板 |
| **出货初期** | 继续减仓 | 减至观察仓（5%）或清仓 | 与主力同步退出 |
| **出货确认** | 完全清仓 | 空仓，等待下一轮 | 回到"无"的状态 |
| **趋势不明** | 空仓 | 不交易是最佳交易 | 守"无" |

### 2.3 第三层：市场环境多维研判（环境层）

| 环境维度 | 指标 | 对策略的影响 |
|----------|------|-------------|
| **大趋势** | BTC主导方向 | 顺势做多/做空/观望 |
| **市场情绪** | 恐惧贪婪指数 | 极端值反向操作 |
| **波动率** | ATR/布林带宽度 | 调整止损距离和仓位 |
| **板块轮动** | 热点板块资金流向 | 选择主力活跃品种 |
| **宏观事件** | 利率决议/CPI/监管 | 重大事件前减仓或空仓 |

## 三、动态联动博弈规则

### 3.1 核心博弈公式

```
博弈决策 = 主力阶段判定 × 个人状态评估 × 市场环境系数

主力阶段:   吸筹=-1  洗盘=-0.5  拉升=+1  出货=+0.5  不明=0
个人状态:   空仓=0   轻仓=+0.3  标准=+0.6  重仓=+1
环境系数:   熊市=0.5  震荡=0.8  牛市=1.2  极端=0.3

最终决策值 = 主力阶段 × (0.6) + 个人状态趋势 × (0.2) + 环境系数调整
```

### 3.2 实时联动规则表

| 场景编号 | 主力信号 | 市场环境 | 个人状态 | 操作指令 | 仓位目标 |
|:---:|------|------|------|------|:---:|
| S1 | 吸筹确认 | 震荡偏多 | 空仓 | 小仓试探入场 | 10% |
| S2 | 洗盘结束+放量突破 | 趋势转多 | 轻仓 | 加至标准仓位 | 20% |
| S3 | 拉升中+量价齐升 | 牛市 | 标准仓 | 阶梯加仓 | 25% |
| S4 | 高位放量滞涨 | 任何 | 任何 | 减仓至轻仓 | 10% |
| S5 | 出货确认(破位) | 任何 | 任何 | 全部清仓 | 0% |
| S6 | 主力信号不明 | 震荡 | 任何 | 观望不动 | 维持 |
| S7 | 洗盘中+假跌破 | 震荡 | 标准仓 | 守止损不操作 | 维持 |
| S8 | 急跌+无实质利空 | 震荡 | 空仓 | 观察等企稳 | 0% |

### 3.3 博弈制衡三原则

```
原则一【敌不动我不动】
  → 主力未给出明确阶段信号时，我方保持空仓或维持现有仓位
  → 不猜测、不预判、不抢先
  → 守"无"等"有"

原则二【敌一动我必先动】
  → 主力阶段转换信号出现的第一时间，我方立即调整
  → 比市场早一步、比散户快一拍
  → 从"有"中见"无"（从拉升中看到出货的苗头）

原则三【顺势不逆势、借势不造势】
  → 永远不与主力方向对抗
  → 主力的势就是我们的势
  → 借主力之势成就我方之利
```

## 五、执行命令速查表

### 5.1 开仓命令

| 条件 | 命令 |
|------|------|
| 主力吸筹确认 + 环境偏多 + 空仓 | `开多 10%仓位 止损=近低点-1%` |
| 洗盘结束 + 放量突破 + 轻仓 | `加多 至20%仓位 止损=突破K线低点` |
| 拉升确认 + 量价配合 + 标准仓 | `加多 至25%仓位 移动止损=前低` |

### 5.2 平仓命令

| 条件 | 命令 |
|------|------|
| 止损触发 | `无条件平仓 不犹豫` |
| 高位滞涨信号 | `减仓 至10% 移动止盈` |
| 出货确认信号 | `全部清仓 不留底仓` |

### 5.3 禁止命令（铁律）

| 禁止行为 | 原因 |
|----------|------|
| `止损移动扩大` | 自欺欺人，放大亏损 |
| `亏损加仓摊平` | 加速亏损，越陷越深 |
| `无信号开仓` | 赌博行为，必亏 |
| `重仓(>25%)` | 单笔风险过高 |
| `连续亏损后立刻再开仓` | 情绪驱动，必错 |
