## 一、体系总纲

### 1.1 核心理念

```
┌──────────────────────────────────────────────────────────┐
│               Maris 交易博弈双向动态体系                    │
│                                                            │
│   个人策略 ←──── 追踪 ────→ 主力行为                        │
│      │                          │                          │
│      ├── 识别主力动向            ├── 改变操作手法          │
```

## 二、L1 感知层：主力动向跟踪规则

### 2.1 主力阶段识别矩阵

| 主力阶段 | 价格信号 | 量价信号 | 指标信号 | 个人仓位规则 |
|----------|----------|----------|----------|-------------|
| **吸筹** | 低位横盘，波动率低 | 缩量或温和放量 | RSI 30-50，MACD走平 | 首仓10-15%，止损宽松ATR×2.5 |
| **洗盘** | 急跌5-15%后快速收复 | 放量下跌→缩量反弹 | RSI短暂<30，布林带触下轨 | 不割肉，等收复确认，禁止加仓 |
| **拉升** | 连续阳线，突破关键阻力 | 持续放量，量价齐升 | EMA多头排列，MACD金叉 | 金字塔加仓50%→30%→20% |
| **震荡** | 宽幅区间波动 | 成交量萎缩 | RSI徘徊40-60，布林带收窄 | 不参与或极小仓位，等待方向确认 |
| **出货** | 高位放量滞涨，利好不涨 | 量价背离，放量下跌 | MACD顶背离，RSI>70钝化 | 减仓至0-10%，禁止新开仓 |

### 2.2 主力动向识别指标

| 指标 | 数值 | 含义 | 个人行动 |
|------|------|------|----------|
| **5日涨幅** | >80% | 主力逼空拉升中 | 贪婪熔断48h，禁止入场 |
| **5日涨幅** | >30%且<80% | 主力拉升中 | 仅A级信号可做多，严格止损 |
| **5日跌幅** | >20% | 主力可能出货/洗盘 | 区分出货vs洗盘再决策 |
| **24h成交额** | >20日均值2× | 主力活跃 | 关注方向，准备跟进 |
| **24h成交额** | <20日均值0.5× | 主力休眠 | 不参与，等待放量 |
| **布林带外溢** | >30% | 主力极端拉升/打压 | 禁止新开仓 |
| **RSI** | >90 | 主力逼空中 | 禁止追高做多 |
| **RSI** | <20 | 主力恐慌砸盘中 | 等待企稳信号，不抄底 |

### 2.3 "敌不动我不动"触发矩阵

| 主力状态 | 个人策略 | 具体规则 |
|----------|----------|----------|
| **无方向震荡** | 不参与 | 所有信号降至B级以下不交易 |
| **缩量横盘** | 不参与 | 成交量<20日均值0.5×不交易 |
| **低波动休眠** | 不参与 | ATR<30日均值0.5×不交易 |
| **方向不明确** | 不参与 | 5因子<3个达标不交易 |
| **恐惧极端** | 不参与 | 恐惧指数<20暂停新开仓 |

### 2.4 "敌一动我必先动"触发矩阵

| 主力动作 | 识别信号 | 个人先手反应 |
|----------|----------|-------------|
| **开始放量突破** | 成交量>20日均值1.3× + 价格突破关键位 | 首仓50%入场 |
| **洗盘结束反弹** | 急跌后放量收复关键位 + RSI脱离超卖 | 等2根4H阳线确认后半仓入场 |
| **拉升加速** | 浮盈>3% + 4H EMA多头排列 | 追加30%仓位 |
| **出货信号出现** | 放量滞涨 + MACD顶背离 | 立即启动追踪止盈，减仓30% |
| **恐慌崩盘** | ETF连续流出 + 全网爆仓 | 恐惧指数分层降仓/暂停 |

## 三、L2 分析层：主力策略拆解学习

### 3.1 主力策略拆解框架

```
观察一次完整行情 → 标注主力行为节点 → 提取可学习要素 → 融入自身体系

示例：LABUSDT完整行情拆解（2026年3月-5月）
┌────────────────────────────────────────────┐
│ 主力行为节点:                                │
│ ① 2026-03: $1.50-$3.00 缩量横盘（吸筹）     │
│ ② 2026-04: 假跌破$1.00（洗盘）              │
│ ③ 2026-05-25: 放量突破$3.00（拉升启动）      │
│ ④ 2026-05-28: 加速拉升至$6.00（逼空）        │
│ ⑤ 2026-05-31: $8.70极端超买（出货预备）      │
│ ⑥ 2026-06-01: $5.50-$6.00（出货/震荡）       │
└────────────────────────────────────────────┘

可学习要素:
✅ 吸筹期需要1-3个月（耐心）
✅ 洗盘中的恐慌是入场机会（逆向思维）
✅ 拉升启动需要成交量确认（信号纪律）
✅ 极端超买后回调概率>80%（止盈时机）
✅ 出货区禁止追高（风险控制）
```

### 3.2 主力优势学习清单

| 主力优势 | 具体表现 | 学习要点 | 融入策略 |
|----------|----------|----------|----------|
| **极端耐心** | 吸筹1-3个月不动 | 等待A级信号才入场 | 仅A级交易 |
| **反人性操作** | 恐慌时买入，贪婪时卖出 | 恐惧指数<20考虑入场 | O03恐惧分层 |
| **仓位管理** | 分批建仓，从不一把梭 | 金字塔三批加仓 | 已融入v4.4 |
| **止损纪律** | 控制单笔亏损 | 止损代码强制 | 已融入v4.5 |
| **信息优势** | 提前布局ETF催化标的 | 跟踪基本面-价格背离 | O01背离度指标 |
| **资金流监控** | 跟踪大单流向 | 监控ETF资金流 | O02 ETF熔断 |
| **情绪利用** | 利用散户FOMO/恐惧 | 恐惧贪婪指数分层 | 已融入v4.3 |

### 3.3 主力策略迭代学习机制

```
每完成一轮行情（从吸筹到出货）：
  1. 记录主力完整行为链
  2. 标注主力使用的诱多/诱空手法
  3. 分析个人在哪个节点被诱/亏损
  4. 更新主力手法库（§3.3 of 主力画像）
  5. 提出策略参数优化建议
  6. 2周迭代周期内回测验证

每次爆仓/大亏事件：
  1. 72h内完成独立复盘
  2. 对照主力画像判断是否为主力陷阱
  3. 如为主力陷阱 → 更新防范规则
  4. 如为自身失误 → 更新执行层机制
```

## 四、L3 适应层：自身体系迭代规则

### 4.1 策略迭代触发条件

| 触发条件 | 阈值 | 行动 |
|----------|------|------|
| **胜率连续下降** | 月胜率<上月80% | 检查是否主力手法变化 |
| **盈亏比恶化** | 月盈亏比<0.8 | 检查止盈止损设置 |
| **特定品种异常** | 单品种连续5笔亏损 | 暂停该品种，复查主力状态 |
| **新型陷阱出现** | 主力新手法不在现有库中 | 72h内新增防范规则 |
| **环境重大变化** | ETF流向/恐惧指数极端 | 升级熔断规则（如v4.6候选参数） |
