### 3.3 主力策略迭代学习机制 v2.0

```
每完成一轮行情（从吸筹到出货）：
  1. 记录主力完整行为链（静-动-静三段式）
  2. 匹配主力人格画像——判断类型（极限施压者/机构章鱼/其他）
  3. 标注主力使用的诱多/诱空手法
  4. 分析个人在哪个节点被诱/亏损
  5. 更新主力手法库
  6. 提出策略参数优化建议
  7. 2周迭代周期内回测验证

每次爆仓/大亏事件：
  1. 72h内完成独立复盘报告
  2. 对照主力画像判断是否为主力陷阱
  3. 如为主力陷阱 → 更新防范规则
  4. 如为自身失误 → 更新执行层机制
  5. v2.0 新增：48h内回血验证——爆仓后48h盈亏需>0才算通过

每2周策略迭代：
  1. 统计L1层识别准确率（主力阶段判断vs实际走势）
  2. 统计L2层学习转化率（从主力策略提取→融入自身体系的比例）
  3. 统计L3层迭代有效率（新规则上线后盈亏比/胜率改善幅度）
  4. 输出迭代报告：迭代日志_[日期]_博弈体系_R{轮次}.md
```
