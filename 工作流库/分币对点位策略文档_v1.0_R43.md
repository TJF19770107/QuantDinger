## BTCUSDT — 极保守趋势跟踪

| 参数 | 数值 |
|------|------|
| 策略类型 | 纯趋势跟踪（极保守） |
| 仓位 | ≤ 3% 总资金 |
| 入场条件 | EMA20 > EMA50 + MACD金叉 + 量能确认 |
| 止盈T1 | +3%（出50%） |
| 止盈T2 | +5%（出剩余） |
| 止损 | -1% 硬止损 |
| 持仓周期 | 1 - 3 天 |

**开仓条件（全部必须满足）**:
- EMA20 > EMA50 且 EMA50 斜率向上
- MACD金叉（柱状图由负转正）
- 成交量 > 20周期均量 × 1.5
- RSI(14) 在 40-70 之间
- ETF当日净流入（如有数据）

**禁止开仓**:
- 逆势做空（EMA20 < EMA50时禁止任何做空）
- 裸空（无对冲的纯空头仓位）

- 突破追涨（FOMO入场）
- 仓位 > 3%

**止盈条件**:
- +3% → 出50%
- +5% → 出剩余
- EMA20跌破 → 全部平仓

**风控**:
- -1% 硬止损（最紧级别）
- 日亏损 > 2% → 当日不再交易BTC
- 连续2笔亏损 → 本周不再交易BTC
