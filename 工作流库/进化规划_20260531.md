## 三、标准工作流更新

### 3.1 日常学习归档工作流（v1.1）
```
触发：每2小时自动 / 手动「全域蒸馏」
步骤：
  ① 读取角色总说明书
  ② 16平台并行抓取（B站/GitHub/视频号/抖音/小红书/今日头条/公众号/七猫/起点/奇妙/纵横/番茄/YouTube/X/搜狐/币安）
  ③ 分析自己 → 生成/更新 SOUL.md
  ④ 制定进化规划 → 更新 进化规划.md
  ⑤ 构建知识库 → 归档至知识库/
  ⑥ 创建/更新技能 → 归档至技能库/
  ⑦ 更新核心配置 → SOUL.md / USER.md / AGENTS.md
  ⑧ 全域同步 → 豆包/Hermes/OpenClaw
  ⑨ 生成蒸馏日志 → 定时任务/蒸馏日志/
```

### 3.2 智能体迭代工作流（v1.1）
```
触发：蒸馏完成后自动 / 手动「迭代」
步骤：
  ① 读取角色总说明书
  ② 健康巡检（所有Agent/插件/进程/端口）
  ③ 解锁状态锁 → 执行迭代脚本 → 功能校验 → 锁定状态锁
  ④ 更新技能/工作流配置
  ⑤ 全目录归档备份
  ⑥ 生成迭代报告
```

### 3.3 对话交互工作流（v1.1）
```
触发：用户输入
步骤：
  ① 读取角色总说明书（激活顶层规则）
  ② 调用记忆库（USER.md / SOUL.md）
  ③ 匹配用户指令 → 路由对应Sub Agent
  ④ 子Agent协同执行
  ⑤ 生成回复
  ⑥ 更新记忆库
  ⑦ 归档对话日志
```
