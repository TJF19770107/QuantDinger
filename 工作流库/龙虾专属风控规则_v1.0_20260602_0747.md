## 第一部分：优势强化规则（绿灯条款）

### 规则 G-1: 核心币对白名单
```
允许交易币对（按优先级排序）:
  Tier1: MYXUSDT, BNBUSDT
  Tier2: PUMPBTCUSDT, COAIUSDT, AIAUSDT
  Tier3: RIVERUSDT, XPINUSDT, PIPPINUSDT
```

- **违规成本**: 白名单外交易历史上净亏损-347.16 USDT

### 规则 G-2: 黄金交易窗口
```
允许开仓时段（UTC+8）:
  早盘: 08:00 - 11:00
  午盘: 14:00 - 18:00
  夜盘: 20:00 - 22:00

其他时段: 仅限止盈/止损平仓，禁止新建仓位
```
- **依据**: 黄金时段贡献+1,523 USDT，禁入时段亏损-624 USDT
- **强制熔断**: 23:00-05:00 系统硬锁定，拒绝一切交易指令

### 规则 G-3: 盈利保护机制
```
单笔浮盈达 +30 USDT → 移动止损至开仓价
单笔浮盈达 +50 USDT → 移动止损至+20 USDT
单笔浮盈达 +100 USDT → 锁定50%仓位利润，余仓移动止损至+40 USDT
```
- **依据**: MYXUSDT和BNBUSDT的大额盈利均来自趋势延续，中途回撤是最大利润杀手

### 规则 G-4: 盈亏比强制
```
每笔开仓前:
  目标止盈 / 初始止损 ≥ 1.5 : 1
  初始止损 ≤ 账户净值 × 2%

不满足 → 放弃此交易
```

## 第二部分：劣习约束规则（红灯条款）

### 规则 R-1: 深夜交易禁令 🔴 最高优先级
```
时段: 23:00 - 05:00 (UTC+8)
行为: 禁止一切开仓操作（包括市价单、限价单、条件单）
例外: 仅允许手动触发止损平仓
违规: 自动撤销订单 + 计入违规日志
```
- **依据**: 该时段累计净亏损-499.58 USDT
- **根因分析**: 疲劳决策 + 低流动性 + 报复交易心理

### 规则 R-2: 连续亏损熔断 🔴
```
触发条件: 连续3笔交易亏损
熔断动作:
  - 强制冷却 30 分钟（禁止下单）
  - 冷却期后，下一笔仓位减半
  - 若冷却后首笔仍亏损 → 熔断 2 小时

触发条件: 当日累计亏损达 -50 USDT
熔断动作:
  - 当日剩余时间禁止开仓
  - 次日仓位降为正常仓位的 50%
```
- **依据**: 连续8笔亏损-279.78 USDT、连续15笔亏损-140.50 USDT
- **心理剖析**: 报复性交易是亏损放大器，强制冷却打断恶性循环

### 规则 R-3: 仓位硬上限
```
Tier1 单币对最大仓位: 总资产 × 25%
Tier2 单币对最大仓位: 总资产 × 15%
Tier3 单币对最大仓位: 总资产 × 10%
总持仓风险敞口: ≤ 总资产 × 60%
杠杆上限: 5×
```
- **依据**: BTCUSDT亏损-173.90 USDT（占总额16.9%），源于大仓位方向错误

### 规则 R-4: 爆仓保护
```
触发条件: 保证金率 < 200%
自动动作:
  - 减仓至保证金率 > 500%
  - 发送告警通知
  - 暂停开仓直至手动确认
```
- **依据**: 2026-05-31 LABUSDT爆仓（虽仅4 USDT，但暴露凌晨交易风险）

### 规则 R-5: 山寨币防火墙
```
定义: 市值排名100以外的币种
行为: 禁止开仓（仅平仓）
例外: 无
```
- **依据**: 山寨币交易净亏损，且数据无统计显著性
