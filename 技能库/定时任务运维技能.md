## 概述
定时任务运维技能负责核查所有自动化任务的运行状态、执行日志，优化执行计划，备份任务配置，确保定时体系稳定运行。

## 四项子技能

### 1. 任务状态核查（Cron Status Check）
- 读取定时任务目录下全部任务配置
- 检查每个任务的最近执行状态
- 统计成功率、失败率、平均执行耗时
- 标记异常任务（连续失败、超时、未触发）
- 输出：任务状态汇总表

### 2. 执行日志分析（Log Analysis）
- 读取每个任务的最近N次执行日志
- 分析失败原因归类：
  - 资源不足（CPU/内存/磁盘）
  - 依赖缺失（文件不存在、Agent未就绪）
  - 超时中断
  - 权限拒绝
- 输出：失败原因分布报告

### 3. 执行计划优化（Schedule Optimize）
- 分析任务执行时间分布
- 检测时间冲突（多任务同时触发）
- 按优先级重新排布执行时间
- 高负载时段自动错峰
- 输出：优化后的执行计划

### 4. 配置备份（Config Backup）
- 导出全部定时任务配置为JSON/YAML
- 备份至定时任务目录的backup子目录
- 保留最近5个历史版本
- 输出：备份文件路径

## 任务配置规范
```json
{
  "task_id": "cron_001",
  "name": "任务名称",
  "schedule": "0 8 * * *",
  "action": "调用技能/工作流",
  "agent": "执行子Agent",
  "priority": "high|normal|low",
  "timeout": 300,
  "retry": 3,
  "enabled": true
}
```
