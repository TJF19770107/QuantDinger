## 一、协议概述

本协议基于AI Memory赛道四阶段演进路线，为龙虾AI主控中心构建从全量上下文到长期记忆产品化的完整链路，实现"知道什么时候该想起什么"的智能记忆。

## 二、四阶段记忆架构

### 2.1 阶段一：全量上下文（已完成）

| 特性 | 实现 |
|------|------|
| 上下文窗口 | 长窗口全量加载 |
| 记忆持久化 | 单会话有效 |
| 局限 | 跨会话遗忘，成本线性增长 |

### 2.2 阶段二：RAG检索增强（已完成）

| 特性 | 实现 |
|------|------|
| 向量存储 | 记忆库/向量数据库 |
| 检索策略 | 语义相似度Top-K |
| 局限 | 缺乏结构化理解，相关性漂移 |

### 2.3 阶段三：Agentic RAG + GraphRAG（当前执行）

| 组件 | 功能 |
|------|------|
| Agentic RAG | Agent自主决策检索时机+检索策略 |
| GraphRAG | 知识图谱结构化记忆关联 |
| 实体链接 | 人名/项目/技能/偏好实体化 |
| 时间轴 | 按时间线组织记忆 |
| 置信度 | 记忆可信度评分（0-100） |

**GraphRAG记忆图谱示例：**

```
[用户] --偏好--> [AI Agent领域]
[用户] --关注--> [MCP协议] --关联--> [MCP 1.0]
[用户] --使用--> [豆包Agent] --迭代至--> [R13]
[用户] --学习--> [数字分身蒸馏] --来自--> [豇豆方法论]
```

## 三、记忆层级模型

### 3.1 三层记忆架构

| 层级 | 内容 | 生命周期 | 容量 |
|------|------|---------|------|
| **工作记忆** | 当前会话上下文 | 单会话 | 无限（窗口内） |
| **短期记忆** | 近期对话摘要 | 7天 | 100条 |
| **长期记忆** | 用户画像/偏好/事实 | 永久 | 1000条+ |

### 3.2 记忆转化流程

```
工作记忆 → [会话结束] → 提取关键信息
    → 短期记忆 → [7天窗口] → 去噪+结构化
        → 长期记忆 → [智能策展] → 永久存储
```

## 四、记忆召回机制

### 4.1 多策略召回

| 策略 | 适用场景 | 权重 |
|------|---------|------|
| 语义相似度 | 通用搜索 | 40% |
| 时间衰减 | 近期优先 | 25% |
| 实体关联 | 图谱遍历 | 20% |
| 用户意图 | 上下文匹配 | 15% |

### 4.2 召回质量指标

| 指标 | 当前值 | 目标值 |
|------|--------|--------|
| 召回准确率 | 85% | 90%+ |
| 召回覆盖率 | 80% | 88%+ |
| 信噪比 | 3:1 | 5:1 |

## 五、隐私与安全

| 保护项 | 措施 |
|--------|------|
| 敏感记忆 | 加密存储，脱敏后使用 |
| 用户控制 | 支持手动删除指定记忆 |
| 过期机制 | 自动清理N天未访问记忆 |
| 审计日志 | 所有记忆读写操作可追溯 |
