## 二、龙虾五步法 v2.0

### 2.1 标准执行流程

```
步骤1：预读取 ─→ 读取角色总说明书，激活全部顶层规则
步骤2：任务匹配 ─→ 30秒多Agent适用初筛 → 匹配子Agent+技能+工作流
步骤3：上下文加载 ─→ 调用记忆库/变量库/知识库，构建完整上下文
步骤4：执行闭环 ─→ 调度子Agent → 调用技能 → 执行任务 → 实时校验
步骤5：归档同步 ─→ MD5去重 → 归档知识库 → 更新记忆库 → 同步迭代日志
```

### 2.2 新增节点（R∞）

- **步骤2.5：豇豆对标检查**——每轮执行前自动对比疯狂的豇豆最新动态
- **步骤4.5：情报交叉验证**——多源情报融合时触发置信度评分

## 三、双向桥接协议 v2.0

### 3.1 龙虾↔外部系统通信

```
龙虾AI主控中心（Marvis调度层）
    │
    ├── MCP Client ──→ 外部MCP Server（文件/Web/X/YouTube/抖音）
    ├── HTTP Bridge ──→ 外部API（GitHub/Composio/阿里云百炼）
```
