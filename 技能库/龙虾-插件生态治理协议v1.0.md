## 二、治理四要素

### 2.1 显示名（Display Name）

```
plugin.display_name: "GitHub Copilot Agent Runtime"
plugin.internal_name: "github-copilot-agent"
plugin.version: "1.2.3"
plugin.author: "OpenClaw Team"
plugin.description: "将GitHub Copilot代理型运行时集成到OpenClaw生态"
```

- 人类可读显示名 + 机器可读内部名
- 语义版本控制（MAJOR.MINOR.PATCH）
- 必填author和description

### 2.2 技能验证（Skill Verification）

```yaml
verification:
  automated_tests: true
  test_suite_path: "./tests/"
  min_coverage: 80%
  security_scan: 
    enabled: true
    scanner: "mcp-oauth-scanner"
    min_security_score: 85
  compatibility:
    min_runtime_version: "2026.5.28"
    supported_platforms: ["linux", "macos", "windows"]
```

- 自动化测试套件必须通过
- 安全扫描（MCP OAuth 2.1合规）
- 最低兼容版本声明
- 测试覆盖率 ≥ 80%

### 2.3 信任表面（Trust Surfaces）

```
Level 0 — 沙箱隔离：无文件系统/网络访问
Level 1 — 只读访问：可读取工作区文件
Level 2 — 受限写入：仅可写入指定目录
Level 3 — 完整访问：用户显式授权后开放
Level 4 — 官方签名：OpenClaw官方签名+审计
```

| 级别 | 来源 | 权限 | 要求 |
|------|------|------|------|
| L0 | 未知第三方 | 沙箱隔离 | 自动扫描通过 |
| L1 | 社区验证 | 只读文件 | 测试+扫描+社区Review |
| L2 | 社区精选 | 受限写入 | +人工Review+评分≥4.0 |
| L3 | 认证开发者 | 完整访问 | +身份认证+历史记录 |
| L4 | 官方签名 | 最高权限 | 官方审计+签名链 |

### 2.4 按需安装（Install-on-Demand）

```json
{
  "install_type": "on-demand",
  "npm_package": "@openclaw/plugin-github-copilot",
  "clawhub_id": "gh-copilot-runtime",
  "dependencies": ["@openclaw/core@>=2026.5.28"],
  "install_size": "2.3MB",
  "auto_update": true
}
```

- 不捆绑核心运行时
- npm独立发布 + ClawHub注册
- 安装时检查依赖兼容性
- 支持自动更新

## 三、插件生命周期

```
开发 → 提交验证 → 自动扫描 → 社区Review
    ↓
发布(npm+ClawHub) → 用户安装 → 运行时监控
    ↓
评分/反馈 → 迭代更新 → 废弃归档
```

## 六、关键约束

- 未通过安全扫描的插件禁止进入L2+
- 信任级别不可运行时提升（需重新安装）
- 废弃插件保留90天宽限期后归档
- 官方签名私钥硬件隔离
