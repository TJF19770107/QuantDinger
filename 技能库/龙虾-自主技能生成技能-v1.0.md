## 二、技能评估 Rubric（对标 Hermes Curator）

| 维度 | 评分标准（1-5） | 权重 |
|------|----------------|------|
| 可复用性 | 技能是否可被其他任务复用 | 30% |
| 完整性 | 步骤是否涵盖端到端流程 | 25% |
| 安全性 | 是否定义了安全边界和约束 | 20% |
| 可测试性 | 是否有明确的验证方式 | 15% |
| 创新性 | 是否包含从迭代中提炼的新模式 | 10% |

**生成阈值**: 总分 ≥ 3.5 才注册为正式技能，否则标记为 draft 待人工审核。

## 三、生命周期管理

```
┌─────────────────────────────────────────────────┐
│  Draft → 人工审核 → Published → Active          │
│                                         │        │
│                                     Deprecated   │
│                                         │        │
│                                     Archived     │
└─────────────────────────────────────────────────┘
```

- **Active → Deprecated**: 连续 3 轮迭代未被调用
- **Deprecated → Archived**: 超过 7 天未被调用
- **Archived 保留期**: 30 天，超期可彻底删除
- **Pin 锁定**: 关键技能可标记为不被自动弃用

---

## 四、技能去重与合并

- 新技能生成前，先与技能库做语义相似度比对
- 相似度 > 0.8：合并为同一技能的版本升级
- 相似度 0.5-0.8：创建关联引用，不重复生成
- 相似度 < 0.5：注册为新技能
