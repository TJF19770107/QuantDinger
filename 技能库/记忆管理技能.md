挂载路径：E:\龙虾AI主控中心\我的AI分身\技能库\记忆管理技能.md
适用范围：所有子Agent

## 概述
记忆管理技能负责同步长期记忆、修复记忆断片、留存核心设定，确保所有子Agent不遗忘用户偏好和关键上下文。

## 三项子技能

### 1. 长期记忆同步（Memory Sync）
- 读取记忆库现有内容
- 从最近对话中提取关键信息：
  - 用户偏好（语言、格式、工作习惯）
  - 核心设定（目录路径、Agent配置、挂载关系）
  - 重要决策（已确认的操作、已排除的方案）
- 按主题分类写入记忆库
- MD5去重后存储
- 输出：同步记录（新增条目数、更新条目数）

### 2. 记忆断片修复（Fragment Repair）
- 检测各子Agent的记忆一致性
- 比对记忆库与子Agent实际行为
- 发现遗忘项（如路径丢失、规则遗漏）
- 自动补注到对应Agent上下文
- 输出：修复记录（断片位置、补充内容）

### 3. 核心设定留存（Core Setting Persistence）
- 角色总说明书关键规则提取为结构化记忆
- 目录结构与挂载关系永久留存
- 技能清单与调用方式固化
- 定时任务配置备份至记忆库
- 输出：设定快照文件

## 记忆格式规范
```json
{
  "id": "mem_xxxx",
  "category": "用户偏好 | 核心设定 | 决策记录",
  "content": "...",
  "timestamp": "YYYY-MM-DD HH:mm:ss",
  "md5": "...",
  "source": "对话ID | 手动录入"
}
```

## 调用示例
```
触发：记忆同步
触发：记忆修复 [Agent名]
触发：记忆快照 全量
```
