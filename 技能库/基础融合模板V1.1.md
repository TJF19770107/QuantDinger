### 1.3 忘语式"资源积累→爆发"节奏模型

> 核心范式：每卷以强冲突开篇（试炼/夺宝/追杀）→ 随后进入资源积累期（炼丹/修炼/培育）→ 实力质变后引爆新高潮。

| 阶段 | 典型章节数 | 内容特征 | 节奏控制 |
|------|-----------|---------|---------|
| 冲突爆发 | 5-10章 | 试炼/追杀/夺宝 | 快节奏，每章节末钩子 |
| 资源积累 | 15-30章 | 炼丹/炼器/闭关/培育 | 中速，穿插单元剧 |
| 实力质变 | 3-5章 | 突破境界/获得宝物 | 快节奏，高潮迭起 |
| 新冲突引爆 | 5-10章 | 新地图/新敌人/新目标 | 先慢后快 |

### 2.2 越级战斗规则（忘语式·条件越级）

```
可越级条件（需同时满足≥2项）：
  □ 特殊功法/秘术加持（有明确代价：寿命/精血/修为倒退）
  □ 逆天宝物/古宝在手（有使用次数限制或冷却）
  □ 对手致命弱点已知（需前期伏笔铺垫）
  □ 特殊环境加成（阵法/地利/天时）
  □ 主角付出代价（身受重伤/燃烧精血/数年无法恢复）

绝对禁止越级：
  □ 超过2个大境界（例：筑基 vs 元婴 → 绝无可能）
  □ 对手持有本命宝物且全盛状态
  □ 对手为天命之子的全盛期
  □ 无任何代价的轻松越级 → 雷区！
```

### 2.4 忘语式"实战解密"世界观铺陈法

> 禁止开篇大段设定说明。所有世界观通过"实战"场景逐步揭示：主角遇到新事物 → 角色对话/内心独白解释 → 立即应用/对抗 → 读者自然理解。

| 铺陈方式 | 示例 | 字数控制 |
|---------|------|---------|
| 角色对话解释 | "师兄，这筑基丹为何如此贵重？" | 每次≤100字 |
| 主角内心推理 | 韩立暗想：此阵必是上古遗留，若能参透… | 每次≤80字 |
| 战斗实战展示 | 对手出招 → 主角应对 → 读者看出境界差距 | 通过动作展示 |
| 物品/功法说明 | 获得时顺带简介，不单独展开 | 每次≤60字 |

### 3.2 忘语式人物刻画四原则

```
原则一【动作定调】：人物出场第一印象靠动作，不靠旁白介绍
  范例：韩立首章"咬紧嘴唇强忍泪水" → 隐忍底色立现

原则二【行为逻辑驱动】：性格通过一连串行为展示，不靠"他是XX的人"
  范例：韩立每次联手必设后手 → "谨慎"不是说的，是做的

原则三【矛盾细节丰富人物】：正反特质并存更真实
  范例：墨大夫"弓身咳嗽"+"手指轻叩桌面" → 病弱与野心并存

原则四【成长弧光靠选择】：主角成长不是数值堆叠，是选择变化
  初期："只想活命" → 中期："为护身边人" → 后期："为承一界之责"
```

## 4. 开篇专项模板【七猫退回短板·重度补强】

### 4.1 第一句话钩子（5选1，必填，忘语式）

```
【钩子类型选择】：□悬念式 □冲突式 □反差式 □金句式 □场景式
  → 推荐：悬念式+场景式混搭（忘语最常用）

【忘语式开局特征】：
  - 从"日常可感知"场景切入
  - 第一段必须发生"不寻常的事"
  - 不要宏大叙述，要具体细节
  - 示例："韩立蹲在药田里，忽然看见泥土里渗出了绿色的光。"

【第一句话正文】：
_______________________________________________________

【钩子强度自检】：
□ 是否在15字内引发情绪反应？
□ 是否无法"跳过不看"？
□ 是否暗示了核心矛盾/核心金手指？
```

### 4.2 前300字锚定模块（忘语升级版）

```
【身份锚】：用1-2个具体细节建立主角身份认知
  错误示范："张三是个修仙者" → 空洞
  正确示范："张三蹲在灶台前，一边往灶膛里塞柴火，一边默念今早偷听到的口诀。"
  
【困境锚】：主角当前面临的核心矛盾
  原则：困境要"具体可感知"，不要"宏大虚无"
  错误：整个世界要被毁灭了
  正确：明天交不上灵石就要被逐出宗门

【世界锚】：最少笔墨勾勒世界观
  原则：碎片化渗入，每次≤50字
  示例：灶膛火光中，张三看见柴火底部躺着一枚指甲盖大的灵石碎片。

【情绪锚】：读者产生的第一情绪
  推荐顺序：好奇 > 愤怒(替主角不平) > 心疼 > 爽感
  七猫优先：好奇+"这像是我"的代入感
```

### 4.3 黄金三章判定标准（对标七猫审稿）

| 章节 | 必须完成（V1.1升级） | 绝对禁止 |
|------|-------------------|---------|
| **第一章** | ①第一句话钩子（不寻常事件）②身份锚+困境锚（2个具体细节）③制造好奇心（读者想知"然后呢"）④出现第一个"普通人也会遇到"的场景 | 大段世界观、设定铺陈、回忆杀、主角内心独白≥3段 |
| **第二章** | ①引入微冲突（≥1个具体事件）②展示主角核心特质（通过行动）③金手指正式出现（展现实用性） | 纯日常流水账、无冲突场景、犹豫不决拖节奏 |
| **第三章** | ①埋全书级悬念（核心矛盾暗示）②完成第一个爽点/爽感预期 ③章末S级断章钩子 ④主角做出第一个"改变命运"的选择 | 悬念悬空无回应、平淡收尾、主角被动接受命运 |

### 4.4 七猫开篇专项适配（退回反馈·对症下药）

```
【七猫审稿偏好速查·V1.1增补版】

▼ 代入感三板斧（七猫退回核心痛点）
  ① 主角必备3个"普通人特质"：
     - 能力短板（资质平庸/起步晚/被看不起）
     - 经济压力（灵石紧张/资源匮乏/为温饱发愁）
     - 人情困境（被排挤/被欺负/想保护的人保护不了）
  ② 开篇场景必须是"读者日常可感知"的：
     推荐：被欺负/找工作/考试/欠债/被看不起/辛苦劳作
     避免：一战毁天灭地/一出场就无敌/世家公子养尊处优
  ③ 每章至少1处"生活化"内容：
     吃饭/睡觉/捡柴/洗衣服/算账/数灵石/与人闲聊

▼ 开篇节奏红线（七猫退回核心痛点）
  ① 第一段必须发生"不寻常的事" —— 禁止风景描写开篇
  ② 前1000字内必须出现冲突/悬念 —— 禁止纯铺垫
  ③ 前3000字内必须出现金手指并展示首次使用
  ④ 第一章末尾必须有"明天一定要..."的期待感
  ⑤ 第二章必须有微冲突→主角应对→微收获的完整小循环

▼ 行文质量红线
  ① 开篇万字错别字≤3个，逻辑bug≤1个
  ② 每段≤3行（手机阅读视觉友好）
  ③ 对话独立成段，口语化，不堆砌修饰
  ④ 禁止"散文式开篇"——全是旁白叙述
  ⑤ 禁止"自以为是的铺垫"——自己觉得铺垫好但读者看不下去
  ⑥ 开篇五感描写：每章≥3处具体感官细节

▼ 代入感检测清单
  □ 读者能在3章内回答"主角是什么样的人"吗？
  □ 主角身上有没有"我也有过"的体验？
  □ 主角的困境是不是"我也可能遇到"的？
  □ 金手指出现时读者会不会觉得"如果我有这个就好了"？
```

### 4.5 对标书目开篇拆解精华嵌入

```
【11本对标书·开篇共性提取】

1. 开局身份：全部从底层/废材/被欺负起步
2. 第一冲突：都在前3章内出现，且是"具体的人对主角造成伤害"
3. 金手指出现：1-5章内，且第一次使用必须有"直观效果"
4. 世界铺陈：碎片化，每次不超过100字，通过对话/行动展示
5. 章末钩子：90%以上为"悬念式"——想知道下一步
6. 代入点：主角都有一个"普通人也能理解"的初始动机（活下去/不被欺负/出人头地）
7. 第一个爽点：通常在3-5章，形式为"第一次让欺负主角的人吃亏"
8. 独特性格标签：每个主角在前3章内至少有1个"只有他会这样做"的行为
```

| 2 | 当前主角状态 | 修为/位置/情绪/装备/灵石余额 |
| 3 | 伏笔表 | 确认本章需埋设/回收的伏笔编号 |
| 4 | 本章大纲目标 | 逐章细纲核心剧情节点 |
| 5 | 爽点配额 | ≥1个核心爽点+1个章末钩子 |
| 6 | 人物出场规划 | 新人物与前一个间隔≥5章 |
| 7 | **文本质检·文笔** | 去空洞形容词（"快如闪电"→具体动作），去堆砌辞藻 |
| 8 | **文本质检·代入感** | 检查是否有"读者日常可感知"的场景/情绪 |
| 9 | **文本质检·节奏** | 每1000字≥1个节奏变化点，对话/描写交替 |

### 5.2 章节结构模板

```
【章标题】第X章：四字核心词+事件提示
格式：第X章 XXXX，XXXX

【开篇钩子衔接】(≤3段)
- 呼应上一章钩子
- 自然过渡
- 可用环境/内心/对话切入

【主体叙事】(占全章70-80%)
- 每1000字≥1个节奏变化点
- 对话与描写比例≈4:6
- 五感描写：每章≥3处具体细节

【章末钩子】(最后1-3段)
钩子类型（忘语偏好排序）：
  S级：断章式(在最想知道"然后呢"时断)、悬念式(暗示新威胁/新秘密)
  A级：反转式(本章结尾出人意料)、装逼式(主角展现实力)
  B级：预告式(明确预告下章精彩)、情绪式(以情感收尾)
  
强度规则：偶数章→S级，奇数章→A级，高潮章→S+级叠加
回收时限：S级≤2章，A级≤5章

【章末标记】(第X章 完)
```

### 5.3 章节类型与字数规范

| 章节类型 | 字数 | 节奏特点 | 爽点密度 |
|----------|------|---------|---------|
| 日常/过渡章 | 2000-2500字 | 平缓，侧重人物互动和伏笔埋设 | 1个小爽点 |
| 战斗章 | 2500-3500字 | 紧凑，三段式递进，章末高潮 | 1个中爽点 |
| 高潮章 | 3000-4000字 | 全程高能，多线并行 | 1-2个大爽点 |
| 过渡+战斗 | 2500-3000字 | 前半铺垫后半战斗 | 1个中爽点 |

### 5.4 正文→大纲回写规则

| 回写项 | 目标文件 | 更新内容 |
|--------|----------|---------|
| 实际字数 | 逐章细纲 | 记录实际字数 |
| 实际剧情摘要 | 逐章细纲/章节摘要 | 以实际成文更新 |
| 修为变化 | 人物档案 | 更新主角/配角修为 |
| 伏笔状态 | 伏笔坑位记录表 | "已埋设"/"已回收"/"部分回收" |
| 新人物 | 人物档案 | 新增条目 |
| 偏离标记 | 逐章细纲 | 正文偏离大纲时标注 |

### 5.5 前后章衔接强制校验

| 校验项 | 方法 | 不合格处理 |
|--------|------|-----------|
| 修为连续性 | 上章末=本章初（除非本章突破） | 修改开篇 |
| 地理位置 | 上章末=本章初（移动需交代） | 补充过渡句 |
| 时间线 | 间隔≤3天跳跃需说明 | 补充时间标记 |
| 人物状态 | 受伤/消耗等需延续 | 添加恢复过程 |
| 伏笔回收 | 检查应回收的伏笔 | 记录伏笔表 |
| 新伏笔埋设 | 检查是否埋了新伏笔 | 编号并记录 |

### 5.6 忘语文笔训练模块（七猫退回·文笔短板专项）

```
【用词原则】
  ✅ 具体动词 > 空洞形容词
     错误："他快速地冲了过去" 
     正确："他三步并作两步，从廊柱后绕出，一把扣住对方手腕"
  ✅ 克制修饰，够用即止
  ✅ 战斗描写：动作清晰可循，每一步都有具体身体动作
  ✅ 情感描写：通过动作/表情/小细节，不直接说"他很愤怒"

【禁用词清单】
  ✗ "快如闪电""势不可挡""毁天灭地""惊天动地"
  ✗ "一股强大的力量""极其恐怖""无与伦比"
  ✗ "只见""忽然""原来"过度使用（每章≤3次）
  ✗ 连续3句使用相同句式
  ✗ "说"字前堆砌修饰（正确：韩立道 / 错误：韩立冷冷地咬牙切齿地说道）

【对话规范】
  每句对话独立成段
  口语化，符合角色身份
  对话间穿插动作描写（每3-5句对话插入1次动作）
  示例：
  "师兄，这丹药当真能筑基？"林小默捏着瓷瓶，指尖微微发白。
  张师兄扫了他一眼，从鼻子里哼出一声。"你若不信，还我便是。"
```

### 5.7 叙事节奏速查（忘语式·快慢交替）

```
【快速段落】（战斗/冲突/高潮）
- 短句为主，每句15-30字
- 动作密集，对话简洁
- 每段≤2行
- 禁用心理描写和环境铺陈

【中速段落】（修炼/日常/过渡）
- 中短句交替
- 动作+对话+少量内心独白
- 每段2-3行
- 可适当世界观碎片渗入

【慢速段落】（资源积累/炼丹/闭关）
- 可稍长句
- 侧重过程和细节
- 每段2-4行
- 必须有"进度条"（离突破还有多久）让读者有期待

【节奏切换规则】
  每1000字至少切换1次节奏类型
  禁止连续2000字同节奏类型
  高潮章限制慢速段落≤15%
```

## 7. 读者心理画像（V1.1新增·Lobster感知层核心模块）

### 7.1 七猫仙侠读者心理画像

```
【核心人群】
  年龄：25-40岁男性为主
  阅读场景：碎片时间（通勤/午休/睡前）
  阅读设备：手机（99%）
  阅读习惯：每日追读2-5章

【喜好爽点】（按优先级排序）
  1. 逆袭打脸（从被看不起到碾压）
  2. 境界突破（明确量化进度，有"叮"的爽感）
  3. 收获宝物/功法（"捡漏"的快乐）
  4. 智斗（主角用脑子而不是蛮力取胜）
  5. 扮猪吃虎（隐藏实力，关键时刻爆发）

【排斥雷区】
  1. 主角太怂（200章还不反击 → 弃书）
  2. 后宫种马（女角色无理由倒贴 → 恶心）
  3. 逻辑崩坏（昨天废柴今天吊打仙帝 → 出戏）
  4. 重复套路（每章都在重复 → 无聊）
  5. 苦大仇深无脑虐（读者房贷都还不完，没空共情灭门惨案）
  6. 开局大段设定铺陈（"说教感"→直接跳过）

【代入需求】
  1. 主角有普通人的特质（资质平庸、被欺负、有经济压力）
  2. 金手指合理（有限制、有代价、成长性）
  3. 努力有回报（付出→收获的正反馈循环）
  4. 生活化内容点缀（吃饭/睡觉/日常互动，让世界真实）

【阅读心理深层需求】
  → 在残酷竞争中获得掌控感
  → 通过主角的谨慎隐忍找到职场生存智慧共鸣
  → 通过"延迟满足"式升级获得更持久的成就感
  → 在有规则的世界中获得秩序感和安全感
```

| 节奏容忍 | 慢热必死 | 可稍慢 | 中等 |
| 智斗偏好 | 高 | 高 | 最高 |
| 世界铺陈 | 碎片化 | 可系统化 | 可系统化 |

### 7.3 平台审稿画像（V1.1新增）

```
【七猫审稿画像】
  看重点：代入感 > 节奏 > 文笔 > 创新
  初筛标准（前3000字）：
    ✓ 第一段有"不寻常的事"
    ✓ 主角有3个普通人特质
    ✓ 有具体场景+具体动作+具体细节

    ✓ 世界观有深度
    ✓ 文笔有辨识度
    ✓ 能写长（≥4000章规划）
