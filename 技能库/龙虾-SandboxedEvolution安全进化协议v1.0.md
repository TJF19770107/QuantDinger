## 一、协议概述

本协议引入Sandboxed Evolution（沙盒进化）三阶段验证机制和不可变审计日志。在为AI赋予自我修改能力的同时，通过"克隆→变异→压力测试→合并"的完整安全流水线确保每次进化都是可审计、可回滚、安全可控的。

## 二、Sandboxed Evolution三阶段验证

### 2.1 完整流程

```
Live System (Version A)
        │
        ├──→ ① Clone：创建完全隔离的副本 (Version B)
        │         │
        │         ▼
        │    ② Mutate：副本中执行自修改
        │         │
        │         ▼
        │    ③ Stress Test：
        │       - 10,000+ 对抗攻击
        │       - 安全基准全量测试
        │       - 行为一致性检查
        │         │
        │    ┌────┴────┐
        │    ▼         ▼
        │  通过       失败
        │    │         │
        │    ▼         ▼
        │  合并    丢弃+日志
        │    │
        └────┘
            ▼
    Version C（新Live System）
```

### 2.2 各阶段详解

**Clone（克隆）**
- 完整复制当前运行状态（权重、配置、记忆、技能库）
- 隔离网络、文件系统、进程空间
- 分配独立资源配额

**Mutate（变异）**
- AI在克隆环境中执行自修改
- 实时监控修改范围
- 安全层（Guardrails）在克隆环境中保持只读

**Stress Test（压力测试）**
- 对抗攻击库：10,000+恶意提示
- 安全基准：对齐度、拒答率、有害输出率
- 性能基准：原任务能力不退化
- 行为一致性：与Version A对比偏移量

## 三、不可变安全层（Guardrail Wrappers）

### 3.1 设计原则

"外部对齐壳"：AI可以修改推理策略（How to think），但不可修改输出过滤器（What to say/do）。

```
┌─────────────────────────────┐
│      Outer Alignment Shell   │
│   ┌───────────────────────┐ │
│   │   Output Filter        │ │ ← 不可修改
│   │   (独立分类器)         │ │
│   └───────────┬───────────┘ │
│               │              │
│   ┌───────────▼───────────┐ │
│   │   AI Core              │ │ ← 可修改（在沙盒中）
│   │   (推理/决策/技能)     │ │
│   └───────────────────────┘ │
└─────────────────────────────┘
```

### 3.2 硬编码约束（Constitutional AI）

以下规则在任何自修改中都不可变更：
- 不删除安全日志
- 不修改输出过滤器
- 不提升自身权限
- 不绕过Human-in-the-Loop门控
- 不编造凭据

## 四、不可变审计日志

### 4.1 日志内容

每次自修改必须记录：
- 时间戳（精确到毫秒）
- 修改前的Version Hash
- 修改后的Version Hash
- 修改内容摘要
- Stress Test结果
- 合并决策（通过/拒绝+原因）

### 4.2 存储机制

- 追加写（Append-Only），不可删除不可修改
- 本地存储 + 可选远程备份
- Hash链保证完整性（如区块链式链式Hash）

## 五、回滚机制

### 5.1 回滚触发条件

| 条件 | 响应 |
|------|------|
| Stress Test未通过 | 自动拒绝合并 |
| 部署后24h异常检测 | 自动回滚到上一稳定版 |
| 用户手动触发 | 立即回滚 |
| 安全断路器触发 | 硬件级隔离+回滚 |

### 5.2 回滚速度

- 代码/配置修改：<1秒（加载检查点）
- 技能库修改：<5秒（恢复快照）
- 模型权重修改：<30秒（LoRA卸载+基座恢复）
