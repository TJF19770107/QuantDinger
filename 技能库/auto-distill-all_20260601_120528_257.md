# Self-Skill：全域自动蒸馏技能
**技能名称**: auto-distill-all
**版本**: v1.1（2026-06-01 升级）
**所属**: 龙虾AI主控中心 → AI分身 → 技能库
**创建日期**: 2026-05-31 | **升级日期**: 2026-06-01

## 技能描述
每2小时自动执行全域多源情报抓取、六步蒸馏、分身进化、配置同步的全闭环自动化技能。

## 触发方式
- 定时触发（每2小时）
- 手动触发：输入"全域蒸馏"或"嗡阿喇巴札那谛"

## v1.1 升级要点
- ✅ **反脆弱机制**：单平台失败不中断、全局最大执行时间300s、输出完整性校验
- ✅ **六步蒸馏法**：清洗→提炼→结构化→模式识别→策略映射→知识注入
- ✅ **跨领域模式识别**：新增元模式识别步骤
- ✅ **子Agent差异化映射**：Hermes/Codex/豆包/OpenClaw 各有专属知识注入路径
- ✅ **P0/P1/P2优先级体系**：行动项分级管理

## 执行流程

### Phase 1: 前置检查（~5s）
1. 读取 `E:\龙虾AI主控中心\我的AI分身\角色总说明书\角色总说明书.md`
2. 验证目录结构完整性：技能库/知识库/子Agent/迭代日志
3. 读取上次蒸馏日志，获取增量上下文

### Phase 2: 多源抓取（~30s）
对以下信息源并行抓取最新内容：

**社区与平台（16路）**：
B站 / GitHub / 视频号 / 抖音 / 小红书 / 今日头条 / 公众号
七猫 / 起点 / 奇妙 / 纵横 / 番茄 / 油管YouTube / X / 搜狐 / 币安

**专业情报（4路新增）**：
交易策略社区 / 量化Alpha信号 / 全球市场热点 / AI Agent前沿

抓取策略：
- 公开平台：ai_search 获取最新趋势
- 封闭平台：通过第三方报道间接获取
- 关键数据点：新功能/融资/政策/爆款/行情

### Phase 3: 六步蒸馏（~15s）

```
Step 1: 清洗 → 去重、去噪、术语标准化、时间校准
Step 2: 提炼 → 每路情报提取4-5项核心洞察
Step 3: 结构化 → 按7大能力域分类，建立优先级矩阵
Step 4: 模式识别 → 跨领域关联分析，识别元模式（≥2个）
Step 5: 策略映射 → 将洞察映射到龙虾AI具体能力/技能/配置
Step 6: 知识注入 → 更新相关文件，同步子Agent
```

### Phase 4: 分身进化（~20s）
1. 更新用户人格画像
2. 生成进化规划
3. 创建/更新专属技能
4. 同步SOUL/USER/AGENTS配置

### Phase 5: 闭环归档（~10s）
1. 生成蒸馏日志（`迭代日志/迭代日志_YYYYMMDD_全域蒸馏.md`）
2. 生成蒸馏结果（`技能库/蒸馏结果_YYYYMMDD.md`）
3. 更新全域知识库（`知识库/全域知识库_YYYYMMDD.md`）
4. 全域同步子Agent（Hermes/豆包/OpenClaw）
5. 返回执行摘要

## 反脆弱机制（v1.1新增）

| 机制 | 说明 |
|------|------|
| **单平台失败隔离** | 单个信息源抓取失败时跳过并记录，不中断全局流程 |
| **全局熔断** | 全局最大执行时间300秒，超时自动终止并输出部分结果 |
| **输出完整性校验** | 蒸馏结果至少包含2个元模式、8项洞察，否则标记为"部分完成" |
| **降级策略** | ai_search失败 → 使用本地知识库缓存；写入失败 → 重试1次 → 记录异常 |
| **恢复标记** | 中断后下次执行自动检测上次未完成阶段，从中断点继续 |

## 依赖
- `角色总说明书.md`：顶层规则
- `ai_search`：全平台信息抓取
- `write_file` / `edit_file`：产出物归档
- `shell_executor`：目录检查和系统操作

## 输出
| 产出物 | 路径 |
|--------|------|
| 蒸馏结果 | `技能库/蒸馏结果_YYYYMMDD.md` |
| 蒸馏日志 | `迭代日志/迭代日志_YYYYMMDD_全域蒸馏.md` |
| 全域知识库 | `知识库/全域知识库_YYYYMMDD.md` |
| 子Agent同步 | `子Agent/{Name}Agent/蒸馏同步_YYYYMMDD.md` |
| AGENTS.md更新 | `技能库/AGENTS.md`（追加模式） |

## 容错规则
- 单平台抓取失败：跳过并记录，不中断流程
- 写文件失败：重试1次，仍失败则记录异常
- 全流程失败：在下次执行时自动恢复
- 超时保护：300秒全局熔断

## MD5去重规则
- 知识库写入前，遍历同目录文件计算MD5
- 内容重复率>90%视为重复，跳过写入
- 白名单URL去重：读取`url_whitelist.json`过滤
