# 龙虾-双层自改进闭环协议 v1.0

> **对标来源**：Hexo Labs SIA + Autogenesis AGP SEPL
> **创建日期**：2026-06-01 (R13)
> **版本**：v1.0

---

## 一、协议概述

将自进化能力从"仅修改文本层产物（提示词/记忆schema/工作流图）"升级为"同时修改Harness层（行为逻辑/路由/钩子）和模型层（权重微调）"，实现源码级自进化闭环。

## 二、双层自改进架构

### 2.1 Core Loop

```
任务 → Harness → 模型推理 → 结果评估
  ↑                              ↓
  └──── 权重微调 ← 评估反馈 ←────┘
  ↑                              ↓
  └──── Harness修改 ← 失败分析 ←─┘
```

### 2.2 两层定义

| 层次 | 修改对象 | 示例 |
|------|---------|------|
| Harness层 | 行为逻辑 | 路由规则、钩子顺序、状态不变量、调用编排 |
| 模型层 | 权重参数 | LoRA微调、Prompt嵌入优化、记忆向量更新 |

### 2.3 与文本层自进化的区别

| 维度 | 文本层（旧） | 双层（新） |
|------|------------|-----------|
| 修改范围 | 提示词/记忆schema/工作流图 | + 路由逻辑/钩子/状态不变量/权重 |
| 进化深度 | 浅层行为调整 | 深层架构优化 |
| 瓶颈 | 代码层逻辑无法触达 | 全栈可进化 |
| 风险 | 低 | 中（需SafeGuard监察） |

## 三、SEPL闭环协议（继承自AGP）

### 3.1 闭环流程

```
Propose(提出改进) → Evaluate(评估有效性) → Commit(提交变更)
                                              ↓
                                    可审计血缘追溯 + 版本化回滚
```

### 3.2 五阶段

| 阶段 | 操作 | 产出 |
|------|------|------|
| 反思 | 分析失败/低效模式 | 改进建议列表 |
| 选择 | 筛选最优改进方案 | 候选变更集 |
| 改进 | 执行Harness/模型修改 | 变更diff |
| 评估 | 在沙箱中验证效果 | 评估报告 |
| 提交 | 通过后合并到主分支 | 版本号+审计日志 |

## 四、安全约束

- 所有Harness层修改必须经过SafeGuard审计
- 模型层修改限制在LoRA/Adapter级别，不动基座模型
- 每次修改生成版本快照，支持一键回滚
- 修改频率限制：单Agent每小时最多1次Harness修改

## 五、豆包Agent适配方案

1. 自进化闭环从Prompt编辑扩展至dispatch_task路由逻辑修改
2. 引入沙箱验证环节：修改后先在隔离环境测试
3. SafeGuard对所有Harness修改进行四级异常检测
4. 每次进化生成版本快照存入checkpoints目录
