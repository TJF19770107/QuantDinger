## 1. 作者画像：忘语行文DNA全息建模

### 1.1 基础档案

| 属性 | 数据 |
|------|------|
| 笔名 | 忘语 |
| 代表作 | 《凡人修仙传》（2008-2013，771万字，2446章） |
| 流派开创 | "凡人流"奠基人 |
| 创作时长 | 近10年持续创作（2005年构思，2008年动笔） |
| 写作动机 | 考研期间半辞职状态开启写作 |

### 1.2 核心创作心智模型（马斯克范式拆解）

```
【第一性原理】
  修仙的本质不是"变强"，是"在残酷环境中活下来"。
   → 忘语将所有仙侠叙事还原到这个等式：
    资质平庸 × 资源有限 × 环境残酷 = 必须靠算计才能活
   → 这条底层逻辑贯穿全书，决定了所有叙事选择。

【反套路思维】
  传统仙侠：天赋异禀→奇遇不断→横推一切
  忘语范式：资质平庸→环境残酷→小心翼翼→步步算计→延迟爆发
   → 他主动做了"反向选择"，并坚持到底。

【系统化思维】
  修炼体系不是随便写的，是完整自洽的运算系统：
  炼气(13层) → 筑基(初/中/后) → 金丹(初/中/后) → 元婴(初/中/后/大圆满) → 化神 → 炼虚 → 合体 → 大乘 → 渡劫
  每个境界都有明确的：
  - 突破条件（需要什么资源）
  - 战力区间（能打什么级别的对手）
  - 寿命上限（给叙事紧迫感）
  - 瓶颈描述（为什么卡住）

【工具理性决策模式】
  韩立的每个决策都可以还原为：
  "在当前信息下，怎么做才能最大化生存概率？"
  → 这个决策逻辑是忘语赋予主角的"操作系统"
  → 也是读者觉得韩立"真实"的根源
```

### 1.3 叙事习惯DNA

```
【视角选择】
  类型：第三人称限知视角
  特征：严格绑定韩立视角，读者知道的不比韩立多
  效果：增强代入感+悬疑感，读者和韩立一起"摸索"
  禁忌：禁止上帝视角预叙（"多年后他会知道..."）

【开篇策略】
  模式：从最普通的场景切入，一点点铺开不寻常
  标志：第一段必有"反常细节"——看似日常，实则暗示异常
  示例：《凡人》第1章：韩立在药田→发现泥土渗绿光→掌天瓶初现

【章节节奏】
  核心模式：冲突爆发(5-10章) → 资源积累(15-30章) → 实力质变(3-5章) → 新冲突引爆
  比例：冲突:积累:质变 ≈ 20%:60%:20%
  特征：大量篇幅用于"积累"，但通过：
    - 积累过程中设置小冲突维持节奏
    - 每个积累阶段有明确的"进度条"（离下次突破还差什么）
    - 积累结束后必有"高回报"让读者觉得值

【伏笔手法】
  类型：草蛇灰线，伏笔千里
  示例：
    第10章：小瓶初现 → 第14章：启封得绿液 → 中间穿插砸瓶/藏瓶/夜观异象三次递进
    全书级伏笔：掌天瓶来历/银月身世/轮回殿主身份 → 均跨越数百章后回收
  执行规则：
    - 每个伏笔埋设时都有"看起来合理"的表层解释
    - 回收时让读者"原来如此"而非"强行解释"
    - S级伏笔（全书级）≤5个
    - A级伏笔（分卷级）每卷≤3个

【战斗描写】
  原则：策略博弈 > 力量碾压
  特征：
    - 每次战斗前必有准备（丹药/法宝/阵法/信息收集）
    - 战斗中必有"策略调整"（对手出招→主角分析→应对）
    - 战后必有"收获清点+损失评估+经验总结"
  禁忌：无脑碾压、全程碾压、战斗后不收拾战场
```

### 1.4 行文特征量化

```
【用词偏好】
  动词优先：具体动作动词 > 形容词修饰
  名词精准：法宝/丹药/功法名皆有来源逻辑
  量词严谨：灵石的"块"、丹药的"粒"、法宝的"件"
  避讳词：不用"毁天灭地""转眼千年"等虚词

【句式特征】
  平均句长：18-25字（现代白话文标准区间）
  长句占比：≤15%（仅用于复杂场景描述）
  短句占比：≥40%（战斗/对话场景）
  对话占比：约28%（多用于揭示立场、推动转折，少用于抒情）

【段落特征】
  平均段落：2-4行（手机阅读友好）
  战斗段落：1-2行（快节奏）
  描写段落：2-3行（够用即止）
  对话段落：每句独立成段

【情感表达】
  特征：极度克制，情感通过行动表达
  示例：
    不写"韩立很担心南宫婉"
    写"韩立将最后三枚护身符全部打入南宫婉体内，自己只留了一枚"
  情感爆发场景：全书≤5次，每次都是关键转折
```

### 1.5 人物塑造手法

```
【主角塑造四步法】
  Step 1：动作定调
    出场第一印象靠具体动作，不靠旁白介绍
    韩立首章"咬紧嘴唇强忍泪水" → 隐忍底色立现

  Step 2：行为逻辑连贯
    性格通过一连串行为展示，不靠"他是XX的人"
    韩立每次联手必设后手 → "谨慎"是做的

  Step 3：矛盾细节丰富
    正反特质并存更真实
    韩立：极端谨慎但关键时刻敢赌
    韩立：对陌生人冷酷但对身边人极重情义

  Step 4：成长弧光靠选择
    初期："只想活命" → 中期："护佑身边人" → 后期："承一界之责"
    不是数值堆叠，是价值观选择的变化

【配角塑造原则】
  原则1：每个配角必须有独立于主角的动机
  原则2：配角不为主角而存在，为增加世界真实感而存在
  原则3：反派动机必须"从ta的角度看是对的"
  原则4：配角出场/退场有明确逻辑

【人物语言个性】
  韩立：寡言、每句话都留有后手、语气平淡但内容精准
  墨大夫：表面温和实则阴冷、话中带话
  南宫婉：清冷中有温度、话少但分量重
```

### 1.6 世界观搭建三原则

```
【原则一：实战解密法】
  禁止开篇大段设定说明。
  所有世界观通过"实战"逐步揭示：
  遇到新事物 → 角色对话/内心解释 → 立即应用 → 自然理解

【原则二：资源决定论】
  修仙世界不是快意恩仇的江湖，是赤裸裸的资源竞争。
  核心矛盾：对灵石/丹药/功法/机缘的争夺
  高阶修士视低阶修士为"资源"而非"同类"

【原则三：丛林法则真实感】
  杀伐果断是常态，仁慈是奢侈品
  每场战斗都可能丧命，每次冒险都要计算风险收益比
```

## 2. 读者画像：三重受众心理模型

### 2.1 核心读者群（七猫平台画像）

| 维度 | 数据 |
|------|------|
| 年龄 | 25-40岁男性为主（>85%） |
| 职业 | 职场人/个体户/蓝领 |
| 阅读场景 | 碎片时间（通勤/午休/睡前，单次5-15分钟） |
| 阅读设备 | 手机端99% |
| 日读量 | 2-5章（5000-15000字） |
| 付费意愿 | 中高（免费+广告模式下的追读忠诚度） |

### 2.2 深层心理需求

```
【需求1：掌控感的代偿】
  现实：职场内卷、房贷压力、无力感
  书中：主角通过精于算计获得掌控感
  连接点：韩立式的"职场生存智慧"让读者产生强烈共鸣

【需求2：努力有回报的信仰确认】
  现实：努力不一定有回报
  书中：每次付出都有明确收获（丹药/突破/宝物）
  连接点：正反馈循环给读者"努力有用"的信念补充

【需求3：规则世界中的秩序感】
  现实：世界充满不确定性
  书中：境界体系/战力体系是明确的，努力方向是清晰的
  连接点：清晰规则让读者获得"可以理解这个世界"的安全感

【需求4："延迟满足"的高级愉悦】
  现实：碎片化信息让耐心下降
  书中：漫长的积累→爆发→巨大成就感
  连接点：延迟满足比即时爽感更持久更有深度
```

### 2.3 喜好爽点（优先级排序）

| 优先级 | 爽点类型 | 触发条件 | 强度 |
|--------|---------|---------|------|
| 1 | 逆袭打脸 | 被看不起→实力爆发→碾压 | ★★★★★ |
| 2 | 境界突破 | 长期积累→厚积薄发 | ★★★★★ |
| 3 | 捡漏/收获 | 意外获得宝物/功法/机缘 | ★★★★☆ |
| 4 | 智斗取胜 | 用脑子击败强敌 | ★★★★☆ |
| 5 | 扮猪吃虎 | 隐藏实力→关键时刻爆发 | ★★★★☆ |
| 6 | 打脸反派 | 反派嚣张→主角反杀 | ★★★☆☆ |

### 2.4 排斥雷区（零容忍）

```
✗ 主角太怂：200章还不反击 → 直接弃书
✗ 后宫种马：女角色无理由倒贴 → 恶心/出戏
✗ 逻辑崩坏：昨天废柴今天吊打仙帝 → 弃书
✗ 重复套路：每章都在复制 → 无聊
✗ 苦大仇深虐主：灭门惨案无脑虐 → 读者没空共情
✗ 开局大段设定：说教感 → 跳过/弃书
✗ 无脑系统文："叮，获得混沌体" → 审美疲劳
✗ 开局平铺直叙：写了3000字什么都没有发生 → 直接淘汰
```

### 2.5 生活化偏好

```
读者需要"也像我"的日常点缀：
  ✅ 吃饭/做饭场景（灵食/灵餐的烟火气）
  ✅ 算账/数灵石（经济压力真实感）
  ✅ 睡觉/休息/恢复（不是铁人，会累）
  ✅ 与人闲聊/吐槽（日常对话的亲切感）
  ✅ 整理收获/盘点宝物（"仓库整理"的满足感）
```

## 3. 平台画像：三大平台仙侠品类深度分析

### 3.1 七猫平台画像（主攻平台）

```
【定位】日活2000万+，读者偏成熟，偏好传统题材
【仙侠偏好】
  收稿类型：全品类仙侠（玄幻仙侠、传统修仙、凡人流）
  不收类型：同人、文娱题材（男频）
  题材热度：凡人流修仙 > 传统玄幻 > 系统流 > 都市修真

【审稿核心标准（权重排序）】
  1. 代入感（40%）：读者能否在3章内"代入"主角
  2. 节奏（30%）：开篇3000字内必须有冲突/悬念
  3. 文笔（20%）：现代白话文、简洁有力、对话口语化
  4. 创新（10%）：有亮点的设定/人设加分，套路化减分

【审稿淘汰红线（任意触发即淘汰）】
  ✗ 散文式开篇：开篇全是旁白叙述
  ✗ 开局平铺直叙：无冲突无悬念
  ✗ 人设空洞：不知道主角是什么样的人
  ✗ 开篇万字错别字≥5个
  ✗ 一稿多投
  ✗ 工作室投稿

【签约后要求】
  日更：≥4000字
  连载：百万字级长篇为主
  编辑对接：签约后分配专属编辑

【流量扶持】
  新书期：签约后1-2周开始有流量推荐
  推荐位：分类榜/新书榜/编辑推荐/首页banner
  数据权重：追读率 > 完读率 > 收藏 > 评论
```

## 4. 忘语蒸馏·可执行写作模块

### 4.1 开篇模块：忘语式开局生成器

```
【检查清单】
□ 开篇场景是"日常可感知"的（药田/灶台/杂役房/矿洞）
□ 第一段存在"反常细节"（不寻常的光/声音/物品/事件）
□ 前300字内建立身份锚（主角是谁/在干什么/有什么困境）
□ 前1000字内出现冲突/悬念
□ 前3000字内金手指出现并展示首次使用
□ 主角在前3章至少有1个"只有ta会这样做"的行为标签

【开篇节奏模板】
  第1段：场景+身份锚（2-3句）
  第2段：困境锚（2-3句）
  第3段：反常细节引入（3-5句）
  第4段：主角应对+悬念建立（5-8句）
  第5段：过渡到日常/铺垫下一冲突（3-5句）
```

### 4.2 人物模块：忘语式主角生成器

```
【主角设计-18维检查表】
  □ 出身：底层/凡俗（杂役/记名弟子/矿工/药童）
  □ 资质：平庸或偏下（不是废材到离谱，就是"普通"）
  □ 初始困境：具体可感知（灵石不够/被欺负/活不过明天）
  □ 核心性格：隐忍/谨慎/算计/趋利避害（选1-2个主导）
  □ 内在动机："活下去"+"更强地活下去"
  □ 金手指：渐进式解锁、有明确限制和代价
  □ 说话特点：寡言或话藏机锋，不超过1个口头禅
  □ 决策模式：谋定后动，出手必留后手
  □ 核心价值观：人不犯我我不犯人、留得青山在
  □ 成长弧线：活命→护佑→承责（三阶段递进）
  □ 落地细节1：小习惯（如每次闭关前布阵三层）
  □ 落地细节2：标志动作（如摩挲储物袋思考时）
  □ 落地细节3：语言特征（如从来不说"我保证"）

【第一印象设计】
  主角出场用"动作+细节"定调，不要用形容词：
  错误："林小默是个谨慎的少年。"
  正确："林小默挪到药田最边上，选了个墙角的位置，才小心翼翼地蹲下来。"
```

### 4.3 节奏模块：忘语式章节节奏控制器

```
【快慢交替规则】
  每1000字切换1次节奏类型
  禁止连续2000字同一节奏

【爆发-积累-再爆发大循环】
  全书级大循环：每卷1次
    卷初：强冲突开篇(5-10章)
    卷中：资源积累(15-30章，穿插单元剧)
    卷末：实力质变+新冲突引爆(5-10章)

  章级小循环：每3-5章1次
    2-3章推进/积累 → 1章冲突/收获 → 1章过渡/总结

【章末钩子轮换表】
  偶数章：S级（断章式/悬念式）——强制次日追读
  奇数章：A级（反转式/装逼式）——提供满足感
  高潮章：S+级叠加（断章+悬念+反转三项叠加）——炸裂收尾
  过渡章：B级（预告式/情绪式）——给读者喘息

【爽点密度基准】
  七猫：每章≥1个核心爽点
  纵横：每3-5章≥1个核心爽点
  起点：每3-5章≥1个，每卷1个大高潮
```

### 4.4 世界观模块：忘语式世界铺陈法

```
【碎片化渗入规则】
  每次世界观说明≤100字（七猫≤80字）
  必须通过以下方式之一自然渗入：
    - 角色对话中顺带解释
    - 主角第一次遇到时的内心推理
    - 战斗/交手过程中的"看出来"
    - 获得物品时的"附带简介"
  禁止方式：
    - 旁白大段说明
    - "在这个世界..."式开篇介绍
    - 角色突然对空气解释世界观

【示例对比】
  错误："这个世界分为九重天，每重天都有不同的修炼体系..."
  正确："你这炼气三层，在这片地界勉强能挖矿。"监工扫了他一眼，"筑基期的都去内山了，那里灵石矿脉更纯。"
```

### 4.5 对标书拆解精华嵌入

```
【12本对标书·核心共性提取】

1. 主角起点：100%底层/废材/被欺负
2. 金手指类型：物品类(瓶/鼎/棺/塔/鼎/剑/星辰) > 系统类 > 血脉类
3. 开篇节奏：全部在3章内完成"冲突+金手指+悬念"
4. 修炼体系：全部有明确9-12境分级，每境细分4小阶
5. 越级规则：全部有"条件越级"而非"无脑越级"
6. 智斗占比：高（主角用脑子取胜的占比≥40%）
7. 章末钩子：90%以上为悬念式/断章式
8. 爽点密度：前100章每3-5章1个爽点
9. 感情线：极度克制，占比≤5%
10. 字数体量：全部4000章以上（超长篇）

【品类差异化空间】
  鼎类/棺类/塔类/星辰类金手指已有大量作品覆盖
  → 新书金手指选型需避开高度同质化赛道
  → 推荐方向：古物+日常生活组合（如古灶台/古农具/古药锄）
  → 或：融合型金手指（不止一个功能，组合使用产生新玩法）
```
