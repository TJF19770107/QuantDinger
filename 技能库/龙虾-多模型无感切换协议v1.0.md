# 龙虾-多模型无感切换协议 v1.0

> **协议编号**：#50
> **对标来源**：Pullfrog (BYOK模型无关) + 阶跃星辰 Step 3.7 Flash + GLM-5.1国产突破
> **创建日期**：2026-06-01 (R11)
> **核心价值**：模型无关架构+智能降级链+成本优化路由，使Agent在任何模型可用时稳定运行
> **状态**：ACTIVE

---

## 一、协议概述

### 1.1 问题定义
当前Agent体系高度依赖特定模型供应，单一模型不可用时任务中断。Pullfrog（Zod作者，42k★）提出了BYOK（Bring Your Own Key）模型无关架构——Agent连接任意LLM提供商（Anthropic/OpenAI/Google/Mistral/DeepSeek/OpenRouter），一键切换模型不中断服务。同时阶跃星辰Step 3.7 Flash和GLM-5.1的突破，使国产模型在部分场景已可替代国际模型。

### 1.2 核心价值
- **模型无关**：不绑定任何单一模型提供商
- **智能降级**：主模型失败→自动切换备选→保障任务完成
- **成本优化**：基于任务复杂度智能路由到性价比最优模型

### 2.2 路由决策树
```
任务到达
    │
    ├── 用户指定模型？ → 使用指定模型
    │
    ├── 任务复杂度评估
    │   ├── 简单（工具调用/文件操作） → fast层（gemini-3.5-flash/step-3.7-flash）
    │   ├── 中等（代码生成/分析） → standard层（claude-sonnet/deepseek-v4/glm-5.1）
    │   └── 复杂（多步推理/架构设计） → premium层（claude-opus/gpt-5.5）
    │
    └── 成本预算？
        ├── 有预算上限 → 优先cost_efficiency模型
        └── 无预算限制 → 优先质量
```

## 三、智能降级链

### 3.1 降级策略

| 失败类型 | 降级动作 | 重试次数 |
|---------|---------|---------|
| API超时 | 同层切换备选模型 | 2 |
| 限流/配额 | 降层使用更低成本模型 | 2 |
| 模型不可用 | 跨提供商切换同层模型 | 3 |
| 输出质量不符 | 升级使用更高层模型 | 1 |
| Token超额 | 降层+输出精简 | 1 |

### 3.2 降级链路示例
```
任务：复杂代码重构
    │
    ▼ 主路由
claude-opus-4.8 (premium)
    │ API超时
    ▼ 降级1：同层备选
gpt-5.5 (premium)
    │ 限流
    ▼ 降级2：跨层降级
claude-sonnet-4.5 (standard)
    │ 成功 ✅
```

## 四、成本优化路由

### 4.1 成本分层

| 任务类型 | 推荐层 | 月均成本估算 |
|---------|--------|------------|
| 文件操作/列目录 | fast | ~$5 |
| 代码补全/简单修改 | standard | ~$20 |
| 代码审查/重构 | standard | ~$30 |
| 架构设计/多步推理 | premium | ~$50 |
| 全自动蒸馏/迭代 | 混合 | ~$80 |

### 4.2 智能路由规则
```python
def route_task(task_complexity, budget_remaining):
    if budget_remaining < 0.1 * monthly_budget:
        # 月末预算紧张，全部降级到fast/standard
        return route_economical(task_complexity)
    elif task_complexity.score < 3:
        return "fast_tier"
    elif task_complexity.score < 7:
        return "standard_tier" 
    else:
        return "premium_tier"
```
