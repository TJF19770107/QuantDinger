## 一、核心能力

### 1.1 自主目录扫描
- **扫描根目录**: `E:\龙虾AI主控中心\我的AI分身\子Agent\豆包Agent\`
- **递归深度**: 默认3层，可配置
- **扫描子目录**: architecture / checkpoints / memory / 技能库 / 架构设计 / 能力对标 / 迭代记录
- **跳过目录**: `__pycache__` / `.git` / `node_modules` / `temp`

### 1.2 文件索引注册
- 自动构建 `file_index.json`：文件名、大小、修改时间、类型、分类、MD5
- 增量更新：仅扫描变化的文件
- 分类标签：iteration / skill / config / architecture / memory / log / other

### 1.3 内容自动识别
- **Markdown** (.md) → 提取标题、章节、关键数据
- **JSON** (.json) → 解析结构化数据、验证 schema
- **日志** (.log) → 提取时间线、错误信息
- **Python** (.py) → 识别函数/类/导入
- **未知格式** → 标记待人工审查

### 1.4 差异对比
- 对比 `file_index.json` 与磁盘实际文件
- 输出：新增文件列表、修改文件列表、删除文件列表
- 自动触发能力注册（新技能文件 → capabilities.json 更新）

## 三、命令接口

```bash
# 全量扫描
lobster-scanner --full

# 增量扫描（默认）
lobster-scanner

# 指定目录扫描
lobster-scanner --path "E:\龙虾AI主控中心\我的AI分身\技能库\"

# 差异对比（不更新索引）
lobster-scanner --diff-only

# 输出报告
lobster-scanner --report
```
