## 一、三层记忆架构总览

```
Layer 1: 静态快照层 (即时可用)
  ├── MEMORY.md   → Agent自身工作记录（环境配置、项目约定、踩过的坑）
  └── USER.md     → 用户画像（沟通偏好、技术背景、工作习惯）
  容量: ~1300 token
  加载: 每次会话启动时注入系统提示，会话期间不变

Layer 2: 持久化存储层 (按需检索)
  ├── SQLite数据库 (state.db)
  ├── FTS5全文索引
  └── LLM摘要压缩
  容量: 无上限
  加载: 通过 session_search 接口检索 + LLM摘要

Layer 3: 进化知识层 (持续优化)
  ├── 自组织超图 (借鉴EverOS HyperMem)
  ├── 语义图谱 (三元组: 实体-关系-实体)
  ├── 技能模式库 (已验证的成功模式)
  └── 权重自适应 (每10次会话 ±2%调整)
```

## 二、各层协作机制

| 场景 | Layer 1 | Layer 2 | Layer 3 |
|------|---------|---------|---------|
| 会话启动 | ✅ 立即注入 | - | - |
| "上周我们讨论过什么？" | - | ✅ FTS5检索+摘要 | - |
| "用上次那个方案" | ✅ 项目约定 | ✅ 检索历史方案 | ✅ 技能匹配 |
| "这个场景以前遇到过" | ✅ 踩过的坑 | ✅ 检索类似场景 | ✅ 模式匹配+权重推荐 |
| 经验沉淀 | ✅ MEMORY.md更新 | ✅ 写入state.db | ✅ 提炼为Skill |

## 四、SOMA 加权检索

借鉴 SOMA 的 RRF (Reciprocal Rank Fusion)：

```
加权RRF = 语义相似度 × 2 + 关键词匹配 × 1

三记忆库并行检索:
  • 情节记忆 (SQLite + 向量) → 过往具体经验
  • 语义记忆 (三元组图谱)  → 抽象知识和规律
  • 技能记忆 (模式匹配)     → 已验证成功模式

每10次会话 auto evolve():
  • 表现好的规律: +2% 权重
  • 表现差的规律: -2% 权重
  • 成功模式: 固化为技能
```

## 五、MIA 双向转换回路

借鉴 MIA (Memory-Intelligent Agent)：

```
参数记忆 (模型内在知识)
      ↕  双向转换回路
非参数记忆 (外部知识库)
```

- 任务执行 → 提取经验 → 更新非参数记忆
- 结构化知识 → 引导/微调参数记忆
- "测试时学习" (Test-time Learning)：无需中断服务
