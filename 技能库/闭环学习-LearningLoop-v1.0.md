## 一、技能概述

闭环学习系统是豆包Agent自进化的核心引擎，对标Hermes Agent的Learning Loop。每次任务完成后，系统自动分析执行轨迹，提炼可复用模式，沉淀为技能文件。

## 二、核心循环

```
观察(Observe) → 执行(Execute) → 反思(Reflect) → 沉淀(Crystallize) → 复用(Reuse)
    ↑                                                                    │
    └──────────────────── 持续改进 ─────────────────────────────────────┘
```

## 三、各阶段详解

### 3.1 观察 (Observe)
- 捕获完整的任务上下文
- 记录用户输入、环境状态、工具调用序列
- 追踪每步执行时间和成功率

### 3.2 执行 (Execute)
- 正常执行任务流程
- 记录所有工具调用及其结果
- 标记成功/失败/部分成功节点

### 3.3 反思 (Reflect)
触发条件：任务步数 > 5 或涉及 ≥3 种工具

分析维度：
- 哪些步骤可以合并简化
- 哪些错误可以预判避免
- 哪些模式是通用可复用的
- 执行时间是否有优化空间

### 3.4 沉淀 (Crystallize)
当反思发现可复用模式时：

1. 提取步骤序列
2. 生成 SKILL.md 文件
3. 分配触发词
4. 保存至技能库
5. 注册到Agent技能加载器

### 3.5 复用 (Reuse)
- 新任务到来时自动匹配已有技能
- 匹配成功则加载技能指导执行
- 记录复用次数，用于后续优化分析

## 四、技能自动生成规则

### 4.1 生成条件
- 任务成功完成
- 步数 ≥ 3
- 提取的模式置信度 > 0.7
- 模式不与已有技能重复 (相似度 < 0.8)

### 4.2 技能文件格式
```yaml
name: skill-name
version: 1.0.0
created: ISO8601
confidence: 0.85
triggers: [触发词列表]
steps: [步骤描述]
tools: [工具列表]
evolve_condition: called_count > 10
```

## 五、记忆三层架构

| 层级 | 存储 | 容量 | 用途 |
|------|------|------|------|
| L1 短期 | 会话上下文 | ~131K tokens | 当前任务理解 |
| L2 中期 | SQLite + FTS5 | 无上限 | 跨会话检索历史 |
| L3 长期 | 技能文件 (.md) | 无上限 | 沉淀可复用能力 |
