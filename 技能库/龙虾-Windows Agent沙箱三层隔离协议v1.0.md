## 一、设计目标

为AI Agent在Windows平台上提供**安全、轻量、高性能**的沙箱隔离环境，防止Agent意外或恶意操作破坏宿主系统。对标Codex的三层架构和TRAE的轻量级设计，实现毫秒级启动、零侵入系统进程、细粒度文件权限控制。

## 二、三层架构

```
┌─────────────────────────────────────────────┐
│ L3: 专用沙箱用户层                           │
│  · 隐藏影子账户 + 独立Profile                │
│  · 与主用户完全隔离                          │
│  · 网络防火墙规则绑定                        │
├─────────────────────────────────────────────┤
│ L2: 文件系统ACL层                            │
│  · 动态Deny-Write规则                       │
│  · 系统目录/用户配置/敏感路径自动保护         │
│  · Agent结束后自动回滚ACL                    │
│  · .git/.agents/.codex 目录只读保护          │
├─────────────────────────────────────────────┤
│ L1: Restricted Tokens层                     │
│  · 合成SID + 写限制Token                     │
│  · CreateProcessAsUserW 启动受限进程          │
│  · 继承策略传播至子进程                      │
└─────────────────────────────────────────────┘
```

## 三、启动流程

```
解析安全策略
  → 创建Restricted Token（合成SID+写限制）
    → 设置文件系统ACL（动态Deny-Write规则）
      → 创建I/O管道（stdin/stdout/stderr重定向）
        → CreateProcessAsUserW 启动受限进程
          → 进程超时监控 + 资源限制
            → 进程结束 → 清理Token
              → 回滚文件系统ACL
```

## 四、核心规则

### 4.1 沙箱三档模式

| 模式 | 行为 | 适用场景 |
|------|------|---------|
| **workspace-write** | 工作目录完全读写；出界操作需确认 | 日常开发任务（默认） |
| **read-only** | 仅浏览文件系统；所有写入被拦截 | 代码审查/分析任务 |
| **danger-full-access** | 跨目录+网络操作；无需确认 | CI脚本/隔离环境 |

### 4.2 文件系统ACL规则

| 路径 | 权限 | 说明 |
|------|:---:|------|
| `C:\Windows\*` | Deny-Write | 系统核心 |
| `C:\Program Files\*` | Deny-Write | 程序文件 |
| `C:\Program Files (x86)\*` | Deny-Write | 程序文件(x86) |
| `C:\ProgramData\*` | Deny-Write | 程序数据 |
| `C:\Users\*\AppData\*` | Deny-Write | 用户配置 |
| `.git\*` | Read-Only | 版本控制 |
| `.agents\*` | Read-Only | Agent配置 |
| `E:\龙虾AI主控中心\*` | Read-Only | 龙虾主控（例外：output/temp子目录可写） |
| `$WORKSPACE\*` | Read+Write | Agent工作区 |
| `$WORKSPACE\temp\*` | Read+Write | 中间产物 |

### 4.3 进程树策略传播

- 所有子进程自动继承父进程的沙箱策略
- 子进程尝试提权时自动拒绝并记录
- 进程退出时自动清理所有子进程

## 五、AgentPatterns 四要求对标

| 要求 | 实现方式 | 状态 |
|------|---------|:---:|
| ① 开放二进制执行 | Token中的Execute权限仅限制系统目录 | ✅ |
| ② 宿主工作区读写 | workspace-write模式默认支持 | ✅ |
| ③ 无管理员提权 | Token中去除SeIncreaseQuotaPrivilege等 | ✅ |
| ④ 进程树策略传播 | 子进程继承+CreateProcessAsUserW | ✅ |

## 六、安全边界

### 6.1 禁止逃逸路径

- 禁止通过命名管道/共享内存与宿主机进程通信
- 禁止通过注册表修改系统配置
- 禁止通过服务控制管理器(SCM)创建/修改服务
- 禁止通过WMI执行操作
- 禁止通过COM/DCOM跨进程调用

### 6.2 网络隔离

- 默认禁止所有出站网络连接
- 可配置白名单域名/IP放行
- Agent请求网络权限时自动触发审批
