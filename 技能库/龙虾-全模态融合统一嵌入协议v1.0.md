## 二、交错输入模式 (Interleaved Input)

### 2.1 核心机制

`交错输入`允许多种模态在一次请求中同时传入，模型将其作为统一整体理解：
- 图片 + 文字 → 理解图文关系（如"图中第三段文字的摘要"）
- 视频 + 音频 → 理解视听时序（如"视频第30秒说的话"）
- 文档 + 文本 → 跨文档语义关联（如"这份合同和其他合同的差异"）

### 2.2 跨模态检索矩阵

| 查询模态 → 目标模态 | 文本 | 图像 | 视频 | 音频 | 文档 |
|---------------------|------|------|------|------|------|
| 文本查询 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 图像查询 | ✓ | ✓ | ✓ | ✗ | ✗ |
| 音频查询 | ✓ | ✗ | ✗ | ✓ | ✗ |
| 组合查询 | ✓ | ✓ | ✓ | ✓ | ✓ |

### 2.3 组合查询语法

```
# 文本搜图
"红色的跑车在高速公路上" → [相关图片]

# 图搜文本
[产品包装图] → "这份产品的使用说明书"

# 视频+文本组合
[会议录像] + "提到第三季度预算的那段" → [精确时间戳+文本]

# 跨文档语义关联
[合同A.pdf] + [合同B.pdf] + "找出所有不一致条款"
```

## 三、Matryoshka表示学习 (MRL)

### 3.1 嵌套维度配置

```
1024维 ──┐
         │ 完整语义 (sBERT/分类任务)
 768维 ──┤ 标准语义 (跨模态检索)
         │
 512维 ──┤ 轻量语义 (快速相似度)
         │
 256维 ──┤ 粗粒度语义 (聚类/去重)
         │
 128维 ──┘ 极简语义 (近似去重)
```

### 3.2 维度选择策略

| 场景 | 推荐维数 | 精度 | 速度 |
|------|---------|------|------|
| 精准跨模态检索 | 1024 | 99.5% | 慢 |
| 通用跨模态检索 | 768 | 98.2% | 中 |
| 批量快速过滤 | 512 | 95.8% | 快 |
| 去重和聚类 | 256 | 91.3% | 极快 |
| 近似去重 | 128 | 84.6% | 超快 |

## 四、多模融合评估矩阵

### 4.1 六维评估体系

| 评估维度 | 权重 | 当前 | 目标 | 提升方案 |
|---------|------|------|------|---------|
| 模态覆盖度 | 25% | — | 5/5 | 五模统一支持 |
| 跨模态检索精度 | 25% | — | 98%+ | MRL + 交错输入 |
| 语义对齐质量 | 20% | — | 95%+ | 统一嵌入空间 |
| 处理延迟 | 15% | — | <3s | MRL维度降级 |
| 存储效率 | 10% | — | <50MB/千文件 | 嵌套降维 |
| 可扩展性 | 5% | — | 新增模态零代码 | 插件化编码器 |

### 4.2 多模融合得分公式

```
多模融合得分 = Σ(维度得分 × 权重)

达到条件触发升级：
- 模态覆盖度 = 5: 得25分
- 跨模态精度 ≥ 98%: 得25分
- 对齐质量 ≥ 95%: 得20分
- 延迟 ≤ 3s: 得15分
- 存储 ≤ 50MB: 得10分
- 可扩展 ≥ 1: 得5分
─────────────
满分: 100 → 映射为96分 (顶级水平)
```
