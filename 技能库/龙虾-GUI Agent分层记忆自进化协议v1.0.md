## 一、协议背景

### 1.1 核心问题

GUI Agent面临两大结构性短板：
1. **记不住**：上下文窗口受限，多步骤任务中早期关键信息随上下文滑动丢失，导致"误差累积"连锁失败
2. **学不会**：静态策略固化，无法从过往成功经验中学习和迁移，难以适应动态变化环境

### 1.2 SE-GA框架突破

天津大学+上海交大团队在ICML 2026提出的SE-GA框架，引入分层记忆结构和迭代自我改进机制：
- 论文：SE-GA: Memory-Augmented Self-Evolution for GUI Agents (arXiv:2605.16883)
- 代码：https://github.com/jinshilong-dev/SE-GA
- 基座模型：Qwen2.5-VL-7B，仅4K条交互轨迹训练
- ScreenSpot 89.0%超越UI-TARS-72B(88.4%)
- AndroidWorld 39.0%显著领先GPT-4o(23.7%)

## 二、三层分层记忆结构 (TTME)

### 2.1 架构总览

```
┌─────────────────────────────────────────────────────┐
│                  TTME 分层记忆库                      │
├─────────────────┬─────────────────┬─────────────────┤
│  情景记忆 (EM)   │  语义记忆 (SM)   │  经验记忆 (XM)   │
│  "刚才做了什么"  │  "怎么做才对"    │  "成功的经验"    │
│  短期工作记忆    │  通用规则库      │  过往经历库      │
│  前步观察+动作   │  抽象交互规则    │  成功轨迹+反思   │
│  +新观察         │  跨任务通用      │  文本+图像混合   │
└─────────────────┴─────────────────┴─────────────────┘
```

### 2.2 情景记忆 (Episodic Memory)

| 属性 | 说明 |
|------|------|
| 粒度 | 每时间步记录：(观察_t-1, 动作_t-1, 观察_t) |
| 优势 | 避免保留全部历史带来的计算开销，过滤过时信息 |
| 更新 | 实时增量写入，滑动窗口保留最近N步 |
| 容量 | 单任务级，任务完成后可选归档至经验记忆 |

### 2.3 语义记忆 (Semantic Memory)

| 属性 | 说明 |
|------|------|
| 粒度 | 抽象的跨任务通用交互规则 |
| 示例 | "需要先登录才能访问受限页面"、"搜索功能通常在页面顶部" |
| 来源 | 预训练知识 + 任务执行中提取的模式 |
| 检索 | 基于当前状态自动匹配相关规则 |

### 2.4 经验记忆 (Experiential Memory)

| 属性 | 说明 |
|------|------|
| 粒度 | 完整成功任务轨迹 + Agent自生成的反思总结 |
| 检索机制 | **文本-图像混合检索**：同时考虑语义一致性和视觉相似性 |
| 检索流程 | 当前截图→视觉编码→与经验库视觉特征比对 + 当前任务描述→语义编码→与经验库文本特征比对→加权融合排序 |
| 价值 | 让智能体"站在过去的肩膀上"做决策，精准复用成功经验 |

## 三、自我进化训练框架 (MASE)

### 3.1 两阶段训练

```
阶段一：基础能力训练 (Grounding Training)
  ├─ 监督微调 (SFT) 对专家轨迹行为克隆
  ├─ 强化视觉定位能力
  └─ 强化动作推理能力
       ↓
阶段二：自我进化训练 (Self-Evolution Training)
  ├─ 基于GRPO算法 (Group Relative Policy Optimization)
  ├─ 从与环境交互产生的数据中持续学习
  ├─ Hindsight Goal-Shifting 失败轨迹精炼
  └─ 分层奖励设计（点定位/包围框/步骤成功/任务完成）
```

### 3.2 Hindsight Goal-Shifting（关键创新）

**核心思想**：失败轨迹的"变废为宝"

| 步骤 | 说明 |
|------|------|
| 1. 检测 | 识别失败轨迹中的有效前缀子序列 |
| 2. 判定 | 前缀是否已完成某个有效子目标（如成功打开应用） |
| 3. 重标注 | 将该轨迹重新标注为对该子目标的成功实例 |
| 4. 注入 | 转化为有价值的监督信号，提升训练数据利用率 |

**效果**：在有限交互数据下实现有效自我进化，数据利用率提升数倍。

### 3.3 分层奖励设计

| 奖励层级 | 粒度 | 目标 |
|---------|------|------|
| L1 点定位奖励 | 像素级 | 精确点击目标UI元素 |
| L2 包围框奖励 | 区域级 | 正确定位元素边界 |
| L3 步骤成功奖励 | 步骤级 | 单步操作正确执行 |
| L4 任务完成奖励 | 任务级 | 端到端任务成功 |

## 四、龙虾豆包Agent适配方案

### 4.1 三层记忆映射

| SE-GA组件 | 豆包Agent映射 | 实现方式 |
|-----------|-------------|---------|
| 情景记忆 | 会话上下文窗口 | 当前对话的最近N步交互历史 |
| 语义记忆 | 技能库规则层 | 协议中的通用交互规则模板 |
| 经验记忆 | MemoryOS持久化层 | 成功任务轨迹+反思摘要存储 |

### 4.2 混合检索实现

```
经验记忆检索流程：
1. 当前任务描述 → text_encoder → 文本向量
2. 当前截图/UI状态 → vision_encoder → 视觉向量
3. 经验库 → 双通道检索：
   - 文本向量余弦相似度 Top-K
   - 视觉向量余弦相似度 Top-K
4. 加权融合排序 (α * text_sim + (1-α) * visual_sim)
5. 返回Top-N相关经验注入决策上下文
```

### 4.3 自进化闭环

```
任务执行 → 成功？
  ├─ 是 → 轨迹存入经验记忆 + 生成反思摘要
  └─ 否 → Hindsight Goal-Shifting 精炼 → 提取有效子目标 → 存入经验记忆
       ↓
定期（每N次任务或每M小时）：
  经验记忆 → 模式提取 → 语义记忆规则更新 → 技能库沉淀
```
