## 1. 作者画像：忘语行文习惯与创作心法

### 1.1 核心创作哲学

| 维度 | 忘语特征 | 模板转化 |
|------|---------|---------|
| **创作内核** | "奋斗精神"——不论基础天赋如何，只有奋斗才有成功可能 | 主角必须有"靠自己"的成长弧线，金手指只是加速器而非替代品 |
| **世界观构建** | 提前3年构架世界观，后期再细化丰满 | 强制要求：大纲阶段完成三级位面体系（凡界→灵界→仙界）骨架 |
| **人物塑造** | 把自己代入角色，把身边熟人写进去 | 主角必须注入作者本人的选择与决断逻辑，配角从真实人物取材 |
| **逻辑性追求** | "追求逻辑性和现实性"，与传统爽文不同 | 每个剧情转折必须有"为什么"的解释，禁止无理由的巧合 |
| **细节执念** | "最大的特色和看点就是细节描写" | 每章强制≥5处具体细节描写（动作/环境/心理/物品/对话） |

### 1.2 叙事手法拆解

#### 1.2.1 第三人称限知视角

```
【忘语手法】全程紧跟韩立视角，读者只能看到韩立所见所闻
【模板转化】
- 禁止上帝视角旁白（"与此同时，千里之外……"）
- 禁止提前透露反派计划（除非主角通过某种方式获知）
- 世界信息通过主角"发现"而非作者"告知"
- 悬念保持：主角不知道的事，读者也不能知道
```

#### 1.2.2 草蛇灰线·伏脉千里

```
【忘语手法】前期看似无关紧要的道具/人物，后期成为关键转折
  案例：第10章小瓶初现 → 第14章启封得绿液 → 中间穿插砸瓶/藏瓶/夜观异象三次递进
  案例：向之礼（化神修士）早期以低阶修士身份出场，数百章后揭晓真实身份

【模板转化】
- 伏笔表强制要求：≥50个伏笔编号，闭环回收率≥70%
- 伏笔递进规则：每个重要伏笔至少经过3次"暗示→强化→揭晓"递进
- 禁止"一次性伏笔"：埋设后50章内必须至少呼应1次
- 人物伏笔：重要配角首次出场时即埋设真实身份线索
```

#### 1.2.3 慢热延迟满足

```
【忘语手法】一个小境界提升需要数十甚至上百章铺垫（寻找材料→炼丹→闭关）
【模板转化（七猫适配版）】
- 保留"积累→突破"的成就感逻辑，但压缩铺垫周期
- 原版：50-80章升1境 → 七猫适配：15-25章升1境
- 突破前必须有≥3章的"寻找材料/克服困难"铺垫
- 突破瞬间必须有"质变点"描写（不是简单变强，而是"能做新事"）
- 突破后必须有"展示新能力"的场景（1-2章内）
```

#### 1.2.4 资源决定论世界观

```
【忘语手法】修仙核心矛盾不是正邪之争，而是对灵石/丹药/功法的争夺
【模板转化】
- 世界观设定必须包含"资源稀缺性"维度
- 每个境界突破必须消耗具体资源（不能凭空突破）
- 势力冲突根因优先设计为"资源争夺"而非"正邪对立"
- 主角成长路径：获取资源→转化实力→获取更多资源（正向循环）
```

### 1.3 语言风格拆解

| 特征 | 忘语原文表现 | 模板转化 |
|------|------------|---------|
| **语体色彩** | "半文半白"现代白话文，夹杂修仙典雅词汇 | 叙事语言：现代白话文（90%）+ 修仙术语（10%），禁止古风堆砌 |
| **对话占比** | 约28%，多用于揭示立场/推动情节，极少抒情 | 对话功能限定：推动情节/揭示信息/展示性格，禁止纯抒情对话 |
| **心理描写** | 约15%，严格限于可观察生理反应，避免内心独白 | 心理描写规则：通过动作/表情/生理反应外化，禁止大段内心独白 |
| **修辞风格** | 具象化比喻，载体集中于自然物 | 比喻规则：灵力→水流/光芒/火焰等自然物，禁止抽象比喻 |
| **景物描写** | 每新地图必有环境介绍，不带修辞渲染气氛 | 新场景规则：首次进入必须200-400字环境描写，功能=渲染气氛+暗示危险 |
| **通篇无废话** | 老读者评价"通篇无废话" | 每段必须有信息增量（推进剧情/展示性格/埋设伏笔/渲染气氛），否则删除 |

### 1.4 人物塑造手法

#### 1.4.1 主角塑造：行为逻辑驱动

```
【忘语手法】性格展示摒弃旁白概括，全赖行为逻辑
  案例：韩立每次出手必留三分余力（第20章救治厉飞雨后仍藏铁筒）
  案例：每次结盟必设后手（第1036章与圭灵联手前已暗查其妖气）
  案例：每次突破必同步强化防御（结婴后立即炼制第二元婴）

【模板转化】
- 主角性格通过"选择"展示，禁止旁白直接说"他是一个谨慎的人"
- 主角每次做决定必须有"算计过程"（哪怕只有一句话）
- 主角的谨慎/算计必须通过具体行为体现（留后手/藏底牌/设反制）
- 主角成长弧线 = "工具理性"的深化：活命→护佑→承责
```

#### 1.4.2 配角塑造：功能性与血肉并重

```
【忘语手法】"很早就领盒饭的路人甲，也会赋予血肉，避免人物空洞"
  案例：韩立小妹——从未正面出场/无肖像描写/无对话，但读者心中自有形象
  案例：墨大夫——"弓身咳嗽"与"手指轻叩桌面"的矛盾细节暗示双重人格

【模板转化】
- 每个配角（含龙套）至少1个独特细节（动作/语言/外貌/习惯）
- 重要配角必须有"矛盾细节"（表面与内在不一致的暗示）
- 配角出场必须有"功能标签"（推动主线/提供信息/制造冲突/情感锚点）
- 禁止"纸片人"配角：出场只为被主角打脸，无任何独立特征
```

#### 1.4.3 反派塑造：动机必须有道理

```
【忘语手法】反派不是纯粹邪恶，而是利益驱动的理性选择
【模板转化】
- 每个反派必须填写"为什么有道理"字段
- 反派的恶行必须有利益逻辑（资源争夺/生存威胁/理念冲突）
- 至少1个反派有"灰色"复杂性（读者能理解其立场）
- 禁止"纯粹的恶"型反派（除非是低阶龙套）
```

### 1.5 忘语创作纪律（可直接执行）

| 序号 | 纪律 | 说明 |
|------|------|------|
| 1 | 提前构架世界观 | 动笔前完成三级位面体系骨架，后期只细化不推翻 |
| 2 | 代入式写作 | 每章写作前自问"如果我是主角，此刻会怎么做" |
| 3 | 细节优先 | 每章至少5处具体细节描写，拒绝空洞叙述 |
| 4 | 逻辑自洽 | 每个剧情转折必须有前因后果，禁止"突然就……" |
| 5 | 伏笔管理 | 埋设时编号，回收时标记，闭环率≥70% |
| 6 | 行为展示性格 | 禁止旁白概括性格，必须通过行为/选择/对话展示 |
| 7 | 资源驱动冲突 | 核心矛盾优先设计为资源争夺，而非正邪对立 |
| 8 | 延迟满足 | 突破前必有铺垫，突破后必有展示，拒绝"秒升级" |
| 9 | 限知视角 | 全程紧跟主角视角，禁止上帝视角 |
| 10 | 通篇无废话 | 每段必须有信息增量，否则删除 |

## 2. 读者画像：仙侠读者阅读心理与偏好

### 2.1 忘语核心读者画像

| 维度 | 特征 | 模板转化 |
|------|------|---------|
| **年龄层** | 30-40岁为主（忘语自述） | 目标读者不是青少年，是有阅读积累的成熟读者 |
| **阅读经验** | 多年网文阅读史，"经过众多小说过滤后"的挑剔读者 | 套路化写作会被识破，必须有创新点 |
| **核心诉求** | 逻辑性+现实性+代入感 | 三大支柱缺一不可 |
| **排斥内容** | 无脑爽文、逻辑漏洞、人物空洞 | 禁止"为爽而爽"、禁止战力崩坏、禁止纸片人 |
| **情感共鸣** | "奋斗精神"——普通人通过努力逆袭 | 主角必须有"普通人的困境"，让读者觉得"这像我" |

### 2.2 七猫站内仙侠读者画像（基于对标书数据反推）

| 维度 | 特征 | 模板转化 |
|------|------|---------|
| **阅读习惯** | 碎片化阅读，单次阅读时长15-30分钟 | 每章2500-3500字，独立成段，章末强钩子 |
| **爽点偏好** | 装逼打脸（最高频）> 升级突破 > 获得宝物 | 爽点类型配比：装逼打脸40% + 升级突破30% + 获得宝物20% + 其他10% |
| **节奏容忍** | 前3章无冲突即弃书，前10章无金手指即流失 | 黄金三章硬性标准，金手指1-5章内出现 |
| **代入需求** | 主角必须有"普通人特质"，开局场景必须"日常可感知" | 开篇切入点：被欺负/被退婚/被轻视/考试失败/家族危机 |
| **排斥雷区** | 开局平铺直叙、人设空洞、大段世界观阐述、回忆杀 | 前3章禁止：世界观铺陈/设定说明/回忆杀/纯日常流水账 |
| **生活化偏好** | 在修炼主线中接受10-15%生活场景 | 每5-8章插入1段生活化场景（吃饭/日常互动/凡人视角） |
| **情感需求** | 接受慢热感情线，但必须有"情感锚点" | 每10-15章插入1次情感线推进（不一定是爱情） |

### 2.3 读者心理模型：压抑→释放曲线

```
【七猫仙侠读者情绪曲线模型】

第1-3章：好奇（钩子）→ 微紧张（冲突）→ 期待（悬念）
第4-10章：压抑积累（困境加深）→ 小释放（第一次爽点）→ 新期待（更大目标）
第11-30章：循环 [压抑→释放] × 3-5次，每次释放强度递增
第30-50章：中释放（第一卷高潮）→ 新世界展开 → 新压抑开始

【关键规则】
- 压抑必须"真实"：读者真的感到憋屈/愤怒/心疼，不能"假压抑"
- 释放必须"彻底"：打了脸就一定要让反派真的后悔，不能"打了但没完全打"
- 释放后必须有"余韵"：其他人的议论/传播/态度转变，延长爽感
- 两次释放之间必须有"新信息"：不能重复同样的爽点模式
```

## 4. 忘语蒸馏 × 七猫爆款融合：开篇专项增强

### 4.1 忘语式开篇心法

```
【忘语《凡人》开篇拆解】
第1章：韩立"咬紧嘴唇强忍泪水" → 动作定调，奠定隐忍底色
第1章末："韩立从未想到……他竟然走上了一条与凡人不同的仙业大道" → 高明伏笔
前10章：七玄门江湖争斗 → 为修仙界做足铺垫，过渡极其自然
金手指：第10章小瓶初现 → 第14章启封 → 中间三次递进 → 期待值拉满

【核心心法】
1. 开篇从"日常可感知"场景切入（韩立离家、被欺负）
2. 第一句话即暗示全书方向（"仙业大道"伏笔）
3. 金手指不急于揭示全部功能，分阶段递进
4. 从凡人世界过渡到修仙世界，自然不突兀
5. 主角性格通过行为展示（咬紧嘴唇、藏铁筒），不靠旁白
```

### 4.2 七猫爆款开篇共性（《太荒吞天诀》等）

```
【七猫爆款开篇共同模式】
1. 第1章必有核心冲突（青楼遇袭/被退婚/被追杀）
2. 前3章内主角展示第一次能力/金手指
3. 前10章完成第一次重大升级
```
