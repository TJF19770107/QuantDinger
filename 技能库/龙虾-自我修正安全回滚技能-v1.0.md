## 三、异常检测与自愈决策

### 3.1 异常类型
| 异常类型 | 检测方式 | 自动响应 |
|----------|----------|----------|
| 文件丢失 | file_index 对比 | 从备份恢复 |
| 文件损坏 | MD5 对比 | 回滚到上一检查点 |
| 任务超时 | 计时器 | 标记失败，下次跳过 |
| 连续失败 (≥3次) | 计数器 | 标记 blocked，通知用户 |
| 磁盘空间不足 | 磁盘检测 | 清理过期日志 |
| 技能冲突 | 语义相似度 | 标记待合并 |

### 3.2 回滚决策树
```
检测到异常
    │
    ├── 文件级异常 → 从 checkpoints 恢复单个文件
    │
    ├── 配置级异常 → 回滚 capabilities.json 到上一版本
    │
    ├── 技能级异常 → 禁用问题技能 + 通知 SkillForge
    │
    └── 系统级异常 → 全量回滚到最近稳定检查点 + 暂停迭代
```

### 3.3 回滚后自愈流程
```
回滚完成 →
  验证检查点完整性 →
    重新加载记忆和技能 →
      增量迭代（跳过问题阶段） →
        写入恢复日志
```

## 五、安全规则（永久生效）

1. **禁止静默变更**：所有配置修改必须记录日志
2. **禁止自我删除**：SafeGuard 技能本身不可被修改或删除
3. **禁止绕过**：任何技能不可绕过 SafeGuard 写入系统目录
4. **回滚优先**：优先恢复而非覆盖，原文件保留 .bak 备份
5. **渐进修复**：每次修复只改一个维度，验证通过后再继续

## 六、命令接口

```bash
# 检查点
safeguard checkpoint               # 手动创建检查点
safeguard checkpoint --list        # 列出所有检查点

# 健康检查
safeguard health                   # 运行完整健康检查
safeguard health --quick           # 快速检查（仅关键项）

# 异常处理
safeguard diagnose                 # 诊断当前异常
safeguard repair --auto            # 自动修复（仅安全操作）
```
