# 龙虾-Tick级订单流分析协议 v1.0

> **协议编号**：#85
> **版本**：v1.0
> **创建日期**：2026-06-02
> **对标来源**：量化交易L2数据标准 + 广发金工DPIN订单流模型 + AI-Trader多模型竞技场
> **核心定位**：补齐豆包Agent交易博弈策略短板（90→92），实现Tick级逐笔数据接入、六大因子族建模、三层决策引擎、端到端回测闭环

---

## 一、协议定位

### 1.1 问题诊断

根据R25对标评估报告，交易博弈策略维度虽然为豆包Agent专属优势，但仍存在4项关键短板：

| 短板 | 严重程度 | 描述 |
|------|---------|------|
| 缺少Tick级数据接入 | 🔴 严重 | 只有K线级数据，无法捕捉盘口微观结构 |
| L2订单流分析缺失 | 🔴 严重 | 主力资金流向粗粒度，缺逐笔委托级分析 |
| 跨市场套利监控不足 | 🟡 中等 | 无实时价差监控和自动套利触发 |
| 回测引擎归因缺失 | 🟡 中等 | 无Sharpe/MaxDD自动归因分析 |

### 1.2 对标分析

| 对标来源 | 核心能力 | 可借鉴要点 |
|----------|---------|-----------|
| **广发金工DPIN** | 基于逐笔成交数据的订单流分析模型，六大因子族 | 因子体系：价格压力/成交量失衡/大单流向/速度/深度/时间 |
| **AI-Trader** | 5+模型竞技场，多策略并行回测 | 多策略竞技 + 自动排名 |
| **Zipline/Backtrader** | Python开源回测引擎 | 事件驱动回测架构 + Sharpe/MaxDD自动计算 |
| **L2数据标准** | 上交所/深交所Level-2行情标准 | Tick数据结构定义 + 数据清洗规范 |

## 二、六大因子族体系

对标广发金工DPIN模型，构建六维订单流因子族：

```
┌─────────────────────────────────────────────────────────────┐
│                Tick级订单流六大因子族                         │
├─────────────────────────────────────────────────────────────┤
│  F1: 价格压力因子 (Price Pressure)                          │
│  F2: 成交量失衡因子 (Volume Imbalance)                      │
│  F3: 大单流向因子 (Block Trade Flow)                        │
│  F4: 交易速度因子 (Trade Velocity)                           │
│  F5: 订单簿深度因子 (Order Book Depth)                       │
│  F6: 时间微观结构因子 (Temporal Microstructure)              │
└─────────────────────────────────────────────────────────────┘
```

### 2.1 F1：价格压力因子

| 子因子 | 公式 | 含义 | 信号方向 |
|--------|------|------|---------|
| 净主动买入比率 | (主动买入额-主动卖出额) / 总成交额 | 主动买卖力量对比 | >0偏多 |
| 价格冲击系数 | ΔP / 净主动量 | 单位成交量对价格的影响 | 高值=流动性差 |
| VWAP偏离度 | (当前价-VWAP) / VWAP | 价格相对于均价的位置 | >0偏强 |
| 有效价差 | 2 × |成交价-买卖中间价| | 实际交易成本 | 高=流动性差 |
| 已实现价差 | 成交价-5分钟后中间价 | 做市商实际收益 | 正=方向正确 |

### 2.2 F2：成交量失衡因子

| 子因子 | 公式 | 含义 | 信号方向 |
|--------|------|------|---------|
| 成交量比率(VR) | 上涨量/下跌量(N日) | 量价配合关系 | >1偏多 |
| 量比 | 当前量/5日均量 | 相对放量程度 | >2放量 |
| 大单成交占比 | 大单成交额/总成交额 | 主力参与度 | >30%关注 |
| 开盘量异常 | 开盘量/昨日开盘量 | 开盘情绪 | >2异动 |
| 尾盘量异常 | 尾盘30分量/日均尾盘量 | 尾盘抢筹/出逃 | >2异动 |

### 2.3 F3：大单流向因子

| 子因子 | 公式 | 含义 | 信号方向 |
|--------|------|------|---------|
| 特大单净流向 | 特大单买入-特大单卖出 | 超大资金动向 | >0偏多 |
| 大单净流向 | 大单买入-大单卖出 | 机构资金动向 | >0偏多 |
| 主力净买入比率 | (特大+大单)净买入/总成交 | 主力参与度 | >10%关注 |
| 大单集中度 | 前10笔大单/总成交 | 资金集中程度 | 高=主力控盘 |
| 拆单检测 | 连续小单同向/同价 | 识别隐藏大单 | 频率异常预警 |

### 2.4 F4：交易速度因子

| 子因子 | 公式 | 含义 | 信号方向 |
|--------|------|------|---------|
| 成交频率 | 每秒成交笔数 | 交易活跃度 | 突增=异动 |
| 撤单率 | 撤单数/总委托数 | 虚假挂单程度 | 高=不坚定 |
| 订单存活时间 | 委托提交到成交/撤单时间 | 高频交易信号 | 短=算法交易 |
| 成交间隔 | 相邻成交时间间隔均值 | 交易节奏 | 缩短=加速 |
| 突发交易波 | 1秒内超阈值成交笔数 | 程序化交易检测 | >10笔=程序化 |

### 2.5 F5：订单簿深度因子

| 子因子 | 公式 | 含义 | 信号方向 |
|--------|------|------|---------|
| 买卖深度比 | 买1-5总量/卖1-5总量 | 盘口挂单力量对比 | >1支撑强 |
| 订单簿斜率 | 深度加权平均价的变化率 | 价格弹性/流动性 | 陡=支撑强 |
| 价差宽度 | 卖1-买1 | 即时交易成本 | 宽=流动性差 |
| 深度衰减率 | 深度随价格远离的衰减速度 | 隐藏流动性 | 慢=深度好 |
| 冰山订单检测 | 同价位连续出现同量成交 | 隐藏大单识别 | 频繁=主力吸筹 |

### 2.6 F6：时间微观结构因子

| 子因子 | 公式 | 含义 | 信号方向 |
|--------|------|------|---------|
| 开盘30分钟动量 | 开盘30分钟涨跌幅 | 日内方向性 | 与日线方向一致=强化 |
| 午盘反转概率 | 13:00-14:00反转频率 | 午间消息消化 | 高概率=震荡 |
| 尾盘30分钟动量 | 尾盘30分钟涨跌幅 | 收盘抢筹 | 与日线同向=可靠 |
| 周期性模式 | 日内固定时段的规律性模式 | 算法交易时间表 | 规律出现=算法交易 |
| 跳跃检测 | 价格非连续跳跃的幅度和频率 | 信息冲击/流动性枯竭 | >2σ=异动 |

## 三、三层决策引擎

```
┌──────────────────────────────────────────────────────────────┐
│                    三层决策引擎架构                            │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  L1: 信号层 (Signal Layer)                                   │
│  ┌──────────────────────────────────────────────────────┐   │
│  │ 六大因子族 → 单因子得分 → 加权综合信号                 │   │
│  │               ↓                                       │   │
│  │  信号强度: 弱(-2~-1) 中(-1~+1) 强(+1~+2)             │   │
│  └──────────────────────────────────────────────────────┘   │
│                          ↓                                    │
│  L2: 策略层 (Strategy Layer)                                  │
│  ┌──────────────────────────────────────────────────────┐   │
│  │ 信号 → 策略匹配 → 仓位计算 → 风险校验                  │   │
│  │                                                       │   │
│  │  策略库: 趋势跟随/反转博弈/套利对冲/事件驱动/做市      │   │
│  └──────────────────────────────────────────────────────┘   │
│                          ↓                                    │
│  L3: 执行层 (Execution Layer)                                 │
│  ┌──────────────────────────────────────────────────────┐   │
│  │ 策略信号 → 下单决策 → 拆单算法 → 滑点控制 → 成交反馈  │   │
│  │                                                       │   │
│  │  风控红线: 单笔≤2%净值 | 连续回撤≤15% | 日最大亏损≤5%  │   │
│  └──────────────────────────────────────────────────────┘   │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 4.1 引擎架构

```
┌──────────────────────────────────────────────────────┐
│               端到端回测引擎                           │
├──────────────────────────────────────────────────────┤
│                                                      │
│  Input: Tick数据 + 策略定义 + 风控参数                 │
│                   ↓                                   │
│  ┌──────────────────────────────────────┐           │
│  │  数据预处理 (Data Preprocessing)      │           │
│  │  - Tick数据清洗 / 缺失值填充           │           │
│  │  - 复权处理 / 对齐时间戳               │           │
│  └──────────────────────────────────────┘           │
│                   ↓                                   │
│  ┌──────────────────────────────────────┐           │
│  │  信号生成 (Signal Generation)          │           │
│  │  - 六大因子族实时计算                   │           │
│  │  - 信号融合与置信度评估                 │           │
│  └──────────────────────────────────────┘           │
│                   ↓                                   │
│  ┌──────────────────────────────────────┐           │
│  │  策略执行 (Strategy Execution)         │           │
│  │  - 信号→交易决策                       │           │
│  │  - 仓位管理 / 滑点模拟                 │           │
│  │  - 交易成本（佣金/印花税/冲击成本）     │           │
│  └──────────────────────────────────────┘           │
│                   ↓                                   │
│  ┌──────────────────────────────────────┐           │
│  │  绩效归因 (Performance Attribution)   │           │
│  │  - Sharpe / Sortino / Calmar 比率     │           │
│  │  - MaxDD / 最大连续亏损天数           │           │
│  │  - 因子贡献分解 / 胜率/盈亏比         │           │
│  │  - 逐笔归因（每笔交易的因子得分）      │           │
│  └──────────────────────────────────────┘           │
│                                                      │
└──────────────────────────────────────────────────────┘
```

### 4.2 核心评估指标

| 类别 | 指标 | 公式 | 用途 |
|------|------|------|------|
| 收益 | 年化收益率 | (终值/初值)^(252/天数)-1 | 绝对收益 |
| 风险 | 年化波动率 | std(日收益)×√252 | 波动风险 |
| 风险调整 | Sharpe比率 | (年化收益-无风险利率)/年化波动 | 风险调整收益 |
| 风险调整 | Sortino比率 | (年化收益-目标收益)/下行标准差 | 下行风险调整 |
| 风险调整 | Calmar比率 | 年化收益/MaxDD | 最大回撤调整 |
| 回撤 | 最大回撤(MaxDD) | max(峰值-谷值)/峰值 | 最大亏损幅度 |
| 回撤 | 最长回撤期 | 新高到新高最大天数 | 回撤持续时间 |
| 交易 | 胜率 | 盈利交易/总交易 | 交易质量 |
| 交易 | 盈亏比 | 平均盈利/平均亏损 | 风险回报 |
| 交易 | 换手率 | 年交易额/平均资产 | 交易频率 |
| 归因 | 因子贡献 | 各因子加权贡献分解 | 策略归因 |
| 归因 | IC/IR | 因子值与收益的相关系数/比率 | 因子有效性 |

## 五、技术实现方案

### 5.1 Tick数据结构标准

```python
@dataclass
class TickData:
    """L2逐笔成交数据结构"""
    symbol: str           # 股票代码
    timestamp: int        # 时间戳（毫秒）
    price: float          # 成交价
    volume: int           # 成交量（股）
    amount: float         # 成交额
    direction: str        # 买卖方向：B/S/N（中性）
    trade_type: str       # 成交类型：0=普通/1=大宗/2=盘后
    bid_price_1_5: list   # 买1-5价
    ask_price_1_5: list   # 卖1-5价
    bid_volume_1_5: list  # 买1-5量
    ask_volume_1_5: list  # 卖1-5量
    total_bid_volume: int # 总买量
    total_ask_volume: int # 总卖量

@dataclass
class OrderFlowSummary:
    """订单流汇总"""
    symbol: str
    window_start: int
    window_end: int
    net_active_buy: float     # 净主动买入额
    large_order_ratio: float  # 大单占比
    avg_spread: float         # 平均价差
    trade_count: int          # 成交笔数
    cancel_rate: float        # 撤单率
    factor_scores: Dict[str, float]  # 六大因子得分
```

### 5.2 核心类设计

```python
class TickOrderFlowEngine:
    """Tick级订单流分析引擎"""

    # === 数据接入 ===
    def load_tick_data(self, symbol, date) -> List[TickData]
    def stream_realtime_ticks(self, symbols) -> AsyncIterator[TickData]

    # === 因子计算 ===
    def compute_factors(self, tick_data) -> Dict[str, float]
    def compute_factor_score(self, factor_name, value) -> float

    # === 信号生成 ===
    def generate_signal(self, factor_scores) -> SignalResult
    def signal_confidence(self, signal) -> float

    # === 策略匹配 ===
    def match_strategy(self, signal) -> List[Strategy]
    def compute_position(self, strategy, capital) -> PositionPlan

    # === 回测引擎 ===
    def run_backtest(self, config) -> BacktestResult
    def compute_metrics(self, equity_curve) -> PerformanceMetrics
    def attribute_performance(self, trades) -> AttributionReport
```
