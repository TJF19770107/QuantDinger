## 一、核心矛盾

**经验每天都在产生，却没有机制把它从一次会话中提取出来、固化为可复用的团队资产。**

```
单人踩坑 → 总结流程 → 验证 → 沉淀Skill
                                    ↓
                          [当前断裂点：无法进入团队共享]
                                    ↓
               下一人继续踩同样的坑 ❌
```

## 二、四路径全生命周期覆盖

```
┌──────────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│  SkillClaw   │ → │ Nacos AI     │ → │   MUSE-      │ → │   SkillOpt   │
│  经验产生     │    │  Registry    │    │  Autoskill   │    │  文本优化     │
│  （从会话生长）│    │  团队分发     │    │  技能进化     │    │  （训练循环） │
└──────────────┘    └──────────────┘    └──────────────┘    └──────────────┘
     产生层              分发层              进化层              优化层
```

### 2.1 SkillClaw：经验产生层

**让Skill从真实工作流中逐步长出来。**

- **双循环模型**：Agent任务循环（执行用户任务）+ SkillClaw演化循环（后台分析会话、演化技能），两个循环并行互不干扰
- **本地Proxy接管**：拦截Agent的API请求，记录关键过程：会话turn、工具调用、结果、错误、Skill命中、修改内容和评分
- **Evolve Server决策**：基于会话数据判断——是否有可复用经验？已有Skill是否需要改进？是否应生成新Skill？
- **跨Agent交叉授粉**：前端Agent积累的模式识别经验，可改善后端Agent的API设计决策

### 2.2 Nacos AI Registry：团队分发层

**Skill进入团队级治理体系。**

- **注册**：Skill标准化注册（名称/版本/描述/适用场景/前置依赖）
- **审核**：自动安全检查 + 人工Review双轨
- **版本管理**：语义化版本号 + 变更日志自动生成
- **灰度发布**：先10%用户验证 → 50%扩量 → 全量
- **回滚机制**：一键回退到上一稳定版本
- **发现与拉取**：Agent启动时自动拉取团队推荐Skill列表

### 2.3 MUSE-Autoskill：技能进化层

**五阶段技能生命周期闭环。**

| 阶段 | 动作 | 产出 |
|------|------|------|
| Create | 从任务执行中自主创建技能 | 初始Skill.md |
| Test | 沙箱验证技能有效性 | 通过/失败报告 |
| Fix | 失败时自动诊断并修复 | 修正版Skill.md |
| Register | 通过验证后注册到技能库 | 入库记录 |
| Maintain | 持续监控性能，触发重新进化 | 进化触发日志 |

- 准确率87.94% vs 人类专家68.40%
- Memory-Utilizing：技能携带执行记忆，知道"上次怎么做成功的"

详见协议#164。

## 三、三层生态架构

```
┌─────────────────────────────────────────────┐
│  L3 进化层（SkillOpt + MUSE）                │
│  持续自动优化：训练循环 + 五阶段生命周期       │
├─────────────────────────────────────────────┤
│  L2 团队层（Nacos AI Registry）              │
│  统一治理：注册/审核/版本/灰度/回滚/分发      │
├─────────────────────────────────────────────┤
│  L1 本地层（SkillClaw + Agent运行时）         │
│  经验产生：从真实会话中生长Skill + 本地缓存    │
└─────────────────────────────────────────────┘
```

### 3.1 数据流

```
Agent执行任务
    ↓
SkillClaw记录会话轨迹（L1）
    ↓
Evolve Server判断：值得提炼？
    ↓ 是
生成候选Skill → Nacos Registry注册（L2）
    ↓
审核通过 → 灰度发布 → 全量
    ↓
MUSE监控性能（L3）
    ↓ 退化
SkillOpt重新训练 → 新版发布
```

### 3.2 安全治理

| 环节 | 安全措施 |
|------|---------|
| 产生 | 仅记录授权会话数据；敏感信息脱敏 |
| 注册 | 自动安全检查（代码注入/路径遍历/提权） |
| 审核 | 人工Review + 双人签字 |
| 分发 | 签名校验 + 沙箱预执行验证 |
| 进化 | Validation Gate防退化 + 有界编辑防失控 |
| 回滚 | 一键回退 + 自动通知受影响Agent |
