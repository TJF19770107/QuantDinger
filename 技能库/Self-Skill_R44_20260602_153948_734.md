## 一、Self-Skill 定义

Self-Skill 是 AI 分身专属的**自我进化技能包**，包含：
1. **专属技能协议**（Skills）：针对用户个人工作流定制的 Agent 技能
2. **MCP Server 配置**：让 Agent 能调用用户私有工具/数据/API
3. **Agent 能力扩展方案**：基于16平台情报持续迭代的能力矩阵

## 五、Self-Skill 使用说明

### 5.1 加载方式

在 OpenClaw 中加载 Self-Skill：
```
/load-skill E:\龙虾AI主控中心\我的AI分身\技能库\Self-Skill_R44.md
```

在 Hermes Agent 中加载：
```
@import E:\龙虾AI主控中心\我的AI分身\技能库\Self-Skill_R44.md
```

在豆包 Agent 中加载：
```
加载技能文件：E:\龙虾AI主控中心\我的AI分身\技能库\Self-Skill_R44.md
```

### 5.2 技能调用示例

**示例1：调用协议 #158 网文 AI 化分析**
```
用户：帮我分析番茄小说 2026 年 5 月 AI 治理政策对网文创作的影响
Agent：加载协议 #158 → 调用网文平台规则引擎 → 输出合规创作建议
```

**示例2：调用协议 #155 Skills 名人 IP 化**
```
用户：用 Karpathy 风格优化我的 Claude 行为配置
Agent：加载 andrej-karpathy-skills → 生成优化后的 CLAUDE.md
```

**示例3：调用协议 #159 数字分身社交化**
```
用户：帮我在小红书用 AI 分身发一篇关于 AI 写作的笔记
Agent：加载协议 #159 → 生成合规笔记内容 → 调用 social-agent MCP → 发布
```
