# 龙虾-移动端远程Agent操控协议 v1.0

> **版本**：v1.0
> **对标来源**：OpenAI Codex Mobile Remote（2026.5.14）
> **生效范围**：跨平台Agent操控
> **创建日期**：2026-06-01（R15）

---

## 一、核心定义

在Agent运行过程中，允许用户通过移动端设备远程安全地查看、审批和操控Agent的执行状态，包括在主机锁屏状态下继续操控。不是传统远程桌面，而是通过受信通道临时解锁目标应用/桌面，阻止本地用户操作。

## 二、关键机制

### 2.1 受信通道临时解锁流程

```
用户手机发起连接请求
    ↓
主机验证：检查是否来自活跃的受信会话
    ↓
临时解锁：仅对Agent操作的应用窗口解锁
    ↓
本地用户被阻止：屏幕保持锁定状态
    ↓
操作完成 → 自动恢复锁定
```

### 2.2 三不原则
- **不**解锁整个桌面（只解锁Agent操作的应用窗口）
- **不**允许其他应用或本地进程解锁电脑
- **不**影响屏幕锁定状态（本地用户看到的仍是锁屏）

### 2.3 Appshots自动截图
- Agent可自动捕获前台应用窗口画面
- 无需用户手动截图或复制
- 用于Agent感知当前UI状态，做语义定位

## 三、移动端能力矩阵

| 能力 | 描述 | 安全等级 |
|------|------|---------|
| 查看输出 | 实时查看Agent执行日志和结果 | 🟢 |
| 批准命令 | 对需要确认的操作进行远程审批 | 🟡 |
| 切换模型 | 在移动端切换Agent使用的模型 | 🟡 |
| 发起新任务 | 远程向主机Agent下发新任务 | 🟡 |
| 监控进度 | 查看长时程任务的执行进度 | 🟢 |
| 查看项目文件 | 访问主机的项目文件结构 | 🟢 |

## 四、安全约束

1. 连接必须经过端到端加密
2. 临时解锁窗口期极短（毫秒级验证窗口）
3. 超出窗口期自动拒绝解锁
4. 支付等最高敏感操作禁止远程执行
5. 所有远程操作记录审计日志

## 五、与现有协议关系

- 协议23（桌面Agent工作区隔离）：提供底层隔离基础
- 协议33（视觉桌面操控）：提供屏幕理解→元素定位能力
- 本协议在此基础上增加移动端远程安全接入层
