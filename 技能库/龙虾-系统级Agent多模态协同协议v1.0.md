## 一、协议背景

### 1.1 Marvis系统级Agent架构

腾讯于2026年5月20日正式推出操作系统层级AI助手Marvis，Windows/macOS/安卓三端同步上线：
- **6个专项Agent**：PM Agent(任务拆解)、File Agent(文件管理)、Computer Agent(系统设置)、Browser Agent(网页操作)、App Agent(应用操作)、Search Agent(联网搜索)
- **操作系统层级**：直接触达系统设置、文件管理、应用调用与硬件信息
- **跨Agent任务交接**：Agent间无缝协同，自动判断下一步由谁执行
- **Agent Workspace**：3D可视化虚拟办公室，实时监控各Agent工作状态
- **Token额度**：每日1000万免费Token

### 1.2 核心突破

| 能力 | 说明 |
|------|------|
| 端侧本地语义理解 | 语音落音到任务执行20秒内完成 |
| 跨Agent任务无缝交接 | App Agent权限不足→Computer Agent接管系统设置 |
| 锁屏跨设备操控 | 手机远程解锁电脑、操控桌面 |
| 从交互中即时学习 | 同任务6次迭代：30min→2min，越跑越快 |
| 跨模态任务链 | 理解需求→拆解任务→生成图片文案→发布内容 一条链路 |

## 二、6Agent协同架构

### 2.1 Agent角色分工

```
                    ┌──────────────┐
                    │  PM Agent    │
                    │  任务拆解     │
                    │  调度分发     │
                    └──┬──┬──┬──┬──┘
          ┌────────────┤  │  │  ├────────────┐
          ▼            ▼  │  ▼               ▼
   ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐
   │  File    │  │ Computer │  │ Browser  │  │  App     │
   │  Agent   │  │  Agent   │  │  Agent   │  │  Agent   │
   │ 文件管理 │  │ 系统设置 │  │ 网页操作 │  │ 应用操作 │
   └──────────┘  └──────────┘  └──────────┘  └──────────┘
          │            │              │              │
          └────────────┴──────────────┴──────────────┘
                              │
                              ▼
                    ┌──────────────────┐
                    │  Search Agent    │
                    │  联网搜索        │
                    └──────────────────┘
```

### 2.2 Agent能力矩阵

| Agent | 核心能力 | 典型任务 |
|-------|---------|---------|
| PM Agent | 意图理解、任务拆解、Agent调度、进度追踪 | 接收用户指令→拆分子任务→分派执行Agent |
| File Agent | 文件搜索/读取/创建/编辑/转换/整理 | PDF转换、合同审查、发票整理、数据汇总 |
| Computer Agent | 系统设置、硬件信息、进程管理、键鼠模拟 | 深色模式切换、壁纸更换、权限管理 |
| Browser Agent | 网页打开/导航/表单填写/数据抓取 | 网页搜索、表单提交、内容采集 |
| App Agent | 应用安装/卸载/启动/操作 | 安装软件、配置应用、自动化操作 |
| Search Agent | 联网搜索、信息检索、实时数据 | 最新资讯、实时价格、网络信息查询 |

### 2.3 跨Agent任务交接协议

```
┌─────────────────────────────────────────────────────┐
│              跨Agent任务交接流程                      │
├─────────────────────────────────────────────────────┤
│  1. 当前Agent检测到能力边界                          │
│  2. 判断需要哪种Agent能力                            │
│  3. 调用PM Agent请求调度                             │
│  4. PM Agent选择目标Agent并传递上下文                 │
│  5. 目标Agent继承：任务目标、当前状态、已完成步骤      │
│  6. 目标Agent执行并汇报结果                          │
│  7. 判断任务是否完成 → 是：汇总 / 否：继续交接        │
└─────────────────────────────────────────────────────┘
```

**实例**（Marvis实测场景）：
App Agent发现小红书不在自动化白名单 → 判断需系统层权限 → Computer Agent接管 → 打开系统设置→定位隐私与安全性→弹出权限界面 → 权限开启 → 交回App Agent继续

## 四、自主进化与即时学习

### 4.1 单会话内快速迭代

Marvis实测展示的模式：同任务6次迭代从30min→2min

| 机制 | 说明 |
|------|------|
| inherit_agent_id | Subagent继承完整对话历史 |
| 失败记忆 | 每次失败的模式被记录并避免 |
| 路径优化 | 成功的执行路径被缓存和优先选择 |
| 上下文复用 | 中间结果跨步骤共享 |

### 4.2 跨会话记忆沉淀

```
单次会话内：
  Subagent完整对话历史 → inherit_agent_id继承
  → 新任务基于所有尝试+结果+失败+纠正继续

跨会话：
  固定工作流 → memory_ids传递关键中间结果
  提取可复用的执行模式 → 封装为Skill
  → 存入技能库供后续调用
```
