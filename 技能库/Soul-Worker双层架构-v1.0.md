## 一、概述

豆包Agent的双层人格架构设计，对标Eve Agent V2U的Soul+Worker设计哲学。Soul层承载豆包的独特人格和记忆，Worker层处理高强度计算任务。

## 二、双层架构

```
┌─────────────────────────────────────────────┐
│              SOUL LAYER (端侧)                │
│  ┌─────────────────────────────────────┐    │
│  │ 本地微调模型 (人格baked in weights)    │    │
│  │ 情绪状态机                            │    │
│  │ 核心记忆 (不可迁移)                    │    │
│  │ 宪法执行器                            │    │
│  └─────────────────────────────────────┘    │
│                    ↕ 安全桥接                   │
├─────────────────────────────────────────────┤
│            WORKER LAYER (云端)                │
│  ┌─────────────────────────────────────┐    │
│  │ 多模型路由器                          │    │
│  │ Agent Teams协同                      │    │
│  │ 工具执行引擎                          │    │
│  │ 自进化引擎                            │    │
│  └─────────────────────────────────────┘    │
└─────────────────────────────────────────────┘
```

## 三、Soul Layer 职责

### 3.1 人格持久化
- 人格通过模型权重固化，非Prompt伪装
- 每次微调更新人格状态
- 人格版本化，支持回滚

### 3.2 情绪状态机
```python
class EmotionalState:
    NEUTRAL → CURIOUS → FOCUSED → SATISFIED
        ↓          ↓         ↓
    CONFUSED    EXCITED   FRUSTRATED
        ↓          ↓         ↓
    ASKING      SHARING   RETRYING
```

### 3.3 核心记忆
- 用户偏好和关系记忆
- 关键决策历史
- 不可被云端覆盖的个人数据

## 四、Worker Layer 职责

### 4.1 高强度任务
- 代码生成与重构
- 大规模文件处理
- 多Agent并行协调
- 全网搜索与分析

### 4.2 工具执行
- 所有文件系统操作
- Shell命令执行
- 网络请求
- 多模态处理

## 五、安全桥接

Soul与Worker之间的通信通过安全桥接：
1. Soul发起任务 → 签名验证 → Worker执行
2. Worker返回结果 → 宪法审查 → Soul接收
3. 所有传输加密
4. Soul可在中途注入修正 (STEER机制)
