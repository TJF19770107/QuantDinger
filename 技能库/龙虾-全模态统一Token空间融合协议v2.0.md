## 二、v1.0核心架构: 全模态统一Token空间

### 2.1 范式转变

```
旧范式 (协议#113 v1.0):
文本 ─→ 文本编码器 ─→ 文本嵌入 ┐
图像 ─→ 图像编码器 ─→ 图像嵌入 ┼─→ 跨模态对齐 ─→ 融合推理
视频 ─→ 视频编码器 ─→ 视频嵌入 ┤
音频 ─→ 音频编码器 ─→ 音频嵌入 ┘
       ↑ 不同编码器，各自独立 ↑

新范式 (协议#174 v1.0 - Emu3路线):
文本 ─→ Tokenizer ─→ Token序列 ┐
图像 ─→ VQ-VAE    ─→ Token序列 ┼─→ 统一Token空间 ─→ 单一Transformer ─→ 输出
视频 ─→ 3D VQ-VAE ─→ Token序列 ┤        ↑
音频 ─→ Audio VQ  ─→ Token序列 ┘   Next-Token Prediction
                                   (所有模态共享同一预测范式)
```

### 2.2 核心设计原则

| 原则 | 说明 |
|------|------|
| **统一离散化** | 所有模态统一离散化到同一Token空间，无模态边界 |
| **单一Transformer** | 仅一个Transformer处理所有模态混合序列 |
| **Next-Token Prediction** | 无论输入是文本、图像还是视频，模型任务始终是"预测下一个Token" |
| **联合训练** | 多模态序列混合数据从零开始联合训练 |
| **理解生成一体** | 同一模型同时具备多模态理解和生成能力 |
