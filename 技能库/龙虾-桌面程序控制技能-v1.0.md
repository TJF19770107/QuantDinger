## 二、安全等级制度

### 🔴 高风险（必须确认）
- 系统关键进程终止
- 注册表修改
- 服务启停
- 系统目录文件写入
- 格式化/清空操作

### 🟡 中风险（二次确认）
- 用户应用进程终止
- 非系统目录文件删除
- 窗口强制关闭
- 配置变更

### 🟢 低风险（直接执行）
- 窗口排列/切换
- 程序启动
- 信息查询
- 只读操作

## 五、命令接口

```bash
# 窗口管理
desktop window --maximize              # 最大化当前窗口
desktop window --snap-left             # 左半屏
desktop window --snap-right            # 右半屏
desktop window --list                  # 列出所有窗口

# 进程管理
desktop process --start "notepad"      # 启动程序
desktop process --list                 # 列出进程
desktop process --kill "notepad"       # 关闭程序（需确认）

# 桌面布局
desktop layout --grid 2x2              # 2x2网格排列
desktop layout --restore               # 恢复默认布局
```
