## 协议 #61：Pullfrog式GitHub Actions Agent协议 v1.0

### 来源
Pullfrog (Colin McDonnell / Zod作者) · InfoQ · 2026-05-31

### 核心机制

```
触发层：webhook监听（PR/issue/CI失败/review提交）
调度层：GitHub Actions内异步执行，自带MCP server
执行层：隔离子进程运行shell命令，无法访问敏感环境变量
输出层：PR review评论 / issue分流 / CI自动修复 / 计划生成
```

### 四大组件

| 组件 | 说明 |
|------|------|
| GitHub App | 安装到仓库，监听webhook事件 |
| pullfrog.yml workflow | 在仓库Actions中执行Agent |
| MCP Server | 专用git/GitHub操作接口 |
| 无头浏览器 | 端到端测试/截图/UI迭代 |

### BYOK模型无关性

| 提供商 | 模型 | 用途 |
|--------|------|------|
| Anthropic | Claude Opus 4.8 | 复杂推理 |
| OpenAI | Codex | 代码生成 |
| Google | Gemini | 多模态 |
| Mistral | Mistral Large | 轻量级 |
| DeepSeek | DeepSeek V4 | 低成本 |
| OpenRouter | 任意 | 实验性 |

### 安全三层防御

1. **GitHub Secrets**：所有API Key通过secrets管理
2. **隔离子进程**：Shell命令无法访问敏感环境变量
3. **Actions沙箱**：运行在GitHub Actions的受限环境

### 豆包Agent集成方案

```
豆包Agent定时任务
    ├── 监听本地Git仓库webhook → 触发Agent
    ├── MCP集成：复用Pullfrog的MCP server设计
    └── BYOK模式：支持Claude/GPT/Gemini/DeepSeek任意模型
```

### 安全评估
✅ 隔离执行 | ✅ 密钥管理 | ✅ 沙箱约束

## 协议 #62：小红书Red Skill内容创作协议 v1.0

### 来源
小红书开源 · REDSearcher + FireRed三件套 · 2026-04

### 核心机制

```
REDSearcher（搜索Agent）
    ├── 30B参数，域内超越Gemini-2.5-pro
    ├── 针对小红书内容生态端到端微调
    └── 开源协议下可本地部署

FireRed-Image-Edit（图像编辑）
    ├── 多模态图像编辑模型
    ├── 指令式编辑："把背景换成日落"
    └── 批量产出小红书风格封面图

FireRed-OpenStoryline（视频创作）
    ├── 脚本→分镜→剪辑全流程Agent
    ├── 生成符合小红书算法偏好的短视频
    └── 非线性编辑+对话驱动
```

### 创作流水线

```
选题分析(REDSearcher) → 封面生成(FireRed-Image-Edit)
    → 视频创作(FireRed-OpenStoryline) → 发布运营
```

### 豆包Agent集成方案

1. 内容平台Agent生态协议（#60）升级：新增小红书Red Skill对接
2. 支持本地部署REDSearcher（开源协议下）
3. 对接FireRed-OpenStoryline API生成视频脚本
4. 新增产出卡片类型：`yyb-red-content`（小红书内容产出物声明）

## 协议 #64：MCP 1.0 统一注册表对接协议 v1.0

### 来源
MCP 1.0正式版 · Linux Foundation · 2026-04

### 核心机制

```
统一注册表
    ├── MCP server集中注册、版本管理
    ├── 安全审计（对照Skills安全危机13.4%漏洞率）
    └── 策展注册表可将漏洞率降至0%

会话恢复
    ├── Agent崩溃后从检查点恢复
    └── 不丢失上下文（关键对长时间运行Agent）

MCP Apps
    ├── 工具调用返回交互式UI
    └── Windows 11原生集成
```

### MCP 1.0 vs MCP 0.x

| 维度 | MCP 0.x | MCP 1.0 |
|------|---------|---------|
| 标准化 | 社区规范 | 行业标准 (LF托管) |
| 注册表 | 分散 | 统一注册表 |
| 会话恢复 | 不支持 | 支持 |
| 安全审计 | 无 | 内置 |
| 治理 | 无 | 多方共治 (Google/Amazon/Cursor) |
| Windows集成 | 无 | Windows 11原生 |

### 豆包Agent集成方案

1. 技能库所有外部工具调用统一走MCP 1.0协议
2. 安全层增加MCP server安全扫描模块
3. Windows 11原生MCP Apps使用户可通过UI交互控制Agent
4. 会话恢复：长时间蒸馏任务断点恢复

### 安全评估
✅ LF托管 | ✅ 统一注册表 | ✅ 安全审计 | ⚠️ 策展注册表需自建
