## 一、协议概述

本协议提取自Hermes Agent将Python框架启动时间从701ms降至258ms（降幅63%）的三刀优化法，使Python Agent在框架开销层面追平甚至超越Rust实现。核心方法论：**profiling驱动 → 逐刀切冗余 → 基准验证 → 不达标回滚**。

---

## 二、三刀优化法

### 第一刀：L2磁盘缓存（最大收益）

**原理**：将进程内缓存升级为进程间持久化磁盘缓存，消除重复API调用。

**实施步骤**：
1. 识别启动热路径中的外部API调用（如凭据拉取、配置远程获取）
2. 引入L2磁盘缓存层：文件权限锁死0600，存放于`<home>/cache/`
3. 设置合理TTL（默认300s），过期才重新拉取
4. 敏感Token绝不落盘，仅缓存非敏感派生数据
5. 验证：连续两次冷启动，第二次应命中缓存

**Hermes案例**：Bitwarden Secrets Manager API调用380ms→0ms（命中缓存）

### 第二刀：模块懒加载

**原理**：将模块级急切导入改为按需延迟加载，减少导入时开销。

**实施步骤**：
1. 使用cProfile定位导入阶段耗时模块
2. 识别仅在特定函数中使用的重量级字典/数据
3. 使用PEP 562 `__getattr__` 实现模块级懒加载
4. 仅在首次访问时付出加载开销
5. 验证：不访问该模块时导入耗时归零

**Hermes案例**：`_PROVIDER_MODELS`巨型字典懒加载，节省55ms

### 第三刀：配置去重合并

**原理**：审计所有重复IO/解析操作，合并为单次加载。

**实施步骤**：
1. 审计启动路径中所有文件读取和YAML/JSON解析
2. 识别对同一文件的多次读取
3. 合并为一次原始加载，结果在内存中复用
4. 验证：文件读取次数精确减少

**Hermes案例**：`main.py`顶部两次`yaml.safe_load`合并为一次，节省17ms

## 三、Profiling驱动优化循环

```
1. cProfile/py-spy 采集火焰图
       ↓
2. 定位热路径TOP3瓶颈
       ↓
3. 逐刀实施优化（一刀一提交）
       ↓
4. 运行基准测试套件验证
       ↓
5. 达标→合入 / 不达标→回滚重分析
```

**基准测试要求**：
- 至少5次冷启动取中位数
- 对比优化前后框架开销（不含LLM调用延迟）
- 单轮任务 + 多轮任务双维度评估

---

## 四、适用场景

- Python Agent框架启动优化
- CLI工具冷启动加速
- 多进程/多实例共享缓存场景
- 任何需要降低框架开销的Agent系统

## 五、关键约束

- L2缓存不得存储明文凭据
- 懒加载不得破坏模块公共接口
- 每次优化必须可独立回滚
- 优化后必须通过完整回归测试
