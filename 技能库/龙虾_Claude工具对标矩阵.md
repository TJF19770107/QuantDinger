## 一、Claude Code 五层架构

```
Layer 1: Model (LLM)
  └─ 决策层：理解意图、推理、决定调用什么
     输出格式: text + tool_use blocks

Layer 2: Claude Code Harness (CLI)
  └─ 编排层：收发API、权限控制、执行调度、状态管理

Layer 3: Built-in Tools (25个)
  └─ 原生能力：文件操作、搜索、Shell、子代理、Skill工具

Layer 4: Skills (8个)
  └─ 本质：动态注入的提示词包
     加载专业指令、上下文，可能注册额外工具

Layer 5: MCP Servers (外部进程)
  └─ 提供额外工具，通过 stdio/HTTP 通信
```

## 二、核心理念

> **Model 眼中只有 "Tools"**

无论是 Bash、Skill、还是 MCP 工具，对 Model 来说都是扁平的 function call。
Model 不知道也不关心这些工具是谁提供的——它只看到一个工具列表(JSON Schema)，选择调用哪个，然后 Harness 负责路由到正确的实现。
