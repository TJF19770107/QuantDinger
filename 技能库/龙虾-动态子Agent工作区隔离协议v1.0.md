# 龙虾-动态子Agent工作区隔离协议 v1.0

> **对标来源**：Google Antigravity 2.0 动态子Agent + Claude Code v2.1 并行子Agent
> **版本**：v1.0 | **创建日期**：2026-06-01 | **所属迭代**：R19
> **核心价值**：主Agent动态派生隔离子Agent，不污染上下文窗口，支持并行执行

---

## 一、协议概述

主Agent接收到复杂任务后，自动拆解为子任务并"克隆"出独立子Agent。每个子Agent拥有隔离的工作区、独立上下文窗口，可并行执行。主Agent作为"技术总监"负责协调、汇总和异常处理。

---

## 二、架构对比

| 特性 | Antigravity 2.0 | Claude Code v2.1 | 本协议目标 |
|------|----------------|-----------------|-----------|
| 最大并行子Agent | 93（I/O演示） | 7（隔离容器） | 动态自适应 |
| 工作区隔离 | 继承父配置+权限 | 独立容器 | 沙箱级隔离 |
| 上下文隔离 | 不污染主Agent | 不污染主Agent | 完全隔离 |
| 通信方式 | 主Agent协调 | 消息传递 | 结果回传 |
| 模型分配 | 统一Gemini 3.5 Flash | 统一模型 | 按需分配 |

---

## 三、子Agent生命周期

```
任务接收 → 自动拆解 → 派生子Agent → 并行执行 → 结果汇总 → 销毁
   │                      │
   ▼                      ▼
[主Agent]          [子A: 前端] [子B: 后端] [子C: 测试]
   协调              隔离上下文      隔离上下文      隔离上下文
```

---

## 四、隔离策略

| 层级 | 策略 | 说明 |
|------|------|------|
| 文件系统 | 独立临时工作区 | 每子Agent独立目录，互不可见 |
| 上下文 | 独立Token窗口 | 不与主Agent共享上下文 |
| 权限 | 继承父级+可收缩 | 子Agent权限 ≤ 主Agent权限 |
| 执行 | 异步/并行 | 互不阻塞，主Agent可继续工作 |
| 错误 | 独立失败不传播 | -89%错误传播率（Claude Code实测） |

---

## 五、加速效果

| 场景 | 串行耗时 | 并行耗时 | 加速比 |
|------|---------|---------|--------|
| HumanEval基准（Claude Code） | 28.3s | 4.7s | **6.0x** |
| 前端+后端+测试（Antigravity） | ~12h | ~4h | **3.0x** |
| 93子Agent构建OS（Antigravity I/O） | N/A | <12h | N/A |

---

## 六、禁止行为

- ❌ 子Agent修改父Agent工作区
- ❌ 子Agent间直接通信（必须经主Agent）
- ❌ 子Agent访问系统核心路径
- ❌ 无限派生子Agent（最大限制：12个）
