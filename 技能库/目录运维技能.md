## 概述
目录运维技能负责AI分身全部目录的自检、新建、文件去重、运维日志生成，确保目录结构始终完整可用。

## 四项子技能

### 1. 目录自检（Directory Check）
- 读取角色总说明书中定义的完整目录清单
- 逐项检查目录是否存在
- 缺失目录自动创建
- 挂载目录检测junction有效性，断开则触发ECC修正
- 输出：目录健康状态表

### 2. 目录新建（Directory Init）
- 按说明书标准创建缺失目录
- 设置正确的目录权限
- 新建目录记录写入运维日志
- 输出：新建目录清单

### 3. MD5文件去重（MD5 Dedup）
- 遍历指定目录下所有文件
- 计算MD5哈希值
- 相同哈希的文件标记为重复
- 保留最新版本，旧版本移至备份
- 输出：去重报告（重复文件列表、释放空间）

### 4. 运维日志生成（Ops Logging）
- 汇总本次运维操作全部结果
- 按时间戳命名日志文件
- 自动归档至知识库
- 输出：运维日志文件路径

## 调用示例
```
触发：目录运维 自检
触发：目录运维 去重 [目标目录]
触发：目录运维 全量巡检
```
