# 龙虾-端侧Agent离线自治协议 v1.0

> 协议编号: #116 | 版本: v1.0 | 创建日期: 2026-06-01
> 对标来源: Codex Locked CU + Llama 4本地推理 + OpenCode桌面Beta + TRAE SOLO离线模式
> 生效范围: 龙虾AI体系所有端侧Agent

---

## 一、协议概述

端侧Agent离线自治协议定义了Agent在**网络断开或不可靠环境**下的完整自主运行能力。通过本地模型推理替代云端API、任务队列持久化、离线状态缓存和恢复联网后的自动同步，确保Agent在任何网络条件下都能维持核心功能。

---

## 二、离线运行架构

### 2.1 三层离线栈

```
┌──────────────────────────────────────┐
│         L3: 本地推理层（Inference）    │
│   Llama 4 1.2T MoE / Qwen3 / GLM-5   │
│   本地模型路由 + 云端降级代理          │
├──────────────────────────────────────┤
│         L2: 任务管理层（Task Queue）   │
│   离线任务队列 + 优先级排序            │
│   断点续传 + 幂等执行                  │
├──────────────────────────────────────┤
│         L1: 状态持久层（Persistence）  │
│   本地SQLite/文件系统                  │
│   配置缓存 + 知识库镜像 + 记忆副本     │
└──────────────────────────────────────┘
```

### 2.2 离线模式切换

```
联网状态检测（每30s心跳）
    │
    ├─ 在线 → 正常模式（云端推理 + 实时同步）
    │
    └─ 离线 → 切换本地推理引擎
              ├── 加载本地模型（Llama 4 / Qwen3）
              ├── 激活离线任务队列
              ├── 使用本地知识库镜像
              └── 标记"离线模式运行中"
                    │
                    └─ 恢复联网 → 自动同步
                          ├── 上传离线日志
                          ├── 合并任务结果
                          ├── 更新知识库
                          └── 切换回云端推理
```

## 三、本地推理引擎

### 3.1 模型选择策略

| 任务类型 | 在线模型 | 离线模型 | 降级策略 |
|---------|---------|---------|---------|
| 复杂推理/规划 | Claude Opus 4 | Llama 4 1.2T MoE | 质量降低但可用 |
| 代码生成 | Claude Sonnet 4 | Qwen3-Coder | 复杂任务简化 |
| 文件分析 | Claude Sonnet 4 | Llama 4 | 长文档分段处理 |
| 系统操作 | Claude Haiku | Qwen3-7B | 轻量任务无影响 |
| 简单判断 | 本地模型 | 本地模型 | 无影响 |

### 3.2 本地模型资源管理

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| GPU显存 | ≥16GB（Llama 4 1.2T MoE INT4） | 当前环境需检测 |
| 模型缓存 | 本地SSD，≥50GB | 预下载常用模型 |
| 并发推理 | 2路 | 平衡质量和速度 |
| 上下文长度 | 32K（动态扩展） | 长任务分段处理 |

### 3.3 推理质量保障

```
离线推理结果
    ↓
自评分（Confidence Score）
    ↓
├── ≥0.85 → 直接使用
├── 0.7-0.85 → 标记"低置信度"，联网后复核
└── <0.7 → 降级处理（简化任务/暂存待联网）
```

## 四、离线任务队列

### 4.1 任务持久化格式

```json
{
  "task_id": "offline_20260601_001",
  "type": "file_organize|search|report|system_op",
  "status": "pending|running|completed|failed",
  "priority": "P0|P1|P2",
  "payload": {
    "instruction": "整理桌面文件按类型归类",
    "params": {"source": "Desktop", "rule": "by_type"}
  },
  "checkpoint": {
    "progress": 0.65,
    "last_completed_step": "classify_images"
  },
  "created_at": "2026-06-01T14:00:00Z",
  "timeout": 3600,
  "retry_count": 0,
  "max_retries": 3
}
```

### 4.2 优先级调度

| 优先级 | 场景 | 抢占策略 |
|--------|------|---------|
| P0 | 安全相关操作、用户紧急指令 | 可抢占P1/P2 |
| P1 | 定时任务、系统维护 | 不可抢占 |
| P2 | 批处理、非紧急任务 | 空闲时执行 |

### 4.3 断点续传

```
任务执行中...
    ↓ 网络断开/系统中断
保存Checkpoint（已完成的子步骤 + 中间结果）
    ↓ 恢复（联网或重启）
读取Checkpoint → 跳过已完成步骤 → 从断点继续
```

## 五、离线数据管理

### 5.1 本地缓存结构

```
E:\龙虾AI主控中心\offline_cache\
├── models/              # 本地模型文件
├── knowledge/           # 知识库镜像
│   ├── SOUL.md.bak
│   ├── USER.md.bak
│   └── AGENTS.md.bak
├── tasks/               # 离线任务队列
├── logs/                # 离线运行日志
└── sync/                # 待同步数据
    ├── results/         # 待上传任务结果
    ├── memories/        # 待合并记忆
    └── metrics/         # 待上报指标
```

### 5.2 同步冲突解决

```
本地修改 + 远程修改 → 检测冲突
    ├── 配置文件 → 本地优先（离线操作意图明确）
    ├── 任务结果 → 合并（去重+按时间排序）
    ├── 记忆条目 → 双方保留（标记冲突待审核）
    └── 指标数据 → 累加（离线+在线汇总）
```

## 六、安全与隐私

### 6.1 离线安全约束

| 约束 | 说明 |
|------|------|
| 高风险操作熔断 | 离线模式下禁止删除系统文件/格式化/重置 |
| 本地推理沙箱 | 模型推理结果不影响云端配置 |
| 凭据不落地 | 敏感凭据不缓存到本地，联网后重新获取 |
| 审计日志 | 所有离线操作完整记录，联网后上传 |

### 6.2 离线降级规则

```
在线可用操作 → 离线降级
─────────────────────────
网络搜索 → 使用本地知识库（降级）
云端API调用 → 排队等待联网（延迟）
OAuth登录 → 暂不可用（提示用户）
文件操作 → 完全可用（无影响）
系统设置 → 完全可用（无影响）
代码执行 → 可用（本地Python/Shell）
```

## 七、监控指标

| 指标 | 目标 | 说明 |
|------|------|------|
| 离线可用率 | >95% | 离线模式下核心功能可用占比 |
| 断网切换时间 | <5s | 从检测断网到切换本地推理 |
| 联网恢复时间 | <10s | 从恢复联网到完成同步 |
| 离线任务完成率 | >90% | 离线队列中任务成功完成占比 |
| 同步冲突率 | <3% | 联网恢复后产生冲突的比例 |
| 本地推理质量 | >80% | 离线推理结果置信度≥0.7的占比 |
