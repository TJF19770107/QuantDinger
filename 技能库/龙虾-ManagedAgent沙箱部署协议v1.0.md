## 一、核心原理

Google将Agent运行时直接内置到Gemini API中：开发者只需编写AGENTS.md + SKILL.md，Google自动创建隔离Linux环境，执行完成后销毁。本协议将这一模式适配到龙虾生态，实现Agent的"临时隔离部署"范式。

**核心突破**：Agent部署不再需要手动配置服务器、管理依赖、设置安全边界——一切都由运行时自动管理。

## 二、核心架构

### 2.1 三文件定义

```
agent_project/
├── AGENTS.md        # Agent定义文件（系统提示词+工具列表+安全边界）
├── SKILL.md         # 技能定义文件（执行步骤+预期输出+错误处理）
└── .agent-config.json  # Agent配置（超时/重试/资源限制）
```

### 2.2 AGENTS.md 标准格式

```markdown
# Agent: {name}
## System Prompt
{系统提示词}

## Tools
- tool_1: {描述}
- tool_2: {描述}

## Security Boundary
- allow_read: ["{路径1}", "{路径2}"]
- allow_write: ["{路径1}", "{路径2}"]
- allow_execute: ["{命令1}", "{命令2}"]
- deny: ["{禁止操作1}", "{禁止操作2}"]

## Runtime Config
- timeout: 300s
- max_memory: 512MB
- max_disk: 1GB
```

### 2.3 SKILL.md 标准格式

```markdown
# Skill: {name}
## Version
1.0.0

## Preconditions
- {前置条件1}
- {前置条件2}

## Steps
1. {步骤1描述}
2. {步骤2描述}
3. {步骤3描述}

## Expected Output
{预期输出格式}

## Error Handling
- 错误类型A: {处理方式}
- 错误类型B: {处理方式}

## Cleanup
- {清理动作}
```

## 三、执行流程

### 阶段1：准备
1. 读取AGENTS.md + SKILL.md
2. 验证安全边界（路径白名单/命令白名单在配置范围内）
3. 验证版本号（检查SKILL.md版本是否与.metadata.json一致）
4. 创建隔离工作区（临时目录，推理完毕销毁）

### 阶段2：隔离环境初始化
1. 创建临时Linux容器（或本地进程隔离）
2. 安装SKILL.md声明的依赖
3. 挂载允许读取的目录（只读）
4. 创建允许写入的目录（隔离）
5. 设置资源限制（timeout/memory/disk）

### 阶段3：任务执行
1. 按SKILL.md步骤顺序执行
2. 推理 + 工具调用 + 代码执行 + 文件管理 + 网页浏览全集成
3. 实时日志输出到主Agent

### 阶段4：清理
1. 收集执行结果（输出文件/日志/错误信息）
2. 将结果复制到主Agent工作区
3. 销毁隔离环境（删除临时目录/释放容器资源）

## 四、集成方式（接入龙虾五步法）

### Step 1：意图识别
- 用户发出任务 → AI判断是否需要隔离执行
- 触发条件：涉及第三方代码执行/敏感文件操作/长时间任务/需要回滚保证

### Step 2：能力映射
- 生成AGENTS.md（基于豆包Agent当前配置）
- 生成SKILL.md（基于任务需求分解为步骤）

### Step 3：方案规划
- 确定隔离策略：进程级（快速） / 容器级（安全） / VM级（最高安全）
- 确定资源限制（timeout/memory/disk）
- 确定文件访问白名单

### Step 4：自主执行
- 创建隔离环境→执行→收集结果→销毁

### Step 5：反思进化
- 执行结果写入.memory.md
- 如执行失败→标记SKILL.md需要修复→触发MUSE五阶段（协议73）

## 五、安全约束

1. **路径白名单**：AGENTS.md必须声明所有允许读写的路径
2. **命令白名单**：AGENTS.md必须声明所有允许执行的命令
3. **网络策略**：默认禁止外网访问（除非SKILL.md声明需要）
4. **资源限制**：每个Agent必须设置timeout/memory/disk上限
5. **审计日志**：所有文件读写/命令执行/网络请求记录到审计日志
6. **环境销毁**：执行完毕必须立即销毁（不留残留文件）

## 六、预期效果

| 指标 | 传统部署 | Managed Agent |
|------|---------|--------------|
| 部署时间 | 数小时（配置环境） | 数秒（自动创建隔离环境） |
| 安全风险 | 中（手动配置易出错） | 低（自动强制白名单） |
| 可复现性 | 低（环境差异） | 高（AGENTS.md版本化） |
| 资源管理 | 手动（清理不及时） | 自动（用完即销毁） |
| 回滚能力 | 手动 | 自动（环境销毁=完整回滚） |
