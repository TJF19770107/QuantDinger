## 一、三层记忆架构

```
┌────────────────────────────────────────────┐
│  L1 短期记忆 (Short-Term Memory)            │
│  ├ 存储: LLM 上下文窗口（当前会话）          │
│  ├ 内容: 当前消息历史 / 推理中间态 / 临时变量 │
│  ├ 生命周期: 单次会话                        │
│  └ 管理: 上下文窗口自动管理                   │
├────────────────────────────────────────────┤
│  L2 工作记忆 (Working Memory)               │
│  ├ 存储: memory/working/ 目录                │
│  ├ 内容: 会话摘要 / 近期关键决策 / 偏好快照   │
│  ├ 生命周期: 跨多轮会话，自动过期             │
│  └ 管理: 自动摘要 + 定时清理                  │
├────────────────────────────────────────────┤
│  L3 长期记忆 (Long-Term Memory)              │
│  ├ 存储: memory/longterm/ 目录               │
│  ├ 内容: 用户偏好 / 经验技能 / 知识图谱       │
│  ├ 生命周期: 永久保留                         │
│  └ 管理: 结构化索引 + 语义检索                │
└────────────────────────────────────────────┘
```

## 二、记忆生命周期

### 2.1 Record（记录）
```
对话结束 →
  提取关键事实/偏好/决策 →
    分类（偏好/事实/经验/技能） →
      写入对应记忆层 →
        更新索引
```

### 2.2 Retrieve（检索）
```
新会话开始 →
  加载用户偏好（L3） →
    加载近期摘要（L2） →
      加载技能索引（L3） →
        按需语义检索补充 →
          注入上下文
```

### 2.3 Compress（压缩）
```
定时触发（每8小时） →
  检查 L2 工作记忆大小 →
    超过阈值 → LLM 摘要压缩 →
      旧摘要 → L3 长期记忆 →
        清理 L2 过期条目
```

### 2.4 DreamBackup（做梦）
对标 Claude Dreaming 机制：
```
空闲时自动 →
  回顾历史迭代报告 →
    提取行为模式 →
      发现可优化点 →
        写入 DreamLog →
          下次唤醒时参考
```

## 四、记忆安全

- L3 长期记忆写入前触发 SafeGuard checkpoint
- 记忆文件不可被外部直接修改
- 自动备份：每24小时备份一次 L3 到 checkpoints/
- 过期机制：L2 超过48小时未访问自动过期

## 五、命令接口

```bash
# 记忆状态
memory status                    # 查看三层记忆占用统计

# 手动操作
memory compress                  # 强制压缩 L2 → L3
memory dream                     # 启动做梦模式
memory backup                    # 手动备份 L3
memory restore --checkpoint <id> # 从检查点恢复

# 检索
memory search "keyword"          # 全文搜索记忆
memory recall --type preference  # 调取偏好
memory recall --type experience  # 调取经验
```
