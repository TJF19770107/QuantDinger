# 模型路由器-ModelRouter v1.0

**对标来源**: OpenCode (75+模型) + Gemini Flash (性价比)  
**创建日期**: 2026-05-31  
**类别**: 基础设施  
**优先级**: P1  
**关联技能**: VarCall, GStack

---

## 一、概述

豆包Agent的智能模型路由系统，支持多模型热切换，根据任务类型自动选择最优模型组合。

## 二、模型池

### 2.1 云端模型

| 模型 | 提供方 | 优势 | 适用场景 |
|------|-------|------|---------|
| DeepSeek V4 | DeepSeek | 编码最强 | 代码生成/调试/重构 |
| 混元Hunyuan3 | 腾讯 | 深度推理 | 复杂逻辑/架构设计 |
| Gemini 3.5 Flash | Google | 多模态+性价比(1/100 GPT-5成本) | 图像理解/PDF分析/轻量任务 |
| Claude Opus 4.5 | Anthropic | 长文本理解 | 大型代码库分析/文档处理 |
| GPT-5.4 | OpenAI | 强推理+1M上下文 | 超大项目理解 |

### 2.2 本地模型 (隐私模式)

| 模型 | 大小 | 显存需求 | 适用场景 |
|------|-----|---------|---------|
| Qwen2.5 7B | 7B | 4-5GB | 日常对话/轻量任务 |
| CodeLlama 7B | 7B | 4-5GB | 本地编码 |
| Mistral 7B | 7B | 4-5GB | 通用推理 |

## 三、路由策略

```
用户输入
    │
    ├── 含代码/编程关键词 → DeepSeek V4
    │   (写代码/修复bug/重构/调试/实现)
    │
    ├── 含图片/视频/音频 → Gemini 3.5 Flash
    │   (看图/分析截图/OCR/视频理解)
    │
    ├── 含深度推理/架构设计 → 混元Hunyuan3
    │   (设计系统/分析架构/复杂决策)
    │
    ├── 含大文件/长文本 → Claude Opus 4.5
    │   (分析整个代码库/长文档处理)
    │
    ├── 隐私模式 → Qwen2.5 7B (本地)
    │   (离线/敏感数据/端侧推理)
    │
    └── 简单对话 → Gemini 3.5 Flash (性价比)
        (闲聊/简单问答/日常任务)
```

## 四、Fallback机制

| 场景 | 策略 |
|------|------|
| 主模型不可用 | 自动切换备用模型 |
| 本地模型超时 | 切换云端轻量模型 |
| Token配额耗尽 | 切换更小/更便宜的模型 |
| 推理失败3次 | 切换更强模型重试 |

## 五、成本优化

- 任务分类路由：重任务用强模型，轻任务用便宜模型
- Token预算管理：每会话设定预算上限
- 本地优先：能本地处理的不上云
- Gemini Flash兜底：1/100成本作为默认轻量模型
