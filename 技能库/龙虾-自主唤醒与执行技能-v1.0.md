## 一、核心能力

### 1.1 定时自主唤醒
```
┌──────────────────────────────────────────────┐
│  主循环: 每4小时自动触发                       │
│  │                                             │
│  ├── 唤醒 → 任务队列检查 → 优先级排序            │
│  ├── AutoFileScanner 目录扫描                  │
│  ├── MemoryOS 记忆加载                         │
│  ├── SkillForge 技能锻造（如有新迭代报告）       │
│  ├── SafeGuard 安全检查                        │
│  └── 写入执行日志 → 休眠等待下次唤醒            │
└──────────────────────────────────────────────┘
```

### 1.2 任务优先级调度

| 优先级 | 任务类型 | 示例 |
|--------|----------|------|
| P0 | 阻塞核心能力 | GAP修补、安全漏洞修复 |
| P1 | 关键迭代任务 | 技能锻造、情报采集、架构升级 |
| P2 | 常规维护 | 目录扫描、健康检查、记忆压缩 |
| P3 | 后台任务 | 日志归档、索引优化 |

### 1.3 自主决策规则

```
IF 任务队列非空:
    按优先级排序 → 顺序执行
ELSE:
    启动默认巡检流程（扫描+健康+记忆压缩）

IF 执行异常:
    记录错误 → SafeGuard 介入 → 决定重试/跳过/回滚

IF 连续3次失败:
    标记任务为 blocked → 写入报告 → 等待人工介入
```

### 1.4 静默运行模式
- 不弹窗、不打断用户当前操作
- 所有输出写入日志文件
- 仅在完成全部任务后输出结构化摘要
- 异常情况通过 ask_user 优雅通知
