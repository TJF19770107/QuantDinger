## 一、协议定位

本协议将豆包Agent的交易策略维度从粗粒度量价分析升级到Tick级微观市场结构分析，补齐L2逐笔订单流分析能力。对标业界最前沿的高频知情交易因子方法论，实现主力行为动态监测、订单流Alpha提取、跨市场实时套利监控的端到端闭环。

## 二、核心数据模型

### 2.1 Tick数据三层结构

```
Layer 1: 逐笔成交 (Tick Trade)
├── trade_time      # 成交时间（毫秒精度）
├── price           # 成交价格
├── volume          # 成交量（手）
├── amount          # 成交额
├── tx_dir          # 成交方向：1=买方驱动(B) / 2=卖方驱动(S) / 0=未知
├── trade_index     # 成交序号
└── ask_order_id / bid_order_id  # 对应委托单号

Layer 2: 逐笔委托 (Tick Order)
├── order_time      # 委托时间
├── price           # 委托价格
├── volume          # 委托量
├── order_type      # 委托类型：1=市价 / 2=限价
├── side            # 委托方向：1=买 / 2=卖
├── order_status    # 状态：0=全部成交/1=部分成交/2=未成交/4=撤单
└── order_id        # 委托编号

Layer 3: 十档盘口 (Level-2 Quote)
├── ask_price[1..10] / ask_volume[1..10]   # 卖1-10档
├── bid_price[1..10] / bid_volume[1..10]   # 买1-10档
├── total_ask_volume / total_bid_volume
└── weighted_avg_ask / weighted_avg_bid
```

### 2.2 数据接入方案

| 来源 | 类型 | 延迟 | 覆盖范围 | 接入难度 |
|------|------|------|---------|---------|
| QMT/MiniQMT | 免费券商端 | 实时 | A股全市场 | 低 |
| Tushare Pro | 付费API | 实时/历史 | A股+指数 | 中 |
| 同花顺iFinD | 付费终端 | 实时 | A股+期货 | 中 |
| 东方财富L2 | 免费/付费 | 3s延迟 | A股 | 低 |
| 迅投XtQuant | 免费券商端 | 实时 | A股 | 低 |

**推荐接入路径**：QMT（实时）+ Tushare Pro（历史回测）

## 三、六大核心因子体系

### 3.1 资金流因子族

| 因子 | 公式 | 含义 | IC均值 | 对标来源 |
|------|------|------|--------|---------|
| VPIN_vol | (主动买量-主动卖量) / 总成交量 | 成交量不平衡度 | ~10.05% | 广发金工 |
| VPIN_amt | (主动买额-主动卖额) / 总成交额 | 成交额不平衡度 | ~9.2% | 广发金工 |
| VPIN_cnt | (主动买笔数-主动卖笔数) / 总成交笔数 | 交易笔数不平衡度 | ~8.5% | 广发金工 |
| NetFlow_Ratio | 大单净流入 / 流通市值 | 大资金参与度 | ~8.8% | 自定义 |
| SmartMoney_Index | Σ(大单成交价×量) / Σ(小单成交价×量) | 聪明钱方向 | ~7.5% | 学术文献 |

### 3.2 订单流微观结构因子族

| 因子 | 公式/定义 | 含义 | IC均值 | 对标来源 |
|------|----------|------|--------|---------|
| DPIN_Base | 知情交易概率动态估计 | 内幕信息含量 | ~8.0% | DPIN模型 |
| OrderImbalance | (买委托量-卖委托量) / (买委托量+卖委托量) | 委托不平衡 | ~7.2% | 学术文献 |
| Cancel_Rate | 撤单量 / 总委托量 | 虚假挂单检测 | ~6.5% | 自定义 |
| LargeOrder_Ratio | 大单（前10%分位）占比 | 机构参与度 | ~9.1% | 北大/国信 |
| Duration_Long | 漫长订单（超阈值时长）占比 | 投资耐心度 | ~7.8% | 国信证券 |

### 3.3 盘口深度因子族

| 因子 | 公式 | 含义 | IC均值 |
|------|------|------|--------|
| Spread | (卖一-买一) / 中间价 | 流动性宽度 | ~5.5% |
| Depth_Imb | (买一至五量-卖一至五量) / (总量) | 盘口深度偏向 | ~6.8% |
| Slope | 盘口挂单量随价格的变化率 | 支撑/阻力强度 | ~5.2% |
| Iceberg_Detect | 深档位隐藏大单检测 | 冰山订单概率 | ~6.0% |

### 3.4 主力行为因子族

| 因子 | 检测模式 | 含义 |
|------|---------|------|
| 主力建仓 | 连续大单买方成交+卖单被快速吃掉+挂单减少 | 机构建仓信号 |
| 主力出货 | 连续大单卖方成交+买单被快速砸穿+委托堆积 | 机构出货信号 |
| 虚假突破 | 价格突破前高但多笔小单推动+大单卖盘未撤 | 诱多陷阱 |
| 试盘行为 | 小单测上方抛压→大单未跟随→价格回落 | 主力试探 |
| 对倒拉升 | 同一ID买卖配对+价格快速上行+量异常放大 | 庄股坐庄 |

### 3.5 跨市场因子族

| 因子 | 数据源 | 应用场景 |
|------|--------|---------|
| AH溢价率 | A股+H股实时价差 | 跨市场套利信号 |
| 期现基差 | 期货-现货价格差 | 套利/对冲时机 |
| 板块资金轮动 | 行业ETF资金流向 | 风格切换信号 |
| 北向资金实时 | 沪深港通逐笔 | 外资动向跟踪 |

### 3.6 风险控制因子族

| 因子 | 检测机制 | 触发条件 |
|------|---------|---------|
| VPIN_Spike | VPIN急剧上升 | VPIN>历史95%分位→减仓 |
| Flow_Reversal | 资金流向突然逆转 | NetFlow 5min变化超过3σ |
| Liquidity_Dry | 盘口深度骤降 | 盘口总量<历史20%分位 |
| StopLoss_Hunt | 密集止损区域被扫 | 整数关口下方大单堆积 |

## 四、策略框架

### 4.1 三层决策架构

```
Level 1: 市场环境判断（日频）
├── VPIN趋势：上升/下降/震荡
├── 资金流向：持续流入/流出/平衡
├── 波动率环境：高波/常态/低波
└── 输出：仓位中枢（0-100%）

Level 2: 个股信号生成（Tick级实时）
├── 多因子复合评分（六大因子族加权）
├── 主力行为模式匹配
├── 异常信号检测（3σ）
└── 输出：个股买卖信号 + 置信度

Level 3: 执行与风控（实时）
├── 动态止损（VPIN触发 + 波动率自适应）
├── 仓位管理（凯利公式 + 连续回撤≤15%）
├── 熔断机制（单日回撤>7%→暂停）
└── 输出：最终交易指令
```

### 4.2 风控铁律（用户长期偏好）

| 规则 | 阈值 | 触发动作 |
|------|------|---------|
| 单笔最大亏损 | ≤净值2% | 强制止损 |
| 策略连续回撤 | ≤15% | 策略暂停+复盘 |
| 单日最大亏损 | ≤7% | 暂停交易+报告 |
| 总仓位上限 | 单票≤20% | 超限报警 |
| 无数据不决策 | L2数据中断 | 自动平仓观望 |
| 无回测不上线 | 年化Sharpe<1.5 | 拒绝实盘 |

## 五、端到端回测引擎

### 5.1 回测框架

```
输入：Tick数据 + 策略参数 + 时段范围
  ↓
回放引擎：按Tick时间戳逐步推送数据
  ↓
策略执行：Level1环境判断→Level2信号生成→Level3风控
  ↓
撮合模拟：考虑滑点（买卖一价+0.01%冲击）+ 手续费（双边千1.5）
  ↓
输出：
  ├── 收益曲线
  ├── Sharpe Ratio / MaxDD / Calmar
  ├── 胜率 / 盈亏比 / 平均持仓时间
  ├── 因子IC序列 / 衰减曲线
  ├── 归因分析（行业/因子/时段）
  └── 优化建议
```

### 5.2 核心指标

| 指标 | 合格线 | 优秀线 | 计算方法 |
|------|--------|--------|---------|
| 年化收益率 | >15% | >30% | CAGR |
| Sharpe Ratio | >1.5 | >2.5 | (年化收益-无风险)/年化波动 |
| Max Drawdown | <15% | <8% | 最大净值回撤 |
| Calmar Ratio | >1.0 | >3.0 | 年化收益/MaxDD |
| 胜率 | >55% | >65% | 盈利次数/总交易次数 |
| 盈亏比 | >1.5 | >2.5 | 平均盈利/平均亏损 |
