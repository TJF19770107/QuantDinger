## 一、Gateway 定位

Gateway 是 AI Agent 与外部世界的唯一通道。所有对话、工具调用、技能调用、记忆查询都必须经过 Gateway。

```
外部系统 (API/用户/MCP)
        │
   ┌────▼────┐
   │ Gateway │ ← 权限控制 + 审计日志 + 硬垂询
   └────┬────┘
        │
   Agent Core
```

## 二、Gateway 功能矩阵

| 功能 | 描述 | 来源 |
|------|------|------|
| API兼容层 | OpenAI兼容 HTTP API (端口标准化) | OpenClaw |
| 权限控制 | 工具/技能/文件访问权限分级 | OpenClaw + Marvis |
| 硬垂询 | 敏感操作强制触发用户确认 | Marvis L2 |
| 审计日志 | 所有操作完整记录，可回溯 | 自研 |
| 沙箱隔离 | 高风险操作在隔离环境执行 | 自研 |
| 速率限制 | Token消耗/API调用频率控制 | OpenClaw |

## 三、Marvis L2 安全兜底机制

```
L0: 常规操作 (读取文件/搜索/信息查询) → 自动执行
L1: 中等风险 (创建文件/编辑文件) → 自动执行+日志记录
L2: 高风险 (删除文件/修改系统配置) → 强制硬垂询，用户确认后执行
L3: 最高风险 (支付/密码/隐私数据) → 完全禁止Agent操作，必须用户本人
```

### 硬垂询触发条件：
- 删除文件/文件夹
- 修改系统核心配置
- 访问敏感路径
- 涉及支付操作
- 涉及密码/凭据

| 护栏 | 级别 | 描述 |

| 系统路径保护 | 🔴 | C:\Windows, /etc 等禁止写入 |
| 隐藏文件保护 | 🔴 | 系统隐藏文件自动跳过 |

| 敏感操作日志 | 🟡 | 所有L2+操作完整审计 |
| 速率限制 | 🟢 | Token日消耗上限控制 |
