## 六步蒸馏法（R24版）

### 步骤1：分析自己
**目标**：生成/更新用户人格画像
**输入**：SOUL.md + USER.md + AGENTS.md + 交易心理画像.md + 上一轮人格画像
**输出**：`E:\龙虾AI主控中心\我的AI分身\知识库\用户人格画像_[日期]_R[N].md`
**R24要求**：明确双轨工作流（AI分身+量化交易），识别R23增量变化

### 步骤2：制定计划
**目标**：生成AI分身进化规划
**输入**：步骤1产物 + 对标矩阵 + 角色总说明书最新版
**输出**：`E:\龙虾AI主控中心\我的AI分身\知识库\AI分身进化规划_R[N].md`
**R24要求**：明确核心配置v2.1升级路径，设定R25预研方向

### 步骤3：文件转换
**目标**：确认非MD文件状态，生成转换日志
**输入**：全目录扫描（知识库/技能库/子Agent/工作流库/记忆库/插件库）
**输出**：`E:\龙虾AI主控中心\我的AI分身\定时任务\蒸馏日志\文件转换日志_R[N].md`
**规则**：JSON/PY/CSV等原生格式无需转换；HTML可转；二进制忽略

### 步骤4：构建知识库
**目标**：生成知识库索引
**输入**：全目录MD文件统计 + 核心文件路径映射
**输出**：`E:\龙虾AI主控中心\我的AI分身\知识库\知识库索引_R[N].md`
**R24要求**：概念词条更新（新增双轨工作流/MCP隧道/平台化产品）

### 步骤5：创建self-skill
**目标**：更新蒸馏技能自身
**输入**：步骤1-4产物 + 角色总说明书
**输出**：`E:\龙虾AI主控中心\我的AI分身\技能库\self-skill_全域蒸馏.md`（本文件）
**规则**：每次蒸馏应更新self-skill以反映最新执行流程

### 步骤6：更新核心配置（G5门控）
**目标**：升级SOUL/USER/AGENTS/角色总说明书
**G5门控**（R23引入，R24沿用）：
```
交叉验证四文件无冲突：
1. SOUL.md → 人格坐标一致性
2. USER.md → 用户画像准确性
3. AGENTS.md → 协作协议完整性
4. 角色总说明书.md → 顶层规则正确性
→ 全部通过才可写入
```

**产出清单**：
- `SOUL.md` 升级至 v2.1（六大坐标 + 交易人格附录）
- `USER.md` 升级至 v2.1（双轨工作流 + R24能力矩阵）
- `AGENTS.md` 升级至 v2.1（CLL闭环学习 + Swarm v2.0）
- `角色总说明书.md` 升级至 v1.8（新增R24蒸馏记录）
