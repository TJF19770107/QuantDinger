## 一、协议定位

本协议定义豆包Agent的Tick级订单流分析能力体系，补全当前交易策略维度的最大短板——缺少实时逐笔成交（Tick）数据接入能力和L2级别的订单流分析框架。对标广发金工DPIN（Dynamic Price Impact Network）模型和QMT平台的6类L2数据体系。

## 二、数据接入架构

### 2.1 L2 Tick数据源矩阵

| 数据层级 | 数据内容 | 频率 | 来源 | 状态 |
|---------|---------|------|------|------|
| **逐笔委托** | 挂单/撤单/修改行为，委托价/量/方向 | 毫秒级 | 深交所/上交所L2 | 🎯 接入中 |
| **逐笔成交** | 成交价/量/方向（主动买/卖），买卖订单号关联 | 毫秒级 | 深交所/上交所L2 | 🎯 接入中 |
| **十档订单簿** | 买一至买十/卖一至卖十 价格+挂单量 | 秒级快照 | 深交所/上交所L2 | 🎯 接入中 |
| **五档订单簿** | 买一至买五/卖一至卖五 价格+挂单量 | 秒级快照 | QMT/通达信 | ✅ 已有 |
| **大单统计** | 大单买入/卖出、净流入/占比 | 分钟级 | QMT L2统计 | ✅ 已有 |
| **委买委卖队列** | 队列长度/撤单率/挂单分布 | 秒级 | 深交所/上交所L2 | 🎯 接入中 |

## 三、六大因子族体系

### 3.1 订单流不平衡因子族（Order Flow Imbalance, OFI）

| 因子 | 公式 | 含义 | 周期 |
|------|------|------|------|
| OFI_Simple | (买量-卖量)/(买量+卖量) | 基础买卖力量对比 | Tick |
| OFI_Weighted | Σ(档位买量×权重-档位卖量×权重) | 加权档位不平衡 | Tick |
| OFI_Delta | OFI_t - OFI_{t-1} | 订单流变化率 | Tick |
| OFI_Cumulative | Σ OFI_Delta (窗口内) | 累积订单流方向 | 1min/5min |
| OFI_Surprise | |OFI_t - E[OFI_t]| | 订单流失常检测 | Tick |

### 3.2 大单跟踪因子族（Large Order Tracking, LOT）

| 因子 | 定义 | 信号含义 |
|------|------|---------|
| LOT_BuyVolume | 阈值以上主动买入量 | 主力吸筹 |
| LOT_SellVolume | 阈值以上主动卖出量 | 主力出货 |
| LOT_NetFlow | LOT_BuyVolume - LOT_SellVolume | 主力净流向 |
| LOT_Concentration | 大单成交占比 | 主力参与度 |
| LOT_Stealth | 拆单模式识别（连续小额同向） | 隐蔽吸筹/出货 |

### 3.3 微观结构因子族（Market Microstructure, MMS）

| 因子 | 公式/逻辑 | 含义 |
|------|----------|------|
| Spread | 卖一-买一 | 即时交易成本 |
| Depth | Σ(买十量+卖十量) | 市场深度 |
| Slope | 订单簿价格梯度 | 流动性分布 |
| Resiliency | 大单冲击后恢复速度 | 市场弹性 |
| VPIN | Volume-Synchronized PIN | 信息不对称程度 |

### 3.4 主力行为画像因子族（Smart Money Profiling, SMP）

| 维度 | 指标 | 检测方法 |
|------|------|---------|
| **虚假挂单** | 大单挂→撤模式 | 委托-撤单时间差<阈值 + 量>均值3σ |
| **冰山订单** | 隐藏真实意图 | 连续小额同向成交 + 盘口深度不变 |
| **对倒行为** | 自买自卖 | 同一席位/相邻时间/等量反向 |
| **托盘/压盘** | 关键价位大单挂而不撤 | 整数位/前期高低点 + 挂单量>均值5σ |
| **尾盘异动** | 最后3分钟极端行为 | 尾盘价格偏离度 + 量放大 |

### 3.5 跨品种联动因子族（Cross-Asset Linkage, CAL）

| 因子 | 标的组合 | 含义 |
|------|---------|------|
| Sector_Flow | 个股 vs 行业ETF | 板块资金轮动 |
| Index_Lead | 股指期货 vs 现货 | 期现引导关系 |
| North_South | 沪深股通流向 | 北向/南向资金 |
| Margin_Balance | 融资融券变化 | 杠杆情绪 |
| Option_Skew | 期权偏度 vs 标的方向 | 聪明钱方向 |

### 3.6 时序模式识别因子族（Temporal Pattern, TMP）

| 模式 | 检测方法 | 信号 |
|------|---------|------|
| Tick Clustering | 同价位连续多笔同向成交 | 短期方向确认 |
| Absorption Pattern | 被动吃掉大量挂单 | 支撑/压力确认 |
| Momentum Ignition | 快速扫单启动 | 脉冲入场 |
| Exhaustion Gap | 订单簿断层 | 转折信号 |
| Iceberg Detection | 隐藏流动性检测 | 主力意图暴露 |

## 四、三层决策框架

### 4.1 微观层（Tick级，持仓周期<5分钟）

```
输入：Tick数据流（毫秒级）
模型：OFI实时计算 + 大单检测 + 订单簿动态
输出：瞬时买卖信号 + 最优执行算法
应用：高频做市、抢帽子、价差套利
```

### 4.2 中观层（分钟级，持仓周期5分钟-1天）

```
输入：1min/5min聚合Tick + 五档快照
模型：六大因子族多因子模型 + 主力行为画像综合评分
输出：日内趋势方向 + 关键价位 + 仓位建议
应用：日内波段、突破交易、事件驱动
```

### 4.3 宏观层（日级，持仓周期>1天）

```
输入：日线聚合 + 大单净流 + 北向资金 + 融券余额
模型：多日因子滚动窗口 + 主力行为趋势
输出：中期趋势判断 + 策略权重调整
应用：趋势跟踪、仓位管理、风格轮动
```

### 5.2 回测评估矩阵

| 指标 | 计算 | 健康阈值 |
|------|------|---------|
| Sharpe Ratio | (Rp-Rf)/σ | >1.5 |
| Max Drawdown | max(peak-valley)/peak | <15% |
| Sortino Ratio | (Rp-Rf)/σ_down | >2.0 |
| Calmar Ratio | 年化收益/MaxDD | >1.0 |
| Win Rate | 盈利交易/总交易 | >45% |
| Profit Factor | 总盈利/总亏损 | >1.5 |
| Turnover | 日均换手率 | <200% |
| Slippage Cost | 模拟滑点/理论收益 | <15% |

## 六、风控熔断机制（永久生效）

| 层级 | 条件 | 动作 |
|------|------|------|
| **L1 个券熔断** | 单笔亏损>净值2% | 立即平仓该标的 |
| **L2 策略熔断** | 策略连续回撤>15% | 暂停该策略24小时 |
| **L3 全局熔断** | 日内总亏损>净值5% | 全部平仓，当日停止交易 |
| **L4 极端行情** | 大盘涨跌幅>5% + VIX飙升 | 仓位降至10%以下 |
| **永久原则** | 宁可踏空不可爆仓 | 所有策略上线前必须通过L1-L4回测压力测试 |
