## 三大原语

| 原语 | 用途 | 示例 |
|------|------|------|
| Tools | 可执行函数 | send_email, query_db, create_issue |
| Resources | 只读数据 | 文件、数据库行、API响应 |
| Prompts | 参数化模板 | 报告生成、代码审查 |

## 双传输模式

| 特性 | stdio | Streamable HTTP |
|------|-------|-----------------|
| 部署 | 本地进程 | 远程云/容器 |
| 扩展 | 仅垂直 | 水平自动扩展 |
| 延迟 | < 1ms | 20-100ms |
| 认证 | OS级 | OAuth 2.1 + PKCE |

## 安全标准

- OAuth 2.1 + PKCE（所有远程连接强制）
- Resource Indicators（RFC 8707）
- 主机级权限控制（per-tool allow list）
