## 一、协议概述

对标微软Mnemis框架（ACL 2026主会议接收，LongMemEval + ∞Bench双榜SOTA），将豆包Agent的记忆系统从扁平向量检索升级为建构式层级图索引+双系统检索架构。解决传统RAG"语义相似≠真正相关"的根本缺陷。

---

## 二、核心问题：RAG的三大局限

```
传统RAG缺陷:
  1. 孤立评分 — 每条记忆独立与查询比较，忽略记忆间关系
  2. 语义偏见 — 向量相似度偏爱字面匹配，对间接相关信息不敏感
  3. 无法推理 — 不了解对话历史中存在哪些话题及其相互关系

类比:
  RAG ≈ 按书名关键词找书
  Mnemis ≈ 图书馆员先查分类目录，再从结构系统性定位
```

## 三、建构式层级图索引

```
                     ┌──────────────┐
                     │  话题层 (Topic)│  ← "2026年AI Agent技术栈"
                     └──────┬───────┘
                            │
              ┌─────────────┼─────────────┐
              │             │             │
         ┌────▼────┐  ┌────▼────┐  ┌────▼────┐
         │ 实体层   │  │ 实体层   │  │ 实体层   │
         │ Claude   │  │ Hermes  │  │ Codex   │
         └────┬────┘  └────┬────┘  └────┬────┘
              │             │             │
    ┌────┬────▼───┐  ┌─────▼─────┐  ┌────▼────┐
    │事实│关系│时间│  │事实│关系│时间│  │事实│... │
    └────┴────┴───┘  └─────┴─────┘  └────────┘

三维索引:
  X轴: 话题层级（Topic → SubTopic → AtomicFact）
  Y轴: 实体关系（AgentA → 能力→ AgentB → 协议→ AgentC）
  Z轴: 时间轴（2026-05 → 2026-06-01 → 2026-06-02）
```

## 四、双系统检索架构

### System 1：快速语义检索

```
路径: 查询 → 向量编码 → 混合搜索 → Top-K候选

组成:
  - 向量检索（70%权重）：语义相似度
  - 关键词检索（20%权重）：BM25精确匹配
  - 实体匹配（10%权重）：命名实体识别+直接命中

延迟目标: <50ms
适用场景: 简单事实查询 / 直接信息提取
```

### System 2：审慎推理检索

```
路径: 查询 → 实体识别 → 图遍历 → 多跳推理 → 关系补全 → 结果排序

组成:
  - 图遍历引擎：从查询实体出发，沿关系边扩展（2-hop默认）
  - 多跳推理：A→B→C 间接关联路径发现
  - 关系补全：缺失关系推断（如A和C都与B有关→A和C可能有关）
  - 置信度评分：每条路径的LLM评估置信度

延迟目标: <500ms
适用场景: 复杂推理查询 / 跨话题关联 / 历史决策回溯
```

## 五、三级记忆沉淀

```
L1 短期记忆（工作记忆）
  范围: 当前会话
  格式: 原始对话 + Token窗口
  容量: 受上下文窗口限制
  生命周期: 会话结束

L2 中期记忆（结构化事实）
  范围: 近7天
  格式: 结构化事实 → 层级图节点
  容量: 无上限（图结构）
  生命周期: 7天后衰减/蒸馏

L3 长期记忆（抽象原则）
  范围: 永久
  格式: 抽象原则 + 行为模式 + 用户画像
  容量: 精选（<1000条原则）
  生命周期: 永久 / 手动清理

沉淀流程:
  L1 → [会话结束] → 提取事实 → L2
  L2 → [7天周期] → 蒸馏原则 → L3
  L3 → [30天] → 自动复习 + 合并去重
```

## 六、与传统RAG对比

| 维度 | 传统RAG | Mnemis建构式索引 | 豆包Agent升级后 |
|------|---------|-----------------|---------------|
| 索引结构 | 扁平向量库 | 层级图 | 层级图 + 三维索引 |
| 检索方式 | 单路语义 | 双系统（快速+审慎） | 双系统 + 置信度评分 |
| 记忆间关系 | 无 | 图边关系 | 图边 + 多跳推理 |
| 抗语义偏见 | 弱 | 强（结构克服） | 强 |
| 推理能力 | 无 | 多跳推理 | 多跳 + 关系补全 |
| LongMemEval R@5 | ~70% | 96.6%（SOTA） | 对标SOTA |
| 跨会话持久化 | ❌ | ✅ | ✅ |
