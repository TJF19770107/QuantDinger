## 三、五层分析架构

### 第一层：L1逐笔成交层

```
逐笔成交数据字段：
{
  "tick_id": "唯一标识",
  "price": "成交价",
  "volume": "成交量(股)",
  "amount": "成交额(元)",
  "direction": "buy/sell/neutral",
  "timestamp": "毫秒级时间戳",
  "trade_type": "主买/主卖/中性盘"
}
```

**分析指标**：
- 大单识别（单笔≥100万/500万/1000万分级标记）
- 主买/主卖比（多空力量实时对比）
- 成交密度（每分钟成交笔数异常放大/缩小）
- 成交节奏（价格与量的背离信号）
- VWAP偏离度（实时成交价与VWAP的偏离）

### 第二层：L2订单簿快照层

```
L2快照数据字段：
{
  "bid_levels": [{"price": 10.50, "volume": 50000}, ...],  // 买1-10档
  "ask_levels": [{"price": 10.51, "volume": 30000}, ...],  // 卖1-10档
  "spread": "买卖价差",
  "depth_imbalance": "买卖深度比",
  "snapshot_time": "快照时间"
}
```

**分析指标**：
- 订单簿深度倾斜（买盘深度/卖盘深度的不对称）
- 冰山订单检测（大单拆分成多档挂单的隐藏行为）
- 价差变化率（spread扩张/收缩速度）
- 订单簿形状分析（堆单/薄单/阶梯单模式识别）
- 撤单率（挂单后撤单比例，反映虚假挂单意图）

### 第三层：主力行为动态分析层

```
主力行为模式库：
1. 吸筹模式：价格窄幅震荡 + 下方大托单 + 小单密集成交
2. 拉升模式：连续大买单 + 卖盘被快速吃掉 + 价差收窄
3. 出货模式：上方大压单 + 成交放大 + 价格滞涨或回落
4. 洗盘模式：恶意砸盘 + 快速拉回 + 成交量萎缩后放大
5. 对倒模式：同一价格附近反复成交 + 成交量异常放大 + 价格不动
6. 垫单模式：不断在买1-3挂大单但不成交，引导散户跟风
7. 托单模式：下跌时的假支撑单，价格跌破后撤单
8. 压单模式：上涨时的假阻力单，价格突破后撤单
```

**评分体系**：每个模式检测后输出0-100的置信度分数，综合主力意图评分

### 第四层：资金流向层

```
资金流向分类：
- 超大单（≥100万元）：机构/游资主力
- 大单（20万-100万元）：中大户
- 中单（4万-20万元）：普通散户
- 小单（<4万元）：迷你散户
```

**进阶分析**：
- 板块资金轮动检测（行业间资金流入/流出热力图）
- 北向资金/南向资金实时跟踪（互联互通）
- 主力净流入/流出与股价走势的背离检测
- 资金集中度（前N大单占比）

### 第五层：AI异常检测层

```
异常检测模型：
- 输入：L1逐笔+L2快照+资金流向+技术指标 多维特征向量
- 模型：无监督深度学习（Autoencoder/Isolation Forest/LSTM-AE）
- 输出：归一化异常分数（0-100）+ 方向（上涨/下跌/震荡）+ 置信度
```

**异常类型**：
- 成交量异常（相对历史均值≥3σ）
- 价格波动异常（相对历史波动率≥3σ）
- 订单簿结构异常（深度倾斜度突变）
- 资金流向异常（单向大幅流入/流出）
- 跨市场联动异常（A股/港股/美股背离）
