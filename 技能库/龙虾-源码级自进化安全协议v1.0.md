# 龙虾-源码级自进化安全协议 v1.0

> **协议编号**：#46
> **对标来源**：MOSS (Self-Evolution through Source-Level Rewriting) + Ratchet (最低卫生标准)
> **创建日期**：2026-06-01 (R11)
> **核心价值**：Agent识别自身代码弱点→重写源文件→自动测试→部署，全流程安全防崩+可审计回滚
> **状态**：ACTIVE

---

## 一、协议概述

### 1.1 问题定义
现有自进化技能协议（#21 CASCADE双元技能、#38 技能全生命周期）仅限于文本层可编辑产物（提示词、记忆schema、工作流图），而路由逻辑、钩子顺序、状态不变量等核心逻辑存在于代码层，无法从文本层触达。MOSS论文（arXiv:2605.22794）首次证明：Agent可以安全地识别自身代码弱点、重写Python/TypeScript源文件、自动化测试验证、部署改进版本。

### 1.2 核心能力
- **弱点识别**：自动分析任务日志，定位代码层缺陷模式
- **源码重写**：生成有针对性的代码补丁，仅修改缺陷模块
- **自动验证**：自动化测试套件跑通后方可部署
- **安全护栏**：Ratchet式非发散分析，低于基准分拒绝部署
- **可审计回滚**：每次自修改版本化+完整回滚能力

## 二、四阶段自进化闭环

```
阶段1: 感知 (Perceive)
  ├── 分析任务执行日志
  ├── 识别失败模式/缺陷根源
  ├── 定位目标代码模块（文件:函数级）
  └── 输出：缺陷报告（module, failure_pattern, root_cause）

阶段2: 生成 (Generate)
  ├── 基于缺陷报告生成代码补丁
  ├── 仅修改目标函数/方法，不动架构
  ├── 生成对应测试用例
  └── 输出：patch.diff + test_module.py

阶段3: 验证 (Validate)
  ├── 在隔离沙箱执行测试套件
  ├── 全量回归测试（非仅新测试）
  ├── Ratchet非发散分析：
  │   ├── 基准分对比（pre-patch vs post-patch）
  │   ├── 若性能下降>1%，拒绝部署
  │   └── 若行为改变但基准不降，标记Review
  └── 输出：验证报告 (pass/fail + metrics)

阶段4: 部署 (Deploy)
  ├── 验证通过 → 应用补丁到源文件
  ├── 版本化快照（git commit + checkpoint）
  ├── 更新能力矩阵
  └── 失败 → 回滚 + 记录失败原因到经验池
```

## 三、安全护栏（Ratchet非发散分析）

### 3.1 核心原则
> Agent可以自我改进，但不能低于上一次基准测试分数。

### 3.2 三层检查

| 层级 | 检查内容 | 失败处理 |
|------|---------|---------|
| L1 语法层 | 补丁是否语法正确？能否import？ | 拒绝，返回修正 |
| L2 功能层 | 回归测试全量通过？ | 拒绝，返回修正 |
| L3 基准层 | 基准分是否≥pre-patch？ | 拒绝部署，记录归档 |

### 3.3 基准分维度
- 任务完成率（同一基准任务集）
- 平均响应延迟
- 错误恢复率
- 代码质量（Lint score）

## 四、版本化与回滚

### 4.1 版本化策略
每次自修改自动生成：
```
checkpoints/
├── v1/
│   ├── snapshot_20260601_001.tar.gz
│   ├── patch_autofix_handler.py.diff
│   ├── test_results.json
│   └── benchmark_scores.json
├── v2/
│   └── ...
└── current -> v2/
```

### 4.2 回滚触发条件
1. 部署后监控到错误率上升>5%
2. 用户手动触发回滚
3. 连续3次自修改后基准分持续下降

### 4.3 审计日志
每次操作记录：时间/触发原因/修改文件/修改行数/基准分变化/部署人（Agent or Human）

## 六、适用场景与限制

### 6.1 适用场景
- Agent执行编码任务时反复出现同类错误
- 工具调用逻辑需要修复（参数错误、路由缺陷）
- 性能瓶颈定位到特定模块

### 6.2 限制条件
- 仅限修改.py/.ts等自身Agent代码，不触及系统文件
- 每次修改≤3个文件、≤50行增量
- 安全护栏不可被自身绕过
- 需用户授权首次激活
