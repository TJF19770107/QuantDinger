# 多Agent批量迭代技能 · Skill: Multi-Agent Iteration
版本：v1.0
类型：版本管理技能
挂载路径：E:\龙虾AI主控中心\我的AI分身\技能库\多Agent批量迭代技能.md
适用范围：豆包Agent、Hermes Agent、OpenClaw龙虾Agent

## 概述
统一管理全部子Agent的版本迭代流程，包含状态锁管控、迭代执行、功能校验、日志归档的标准化全流程。

## 迭代流程

### 阶段1：状态锁解锁（Unlock）
- 检查目标Agent当前状态锁
- 若已锁定，检查锁定原因和剩余时间
- 获取迭代权限，解除状态锁
- 记录解锁操作日志
- 输出：解锁确认

### 阶段2：迭代执行（Iterate）
- 读取目标Agent版本信息
- 拉取最新迭代配置（技能更新、规则变更、参数调整）
- 执行迭代脚本：
  - 豆包Agent：更新交互逻辑、内容处理规则
  - Hermes Agent：更新调度策略、进程管控参数
  - OpenClaw龙虾Agent：更新插件列表、底层引擎
- 记录每步执行状态
- 输出：迭代执行日志

### 阶段3：功能校验（Validate）
- 对迭代后的Agent执行基础功能测试
- 检查输出质量、响应时间、异常处理
- 与上一版本对比关键指标
- 异常项触发ECC修正
- 输出：校验报告

### 阶段4：日志归档（Archive）
- 汇总迭代全流程数据
- 更新版本号
- 写入知识库（迭代档案）
- 输出：迭代闭环报告

### 阶段5：状态锁恢复（Re-lock）
- 恢复Agent状态锁
- 记录锁定时间戳
- 更新Agent运行状态
- 输出：锁定确认

## 批量迭代
- 支持一次迭代全部子Agent
- 按豆包→Hermes→OpenClaw顺序串行执行
- 单个Agent迭代失败不影响其他Agent
- 全部完成后生成汇总报告

## 调用示例
```
触发：Agent迭代 豆包Agent
触发：Agent迭代 全量
触发：Agent迭代 批量 [豆包Agent, Hermes Agent]
```
