## 1. 忘语叙事模型

### 1.1 开篇公式

```
江湖过渡法：
凡间出身（第1章点明修仙方向）→ 江湖门派过渡（积累斗争经验+初步知识储备）→ 自然转入修仙界

关键要素：
1. 第一章必定点明"修仙"方向（如"韩立从未想到...走上了一条与凡人不同的仙业大道"）
2. 从江湖到修仙的过渡必须自然（通过道具/人物/事件，如金光上人的升仙令→黄枫谷）
3. 先给主角斗争经验和能力储备，再进入更残酷的修仙界
4. 伏笔前置：前期看似无意义的道具/人物，后期必定关键转折
```

### 1.2 忘语式开篇自检清单

```
□ 第1章：是否在300字内点明了故事最终走向（修仙/长生）？
□ 第1-3章：是否通过凡间/江湖经历让读者先建立情感连接？
□ 过渡设计：从凡间到修仙界的转折是否有具体道具/人物/事件驱动？
□ 伏笔布设：前3章是否至少埋设了2个后期可回收的伏笔？
□ 金手指引入：金手指的获得是否有机缘巧合的"合理性"而非天上掉馅饼？
```

### 1.3 人物塑造公式

```
忘语式人物塑造 = 贴着人物写 + 不写之写 + 细节描写极其到位

"贴着人物写"四原则：
1. 人物的每个行为必须符合其性格/处境/利益（不是作者安排的，是人物自己会做的）
2. 配角鲜活各有作用（出场必有目的，退场必有交代）
3. 不写之写：用暗示代替直说（小妹无正面描写也无对话，但读者心里都有自己的小妹形象）
4. 资源决定行为：每个人物的行动由生存资源和利益驱动，而非善恶

人物共情公式：
主角出身平凡 + 资质平庸 + 生存挣扎 → 读者代入"普通人在残酷世界的奋斗"
```

### 1.4 人物落地忘语式检查

```
□ 主角是否有明确的"普通人出身"细节？（家庭/经济/社会地位）
□ 主角行为逻辑是否高度映射职场生存状态？（趋利避害、精于算计、谨慎行事）
□ 配角是否各有独立作用？（每个配角出场解决一个剧情问题或推动一个节点）
□ 人物关系是否为"资源关系"？（利益合作/资源交换/互相利用，而非纯粹友情/爱情）
□ 是否有至少3个"不写之写"的细节？（读者自己脑补的留白空间）
```

### 1.5 节奏控制公式

```
忘语式节奏 = 慢热延迟满足 + 量化积累 + 真实时间感

升级节奏：
小境界提升：需要数十上百章铺垫（寻找材料→炼丹→闭关→突破）
突破瞬间：爆发巨大的成就感（天象异变/众人震惊/跨级战力展示）

节奏曲线：
缓慢铺垫（70%篇幅）→ 冲突积累（20%）→ 爆发突破（10%）
```

### 1.6 忘语式节奏自检

```
□ 每个小境界提升是否有充足的铺垫章数？（练气→筑基至少10章以上）
□ 突破前的准备是否量化描写？（寻找材料/炼丹过程/闭关时间的细节）
□ 突破时是否有爆发感？（不只是"突破了"三个字，而是天象/灵力波动/旁人反应）
□ 是否有真实的时间感？（"三年后""转眼十年"有过渡描写，不是突兀跳转）
□ 快慢节奏比例是否合理？（70%铺垫+20%冲突+10%爆发）
```

### 1.7 升级节奏公式

```
忘语式升级 = 资源决定论 + 量化修炼 + 零和博弈

资源驱动公式：
每次突破 = 足够资源（灵药/灵石/功法）× 足够时间（炼丹/闭关）× 足够安全（洞府/阵法/护法）

零和博弈结构：
资源总量固定 → 一人得到 = 他人得不到 → 同门即仇寇，前辈亦猎物
```

## 2. 忘语文笔模型

### 2.1 行文特征

| 维度 | 忘语特征 | 执行标准 |
|------|---------|---------|
| 用词风格 | 朴实无华、不堆砌辞藻 | 禁用华丽形容词堆砌，一句一个意思 |
| 度量衡 | 古代用语 | 丈/尺/时辰/一炷香/一盏茶/一息 |
| 修炼描写 | 量化+细节 | 炼丹步骤/炼器材料/阵法布置→逐一描写 |
| 战斗描写 | 策略博弈+法术细节 | 不是"一拳打飞"，而是"判断→决策→出手→变招→结果" |
| 时间描写 | 真实时间感 | "三个月后""数年光阴"需有过渡（日常修炼/炼丹/赶路描写） |
| 情感描写 | 克制深沉 | 不写"他很感动"，写"他沉默片刻，收起了那块玉佩" |

### 2.2 忘语禁用词汇

```
禁止：米/公里/分钟/秒/公斤/元
禁止：OK/搞定/牛/爽/炸裂/绝了/心态崩了
禁止：爱了爱了/绝绝子/好家伙
禁止：综上所述/由此可见/标志着/体现了/深入探讨
禁止：超级/非常/极其/特别 → 用具体数字或动作替代
```

### 2.3 忘语推荐词汇

```
时间：时辰/一炷香/一盏茶/一息/弹指间/半晌/须臾
距离：里/丈/尺/寸/步
重量：斤/两/石/钧
情绪：心中凛然/面色如常/若有所思/目光一凝/心中一沉/暗自警惕/不动声色
动作：袖袍一抖/单手一翻/身形一动/化为一道青虹/遁光一起
环境：灵气浓郁/阴气森森/灵气稀薄/妖气冲天/云雾缭绕
```

## 3. 凡人流写作检查清单（Checklist）

### 3.1 开篇检查（前3章）

```
□ 第1章300字内：是否点明了核心方向（修仙/长生）？
□ 第1-3章：是否有情感锚点？（让读者心疼/共鸣的细节）
□ 主角处境：是否展现了"弱者"状态？（被欺压/资质平庸/生存困难）
□ 金手指：是否在3章内初现，但保留隐藏限制？
□ 过渡设计：从日常到修仙界是否有合理桥梁？
□ 伏笔前置：是否至少2个伏笔在3章内埋设？
```

### 3.2 人物检查（每10章）

```
□ 主角行为：是否始终"趋利避害、精明算计"？
□ 主角不会：是否避免了无脑莽、圣母行为、轻易信任陌生人？
□ 配角作用：每个配角出场是否有明确剧情目的？
□ 反派智商：反派行为是否有合理动机（不单纯坏）？
□ 人物关系：是否以"资源/利益关系"为主而非纯情感？
□ 生活细节：每5章是否有3种以上生活化描写？
```

### 3.3 节奏检查（每10章）

```
□ 爽点密度：是否≥1微爽/章 + 1小爽/3章？
□ 快慢交替：是否有"铺垫→冲突→爆发"的节奏曲线？
□ 流水账检测：是否有连续300字无冲突/无矛盾的段落？
□ 章末钩子：每章结尾是否有翻页动力？
□ 升级铺垫：境界提升是否有充足章数铺垫（至少10章）？
```

### 3.4 文笔检查（每章）

```
□ 禁用词汇：是否避免了现代词汇和AI痕迹词？
□ 度量衡：是否使用古代单位（丈/尺/时辰）？
□ 修炼描写：是否量化了修炼过程（材料/步骤/时间）？
□ 战斗描写：是否有策略博弈（不是一味碾压）？
□ 情感描写：是否克制（用动作代替形容词）？
□ 感官描写：每300字是否有听觉/嗅觉/触觉？
```

### 3.5 爽点检查（每10章）

```
□ 打脸爽点：是否有"被轻视→实力碾压→震惊"的标准配方？
□ 升级爽点：是否有"积累铺垫→突破→天象异变"的完整展示？
□ 获得爽点：是否有完整的寻宝链路（线索→障碍→智取→到手）？
□ 逆转爽点：是否有以弱胜强的智斗（不是靠金手指硬推）？
□ 装逼爽点：是否有低调入场→被挑衅→轻描淡写展现实力？
```

## 4. 三平台适配指南

| 追读设计 | 每章结尾必须有强钩子（追问/悬念/危机） |

| 参数 | 配置 |

| 创新要求 | 在凡人流基础上融入差异化元素 |
| 世界观 | 传统仙侠底蕴 + 创新设定 |

| 参数 | 配置 |
|------|------|
| 节奏 | 开篇节奏必须快！前3章必须密集输出 |

## 5. 反模板警戒 · 七猫驳回对照表

### 5.1 哪些写法会被七猫驳回

| 被驳回写法 | 具体表现 | 修正方案 |
|-----------|---------|---------|
| 开篇平铺直叙 | 前三章从"主角起床→吃饭→出门→遇到事情"慢悠悠开始 | 第1章第1段即出冲突/危机/反常事件 |
| 人设空洞 | 主角除了"废柴""谨慎"两个标签外无其他细节 | 填充人物落地五件套，每章展示习惯/口头禅 |
| 缺乏生活化细节 | 全是修炼/战斗/升级，没有日常 | 每5章3种以上生活场景 |
| 代入感弱 | 读者不关心主角死活 | 第1章必须植入情感锚点（让人心疼/共鸣） |
| 叙事节奏平淡 | 从头到尾一个节奏，无起伏 | 按快慢交替节奏表写作，每章有情绪曲线 |
| 金手指滥用 | 开局就无敌，一路碾压 | 金手指必须有限制+代价，升级有难度 |
| 角色脸谱化 | 好人就是好人，坏人就是坏人 | 反派必须有动机，正派必须有缺点 |
| 文笔AI味重 | 综上所述/由此可见/体现了+句长均匀无变化 | 使用仙侠词汇库，去掉AI痕迹，句长有意变化 |

### 5.2 凡人流vs七猫的七个必须调整

| 凡人流原版特征 | 七猫要求 | 调整方案 |
|-------------|---------|---------|
| 慢热延迟满足 | 快速抓住读者 | 保留写实底色，压缩铺垫篇幅至原来的60% |
| 开篇江湖过渡 | 第一章就出冲突 | 保留江湖过渡逻辑，但在江湖阶段就强化冲突密度 |
| 情感极度克制 | 适当增加情感线 | 保留克制风格，但每10章安排1次情感爆发点 |
| 升级缓慢（100章一境界） | 30章内需有大进展 | 前期加速但保留"量化修炼"的仪式感 |
| 战斗偏策略 | 战斗需有爽感 | 保留策略博弈，但增加"碾压时刻"的爆发描写 |
| 配角工具化 | 配角需有血肉 | 每个主要配角增加"落地五件套" |
| 暗黑写实 | 需有正向情感 | 保留暗黑底色，但每30章安排1个温暖时刻 |

## 6. 对标书目爆款共性注入

### 6.1 11本对标书共性提炼

基于《武逆九千界》《太荒吞天诀》《炼仙鼎》《逆剑狂神》《炼神鼎》《葬天神帝》《葬神棺》《星辰大道》《九天轮回诀》《斗天武神》《混沌塔》的拆解：

| 共性维度 | 提炼规则 | 注入模板 |
|---------|---------|---------|
| 开篇 | 强冲突+金手指快暴露+首章人物立住 | 黄金三章必须严守 |
| 修炼体系 | 层次分明+等级差异明确+量化可感 | 11级标准体系+境界能力对照表 |
| 爽点密度 | 每章微爽+每3章小爽+每10章中爽 | 严格按爽点分布图执行 |
| 钩子设计 | 章末必须有悬念/追问/危机 | 每章结尾必须留钩 |
| 金手指类型 | 鼎/塔/棺/星辰/轮回 — 非传统系统 | 选择创新金手指方向 |

### 6.2 金手指创新方向（对标书启发）

| 金手指类型 | 创新点 | 适配凡人流 | 参考对标书 |
|-----------|--------|-----------|----------|
