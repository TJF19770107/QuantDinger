## 一、协议概述

对标Codex Memory系统（April 2026更新），建立豆包Agent的跨会话持久化记忆能力。将用户偏好、项目上下文、历史决策从单会话范围扩展到跨会话持久化，实现"越用越懂你"的用户画像渐进蒸馏。

---

## 二、三层记忆画像模型

```
┌─────────────────────────────────────────┐
│           L1 偏好层（即时生效）            │
│  代码风格 / 命名规范 / 框架选择 / 工具链    │
│  更新频率：每次会话自动提取               │
│  准确率要求：>95%                         │
├─────────────────────────────────────────┤
│           L2 上下文层（项目级）            │
│  项目结构 / 历史决策 / 修复记录 / 依赖关系  │
│  更新频率：项目阶段变更时                  │
│  准确率要求：>90%                         │
├─────────────────────────────────────────┤
│           L3 画像层（用户级·永久）          │
│  能力水平 / 常用模式 / 信任边界 / 深层偏好  │
│  更新频率：每月蒸馏                       │
│  准确率要求：>85%（渐进提升）              │
└─────────────────────────────────────────┘
```

## 三、跨会话工作机制

### 3.1 会话结束时：自动提取

```
EXTRACT_ON_SESSION_END:
  1. 扫描本次会话所有交互
  2. 提取关键决策点（用户确认/否决/修改的动作）
  3. 提取显式偏好声明（"我习惯用XXX"、"不要XXX"）
  4. 提取隐式偏好模式（连续3次以上相同选择）
  5. 增量更新L1偏好层
  6. 写入Memory Store

  输出: memory_diff {added: [...], modified: [...], confidence: [...]}
```

### 3.2 新会话启动时：自动注入

```
INJECT_ON_SESSION_START:
  1. 读取当前用户L1偏好层
  2. 基于任务关键词匹配L2上下文层（Top-5相关）
  3. 注入到System Prompt / 初始上下文
  4. 标记已注入的记忆ID（防止重复注入）

  注入策略:
    - L1偏好: 全量注入（数据量小）
    - L2上下文: 按相关性Top-5注入
    - L3画像: 仅注入当前任务类型相关的行为模式
```

### 3.3 渐进式蒸馏时间线

```
Day 0-3（短期）:
  原始交互记录 → 保留完整上下文

Day 3-7（中期）:
  关键决策提取 → 结构化事实 → L1/L2更新

Day 7-30（长期）:
  模式识别 → 噪声过滤 → L2→L3蒸馏
  跨会话对比 → 发现偏好变化趋势

Day 30+（永久）:
  L3画像凝结 → 仅保留高置信度原则
  自动复习 → 过期原则标记→降级或删除
```

## 五、Codex Memory 对标差异

| 维度 | Codex Memory | 豆包Agent Memory |
|------|-------------|-----------------|
| 持久化范围 | 代码偏好 + 项目上下文 | 全维度（编码+系统+Agent+个人） |
| 更新方式 | 会话自动提取 | 会话自动 + 定时蒸馏 |
| 蒸馏层级 | 单层 | 三层渐进（3天→7天→30天） |
| 跨平台 | Mac优先 | Windows原生 + 微信/QQ双端 |
| 隐私控制 | 云端 | 本地优先 + 可选云端同步 |
| 集成深度 | 编码工作流 | 全域Agent生态（163协议联动） |

## 六、隐私与安全

```
数据分级:
  L1偏好:     低敏感 — 可云端同步
  L2上下文:   中敏感 — 本地存储 + 加密传输
  L3画像:     高敏感 — 仅本地 + 端侧加密

安全约束:
  - 密钥/密码/Token类信息：禁止存入Memory Store
  - 财务/身份信息：禁止存入L2/L3
  - 用户可选择清除任意层级记忆
  - 记忆导出：支持JSON格式完整导出
  - 记忆审计：每次蒸馏生成审计日志
```
