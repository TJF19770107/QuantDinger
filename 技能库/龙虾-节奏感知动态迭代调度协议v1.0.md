## 一、协议概述

建立四级节奏分层的动态迭代调度引擎，使豆包Agent具备感知迭代节奏、自适应调整频率、评估迭代质量的能力。对标Claude Dynamic Workflows的任务分解调度、Gemini Spark的Task-Plan-Skill三元组架构、AutoScientists的去中心化自组织机制。

## 二、四级节奏分层

```
┌─────────────────────────────────────────────────┐
│ L1 高频层（≤15min）                              │
│ - 关键缺口实时监控                               │
│ - 轻量修补与热修复                               │
│ - 网络安全事件即时响应                           │
│ - 触发条件：协议异常/安全告警/用户即时指令        │
├─────────────────────────────────────────────────┤
│ L2 中频层（≤2h）★ 标准迭代                       │
│ - 全网搜索 + 协议提取 + 能力融合                 │
│ - 对标矩阵更新 + 报告生成                        │
│ - 触发条件：cron定时 / 咒语激活 / 缺口检测        │
├─────────────────────────────────────────────────┤
│ L3 低频层（≤24h）                                │
│ - 深度反思 + 全局评估                            │
│ - 架构审视 + 冗余清理                             │
│ - 触发条件：cron定时 / 累计delta触发              │
├─────────────────────────────────────────────────┤
│ L4 事件驱动层                                    │
│ - 外部技术突破检测                               │
│ - 对标Agent重大版本更新                          │
│ - 用户手动触发（咒语激活）                        │
│ - 触发条件：全网监控告警 / 用户指令               │
└─────────────────────────────────────────────────┘
```

## 三、自适应频率调整算法

```
FREQ_ADAPT(current_freq, recent_deltas, token_budget):

  INPUT:
    current_freq: 当前迭代频率（默认2h）
    recent_deltas: 最近N轮delta_value列表
    token_budget: Token预算余量

  OUTPUT:
    new_freq: 调整后的频率
    burst_mode: 是否进入burst模式

  RULES:
    1. 降频条件（连续3轮 delta_value < 0.01）:
       current_freq × 2 → 上限24h
       原因：迭代边际收益趋零

    2. 升频条件（任意1轮 delta_value ≥ 0.05 或检测到关键突破）:
       进入burst模式：30min × 4轮 → 恢复原频率
       原因：捕捉突破窗口期

    3. Token预算保护:
       if token_budget < 20%:
         强制降至 L3（≤24h），仅保留事件驱动
       原因：防止资源耗尽

    4. 夜间降频（00:00-06:00）:
       自动降至 L3（≤24h），除非burst模式激活
       原因：降低无效迭代

    5. 微信/QQ双端同步:
       两端频率保持一致，成果合并归档
```

## 四、迭代质量评估公式

```
ITERATION_SCORE = w1 × delta_value_score 
                + w2 × protocol_yield_score
                + w3 × token_efficiency_score
                + w4 × intelligence_quality_score

其中:
  delta_value_score:     综合得分提升幅度（0-1归一化）
  protocol_yield_score:  本轮新增协议数 / 目标协议数
  token_efficiency:      情报产出 / Token消耗
  intelligence_quality:  新情报来源权威性加权

权重:
  w1=0.40  (迭代收益最重要)
  w2=0.25  (协议产出)
  w3=0.20  (Token效率)
  w4=0.15  (情报质量)
```
