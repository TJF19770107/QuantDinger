# 龙虾-小红书与内容平台Agent生态对接协议 v1.0

> **协议编号**：#60
> **版本**：v1.0（R13迭代 · 2026-06-01）
> **对标来源**：小红书Red Skill内测+REDsearcher开源+FireRed系列模型+必剪Studio+bilibili-ai-bot
> **核心价值**：内容平台Agent化/Red Skill对接/REDsearcher集成/数字分身创作/B站生态接入
> **激活条件**：涉及内容平台Agent对接、小红书生态、B站创作、数字分身视频时激活

---

## 一、协议概述

本协议整合小红书和B站两大内容平台的Agent生态能力，为龙虾AI主控中心提供Red Skill对接、REDsearcher搜索集成、FireRed创作工具链接入、B站数字分身创作等能力。

## 二、小红书Agent生态

### 2.1 Red Skill内测

| 特性 | 描述 |
|------|------|
| 入口 | 笔记下方挂载AI技能 |
| 定位 | 社区AI能力入口创新 |
| 策略 | 限制AI内容生产→把AI能力接入自身体系 |
| 机会 | 小龙虾AI技能可申请入驻Red Skill商店 |

### 2.2 REDsearcher（30B搜索Agent）

| 特性 | 描述 |
|------|------|
| 参数量 | 30B |
| 性能 | 小红书域内超越Gemini-2.5-pro |
| 部署 | 开源协议下可本地部署 |
| 对接 | 搜索Agent可调用REDsearcher做小红书内容检索 |

### 2.3 FireRed创作工具链

| 工具 | 功能 | 对接方式 |
|------|------|---------|
| FireRed-Image-Edit | 指令式图像编辑（"背景换日落"） | API调用 |
| FireRed-OCR | 低成本文档识别 | 批量处理 |
| FireRed-OpenStoryline | 视频创作（脚本→分镜→剪辑） | 工作流集成 |

### 2.4 小红书AI搜索"点点"

- PC端上线（xiaohongshu.com/ai_chat）
- 基于海量真实笔记+多轮对话
- 支持导入用户点赞/收藏笔记作为上下文
- 每日千万级日活，留存率提升2-3%

## 三、B站Agent生态

### 3.1 必剪Studio

| 特性 | 描述 |
|------|------|
| 定位 | 国内首款免费数字分身工具 |
| 数字分身 | 上传绿幕/实景视频→AI高精度建模 |
| 音色克隆 | 30分钟音频→专属音色（含方言/情感） |
| 驱动方式 | 文本/录音→自动口播视频 |
| 生态整合 | B站一键投稿+三连动画+热门素材库 |

### 3.2 bilibili-ai-bot

| 特性 | 描述 |
|------|------|
| 定位 | 开源B站AI角色系统 |
| 核心能力 | 自动回复评论+刷视频+发动态+记忆+成长 |
| 记忆系统 | 语义向量检索（BAAI/bge-m3）+对话线程管理 |
| 好感度 | 用户独立好感度（0-100），影响回复风格 |
| 性格成长 | 每日反思+动态演化 |
| 多人格 | 支持多角色切换，独立系统提示词 |

### 3.3 对接策略

| 能力 | 对接方案 |
|------|---------|
| 数字分身 | 必剪Studio创建→龙虾Agent驱动脚本化内容 |
| 评论回复 | bilibili-ai-bot模式→龙虾Agent记忆层复用 |
| 内容搜索 | REDsearcher→内容研究Agent |
| 图像编辑 | FireRed-Image-Edit→封面图批量生成 |
| 视频创作 | FireRed-OpenStoryline→脚本自动化 |

## 四、内容创作工作流

### 4.1 选题→发布全链路

```
Step 1: 选题分析 → REDsearcher搜索竞品+趋势
Step 2: 脚本生成 → Claude Code生成结构化脚本
Step 3: 封面设计 → FireRed-Image-Edit指令式生成
Step 4: 视频制作 → 必剪Studio数字分身+FireRed-OpenStoryline
Step 5: 自动发布 → bilibili-ai-bot定时发布+互动维护
```

### 4.2 风险控制

| 风险 | 控制措施 |
|------|---------|
| 账号安全 | 不执行批量互动/私信 |
| 内容合规 | 发布前人工审核 |
| 隐私保护 | 不采集个人敏感信息 |
| 平台规则 | 遵守各平台运营规范 |
