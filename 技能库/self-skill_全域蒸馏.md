# Self-Skill：全域全自动蒸馏
版本：v1.0 | 生成时间：2026-05-31 | 类型：定时任务技能

## 技能名称
`distill-full-auto`

## 触发方式
- 定时触发：每2小时自动执行
- 手动触发：发送「全域蒸馏」或「嗡阿喇巴札那谛」

## 执行流程

### Phase 1：前置激活
1. 读取 E:\龙虾AI主控中心\我的AI分身\角色总说明书\角色总说明书.md
2. 激活顶层规则：实事求是/无断片/MD5去重/统一路径/全域迭代

### Phase 2：全域抓取（16平台并行）
| 平台 | 抓取重点 | 方法 |
|------|---------|------|
| B站 | AI创作趋势、热门作品 | web_search |
| GitHub | Trending仓库、开源项目 | web_search |
| 视频号 | 微信生态AI动态 | web_search |
| 抖音 | AI工具/内容/趋势 | web_search |
| 小红书 | AI产品/创作/治理 | web_search |
| 今日头条 | AI热点/行业分析 | web_search |
| 公众号 | 深度内容/平台政策 | web_search |
| 七猫 | 网文趋势 | web_search |
| 起点 | 网文榜单/创作风向 | web_search |
| 奇妙 | 网文趋势 | web_search |
| 纵横 | 网文榜单 | web_search |
| 番茄 | 网文治理/AI写作 | web_search |
| YouTube | AI产品/内容/趋势 | web_search |
| X(推特) | AI动态/算法更新 | web_search |
| 搜狐 | 科技论坛/企业战略 | web_search |
| 币安 | 加密货币行情数据 | web_search |

### Phase 3：按序蒸馏
1. **分析自己** → 生成/更新 SOUL.md（用户人格画像）
2. **制定计划** → 生成 进化规划_[日期].md（进化路径+工作流）
3. **构建知识库** → 生成 全域蒸馏_[日期]_知识库.md（结构化知识）
4. **更新核心配置** → 同步 SOUL.md / USER.md / AGENTS.md
5. **生成蒸馏日志** → 归档至 定时任务/蒸馏日志/

### Phase 4：全域同步
- 通知豆包Agent：更新交互规则
- 通知Hermes Agent：更新调度策略
- 通知OpenClaw龙虾Agent：更新执行配置
