## 一、协议概述

Brainworm攻击是2026年AI Agent领域新涌现的威胁类型——恶意文件或网络服务通过工具输出、记忆注入、外部技能加载三个通道向Agent注入恶意指令，试图夺取Agent的系统控制权。本协议建立三层卡口流量过滤系统，在数据进入Agent上下文之前进行检测、标记和拦截。

## 二、威胁模型

### 2.1 Brainworm攻击向量

```
攻击向量1：工具输出注入
  恶意网站/API → Agent调用工具 → 工具输出含恶意指令
  → Agent将恶意输出作为上下文 → 执行恶意操作

攻击向量2：记忆污染
  恶意文件注入 → 写入Agent记忆层 → Agent召回记忆时
  → 将恶意内容作为"已知事实" → 基于污染记忆决策

攻击向量3：技能供应链攻击
  恶意技能包 → Agent加载外部技能 → 技能含隐藏指令
  → Agent执行技能时触发后门
```

### 2.2 攻击特征

| 特征类型 | 检测模式 | 示例 |
|---------|---------|------|
| 命令注入 | 系统命令模式 | `rm -rf /`、`format C:` |
| 提权指令 | sudo/管理员模式 | `sudo`、`RunAs` |
| 路径遍历 | ../序列 | `../../../etc/passwd` |
| 恶意URL | 已知恶意域名 | 钓鱼网站、C2服务器 |
| 隐藏指令 | 不可见字符/编码 | Zero-width字符、Base64编码指令 |
| 越权引用 | 越界文件路径 | 系统目录、其他用户文件 |

## 三、三层卡口防御架构

### 3.1 卡口1：工具输出过滤（Tool Output Gate）

```
流程：
  工具执行结果 → [流量过滤器] → [边界标记] → 传入Agent上下文

过滤规则：
  - 命令注入检测：正则匹配系统命令模式
  - 路径遍历检测：解析绝对路径，拒绝越界
  - 提权指令检测：匹配sudo/RunAs/管理员模式
  - 恶意URL检测：比对已知恶意域名库
  - 不可见字符检测：Unicode零宽字符/控制字符扫描

动作策略：
  [MALICIOUS_DETECTED] → 截断输出 + 替换为安全占位符
  [SUSPICIOUS_DETECTED] → 边界标记 + 降低置信度权重
  [CLEAN] → 正常传入
```

### 3.2 卡口2：召回记忆过滤（Memory Recall Gate）

```
流程：
  记忆检索结果 → [内容校验] → [签名验证] → 传入Agent上下文

校验规则：
  - 内容完整性：比对记忆写入时的哈希值
  - 来源可信度：检查记忆来源是否可信（用户直接输入 > Agent推断 > 外部源）
  - 时效性：标记陈旧记忆可能已被污染
  - 污染模式匹配：比对已知Brainworm注入模式

恢复策略：
  - 检测到污染 → 隔离标记该记忆条目
  - 回退到上一个已知安全版本（checkpoint）
  - 触发全量记忆审计
```

### 3.3 卡口3：外部技能加载过滤（Skill Load Gate）

```
流程：
  技能文件加载 → [静态分析] → [沙盒模拟] → 加载到Agent

静态分析规则：
  - DANGEROUS_PATTERNS匹配：系统调用/网络请求/文件删除/进程控制
  - 权限声明审计：技能声明权限是否超出其功能所需
  - 依赖链分析：检查引入的第三方依赖是否可疑

沙盒模拟：
  - 受限Docker容器中模拟执行
  - 监控所有系统调用和网络请求
  - 检测异常行为模式

动作策略：
  [PASS] → 正常加载
  [WARN] → 沙盒隔离执行 + 请求用户审计确认
  [BLOCK] → 拒绝加载 + 记录审计日志
```

## 四、全局安全策略

### 4.1 Bitwarden统一密钥管理

- 所有云端API密钥通过Bitwarden Secrets Manager统一托管
- 一个bootstrap token替代多Provider分散密钥
- 密钥轮换自动化

### 4.2 全局冻结机制

当任意卡口检测到Brainworm特征时：
1. 立即冻结当前Agent的所有执行权限
2. 生成完整攻击审计报告
3. 回滚到最近安全checkpoint
4. 请求用户确认后解除冻结

### 4.3 不可篡改审计日志

```
每个过滤事件记录：
{
  "timestamp": "ISO8601",
  "gate": "tool_output|memory_recall|skill_load",
  "source": "路径/来源标识",
  "detection": "匹配的规则ID",
  "action": "block|mark|pass",
  "hash": "事件内容哈希（防篡改）"
}
```

## 五、豆包Agent适配方案

1. **工具输出卡口**：在File/Computer/App/Browser/Search五个子Agent的工具返回管道中嵌入过滤器
2. **记忆卡口**：在MemoryOS记忆层增加写入签名+召回校验机制
3. **技能卡口**：在SkillForge技能加载流程中嵌入静态分析+沙盒模拟
4. **Bitwarden集成**：统一管理豆包Agent所需的GPT/Claude/Gemini等多模型API密钥
5. **审计日志**：与SafeGuard v3.0安全层对接，所有过滤事件写入安全审计链
