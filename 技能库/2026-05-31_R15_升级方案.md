# 豆包Agent R15 全维度迭代升级方案

> 生成时间: 2026-05-31 18:30

## Dynamic Workflows 军团模式

- **对标**: Claude Opus 4.8 Dynamic Workflows
- **优先级**: P0
- **当前**: 单一Agent线性执行
- **目标**: 主Agent自动编写编排脚本 → 拆分任务 → 派发子Agent池 → 质疑Agent验证 → 迭代收敛

**实现路径**:

1. 引入编排脚本引擎（Python DSL生成）
2. 子Agent池：最多同时派发N个子Agent并行执行
3. 质疑Agent：独立Agent专门挑战/验证前期结论
4. 迭代收敛机制：结果冲突时自动多轮投票/仲裁
5. 进度实时保存+断点恢复

## GEPA自进化技能引擎

- **对标**: Hermes GEPA Engine
- **优先级**: P0
- **当前**: 手动编写技能
- **目标**: 自动从成功交互中提取技能→Markdown+YAML→补丁式增量更新

**实现路径**:

1. 交互监听器：检测工具调用≥5次或修复错误的交互
2. 技能提取器：自动生成 Markdown+YAML 结构技能文件
3. 补丁更新器(Patch)：仅修改问题片段，避免全量重写
4. 技能检索器：SQLite FTS5 全文索引
5. 技能市场：支持 agentskills.io 开放格式共享

## 四层记忆架构

- **对标**: Hermes 四层记忆 + Codex Memory + Claude 持久化
- **优先级**: P0
- **当前**: 单一会话上下文
- **目标**: L1身份/L2会话/L3任务/L4长期(SQLite FTS5 + 向量检索)

**实现路径**:

1. L1 身份记忆：用户偏好/习惯/工具链配置
2. L2 会话记忆：当前对话上下文（现有能力）
3. L3 任务记忆：任务目标+中间步骤+产物（新增）
4. L4 长期记忆：跨会话知识积累（SQLite FTS5 + 向量DB）
5. 记忆注入：每次对话前无感注入L1+L4

## ACP协议 + 子Agent隔离执行

- **对标**: OpenCode ACP + Gemini 子Agent隔离
- **优先级**: P2
- **当前**: 无标准Agent通信协议
- **目标**: ACP协议+子Agent沙箱隔离+摘要回传+状态持久化

**实现路径**:

1. ACP协议集成（Agent Communication Protocol）
2. 子Agent沙箱：Docker/进程隔离
3. 摘要回传：子Agent只回传结论，不污染主上下文
4. 沙箱持久化：关闭后状态保留
