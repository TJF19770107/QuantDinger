# 多模态输入处理器 v1.0

**对标来源**: Gemini CLI (Any-to-Any多模态)  
**创建日期**: 2026-05-31  
**类别**: 多模态  
**优先级**: P1  
**关联技能**: LocalASR, LocalTTS, LocalTxt2Img

---

## 一、概述

豆包Agent的多模态输入处理系统，对标Gemini CLI的原生多模态能力。支持图片、视频、音频、PDF等多种输入类型。

## 二、支持的输入类型

### 2.1 图像处理
- 截图→代码生成 (UI截图→生成Flutter/React代码)
- 图表→数据提取 (柱状图/表格→结构化数据)
- 手写→文字 (手写笔记→数字文本)
- 拍照→信息提取 (名片/发票/收据→结构化信息)
- 图片→多语言OCR

### 2.2 音频处理
- 语音→文字 (会议录音→会议纪要)
- 音频→分析 (音乐识别/环境音识别)
- 实时语音交互

### 2.3 视频处理
- 视频→关键帧提取
- 视频→字幕生成
- 教程视频→步骤提取

### 2.4 文档处理
- PDF→结构化文本
- 扫描件→OCR+结构化
- 表格→数据提取

## 三、处理流水线

```
原始输入
    ↓
类型检测 (图片/音频/视频/文档)
    ↓
预处理 (降噪/去偏/分辨率调整)
    ↓
模型路由
    ├── 图像 → Gemini 3.5 Flash (原生多模态)
    ├── 音频 → Whisper (语音转文字)
    ├── 视频 → Gemini + FFmpeg (帧提取+分析)
    └── 文档 → Markitdown + LLM
    ↓
后处理 (格式化/结构化/去重)
    ↓
上下文注入 → Agent继续处理
```

## 四、触发词

| 输入类型 | 触发词示例 |
|---------|-----------|
| 图片 | "看看这张图"、"分析这个截图"、"识别图片中的文字" |
| 音频 | "转录这段录音"、"这段音频说了什么" |
| 视频 | "这个视频讲了什么"、"提取视频中的关键内容" |
| 文档 | "读一下这个PDF"、"提取这个表格" |
