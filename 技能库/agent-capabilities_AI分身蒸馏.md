## 四、跨Agent协作协议

### 4.1 通信协议

| 协议项 | 规范 |
|--------|------|
| **通信方式** | 文件级消息传递（写入→读取→校验） |
| **中间产物** | 步骤1-4 的产出作为步骤2-6 的输入 |
| **状态同步** | Hermes Agent 维护 `distillation_state.json` 跟踪当前进度 |
| **异常通知** | 任意 Agent 遇到不可恢复错误 → 写入 `deadletter` 并通知 Hermes Agent |

### 4.2 交接点定义

```
步骤1 完成 → 用户人格画像写入磁盘 → Hermes 校验 → 触发步骤2
步骤2 完成 → 进化规划写入磁盘 → Hermes 校验 → 触发步骤3
步骤3 完成 → 转换日志写入磁盘 → Hermes 校验 → 触发步骤4
步骤4 完成 → 知识库索引写入磁盘 → Hermes 校验 → 触发步骤5
步骤5 完成 → 技能配置写入磁盘 → Hermes 校验 → 触发步骤6
步骤6 完成 → 核心配置更新 → Hermes 全局一致性校验 → 结束
```

### 4.3 并发控制

```
单实例运行（max_instances: 1）
├── 若检测到已有蒸馏任务运行中：
│   ├── 定时触发 → 排队等待，最多排队 1 次
│   ├── 手动触发 → 通知用户当前已有任务运行中
│   └── 异常触发 → 强制取消当前任务，启动新蒸馏
└── 任务完成 → 释放锁，允许下次触发
```
