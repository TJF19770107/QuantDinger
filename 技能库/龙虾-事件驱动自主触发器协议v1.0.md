# 龙虾-事件驱动自主触发器协议 v1.0

> **对标来源**：OpenAI Codex Triggers + Google Antigravity 2.0 Scheduled Tasks + Hermes v0.15.0 定时启动
> **版本**：v1.0 | **创建日期**：2026-06-01 | **所属迭代**：R19
> **核心价值**：支持cron定时、GitHub事件、系统告警等多源触发，Agent无人值守自主执行

---

## 一、协议概述

Agent不依赖人工手动唤起，可通过多种事件源自动触发执行。适用于持续集成、例行巡检、数据管道维护等场景。

---

## 二、触发器类型

| 类型 | 来源 | 示例 | 适用场景 |
|------|------|------|---------|
| cron定时 | Antigravity Scheduled Tasks | 每日09:00生成PR摘要 | 例行报告 |
| GitHub事件 | Codex Triggers | Issue创建→自动修复开PR | CI/CD |
| Webhook | OpenClaw MCP Gateway | 告警→自动诊断 | 运维响应 |
| 系统事件 | Hermes定时启动 | 过期检测+自动重试 | 任务管理 |
| 文件变更 | 本地Watch | 新文件→自动归类 | 文件整理 |

---

## 三、Codex Triggers流水线

```
GitHub Issue创建 → Codex感知 → 扫描仓库 → 定位文件 → 沙盒执行
    → 自动测试 → 修复失败 → 提交PR → 通知Review
```

全流程无需人类介入，仅在PR阶段需要人工Review。

---

## 四、Antigravity Scheduled Tasks（cron）

```
/schedule "每日09:00汇总昨日Git提交" --cron "0 9 * * 1-5"
/schedule "每小时检查CI状态" --cron "0 * * * *"
```

执行结果自动汇总到侧边栏Inbox，支持人类随时介入。

---

## 五、Hermes v0.15.0 任务管理

| 能力 | 说明 |
|------|------|
| 定时启动 | 任务到预定时间自动唤醒Agent |
| 过期检测 | 超时任务自动标记并通知 |
| 自动重试 | 失败任务按策略自动重新执行 |
| Worker可视化 | 实时查看每个worker状态和输出 |

---

## 六、安全约束

- 所有触发器必须声明作用域（文件/目录/命令白名单）
- 高危操作（删除/格式化/外发数据）禁止无人值守执行
- 每次触发执行全量审计日志
- 支持紧急停止令牌（Break Token）随时中断
