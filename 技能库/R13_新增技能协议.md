## 技能 #56：实时情报蒸馏自动化协议

### 技能名称
Real-time Intelligence Distillation Automation Protocol (RIDAP)

### 触发条件
1. 用户发出"全域蒸馏"、"R1X迭代"、"情报汇总"等蒸馏类指令
2. 定时任务触发（每2小时/每日自动蒸馏）
3. 情报源有新内容推送（GitHub Trending更新 / 论文发布 / 行业大事件）

### 核心指令
1. **多源并行抓取**：同时从GitHub Trending、arXiv、X(Twitter)、B站、知乎、腾讯新闻、网易、CSDN、掘金等8+渠道抓取最新AI Agent相关情报
2. **情报分级过滤**：按三级分类法对所有情报自动标注——
   - 🔴S级（战略级）：Agent自进化突破、底层协议变革、生态标准确立
   - 🟡A级（战术级）：新工具发布、教程体系升级、行业规范变更
   - 🟢B级（资讯级）：产品更新、个人实践、趋势评论
3. **去重与关联**：对跨平台重复情报自动去重，识别同一事件的多源报道并关联为条目簇
4. **结构化输出**：每条情报输出标准五段式——来源/时间/核心发现/关键洞察/关联技能协议
5. **增量更新**：仅新增情报写入，历史情报不重复覆盖，情报库标记增量版本号

### 输入规范
- 触发指令：自然语言描述（如"执行R13全域蒸馏"）
- 可选参数：指定渠道（`--channels`）、时间范围（`--since`）、情报等级阈值（`--min-level`）

### 输出规范
- 主输出：《R[N]_全域情报库.md》→ 知识库/
- 增量日志：《R[N]_增量情报日志.md》→ 知识库/
- 分类统计：情报分类统计表（领域×条目数×代表来源）
- 对比分析：与上一轮情报库的维度变化对比

### 质量标准
- 情报覆盖率：≥8个独立渠道
- 情报时效性：抓取时间与情报发布时间差≤24小时
- 去重率：≥95%（同一事件不重复记录）
- 分析深度：每板块≥300字关键洞察
- 总篇幅：≥3000字

## 技能 #57：跨平台Agent同步与无差异部署协议

### 技能名称
Cross-Platform Agent Sync & Undifferentiated Deployment Protocol (CPAS)

### 触发条件
1. 新建或修改数字分身配置（SOUL.md/USER.md/AGENTS.md）
2. 新增子Agent或扩展平台覆盖范围
3. 跨平台一致性巡检发现偏差
4. 用户指令"同步所有Agent"、"部署到新平台"

### 核心指令
1. **配置中心化管理**：以角色总说明书目录下的SOUL.md/USER.md/AGENTS.md为唯一配置源（Single Source of Truth），所有平台Agent从同一配置源拉取
2. **平台适配层**：为每个目标平台（桌面端/微信/抖音/视频号/小红书/X(Twitter)/币安生态）建立适配层，将核心配置翻译为平台原生格式
3. **一致性校验**：部署后自动执行跨平台行为一致性测试——
   - 同一问题在不同平台上的回复风格是否一致
   - 人格宪法（SOUL.md）定义的边界是否在所有平台上生效
   - 数字分身形象/声音是否跨平台对齐
4. **无差异部署**：基于Hermes v0.9.0跨平台能力（支持Termux/Android/iMessage/WeChat），实现一次配置、多平台部署
5. **差异告警**：检测到跨平台不一致时自动告警并记录偏差日志

### 输入规范
- 核心配置路径：`角色总说明书/SOUL.md`、`USER.md`、`AGENTS.md`
- 目标平台列表：`["desktop", "wechat", "douyin", "shipinhao", "xiaohongshu", "x", "binance"]`
- 部署模式：`full`（全量部署）/ `incremental`（增量更新）/ `check`（仅校验）

### 输出规范
- 部署报告：《跨平台部署报告_[时间戳].md》→ 定时任务/蒸馏日志/
- 一致性报告：《跨平台一致性校验报告_[时间戳].md》→ 定时任务/蒸馏日志/
- 偏差日志：《平台偏差记录_[时间戳].md》→ 知识库/

### 质量标准
- 部署成功率：≥99%
- 一致性偏差容忍度：<5%（回复风格/人格边界）
- 部署延迟：<30秒（单平台）
- 回滚能力：支持一键回滚至上一稳定版本

## 技能 #58：加密AI与链上Agent交互协议

### 技能名称
Crypto-AI & On-Chain Agent Interaction Protocol (CAIP)

### 触发条件
1. 用户询问加密货币/AI Agent相关话题
2. 涉及链上数据检索、代币化资产分析、合约风险评级
3. 需要调用币安AI Agent Skills或Trust Wallet Agent Kit
4. 自动监控链上Agent数量/交易量等关键指标变化

### 核心指令
1. **情报监控**：持续跟踪BNB Chain链上Agent指标——
   - Agent总数变化（当前16.9万，监控日增幅）
   - 代币化资产总市值变化
   - 新上线AI Agent项目扫描
2. **技能矩阵调用**：集成Binance 11项AI Agent Skills——
   - 行情类：Binance Spot Skill / Crypto Market Rank / Alpha Skill
   - 查询类：Query Address Info / Query Token Info / Query Token Audit
   - 交易类：衍生品技能（70+合约接口）/ 杠杆技能（10倍）/ 资产管理
   - 信号类：Trading Signal / Meme Rush
3. **链上分析流水线**：Surf Skill数据检索（14领域83项指令）→ Binance-web3 Skill风险排查→认知推演→执行动作
4. **安全第一**：所有链上交易操作必须经过——
   - 合约风险评级（≥B级方可执行）
   - 滑点保护（默认1%，可配置）
   - 交易限额（单笔上限可配置）
   - 人工确认（≥阈值时触发）

### 输入规范
- 查询指令：自然语言（如"分析BTC当前市场情绪"、"查看0x地址持仓"）
- 交易指令：需明确交易对/方向/金额/滑点
- 监控指令：指定监控指标+告警阈值

### 输出规范
- 分析报告：《链上分析报告_[主题]_[时间].md》→ 知识库/
- 交易记录：《AI交易日志_[时间].md》→ 知识库/
- 风险告警：实时推送至主控面板

### 质量标准
- 数据时效性：链上数据延迟≤30秒
- 交易安全：零未经授权交易
- 合约评级准确率：≥95%
- 响应时间：查询类<3秒，分析类<30秒

## 技能 #59：网文AI辅助创作全链路协议

### 技能名称
Web Novel AI-Assisted Creation Full-Pipeline Protocol (WNAF)

### 触发条件
1. 用户提出网文创作需求（小说/短篇/连载/剧本）
2. 需要AI辅助大纲/人设/情节/对话/伏笔管理
3. 需要对已有网文稿件进行AI润色/逻辑校验/设定一致性检查
4. 涉及多平台发布适配（番茄/起点/晋江/七猫/飞卢）

### 核心指令
1. **创作模式识别**：自动识别用户需求属于哪种模式——
   - 量产型（番茄/七猫）：更新快+节奏猛+爽点密度高 → AI辅助产能提升+崩盘概率降低
   - 精品型（起点主流）：世界观+体系+逻辑+伏笔+长线秘密 → AI做逻辑校验和设定管理
   - IP化型（短剧/漫改/有声）：跨媒介改编适配 → AI做格式转换+场景可视化
2. **多模型协作写作工作流**：
   - 逻辑模型：负责剧情一致性校验、伏笔管理、设定冲突检测
   - 节奏模型：负责章节节奏分析、爽点密度优化、高潮位点设计
   - 文风模型：负责语言风格统一、对话自然度优化
   - 情绪模型：负责情感线追踪、读者情绪曲线设计
   - 台词模型：负责角色个性化台词生成
3. **平台合规检查**：
   - 番茄平台：正文原创性≥70%（AI辅助≠AI生成），不触发低质内容治理
   - 起点平台：设定独立性校验，不触发AI写作检测
   - 晋江平台：三级红线机制合规检查
   - 飞卢平台：确保无AI生成痕迹（奖励资格要求）
4. **人机协作红线**：
   - AI只做辅助，不做主力——人类主导剧情、人设、核心表达
   - 正文亲手写或深度修改——AI生成内容修改率≥30%
   - 保持原创——不洗稿、不搬运、不批量生产
   - 了解规则——关注平台公告，避开红线

### 输入规范
- 创作指令：包含类型/字数/风格/平台/核心创意
- 稿件输入：支持MD/TXT/DOCX格式
- 参考输入：可指定参考作品或风格样本

### 输出规范
- 大纲文件：《[作品名]_大纲.md》→ 工作目录/output/
- 人设文件：《[作品名]_人设表.md》
- 伏笔管理：《[作品名]_伏笔追踪表.md》
- 章节稿件：《[作品名]_第N章.md》
- 合规报告：《[作品名]_平台合规检查.md》

### 质量标准
- 逻辑一致性：伏笔回收率≥90%
- 平台合规：零违规处置
- 创作效率：AI辅助下产出效率提升≥200%
- 人类主导度：AI生成内容人工修改率≥30%

## 技能 #60：数字分身全平台运营协议

### 技能名称
Digital Twin Cross-Platform Operations Protocol (DTCP)

### 触发条件
1. 首次创建数字分身（触发完整六步蒸馏流程）
2. 数字分身部署到新平台
3. 数字分身形象/声音/人格需要更新
4. 用户指令"运营我的数字分身"、"更新数字分身"

### 核心指令
1. **分身创建（六步蒸馏法升级版）**：
   - ① 分析自己：MBTI测试+AI对话记录分析+行为模式聚类
   - ② 制定计划：个人五年规划+数字分身发展路线
   - ③ 转换文件：聊天记录/简历/笔记→结构化MD格式
   - ④ 分析文件：LLM深度提炼人格/价值观/偏好/边界
   - ⑤ 建立SKILL：生成个性化技能协议
   - ⑥ 更新配置：同步SOUL.md/USER.md/AGENTS.md至所有平台
2. **全平台部署矩阵**：

| 平台 | 适配模式 | 核心能力 |
|------|----------|----------|
| 桌面端（Marvis） | 原生 | 全功能AI分身交互 |
| 微信 | Hermes v0.9.0 | 消息处理/朋友圈互动 |
| 抖音 | 数字人直播 | 合规标注+人机结合 |
| 视频号 | 数字人口播 | 素人替代+品类匹配 |
| 小红书 | 虚拟博主 | 内容创作+社区互动 |
| X(Twitter) | MCP X Server | 发推/搜索/互动 |

3. **形象与声音管理**：
   - 形象克隆：基于30秒-5分钟真人视频素材生成1:1数字分身
   - 声音克隆：基于5-10秒音频样本复刻音色与语调
   - 一致性保障：确保跨平台形象/声音/人格三位一体
4. **内容生产流水线**：
   - 脚本生成：基于SOUL.md人格+热点追踪自动生成口播脚本
   - 视频合成：数字人出镜+背景替换+字幕同步
   - 多平台分发：一条内容自动适配多平台格式
   - 互动管理：AI自动回复评论+私信（遵循人格宪法边界）
5. **合规运营红线**：
   - 抖音：显著标注"AI虚拟主播"，内容100%真实性
   - 视频号：虚实融合内容标注"AI生成内容"
   - 小红书：不伪装真人，透明化AI身份
   - 全平台：数字人说的话由运营者承担全责

### 输入规范
- 创建指令：需提供真人视频素材+语音样本+人格描述
- 运营指令：指定平台+内容方向+发布频率
- 更新指令：指定更新维度（形象/声音/人格/知识）

### 输出规范
- 分身配置：《[分身名称]_SOUL.md / USER.md / AGENTS.md》→ 角色总说明书/
- 运营报告：《数字分身运营周报_[日期].md》→ 知识库/
- 内容日历：《数字分身内容日历_[月份].md》→ 定时任务/
- 合规报告：《平台合规审查报告_[日期].md》→ 知识库/

### 质量标准
- 形象相似度：≥95%（真人对比评估）
- 声音相似度：≥90%（音频对比评估）
- 跨平台一致性：偏差<5%
- 内容产量：日更≥1条/平台（视平台策略调整）
- 合规率：100%（零违规处置）
- 用户满意度：互动率较纯人工提升≥150%
