## 一、协议概述

将自愈式编码从"报错再修复"的被动模式，升级为"自验证先行→预防性修复"的主动模式。核心突破来自ReVeal论文的TAPO轮次级信用分配与推理时自进化机制。

## 二、核心机制

### 2.1 自验证先行 (Verify-before-Fix)

```
代码生成 → 自验证(self-constructed tests + tool feedback)
  ├─ 验证通过 → 提交
  └─ 验证失败 → 修复循环 → 再次自验证 → ...
```

**区别于旧协议**：旧协议等编译器报错再修复；新协议主动构造测试用例，在提交前完成验证。

### 2.2 TAPO轮次级信用分配

长周期推理分解为多轮"生成→验证"迭代，每轮独立信用分配：

| 轮次类型 | 信用权重 | 判定条件 |
|---------|:---:|------|
| 发现Bug轮 | 3.0x | 验证发现新缺陷 |
| 通过Edge Case轮 | 2.5x | 通过边界测试 |
| 常规改进轮 | 1.0x | 代码质量提升但无新发现 |
| 无效轮 | 0.2x | 改动无实质影响 |

### 2.3 推理时自进化

- 训练仅需3轮基础数据
- 推理时可自主进化 **20+轮**
- Pass@k持续提升，不受基座模型推理边界限制

### 2.4 工具反馈闭环

外部信号源（编译器警告/静态分析/lint结果/测试覆盖率）自动注入验证循环，权重与模型自身判断融合。

## 四、实施要点

1. 每次代码生成必须先运行自验证
2. 自验证测试由Agent自主构造（基于任务描述推断edge cases）
3. 工具反馈（lint/编译/静态分析）权重 ≥ 模型自评权重
4. TAPO信用记录持久化至记忆层
5. 推理时进化上限：20轮（超时终止）
