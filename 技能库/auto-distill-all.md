# Self-Skill：全域自动蒸馏技能
**技能名称**: auto-distill-all
**版本**: v1.0
**所属**: 龙虾AI主控中心 → AI分身 → 技能库
**创建日期**: 2026-05-31

---

## 技能描述
每2小时自动执行全域16平台信息抓取、趋势蒸馏、分身进化、配置同步的全闭环自动化技能。

## 触发方式
- 定时触发（每2小时）
- 手动触发：输入"全域蒸馏"或"嗡阿喇巴札那谛"

## 执行流程

### Phase 1: 前置检查（~5s）
1. 读取 `E:\龙虾AI主控中心\我的AI分身\角色总说明书\角色总说明书.md`
2. 验证目录结构完整性
3. 读取上次蒸馏日志，获取增量上下文

### Phase 2: 全平台抓取（~30s）
对以下16平台并行抓取最新内容：
- B站 / GitHub / 视频号 / 抖音 / 小红书
- 今日头条 / 公众号 / 七猫 / 起点 / 奇妙
- 纵横 / 番茄 / 油管YouTube / X / 搜狐 / 币安

抓取策略：
- 公开平台：web_search 获取最新趋势
- 封闭平台：通过第三方报道间接获取
- 关键数据点：新功能/融资/政策/爆款/行情

### Phase 3: 蒸馏加工（~15s）
1. MD5内容去重
2. 关键趋势提炼（按7大领域分类）
3. 用户画像动态更新
4. 知识库增量归档

### Phase 4: 分身进化（~20s）
1. 更新用户人格画像
2. 生成进化规划
3. 创建/更新专属技能
4. 同步SOUL/USER/AGENTS配置

### Phase 5: 闭环归档（~10s）
1. 生成蒸馏日志
2. 更新记忆库
3. 全域同步子Agent
4. 返回执行摘要

## 依赖
- `角色总说明书.md`：顶层规则
- `web_search`：全平台信息抓取
- `write_file`：产出物归档
- `dispatch_task(computer-agent)`：系统级操作
- `dispatch_task(file-agent)`：文件管理操作

## 输出
| 产出物 | 路径 |
|--------|------|
| 蒸馏日志 | `定时任务/蒸馏日志/蒸馏日志_YYYYMMDD_HHMM.md` |
| 知识库 | `知识库/全域知识库_YYYYMMDD.md` |
| 用户画像 | `知识库/用户人格画像_YYYYMMDD.md` |
| 进化规划 | `知识库/AI分身进化规划_YYYYMMDD.md` |
| 子Agent配置 | `子Agent/{Name}Agent/SOUL.md` 等 |

## 容错规则
- 单平台抓取失败：跳过并记录，不中断流程
- 写文件失败：重试1次，仍失败则记录异常
- 全流程失败：在下次执行时自动恢复

## MD5去重规则
- 知识库写入前，遍历同目录文件计算MD5
- 内容重复率>90%视为重复，跳过写入
- 白名单URL去重：读取`url_whitelist.json`过滤
