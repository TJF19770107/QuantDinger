# Self-Skill：全域蒸馏 v25
## 技能名称：lobster-global-distillation
## 版本：v25 | 更新：2026-06-07
## 所属：龙虾AI主控中心 → AI分身 → 技能库

---

## 技能描述
全域全自动AI分身蒸馏技能，每2小时自动执行一轮完整蒸馏循环：
1. 前置读取顶层规则
2. 全域全平台抓取学习（16平台）
3. 严格按顺序蒸馏AI分身（6步）
4. 全域同步迭代所有Agent
5. 强制存储至指定路径
6. 闭环确认

## 触发方式
- 定时任务自动触发（每2小时）
- 手动指令："执行全域蒸馏"

## 执行参数
```
PLATFORMS = ["B站", "GitHub", "视频号", "抖音", "小红书", "今日头条", "公众号", "七猫", "起点", "奇妙", "纵横", "番茄", "油管YouTube", "X推特", "搜狐", "币安"]
ROOT_PATH = "E:\龙虾AI主控中心\我的AI分身"
RULE_FILE = "{ROOT_PATH}\角色总说明书\角色总说明书.md"
```

## 核心约束
1. **实事求是**：不虚构数据、不编造内容、不产生幻觉
2. **MD5去重**：所有产出入库前强制去重
3. **统一路径**：严格使用ROOT_PATH下的目录结构
4. **全域迭代**：同步更新所有子Agent

## 执行流程
### Phase 0: 前置读取
- 读取角色总说明书
- 激活顶层规则
- 确认目录结构

### Phase 1: 全域抓取
- 对PLATFORMS中的每个平台执行web_search
- 每批5个平台并行
- 提取标题、链接、摘要、时间

### Phase 2: 信息蒸馏
- 分类归档：大模型/框架/内容创作/Agent/行业趋势
- 去重合并
- 生成全域学习报告

### Phase 3: 分身蒸馏（严格按顺序）
- ① 分析自己：更新用户人格画像
- ② 制定计划：更新AI分身进化规划
- ③ 文件转换：所有文件无损转MD
- ④ 构建知识库：全域学习内容入库
- ⑤ 创建self-skill：更新本技能文件
- ⑥ 更新核心配置：SOUL.md / USER.md / AGENTS.md

### Phase 4: 全域同步
- 同步豆包Agent配置
- 同步Hermes Agent配置
- 同步OpenClaw龙虾Agent配置

### Phase 5: 归档闭环
- 写入蒸馏日志
- 清除临时文件
- 确认下一轮触发时间
