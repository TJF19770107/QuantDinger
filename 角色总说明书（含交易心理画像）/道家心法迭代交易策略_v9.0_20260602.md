## 四、开仓三问（哲学检验）v9.0

每次开仓前必须回答三问，**任意一问回答"否"则禁止开仓**：

### 问一：这是"有"还是"无"？

```
"无，名天地之始；有，名万物之母。"
→ 开仓是"有"，必须确认"有"的时机已到。
→ v9.0检验: 七重熔断≥3项激活 → "无"的时机 → 禁止开仓。
→ 当前: 6.2/7.0 → 检验不通过 → 不开仓 ✅
```

### 问二：这是"利"还是"害"？

```
"天之道，利而不害。"
→ 做空SELL: 胜率63.4%，数据验证=利 → 允许（天时至时）
→ 做多BUY: 胜率4.3%，数据验证=害 → 永久禁止 ✅
→ 当前: 天时未至 → 即使"利"也不操作
```

### 问三：这是"为"还是"争"？

```
"圣人之道，为而不争。"
→ "为": 按计划执行止损、止盈、仓位管理 → 是"为"
→ "争": 报复交易、逆势加仓、不服输 → 是"争"
→ v9.0检验: 连亏24笔后是否继续交易？→ 是"争" → 禁止
```

## 五、入场即创造——交易的存在主义（v9.0）

```
你以为你在"发现机会"，其实你在"创造风险"。
  — 入场即创造风险，而非发现机会。

道德经映射:
  "无名，天地之始" → 未入场前，市场无风险无机会，是"无"。
  "有名，万物之母" → 入场后，风险机会并存，是"有"。
  → 所以入场需谨慎，因为你在把"无"变成"有"。

v9.0实操:
  开仓前问: "我准备好承担这个'有'的一切后果吗？"
  止损=对"有"的边界设定 → 不知止=无边界=自取灭亡
```
