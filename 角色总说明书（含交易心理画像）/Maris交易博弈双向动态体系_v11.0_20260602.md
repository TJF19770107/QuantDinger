# Maris交易博弈双向动态体系 v11.0

> **版本**：v11.0 | **生成日期**：2026-06-02 | **底层逻辑**：道家心法 + 博弈论
> **核心原则**：**敌不动我不动，敌一动我必先动**

---

## 一、体系总纲

### 1.1 三层架构

```
┌──────────────────────────────────────────────────┐
│              第一层：感知层（观）                    │
│   实时跟踪主力动向 → 监测信号 → 判断当前阶段          │
├──────────────────────────────────────────────────┤
│              第二层：决策层（判）                    │
│   识别主力意图 → 预判主力下一步 → 制定我方策略        │
├──────────────────────────────────────────────────┤
│              第三层：执行层（动）                    │
│   先于主力行动 → 仓位管理 → 止盈止损执行             │
└──────────────────────────────────────────────────┘
```

### 1.2 核心博弈规则

| 规则 | 内容 |
|------|------|
| **敌不动我不动** | 主力未入场→我方空仓等待。耐心是第一武器 |
| **敌一动我必先动** | 检测到主力入场信号→抢先布局，不等确认 |
| **敌进我退** | 主力拉升出货阶段→我方减仓，不贪最后利润 |
| **敌退我进** | 主力洗盘杀跌→我方分批加仓，逆向操作 |
| **敌疲我打** | 主力震荡犹豫→我方高抛低吸，赚取波动利润 |

## 二、动态联动规则

### 2.1 主力行为 → 我方策略映射表

| 主力阶段 | 主力行为 | 我方策略 | 仓位 | 止损 |
|---------|---------|---------|:---:|------|
| **潜伏吸筹** | 股价窄幅震荡，量能萎缩 | 轻仓试探(20%)，等放量确认 | 20% | ATR×2 |
| **主动吸筹** | 放量小涨，OBV上行 | 金字塔加仓至50% | 50% | ATR×1.8 |
| **洗盘** | 急跌放量，假跌破 | **不割肉**，跌至支撑位加仓20% | 70% | 原止损位不变 |
| **拉升初期** | 突破阻力，均线多头 | 加仓至满仓(100%)，追踪止盈开启 | 100% | 追踪止盈4% |
| **拉升中期** | 连续阳线，散户FOMO | 减仓30%，锁定利润 | 70% | 追踪止盈收紧至2% |
| **震荡出货** | 高位横盘，量价背离 | 减仓至30% | 30% | 移动止损至成本+3% |
| **确认出货** | 放量下跌，大单卖出 | **全仓清仓**，不开新仓 | 0% | — |
| **冷却期** | 无明确信号 | **零开仓**，等待周期结束 | 0% | — |

### 2.2 敌动我先动——先行指标

| 先行指标 | 领先时间 | 检测方法 |
|---------|:---:|------|
| OBV能量潮背离 | 1-3天 | OBV上行而价格不涨→主力吸筹 |
| 布林带收窄至<10% | 1-5天 | 爆发前兆，准备入场 |
| 大单买入占比突增 | 数小时 | 监控taker buy volume |
| ETF资金流向逆转 | 1-2天 | ETF净流出→净流入切换 |
| 恐惧指数极端值 | 1-3天 | <20=黄金坑，>80=顶部区 |
| USDT溢价率变化 | 实时 | 溢价扩大=资金进场 |

## 四、策略跟随与迭代

### 4.1 主力策略学习循环

```
┌─────────────────────────────────────────────┐
│  1. 观察主力  →  记录主力入场/出场信号          │
│       ↓                                      │
│  2. 拆解逻辑  →  分析主力为何此时操作           │
│       ↓                                      │
│  3. 验证模式  →  对比历史数据，确认有效性        │
│       ↓                                      │
│  4. 更新策略  →  将新模式加入交易规则库          │
│       ↓                                      │
│  5. 提前布局  →  下次同样信号出现，先于主力行动   │
└─────────────────────────────────────────────┘
```

### 4.2 迭代触发条件

| 触发条件 | 迭代动作 |
|---------|---------|
| 主力改变吸筹节奏 | 调整建仓周期参数 |
| 新型诱多手法出现 | 新增假突破过滤规则 |
| 市场结构变化(牛→熊) | 切换策略模式 |
| 连续3次策略信号失效 | 回测+修正参数 |
| 新黑马品种特征发现 | 扩展品种监控范围 |

## 五、动态制衡策略

### 5.1 虚实结合

| 层面 | 虚（前兆） | 实（确认） | 行动 |
|------|---------|---------|------|
| 入场 | OBV背离（虚） | 放量突破（实） | 虚→轻仓试探，实→加仓 |
| 加仓 | 回调到支撑（虚） | 支撑位确认+缩量（实） | 挂单等待，确认后加仓 |
| 止盈 | RSI超买（虚） | 顶背离+量缩（实） | 虚→减仓30%，实→减仓70% |
| 止损 | 跌破短期均线（虚） | 跌破ATR×2.5止损位（实） | 虚→不操作，实→全清 |

### 5.2 顺势而为原则

```
"天之道利而不害" = 永远不与主要趋势对抗

牛市: 只做多，回调买入，不做空
熊市: 只做空，反弹卖出，不做多
震荡: 高抛低吸，但仓位控制在50%以内
当前(恐慌): 不操作，等待趋势明朗
```

## 七、道家心法贯穿

### 7.1 博弈心法

```
"道可道，非常道" → 市场规律永远在变，策略必须持续迭代
"名可名，非常名" → 不要给市场贴标签（"牛市""熊市"），只看信号
"无，天地之始" → 空仓等待是交易的最高境界
"有，万物之母" → 信号出现时果断行动，创造利润
"天之道利而不害" → 顺势而为，不逆市场而行
"圣人之道为而不争" → 专注执行策略，不情绪化地与市场/主力对抗
```

### 7.2 执行口诀

```
主力不动我不动，耐心空仓等信号
主力异动我先动，先手布局占先机
主力拉升我减仓，不贪最后一口肉
主力洗盘我加仓，逆向操作收筹码
道法自然顺势为，不争不抢稳盈利
```
