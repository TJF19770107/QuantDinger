```
止损缺失 ──→ 大额亏损失控 ──→ 回撤失控 ──→ 爆仓
    ↑                           ↑
    │                           │
过度交易 ←── 做空偏好偏执 ←── 确认偏误
    │                           │
    └──→ 止盈过早 ←──→ 盈亏不对称
              ↑
              │
币种过度分散 ←── FOMO ←── 看到机会就冲
```

> **v2.0 核心洞察**：止损缺失是几乎所有致命错误的"根节点"。只要堵住止损缺失这一个漏洞，大额亏损和回撤失控就会被自然抑制。v2.0的全部修复措施围绕"止损100%执行"展开。
