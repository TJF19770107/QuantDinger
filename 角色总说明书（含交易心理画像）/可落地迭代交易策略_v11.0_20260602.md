## 一、策略执行总纲

### 1.1 核心原则

```
1. 每笔交易必须设止损（非可选，是硬性要求）
2. 盈亏比必须≥2:1，否则不开仓
3. 单品种仓位≤账户5%
4. 同时持仓品种≤3个
5. 每日最大亏损限额=账户3%
6. 每周至少休息1天（不交易）
```

### 1.2 交易时段限定

| 时段 | 操作 | 说明 |
|------|------|------|
| 08:00-11:00 | 🟢 主力交易 | 亚盘早盘，主力活跃 |
| 14:00-18:00 | 🟢 主力交易 | 欧盘+美盘预备 |
| 20:00-22:00 | 🟢 主力交易 | 美盘主力时段 |
| 其他时段 | 🔴 仅监控 | 不开新仓，只管理已有持仓 |

## 二、入场规则

### 2.1 多条件确认（AND逻辑，全部满足才入场）

| # | 条件 | 参数 | 权重 |
|---|------|------|:---:|
| 1 | 布林带外溢 | 价格突破上轨且带宽>22% | 必选 |
| 2 | RSI确认 | RSI在55-72之间（不超买） | 必选 |
| 3 | 成交量 | 当前量>20日均量的1.5倍 | 必选 |
| 4 | 均线排列 | 5日>10日>20日（多头排列） | 必选 |
| 5 | 恐惧指数 | 20-60之间（不在极端区间） | 强烈推荐 |
| 6 | ETF流向 | 近3日无连续净流出 | 强烈推荐 |

### 2.2 入场仓位（金字塔模式）

```
第一笔（信号确认）: 账户3%（试探仓）
第二笔（盈利>1%）: 账户5%（加仓，总仓位8%）
第三笔（盈利>3%）: 账户5%（加仓，总仓位13%）
——注意总仓位不超过15%（单品种）
```

### 2.3 禁止入场场景

- 恐惧指数<20或>80（极端区间）
- ETF连续3日净流出
- 已触发日亏损3%熔断
- 非允许交易时段
- 品种不在Top10白名单内

## 三、止盈止损规则

### 3.1 止损（强制，不可跳过）

| 类型 | 参数 | 说明 |
|------|------|------|
| 初始止损 | 入场价 - ATR(14)×2.5 | 山寨币；主流币用1.8 |
| 移动止损 | 最高价 - ATR×2.0 | 盈利后开始追踪 |
| 时间止损 | 持仓7天未盈利 | 强制平仓，避免资金沉淀 |
| 日亏损熔断 | 日亏损达账户3% | 当日剩余时间禁止开仓 |

### 3.2 止盈（阶梯式）

```
第一目标（50%仓位）: 盈利=止损金额×2.0 → 止盈一半
第二目标（30%仓位）: 追踪止盈4% → 跟随趋势
放飞仓（20%仓位）: 移动止损至成本+3% → 让利润奔跑
```

### 3.3 具体数值示例

```
入场价: 10.00 USDT
ATR(14): 0.40 USDT
止损价: 10.00 - 0.40×2.5 = 9.00 USDT (亏损1.00)
第一止盈: 10.00 + 1.00×2.0 = 12.00 USDT (盈利2.00) → 平50%
第二止盈: 开启追踪止盈4% (从最高点回撤4%平仓)
放飞仓: 移动止损至10.30 USDT → 保本+3%
```

## 四、仓位管理规则

### 4.1 账户资金分配

| 层级 | 占比 | 用途 |
|------|:---:|------|
| 交易资金 | 80% | 日常交易 |
| 储备资金 | 20% | 极端行情加仓/不参与日常交易 |
| 单品种上限 | ≤15% | 单品种最大风险暴露 |
| 同时持仓上限 | ≤3品种 | 总风险可控 |

### 4.2 动态调整规则

| 账户状态 | 仓位调整 |
|---------|---------|
| 月盈利>10% | 维持当前仓位，不放大 |
| 月盈利<0% | 仓位减半，只做确定性机会 |
| 周亏损>5% | 暂停一周，复盘分析 |
| 月亏损>10% | 暂停一月，重新校准 |
| 连续3笔盈利 | 可恢复标准仓位 |
| 连续3笔亏损 | 仓位降至1%，直到恢复 |

## 七、自进化迭代流程

### 7.1 迭代循环

```
每周复盘（周六）:
  1. 统计本周盈亏、胜率、盈亏比
  2. 标注每笔亏损原因（止损未设/追高/逆势等）
  3. 更新策略参数（如止损倍数/止盈比例）
  4. 记录新的模式发现到经验库

每月深度复盘:
  1. 回测当月所有交易
  2. 对比策略信号与实际执行偏差
  3. 调整Top10品种白名单
  4. 评估是否需要调整ATR周期/RSI阈值

每季度大迭代:
  1. 完整策略回测
  2. 与主力画像对比，更新博弈规则
  3. 版本号升级（v11.0 → v12.0）
```
