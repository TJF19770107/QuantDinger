## 一、道可道，非常道 — 全局研判框架

### 1.1 核心哲学

> **道可道，非常道。**
> 凡是能被语言描述的规律，都不是永恒的规律。
> 市场规律亦然——主力操盘手法永远在变，唯一不变的是"变化"本身。

### 1.2 动态研判框架

```
┌────────────────────────────────────────────────┐
│          道可道，非常道 — 研判框架            │
│                                                        │
│  市场规律（可道）    →  主力手法（非常道）        │
│  ↓ 主力永远在变，规律永远在迭代                    │
│  自身策略（可道）    →  迭代机制（非常道）        │
│  ↓ 自身策略必须跟随主力变化而变                │
│  唯一不变：变化本身                                    │
└────────────────────────────────────────────────┘
```

### 1.3 三层次研判体系

| 层次 | 研判对象 | 道家对应 | 更新频率 |
|------|----------|----------|----------|
| **道（底层）** | 市场本质规律 | 非常道 | 不变 |
| **法（中层）** | 主力操盘手法 | 可道→非常道 | 每2周 |
| **术（表层）** | 自身交易策略 | 可道→非常道 | 每笔交易 |

> **实战含义**：道（市场规律）不变，但法（主力手法）和术（自身策略）必须随市场变化而迭代。死守一套策略等于"守可道而忘非常道"。

## 二、无，天地之始 — 空仓的智慧

### 2.1 核心哲学

> **无，天地之始；有，万物之母。**
> 空仓（无）是交易的起点，持仓（有）是交易的手段。
> 不懂空仓，就不懂交易。

### 2.2 空仓规则体系

| 空仓场景 | 道家解读 | 规则 |
|----------|----------|------|
| **无信号** | 无 → 不妄动 | 空仓，等待A级信号 |
| **三重熔断** | 无 → 避其锋芒 | 强制观望48h |
| **恐惧<20** | 无 → 保全本金 | 暂停新开仓 |
| **布林带超30%** | 无 → 不追极端 | 禁止新开仓 |
| **爆仓后** | 无 → 休养生息 | 7天仓位≤5% |

### 2.3 "无"的仓位管理

```
空仓（无）  ───→  首仓50%（有之始）
    ↑                         ↓
    └──── 平仓归零（回归无）←──── 追踪止盈（有之终）
```

> **核心**：每笔交易结束后，强制回归"无"（空仓）状态，等待下一个"有"（A级信号）出现。禁止连续交易不停手。

## 三、天之道利而不害 — 风控体系

### 3.1 核心哲学

> **天之道，利而不害；圣人之道，为而不争。**
> 天的法则是利益万物而不伤害；圣人的法则是行动而不争夺。
> 交易的最高境界：盈利而不伤害本金，行动而不与市场争夺（不逆势）。

### 3.2 利而不害 — 风控三原则

| 原则 | 道家原文 | 交易规则 |
|------|----------|----------|
| **利** | 利而不害 | 盈利是目的，但不可伤害本金 |
| **不害** | 不伤害万物 | 单笔亏损≤3-5%，最大回撤≤15% |
| **为** | 为而不争 | 行动（开仓）但不争夺（不逆势、不FOMO） |

### 3.3 风控量化规则

| 参数 | 数值 | 道家对应 |
|------|------|----------|
| 单笔最大亏损 | ≤3-5%净值 | 不害 |
| 最大回撤 | ≤15% | 不害 |
| 盈亏比硬约束 | ≥1.5（常态）/ ≥2.0（极端） | 利 |
| 止损设置率 | 100% | 为（有行动） |
| 总仓位上限 | ≤70% | 为而不争（留30%余地） |
| 备用金 | ≥30% | 无（留有余地） |

### 3.4 "为而不争"的操作纪律

```
为（行动）  ───→  等待A级信号（不争）
    ↑                         ↓
    └──── 止损坚决（不害）←──── 顺势而为（不争）
```

> **核心**：开仓是"为"（行动），但必须"不争"——不逆势、不FOMO、不抢跑。止损是"不害"（保护本金），必须坚决执行。

## 四、为而不争 — 顺势交易原则

### 4.1 核心哲学

> **圣人之道，为而不争。**
> 行动（为）但不争夺（不争）。交易中的"争"就是逆势、FOMO、抢跑。

### 4.2 "不争"的识别标准

| 行为 | 是否"争" | 道家判断 | 规则 |
|------|----------|----------|------|
| 突破前抢跑 | 争 | 违背"不争" | 禁止，等2根4H阳线确认 |
| 恐惧时抄底 | 争 | 违背"不害" | 恐惧<20禁止抄底 |
| 贪婪时追高 | 争 | 违背"不害" | 贪婪熔断48h |
| 逆势做空 | 争 | 违背"为而不争" | 三条件缺一不可 |
| 顺势做多 | 不争 | 符合"为而不争" | A级信号可做 |

### 4.3 顺势而为的操作规则

| 趋势 | 操作 | 道家原则 |
|------|------|----------|
| EMA20>EMA50 + 价格>EMA20 | 只做多，禁止裸空 | 为而不争 |
| EMA20<EMA50 + 价格<EMA20 | 只做空，禁止裸多 | 为而不争 |
| EMA20/EMA50纠缠 | 不参与 | 无为而治 |

## 五、虚实结合 — 主力博弈心法

### 5.1 核心哲学

> **虚实结合，以实击虚。**
> 主力是"实"（资金优势、信息优势），我是"虚"（灵活、快速）。
> 以"虚"击"实"必败，以"实"击"虚"必胜。

### 5.2 虚实识别矩阵

| 维度 | 主力（实） | 个人（虚） | 应对策略 |
|------|------------|------------|----------|
| 资金量 | 大，可操纵短期价格 | 小，无法操纵 | 不逆势，跟随主力 |
| 信息 | 提前知道利好/利空 | 滞后 | 跟踪ETF资金流 |
| 持仓周期 | 数周-数月 | 1-7天 | 不抢跑，等主力先动 |
| 止损纪律 | 严格（代码强制） | 缺失（需改进） | 止损代码强制 |
| 情绪控制 | 利用散户情绪 | 被情绪控制 | 恐惧贪婪指数分层 |

### 5.3 "敌一动我必先动"的道家解读

> **实（主力）先动 → 虚（我）先应 → 虚实结合 → 以实击虚**

```
主力动作（实）  ───→  我识别（虚）  ───→  我先动（虚→实）  ───→  盈利（实）
```

> **关键**：主力一动（实），我立即识别（虚）并先手应对（虚→实），在主力完成布局前完成建仓/平仓。这叫"以虚击实，以实击虚"。

### 5.4 主力博弈实战规则

| 主力动作 | 我的先手应对 | 道家心法 |
|----------|-------------|----------|
| 开始放量突破 | 首仓50%入场 | 虚→实，先动 |
| 洗盘急跌 | 不割肉，等收复确认 | 为而不争，不妄动 |
| 拉升加速 | 金字塔加仓30%→20% | 虚实结合，顺势 |
| 高位放量滞涨 | 立即启动追踪止盈 | 利而不害，锁定利润 |
| 恐慌崩盘 | 恐惧分层降仓/暂停 | 无，天地之始 |

## 七、道家心法速查口诀

### 7.1 开仓前默念（三问）

1. **道可道**：这笔交易是否符合当前市场规律？（主力手法是否变化？）
2. **无天地之始**：当前是否应该空仓？（无信号/熔断时禁止妄动）
3. **为而不争**：是否顺势不逆势？（不FOMO、不抢跑、不逆势）

### 7.2 持仓中默念（三守）

1. **天之道利而不害**：守住止损，不伤害本金（代码强制）
2. **虚实结合**：跟踪主力动向，不主观臆测
3. **无**：该平仓时果断平仓，回归"无"状态（空仓）

### 7.3 平仓后默念（三思）

1. **道可道非常道**：主力这次用了什么新手法？记录下来
2. **自知者明**：我这次执行了没有？（止损是否设置？是否过早止盈？）
3. **为而不争**：盈利是否"利而不害"？（是否让利润奔跑？还是赚一点就跑？）
