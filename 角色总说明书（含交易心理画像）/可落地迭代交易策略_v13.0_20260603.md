## 【道】总纲

> 道可道，非常道。名可名，非常名。无，名天地之始；有，名万物之母。故常无，欲以观其妙；常有，欲以观其徼。

### 道的层面：交易之"道"

交易之道，不在某一个策略、某一个参数、某一个信号。而在**对市场运行本质的理解**以及**对自身心理的掌控**。

- **道不固定**：策略需随市场状态变化而迭代。恐惧9的策略≠贪婪80的策略。
- **名不永恒**：概念如"做多""做空""趋势""震荡"并非固定标签。恐惧9中"做空"是顺势（市场在跌），但主力在"做多"（暗中建仓）。真正的"顺势"是顺主力之势，非顺价格之势。
- **无=道之体**：空仓是交易的根本状态。从"无"（空仓）中生出"有"（开仓），"有"最终回归"无"（平仓）。
- **有=道之用**：开仓是"有之以为利"，空仓是"无之以为用"。

### 道层核心原则

```
1. 顺势的核心是顺"主力之势"，而非顺"价格之势"
2. 恐惧是机会的伪装，贪婪是风险的伪装
3. 空仓是常态，开仓是例外
4. 止损不是可选项，是交易存在的先决条件
5. 少则得，多则惑——聚焦<10品种
6. 反者道之动——恐惧9=主力贪婪，贪婪80=主力恐惧
7. 功成身退天之道——盈利目标达成即离场
```

## 【法】规则体系

> 天之道，利而不害；圣人之道，为而不争。

### 法的层面：交易规则体系

法是从"道"生出的具体规则。"天之道利而不害"——规则存在的目的是保护交易者不"害"自己。"为而不争"——执行规则但不与市场争对错。

### 二、出场法（止盈止损）

#### 2.1 止损（强制非可选）

| 类型 | 参数 | 说明 | 道家心法 |
|------|------|------|------|
| 初始止损 | 入场价 - ATR(14)×2.0 | 做多；做空用ATR×1.5更紧 | 知止不殆 |
| 移动止损 | 最高价 - ATR×1.8 | 浮盈>3%后启用追踪 | 功成身退（逐步收紧） |
| 时间止损 | 持仓5天未盈利 | 强制平仓（从v11.0的7天收紧至5天） | 无为之治（不纠缠） |
| 日亏损熔断 | 日亏损达账户3% | 当日禁止开仓+次日半仓 | 曲则全 |
| 周亏损熔断 | 周亏损达账户7% | 下周仅模拟盘 | 知止不殆 |

#### 2.2 止盈（阶梯式）

```
第一目标（初始风险2倍）: 止盈50%仓位
  → 收回本金+锁定部分利润
  → 道家："知足不辱，知止不殆"
  
第二目标（追踪止盈3%）: 止盈30%仓位
  → 跟随趋势
  → 道家："有之以为利"
  
放飞仓（移动止损至成本+3%）: 保留20%仓位
  → 让利润奔跑，不设止盈上限
  → 道家："大盈若冲，其用不穷"
```

#### 2.3 非对称盈亏比（v4.8新增 · v13.0落地）

| 场景 | 最低盈亏比要求 | 说明 |
|------|:---:|------|
| 正常市场 | ≥2:1 | 止损金额×2=止盈目标 |
| 做空方向 | ≥2.5:1 | 做空额外收紧（历史13笔>50U大亏教训） |
| 恐惧9环境（解冻后） | ≥3:1 | 恐慌期对入场更严格 |
| ETF催化品种 | ≥1.8:1 | 可以适度放宽 |

## 【术】操作技法

> 图难于其易，为大于其细。天下难事必作于易，天下大事必作于细。

### 术的层面：具体操作技法

"术"是"法"的具体执行。每一术都对应法的一条规则。

### 术一：入场执行术

```
步骤1: 时段检查（是否在绿/黄时段）
步骤2: 白名单检查（品种是否在6品种内）
步骤3: 熔断检查（无任何熔断触发）
步骤4: 信号检查（5因子≥4达标）
步骤5: 恐惧指数检查（15-65区间）
步骤6: 计算仓位（账户3%）
步骤7: 计算止损（入场价 - ATR×2.0）
步骤8: 计算止盈（止损金额×2.0）
步骤9: 确认盈亏比≥2:1 → 开仓
步骤10: 开仓后立即在API设置止损
```

### 术二：加仓执行术

```
条件确认（3条全满足）:
  □ 浮盈≥3%
  □ 4H EMA维持多头排列（EMA20>EMA50）
  □ MACD未死叉（柱状图仍在零轴上方且不缩短）

执行:
  加仓量为账户5%
  止损上移至加权均价 - ATR×1.8
  总仓位→8%
  
条件不满足: 不加仓，维持原仓
```

### 术三：减仓执行术

```
触发条件（任一满足即减仓50%）:
  □ RSI突破72+MACD柱状图开始缩短
  □ 价格超布林带上轨22%+
  □ 恐惧指数突破65
  □ 浮盈>15%+单日涨幅>8%
  
减仓执行:
  平掉50%仓位
  剩余仓位止损上移至成本+3%
  剩余仓位进入"放飞模式"
```

### 术四：做空执行术（v13.0收紧）

```
做空条件（v13.0新增更严格约束——历史13笔>50U全来自做空）:

必选条件（全部满足）:
  □ EMA20<EMA50且价格<EMA20
  □ 日线吞没阴线确认
  □ MACD死叉确认
  □ 量能衰竭（<20日均量×0.7）
  □ 恐惧指数>40（恐慌期不做空）
  □ 非ETF催化品种或ETF转为流出
  
仓位限制:
  做空总仓位≤账户8%
  单笔做空≤账户4%
  做空止损≤ATR×1.5（比做多更紧）
  
盈亏比要求:
  做空≥2.5:1（比做多更严）
```

### 术五：解冻执行术（恐惧9专属）

```
阶段1（恐惧<15）: 
  仅模拟盘，每日5-10笔
  品种：白名单6品种
  方向：仅做多（模拟）
  
阶段2（恐惧15-25）:
  启动1%账户真实试探仓
  仅做多方向
  盈亏比≥3:1
  日亏损1%熔断
  
阶段3（恐惧25-40）:
  仓位升至3-5%
  金字塔加仓启用
  日亏损2%熔断
```
