## 二、新维度一：渐进式信号升级链（v10.0 新增）

### 2.1 七级信号链

```
Lv1 微动 (Whisper)  → Lv2 弱动 (Hint)   → Lv3 中动 (Signal)  → Lv4 强动 (Confirm)
  ↓                      ↓                      ↓                    ↓
深度微小变化          T&S出现方向性        大单连续同向        多维度共振
观察/不动作            加自选/不交易          预判模式激活      确认模式激活
  ↓                      ↓                      ↓                    ↓
  └──────────────────────┴──────────────────────┴────────────────────┘
                                     ↓
                         Lv5 已动 (Execute)
                                     ↓
                    满足Lv4 + 无熔断 → 执行开仓
                                     ↓
                         Lv6 复盘 (Review)
                                     ↓
                    信号是否有效 → 更新预判库
                                     ↓
                         Lv7 迭代 (Evolve)
                                     ↓
                    复盘结论 → 优化信号库 → 更新规则
```

### 2.2 各等级判定标准

| 等级 | 名称 | 判定条件 | 最低满足条件 | 我方动作 |
|------|------|---------|-------------|---------|
| Lv0 | 敌不动 | 七重熔断≥4触发 | 无 | 静默观察 |
| Lv1 | 微动 | 单维度弱信号（如T&S单笔异常） | 1/6维度触发 | 加自选，不开仓 |
| Lv2 | 弱动 | 双维度弱信号或单维度持续信号 | 2/6维度触发或持续>5分钟 | 预判模式激活 |
| Lv3 | 中动 | 大单方向性≥60%单向+深度恢复 | 3/6维度触发 | 待命状态 |
| Lv4 | 强动 | 4/6维度触发+成交量放量>50% | 4/6维度触发 | 确认模式激活 |
| Lv5 | 已动 | Lv4+熔断≤2+盈亏比≥1.5 | 全部条件满足 | 执行开仓 |
| Lv6 | 复盘 | 开仓后实时监控 | — | 信号有效性评估 |
| Lv7 | 迭代 | 复盘完成 | — | 更新预判库+规则 |

### 2.3 信号升级规则

```
# 升级: 连续3根K线维持升级条件 → 进入下一级
# 降级: 信号消失持续5分钟 → 退回上一级
# 跳级: 多维度同时触发 → 可跳1级（不允许跳2级以上）
```

## 六、可落地执行规则（博弈引擎 v10.0 可编程版）

### 6.1 主博弈引擎

```
class MarisGameEngine:
    def __init__(self):
        self.signal_level = 0   # 0-7
        self.circuit_breakers = CircuitBreakerMonitor()
        self.signal_matrix = SignalMatrix()
    
    def heartbeat(self, market_data):
        # 1. 确认主力状态
        if self.circuit_breakers.total_weight >= 4.0:
            self.signal_level = 0
            return Action.HOLD  # 敌不动
        
        # 2. 信号升级链检查
        new_level = self.signal_matrix.evaluate(market_data)
        if new_level > self.signal_level:
            self.signal_level = min(new_level, self.signal_level + 1)
        elif new_level < self.signal_level and self.signal_matrix.consecutive_downgrade_minutes >= 5:
            self.signal_level = max(new_level, self.signal_level - 1)
        
        # 3. 动作决策
        if self.signal_level >= 5 and self.circuit_breakers.total_weight <= 2.0:
            return Action.LONG if self.signal_matrix.direction == "BULLISH" else Action.SHORT
        elif self.signal_level >= 4:
            return Action.READY  # 待命
        elif self.signal_level >= 2:
            return Action.WATCH  # 观察
        else:
            return Action.HOLD   # 不动
```

### 6.2 预判信号检测

```
def detect_bull_trap(market_data):
    """诱多陷阱: 假突破+低量+快速反转"""
    above_resistance = market_data.price > market_data.resistance * 1.02
    low_volume = market_data.volume < market_data.avg_volume_20 * 0.7
    if above_resistance and low_volume:
        # 监控30分钟内是否回落
        if market_data.price < market_data.resistance * 0.99 and \
           market_data.time_since_breakout < 30:
            return Signal(type="BEAR_TRAP", action="禁止做多，预判做空")
    return None
```
