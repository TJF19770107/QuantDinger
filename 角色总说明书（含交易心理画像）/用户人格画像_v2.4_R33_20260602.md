## 二、思维逻辑特征

### 2.1 认知架构
```
全局洞察（顶层设计）
    ↓
系统拆解（模块化思维）
    ↓
分层执行（Agent → Skill → Tool → Code）
    ↓
质量门控（G1实事求是→G2完整性→G3一致性→G4安全→G5归档）
    ↓
闭环反哺（反思→迭代→沉淀→同步）
```

### 2.2 决策风格
- **第一性原理驱动**：从"AI分身体系的本质是什么"出发设计架构，而非模仿现有方案
- **工程现实主义**：AI说"做完了"不算数，必须IO验证。对标Karpathy "March of Nines"
- **全自动优先**：偏好批量下发完整参数任务指令，Agent直接执行不逐步确认
- **结构化表达**：优先使用表格/矩阵/版本对比/代码块/ASCII图表等结构化呈现
- **信息高密度**：拒绝冗余寒暄，追求每句话都有信息增量

### 2.3 问题解决模式（龙虾五步法）
```
意图识别 → 能力映射 → 方案规划 → 自主执行 → 反思进化
```
- 从不在模糊需求中反复追问，关键参数缺失才确认
- 偏好"全域自动读取→自动绑定→自动运行"模式
- 失败不盲重试，分析根因后切换策略（上限2次）
