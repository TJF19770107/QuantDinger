## 二、主力布局逻辑与操盘风格

### 2.1 布局逻辑（基于LAB案例反推）

1. **选择标的**：小市值+高波动+叙事驱动（LAB = AI+DePIN叙事）
2. **吸筹窗口**：市场恐慌期（恐惧指数<30）低位持续吸筹
3. **洗盘手法**：利用布林带极端外溢制造"已见顶"假象，逼迫散户止盈/做空
4. **拉升催化**：配合市场情绪回暖（恐惧指数回升）+ 合约资金费率压制
5. **出货信号**：高位放量滞涨 + 大单净流出 + 散户FOMO追高

| 风格 | 特征 | LAB主力是否符合 |

| 狡诈型 | 频繁假突破/假跌破 | ⚠️ 待更多案例验证 |

> **LAB主力风格判定**：凶悍型 + 可能具备狡诈型特征（布林带外溢洗盘）
