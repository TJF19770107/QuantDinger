> "道可道，非常道。名可名，非常名。无，天地之始；有，万物之母。" — 《道德经》第一章

本策略以道家思想为底层逻辑，将"道法自然、顺势而为、虚实结合、利而不害"的哲学贯穿交易全程。不以固定规则定义市场（道不可道），而是建立一套随市场变化动态迭代的**自适应交易框架**。

## 一、核心四柱

### 第一柱：道法自然 — 全局研判框架

> "人法地，地法天，天法道，道法自然。" — 《道德经》第二十五章

| 层级 | 道家映射 | 交易映射 | 研判内容 |
|------|----------|----------|----------|
| 天（道） | 市场自然规律 | 宏观大势 | BTC ETF资金流向、恐惧贪婪指数、全球宏观 |
| 地（万法） | 板块/赛道规律 | 中观赛道 | BSC生态健康度、DeFi TVL、LSD赛道 |
| 人（术） | 个人交易行为 | 微观执行 | K线、EMA、RSI、MACD、布林带、成交量 |

**研判流程**：
1. **天层判断**（宏观）：恐惧指数<30 → 半仓+杠杆1x；恐惧指数<20 → 暂停新开仓
2. **地层判断**（赛道）：BSC TVL下降>20% → 全BSC标的降级；PancakeSwap TVL增长>20% → CAKE升级
3. **人层执行**（技术）：5因子评分≥4达标 → A级入场；≥3→B级观望；<3→C级不入场

### 第二柱：虚实结合 — 多空博弈之道

> "无，天地之始；有，万物之母。故常无，欲以观其妙；常有，欲以观其徼。" — 《道德经》第一章

| 道家概念 | 交易映射 | 应用规则 |
|----------|----------|----------|
| **无** | 空仓观望 | 敌不动我不动，不符合入场条件坚决不参与 |
| **有** | 持仓执行 | 敌一动我必先动，信号确认后果断入场 |
| **虚** | 试错轻仓 | 洗盘识别后小仓试错（5%仓位），错了止损 |
| **实** | 趋势重仓 | 拉升确认后金字塔加仓（50%+30%+20%） |

**虚实转换规则**：

```
无（空仓） ──→ 虚（试错） ──→ 实（加仓） ──→ 无（离场）
   ↑              │                │              │
   │              ▼                ▼              │
   │         虚→无（止损）   实→无（止盈）         │
   └──────────────────────────────────────────────┘
          观察下一轮机会，循环往复
```

### 第三柱：利而不害 — 风控体系哲学

> "天之道，利而不害。" — 《道德经》第八十一章

风控的核心哲学是"利而不害"：所有规则设计的目的不是限制盈利，而是**保护本金不受不必要伤害**。

| 道家映射 | 风控规则 | 具体参数 |
|----------|----------|----------|
| 利（保护） | 止损代码强制 | `stopLossPrice` 必填，缺失拒绝开仓 |
| 利（警戒） | 三级熔断体系 | 日回撤5%→暂停；周10%→降仓50%；月15%→全面复盘 |
| 不害（克制） | 贪婪熔断 | 5日涨幅>80% → 强制观望48h |
| 不害（冷静） | 波动率熔断 | 5日振幅>100% → 仓位降至10%/杠杆降至1x |
| 不害（从容） | 爆仓恢复期 | 爆仓后7天仓位5%/杠杆1x |
| 利（储备） | 永不满仓 | 保留30%+备用金，总仓位≤70% |

### 第四柱：为而不争 — 顺势交易核心

> "圣人之道，为而不争。" — 《道德经》第八十一章

| 道家映射 | 交易原则 | 具体执行 |
|----------|----------|----------|
| 为（顺势） | 趋势确认后跟随 | 金字塔加仓：首仓50%→确认30%→加速20% |
| 不争（不逆） | 不预测顶底 | 禁止裸空（三条件缺一不可），禁止逆势抄底 |
| 为（持久） | 低频高质 | 每日交易上限3笔，超限强制冷却 |
| 不争（不贪） | 聚焦少数 | 币种白名单上限10个，聚焦TOP5 |

## 二、可落地执行的迭代交易策略

### 2.1 入场触发条件

#### A级信号（标准仓位入场）

| 条件 | 主流币参数 | 山寨币参数 |
|------|-----------|-----------|
| 1. 布林带突破 | 价格突破上/下轨 | 同主流 |
| 2. 成交量确认 | 成交量 > 20周期均量 × 1.3 | 同主流 |
| 3. EMA趋势 | EMA20 > EMA50（做多） | 同主流 |
| 4. RSI区间 | RSI(14) 30-75 | RSI(14) 30-80 |
| 5. MACD方向 | 柱状图与价格同向且加速 | 同主流 |

**5因子中≥4达标 = A级信号 → 标准仓位入场（首仓50%）**

#### B级信号（观望）

- 5因子中≥3达标 → 不入场，标记观察
- 布林带外溢>30% → 不入场

#### C级信号（不参与）

- 2因子或以下达标 → 不入场
- 任何熔断触发 → 不入场

#### 做空入场（三条件强制校验）

| 条件 | 说明 | 极端行情（5日涨幅>80%） |
|------|------|------------------------|
| 1. 日线吞没阴线 | 全天K线吞没前一天K线 | 需连续2根日线吞没阴线 |
| 2. MACD死叉 | DIF下穿DEA | 同左 |
| 3. 量能衰竭 | 成交量连续3日<20日均量 | 同左 |

**三条件缺一不可，任一不满足禁止开空。**

### 2.2 仓位管理规则

| 标的类型 | 常态仓位上限 | 极端行情仓位上限 | 杠杆上限 |
|----------|------------|----------------|---------|
| 主流币（BNB等） | 25%（ETF催化加成+5%） | 15%（恐惧指数<30） | 3x（常态）/ 1x（极端） |
| 山寨币（LAB等） | 15% | 10%（贪婪熔断/波动率熔断） | 2x（常态）/ 1x（极端） |

**金字塔加仓**：首仓50%（入场信号）→ 追加30%（浮盈≥3%+4H EMA多头排列+MACD未死叉）→ 追加20%（浮盈≥8%+日线突破确认+放量）

**铁律**：
- 禁止倒金字塔加仓
- 亏损状态严禁追加仓位
- 总仓位上限70%，保留30%+备用金

### 2.3 止损止盈规则

#### 止损规则

| 标的类型 | ATR倍数 | 单笔亏损上限 |
|----------|---------|------------|
| 主流币 | 1.8 | ≤3%净值 |
| 山寨币 | 2.5 | ≤5%净值 |

**止损价 = 入场价 - (ATR(14) × 倍数)**

**铁律**：止损从文档强制升级为代码强制——开仓API `stopLossPrice` 为必填字段，缺失则拒绝执行。每日UTC 0:00自动校验所有持仓止损状态。

#### 止盈规则

| 阶梯 | 目标涨幅 | 平仓比例 | 说明 |
|------|----------|----------|------|
| TP1 | +8% | 30% | 第一目标，锁利 |
| TP2 | +18% | 30% | 第二目标，继续锁利 |
| TP3 | +30% | 40% | 第三目标，清仓 |

**追踪止盈**：盈利达2%启动追踪止盈，步长随持仓时间收缩——第1天步长1%，第3天收缩至0.5%，第5天收缩至0.3%。

**盈亏比硬约束**：每笔交易前计算盈亏比，<1.5不参与（常态），极端行情（5日涨幅>80%）自动提升至2.0。

### 2.4 熔断体系

| 熔断级别 | 触发条件 | 措施 | 恢复条件 |
|----------|----------|------|----------|
| 日熔断 | 日回撤≥5% | 暂停当日交易 | 次日自动恢复 |
| 周熔断 | 周回撤≥10% | 仓位降至50% | 连续2日盈利 |
| 月熔断 | 月回撤≥15% | 暂停策略，全面复盘 | 策略修复+回测验证 |
| 贪婪熔断 | 5日涨幅>80% | 强制观望48h | 48h冷却+价格回落 |
| 波动率熔断 | 5日振幅>100% | 仓位降至10%, 杠杆降至1x | 振幅回落至<50% |
| 爆仓熔断 | 发生爆仓 | 7天仓位5%, 杠杆1x | 7天后渐进恢复 |
| ETF流出熔断 | ETF连续5日净流出 | 全账户杠杆降至1x | ETF恢复净流入 |
| ETF流出熔断 | ETF连续10日净流出 | 暂停所有新开仓 | ETF恢复净流入 |

### 2.5 时段禁开仓

| 时段（UTC） | 规则 | 原因 |
|------------|------|------|
| 04:00 UTC | 禁止新开仓 | 流动性低谷，笔均亏损 |
| 23:00 UTC | 禁止新开仓 | 流动性下降，笔均亏损 |

## 三、迭代闭环机制

### 3.1 五步迭代法

```
1. 识别 → 跟踪主力动向（量价行为识别）
    │
    ▼
2. 学习 → 拆解主力策略（吸筹→洗盘→拉升→震荡→出货）
    │
    ▼
3. 适应 → 融入自身体系（参数调整+规则升级）
    │
    ▼
4. 战胜 → 实盘执行验证（盈亏比≥1.5，胜率>50%）
    │
    ▼
5. 迭代 → 2周一次全面复盘（策略版本升级）
    │
    └──────────→ 回到步骤1，循环不息
```

### 3.2 迭代触发条件

| 触发事件 | 迭代动作 | 输出物 |
|----------|----------|----------|
| 每2周定时 | 策略全面复盘 | 策略版本升级报告 |
| 爆仓/大亏（>50 USDT） | 72h内独立复盘 | 爆仓复盘报告 |

| 新增币种入选 | 专属参数配置 | 币种专属tuning |
| 宏观环境剧变 | 全参数重评估 | 全量策略更新 |

## 四、道家心法融入实战 — 每日修行

### 4.1 盘前：虚静以待（无）

> "致虚极，守静笃。万物并作，吾以观其复。" — 《道德经》第十六章

- 检查恐惧贪婪指数、ETF资金流向（天层判断）
- 检查持仓品种的信号等级（地层判断）
- 默念：今天遵守规则比赚钱更重要

### 4.2 盘中：顺势而为（有）

> "动善时" — 《道德经》第八章

- 信号确认 → 金字塔加仓（有）
- 信号不确认 → 继续观望（无）
- 触发熔断 → 强制冷却（无）
- 主力动向出现 → 必先动（有）

### 4.3 盘后：复盘自省

> "知人者智，自知者明。" — 《道德经》第三十三章

- 核对每笔交易是否符合入场条件
- 记录情绪状态和交易偏差
- 最大亏损交易日：额外"静坐"5分钟，反思贪婪和恐惧

### 4.4 周复盘：道法自然

> "反者道之动" — 《道德经》第四十章

- 检查周度盈亏比、胜率、最大回撤
- 对比主力行为 vs 个人行为偏差
- 参数是否需要调整？策略是否需要升级？
