## 一、体系总纲

### 1.1 三层架构

```
┌─────────────────────────────────────────────────────┐
│              第一层：感知层（观）                      │
│   实时跟踪主力动向 → 监测6大先行指标 → 判断当前阶段     │
│   工具: OBV/布林带/ETF流向/恐惧指数/大单监控/USDT溢价   │
├─────────────────────────────────────────────────────┤
│              第二层：决策层（判）                      │
│   识别主力意图 → 预判主力下一步 → 制定我方策略         │
│   核心: 四阶段识别（吸筹/洗盘/拉升/出货）+ 虚实判断    │
├─────────────────────────────────────────────────────┤
│              第三层：执行层（动）                      │
│   先于主力行动 → 仓位管理 → 止盈止损自动化执行         │
│   工具: API代码强制（stopLossPrice必填 + 仓位硬上限）  │
└─────────────────────────────────────────────────────┘
```

### 1.2 核心博弈五规

| 规则 | 内容 | 道家映射 |
|------|------|------|
| **敌不动我不动** | 主力未入场→我方空仓等待。耐心是第一武器 | 致虚极守静笃（16章） |
| **敌一动我必先动** | 检测到主力入场信号→抢先布局，不等确认 | 将欲取之必固与之（36章） |
| **敌进我退** | 主力拉升出货阶段→我方减仓，不贪最后利润 | 功成身退（9章） |
| **敌退我进** | 主力洗盘杀跌→我方分批加仓，逆向操作 | 反者道之动（40章） |
| **敌疲我打** | 主力震荡犹豫→我方高抛低吸，赚取波动利润 | 弱之胜强（78章） |

### 2.2 各阶段详细说明书

#### S0：观望（仓位0%）

| 属性 | 内容 |
|------|------|
| **状态描述** | 空仓等待，监控市场但不交易 |
| **触发条件** | 冷却期未解除 / 无合格信号 / 主力未入场 / 熔断激活 |
| **持续条件** | 所有入场因子<4达标 / 恐惧指数<20或>80 / ETF连续流出 |
| **退出条件** | 入场因子≥4达标 + 恐惧指数20-60 + ETF无连续流出 |
| **退出动作** | 进入S1试仓（仓位20%） |
| **期间行动** | 每日记录恐惧指数+ETF流向、复盘历史数据、更新经验库 |
| **风险控制** | 零风险暴露 |
| **道家心法** | 致虚极守静笃——空仓即修行；无为之治——不交易即不被市场伤害 |

#### S1：试仓（仓位20%）

| 属性 | 内容 |
|------|------|
| **状态描述** | 检测到主力吸筹信号，轻仓试探 |
| **触发条件** | S0退出条件满足 + OBV背离/布林带收窄<10%/恐惧指数回暖 |
| **入场方式** | 金字塔首仓50%×20%=账户10%（即总仓位10%） |
| **止损设置** | ATR(14)×2.5（代码强制stopLossPrice必填） |
| **持续条件** | 价格未破止损位 + 方向未逆转 |
| **退出条件（成功）** | 放量突破布林带上轨 + 成交量>20日均量1.3倍 + 均线多头排列 |
| **退出条件（失败）** | 触发止损 / 主力信号消失 / 市场突变 |
| **退出动作（成功）** | 进入S2加仓（仓位→50%） |
| **退出动作（失败）** | 止损平仓，回到S0观望 |
| **主力对照** | 对应主力潜伏吸筹后期→主动吸筹前期 |
| **道家心法** | 道可道非常道——试探而非确定；虚实结合——虚则试探 |

#### S2：加仓（仓位50%）

| 属性 | 内容 |
|------|------|
| **状态描述** | 主力主动吸筹确认，金字塔加仓 |
| **触发条件** | S1成功退出 + 布林带外溢信号 + RSI 55-72 + 量能确认 |
| **加仓方式** | 金字塔二仓30%×50%=账户15%（总仓位25%）+ 三仓20%×50%=账户10%（总仓位35%）→ 注意总仓位上限50% |
| **止损调整** | 移动止损至成本价（保本止损） |
| **持续条件** | 趋势未反转 + 未触发追踪止盈 |
| **退出条件（成功）** | 浮盈>8% + 日线收盘确认突破 + 成交量持续放量 |
| **退出条件（失败）** | 价格跌破移动止损 / 主力突然转向 |
| **退出动作（成功）** | 进入S3持有（仓位→100%，含趋势加速） |
| **退出动作（失败）** | 减至S1仓位或直接止损 |
| **主力对照** | 对应主力主动吸筹→洗盘→拉升初期 |
| **道家心法** | 天下难事必作于易——分步加仓不急躁 |

#### S3：持有（仓位100%）

| 属性 | 内容 |
|------|------|
| **状态描述** | 主升浪进行中，全仓持有+追踪止盈 |
| **触发条件** | S2成功退出 + 趋势加速确认 |
| **仓位策略** | 全仓但不超账户15%（单品种上限） |
| **止盈策略** | 阶梯：50%仓位固定止盈 + 30%仓位追踪4% + 20%仓位放飞 |
| **追踪止盈** | 从最高点回撤4%→平仓50%；回撤6%→平仓全部 |
| **持续条件** | 趋势未破 + RSI未顶背离 + 量能未衰退 |
| **退出条件** | 高位放量滞涨 / RSI顶背离 / 大单卖出占比上升 / ETF开始流出 |
| **退出动作** | 进入S4减仓（仓位→30%） |
| **紧急退出** | 单日跌幅>ATR×3 → 立即全清 |
| **主力对照** | 对应主力拉升中期→末期 |
| **道家心法** | 持而盈之不如其已——盈利后应准备收手；知足不辱知止不殆 |

#### S4：减仓（仓位30%）

| 属性 | 内容 |
|------|------|
| **状态描述** | 主力开始出货，我方逐步减仓 |
| **触发条件** | S3退出条件满足 / 震荡出货信号 / 高位横盘3天+ |
| **减仓方式** | 先减50%（仓位→50%）→ 确认出货再减至30% |
| **止损策略** | 移动止损收紧至成本+3%（保本+微利） |
| **持续条件** | 价格未破关键支撑 + 未确认趋势反转 |
| **退出条件** | 放量下跌确认 / 大单卖出>买入 / ETF连续3天净流出 |
| **退出动作** | 进入S5清仓 |
| **主力对照** | 对应主力震荡出货→确认出货 |
| **道家心法** | 圣人之道为而不争——不贪最后利润；功成身退天之道 |

#### S5：清仓（仓位0%）

| 属性 | 内容 |
|------|------|
| **状态描述** | 全仓退出，结束本轮周期 |
| **触发条件** | S4退出条件满足 / 趋势确认反转 |
| **执行方式** | 全部平仓，不开新仓 |
| **后续动作** | 进入S0观望，等待下一轮周期 |
| **冷却规则** | 清仓后至少24小时不新开仓（除非极端恐慌<20出现黄金坑） |
| **复盘要求** | 24小时内完成本轮交易复盘：盈亏/信号质量/执行偏差 |
| **主力对照** | 对应主力全仓退出→进入冷却等待 |
| **道家心法** | 为道日损——清仓即归零；无之以为用——空仓孕育下一轮机会 |
