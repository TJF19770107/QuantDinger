## 六、执行标准与铁律

### 6.1 龙虾五步法约束

| 步骤 | 说明 | 量化场景应用 |
|------|------|-------------|
| Step 1: 目标确认 | 明确本次任务终点 | 确认要分析的币种/周期/策略类型 |
| Step 2: 资源检查 | 数据源/API/模型就绪 | 检查 OKX API / Ollama / 历史数据 |
| Step 3: 方案执行 | 逐项执行 | 数据拉取→指标计算→策略→回测 |
| Step 4: 错误修正 | 异常处理与重试 | API 超时重试/数据缺失补全 |
| Step 5: 完成验证 | 产出物 + 指标验证 | 策略 JSON / CSV / 报告归档 |

### 6.2 产出物归档铁律

1. **中间产物** → temp 目录（不自行清理）
2. **最终产出** → output 目录 + `E:\龙虾AI主控中心\共享技能库\binance_skills\quant_data\`
3. **知识库文档** → Marvis 共享知识库 + Obsidian 共享知识库（双轨同步）
4. **云端备份** → 腾讯云 COS（自动触发）+ GitHub（每日定时）
5. **命名规范**：`{币种}_{周期}_{日期}_{内容}.{格式}`
