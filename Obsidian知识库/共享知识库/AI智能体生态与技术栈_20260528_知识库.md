## 一、多智能体协作框架（2024-2026 前沿）

### 1.1 Ruflo（原 Claude Flow）⭐⭐⭐⭐⭐
- **GitHub 星标**：40,000+ | **版本**：v3.6.x

- **技术架构**：
  - 32 个官方插件 + 215 个 MCP 工具
  - 基于 HNSW 的持久化向量记忆
  - 零信任跨机器 Federation（联邦协作）
  - WASM 加速的自学习推理内核
  - Swarm 任务分拆与结果汇总
- **营收落地**：视频团队协作自动化、多项目并行管理

### 1.2 Eigent — 全球首个多智能体工作流桌面应用
- **GitHub 星标**：4,500+（4天）| 总收藏 7,400+
- **核心价值**：100% 开源、本地优先（Ollama）、MCP 协议原生支持
- **技术亮点**：
  - 多智能体并行工作流（非串行）
  - 数据不出本地，隐私安全
  - 支持 Ollama / DeepSeek / Qwen 本地驱动
  - 桌面级通用 AI 工具，可直接接管电脑操作
- **营收场景**：个人 AI 管家、自动化桌面操作、本地知识库管理

### 1.3 LightAgent — 轻量级多智能体框架
- **最新版本**：v0.6.0（2026-04-26）
- **核心特性**：
  - 原生 Skills 支持，可组合可复用

  - MCP over stdio / SSE 全协议接入
  - 支持 OpenAI / DeepSeek / Qwen 等主流大模型
  - OpenAI 兼容流式 API

- **论文**：arXiv 预印本（2509.09292）

## 三、本地大模型部署技术栈

### 3.1 Ollama 生态
- 本地运行大模型的标准方案
- 适用于 Windows / Mac / Linux
- 支持模型：DeepSeek / Qwen / Llama / Gemma 等
- 可通过 llama.cpp Server 提供 API 服务

### 3.2 Unsloth + GGUF 量化
- Unsloth 动态 GGUF：以量化方式运行 LLM，尽可能保留准确性
- llama.cpp 框架：开源 LLM 推理引擎
- llama-server：高效部署 LLM 服务
- 推荐配置：24GB RAM / 统一内存设备
- 最强 35B MoE 智能体与编码模型：Qwen3.5、GLM-4.7-Flash

### 3.3 模型微调（LoRA / QLoRA）
- LLaMA + LoRA 微调方案
- LoRA 核心思想：低秩适配，大幅减少微调参数量
- 适用场景：下游任务定制、垂直领域优化

## 四、MCP 协议（Model Context Protocol）

### 4.1 协议概述
- AI 模型与外部工具、数据源的标准通信协议
- 支持 stdio（标准输入输出）和 SSE（Server-Sent Events）两种传输方式
- 实现多模型、多工具协同工作

### 4.2 生态项目
| 项目 | 星标 | 特点 |
|------|------|------|
| Ruflo | 40,000+ | 215 MCP 工具集成 |
| zen-mcp-server | 8,700+ | 50+ 模型编排 |
| LightAgent | - | MCP over stdio/SSE |
| Eigent | 7,400+ | MCP 原生支持 |

### 4.3 营收落地
- 多工具自动化编排 → 视频剪辑自动化
- MCP + 量化交易工具 → 自动交易信号
- MCP + 文档处理 → 网文自动排版发布
