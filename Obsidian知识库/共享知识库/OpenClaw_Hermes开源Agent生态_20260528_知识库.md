## 一、OpenClaw — GitHub 星标之王

### 1.1 项目概况
- **创始人**：Peter Steinberger（奥地利退休程序员）
- **发起时间**：2025年11月（周末项目）
- **GitHub 星标**：24.8万+（2026年3月登顶，超越 Linux）
- **核心定位**：让大模型获得本地操作系统权限的开源智能体框架

### 1.2 底层架构（四大核心模块）
| 模块 | 功能 | 技术实现 |
|------|------|----------|
| 渠道适配器 | 进驻日常工具 | 飞书、钉钉、Telegram、Discord、Slack |
| 智能决策核心 | 灵活切换大模型 | 多模型路由，任务驱动选择 |
| 技能插件系统 | 执行力载体 | 浏览器控制、邮件调用、代码执行 |
| 双模记忆系统 | 本地长期学习 | 所有数据本地存储，隐私可控 |

### 1.3 技术哲学：组织型 Agent
- 多 Agent 协同，集体智慧
- 平台化技能商店
- 三层架构（渠道层→决策层→执行层）
- 强调"连接能力的广度"

### 1.4 营收落地映射
- 企业级智能办公助手（钉钉/飞书集成）
- 自动化运维 Agent

## 二、Hermes Agent — 自进化单体 Agent

### 2.1 项目概况
- **开发组织**：Nous Research（美国开源 AI 研究）
- **开源时间**：2026年2月
- **GitHub 星标**：102K+（截至2026年5月）
- **当前版本**：v0.12.0（2026-04-30）
- **许可证**：MIT 开源

### 2.2 核心差异：学习闭环（Learning Loop）
Hermes 最核心的设计是完整的**自进化学习闭环**：
```
任务执行 → 自动提炼技能 → 持久化记忆 → 跨会话精准回忆 → 越用越强
```

### 2.3 四层记忆系统
| 层级 | 功能 | 特点 |
|------|------|------|
| 短期记忆 | 当前会话上下文 | 对话连贯性 |
| 长期记忆 | 用户偏好与知识 | 跨会话持久化 |
| 技能记忆 | 自动提炼的 Skill | 自我进化 |
| 元记忆 | 记忆的记忆 | 优化检索策略 |

### 2.4 技术规格
- 6种部署方式：5美元VPS、Docker、Serverless、本地等
- 200+ 大模型一键切换
- 全平台接入：微博、Telegram、Discord、Slack
- 一行命令安装运行
- MCP 协议原生支持

### 2.5 技术哲学：进化型 Agent
- 单 Agent 自我进化
- 学习闭环驱动
- 四层记忆体系
- 强调"学习能力的深度"

### 2.6 OpenClaw vs Hermes 对比
| 维度 | OpenClaw | Hermes Agent |
|------|----------|--------------|
| 架构哲学 | 组织型（集体智慧） | 进化型（自我成长） |
| Agent 模式 | 多 Agent 协同 | 单 Agent 自进化 |
| 核心优势 | 连接广度 + 技能商店 | 学习深度 + 记忆体系 |
| 适用场景 | 企业协作、多平台 | 个人助手、长期陪伴 |
| 部署复杂度 | 中等 | 低（一行命令） |
| 模型支持 | 主流模型 | 200+ 模型 |
| 开源协议 | 开源 | MIT |
| GitHub 星标 | 24.8万+ | 102K+ |

## 四、技术整合：Agent 全栈架构

### 4.1 推荐技术栈组合
```
底层模型：Ollama 本地 + Claude/GPT API 远程
├── 框架层：Hermes Agent（个人助手）+ OpenClaw（多Agent协作）
├── 协议层：MCP（stdio/SSE）打通工具链
├── 记忆层：本地向量数据库 + 四层记忆
├── 工具层：Function Calling + Skill 自动提炼
└── 部署层：Docker / VPS / 本地 Windows
```

### 4.2 Windows 本地部署方案
1. **Ollama 安装** → 下载 Qwen3.5 / DeepSeek 本地模型
2. **Hermes Agent 部署** → Docker 或直接安装
3. **OpenClaw 集成** → 连接飞书/钉钉/微信渠道
4. **MCP 工具配置** → 文件系统、浏览器、Shell 工具接入
5. **Skill 沉淀** → 自动学习，持续优化
