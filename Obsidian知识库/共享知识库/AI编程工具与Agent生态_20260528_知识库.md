## 五、Claude Code + CC Switch + Trae IDE 工具链

### 5.1 工具链组合
- Claude Code：AI编程助手，理解整个项目
- CC Switch：一键切换DeepSeek/Claude/GPT等模型
- Trae IDE：可视化编辑器

### 5.2 安装命令速查
```
# 安装Claude Code
curl -fsSL https://claude.ai/install.sh | bash

# 安装CC Switch
npm install -g cc-switch

# 添加DeepSeek模型
cc-switch add deepseek --api-key sk-xxx --api-base https://api.deepseek.com --model deepseek-chat

# 切换模型
cc-switch use deepseek
```

### 5.3 成本参考
- DeepSeek：约1元/百万token（最低成本方案）
- Claude Code本身免费，模型调用付费
