## 二、接入流程四步法

```
安装 CLI → 配置应用 → 登录授权 → 验证接入
  4-5min      获取凭据      浏览器确认    创建测试日历
```

| 步骤 | 操作 | 时间 | 关键输出 |
|------|------|------|---------|
| 1 | 安装飞书 CLI | 4~5分钟 | `lark-cli --version` |
| 2 | 配置飞书应用 | 即时 | App ID + App Secret |
| 3 | 登录授权 | 即时 | OAuth Token |
| 4 | 验证接入 | 即时 | 日历事件创建成功 |
