## 一、核心要点总结

### 1.1 一句话核心

**Codex 通过 lark-cli / cc-connect / Feishu MCP 三种方式接入飞书，实现自然语言操控飞书全生态（文档/Base/日历/消息/任务/邮件/会议/知识库），无需手动操作飞书界面。**

### 1.2 三大接入路径

| 路径 | 核心工具 | 复杂程度 | 适用场景 |
|------|---------|---------|---------|
| 路径A | lark-cli（飞书官方 CLI） | 低 | 个人办公自动化 |
| 路径B | cc-connect（开源桥接器） | 中 | 团队群聊远程控制 |
| 路径C | Feishu MCP（@larksuiteoapi/lark-mcp） | 中 | Codex 原生集成 |
| 路径D | codex-feishu（NPM 包） | 高 | 生产级项目 |

## 二、关键知识点提炼

### 2.1 飞书 CLI（lark-cli）要点

- **发布时间**：2026 年 4 月正式开源
- **GitHub Star**：5.5K+
- **覆盖范围**：11 大业务域，200+ 命令，19 个 Agent Skills
- **核心理念**：AI Agent 像操作电脑一样通过命令操作飞书
- **关键命令域**：`lark-cli im` / `lark-cli docs` / `lark-cli base` / `lark-cli calendar` / `lark-cli mail` / `lark-cli task` / `lark-cli wiki` / `lark-cli vc` / `lark-cli search`

### 2.2 cc-connect 桥接要点

- **GitHub**：github.com/chenhg5/cc-connect
- **核心价值**：WebSocket 长连接，无需公网 IP
- **支持 Agent**：Claude Code、Codex、Cursor Agent、Gemini CLI、Qoder CLI、OpenCode 等 7 种
- **支持平台**：飞书、微信、钉钉、企业微信、QQ、Telegram、Discord、Slack 等 10 个平台
- **关键特性**：多 Bot 协作、流式输出、Slash 命令控制

### 2.3 Feishu MCP 要点

- **官方包**：@larksuiteoapi/lark-mcp
- **配置方式**：App ID + App Secret → .env.personal
- **重定向 URL**：http://localhost:3000/callback（本地 OAuth）
- **核心权限**：auth:user.id:readoffline_access、docx:document、drive:drive、search:docs:read

### 2.4 Codex Skill 创建要点

- **创建方式**：自然语言描述 → Codex 自动生成 Skill
- **Skill 命名**：feishu-<功能描述>
- **管理命令**：`/skills` 或 `$` 查看列表
- **安装社区 Skill**：`npx skills add <仓库地址>`

## 三、可复用的 SOP 模板

### SOP 1：新用户接入飞书 CLI（5 分钟）

```
Step 1: 在 Codex 中说"帮我安装飞书 CLI"（Codex 自动执行安装）
Step 2: "帮我初始化飞书 CLI 配置"（获取浏览器配置链接）
Step 3: 在浏览器中创建飞书应用，获取 App ID / App Secret
Step 4: 将凭据发给 Codex，完成配置
Step 5: 测试验证："在飞书日历中创建测试事件"
```

### SOP 2：团队飞书 + Codex 自动化配置（10 分钟）

```
Step 1: npm install -g cc-connect
Step 2: cc-connect feishu setup --project my-team
Step 3: 扫码创建飞书应用
Step 4: 编辑 config.toml 配置 Codex Agent + API Key
Step 5: cc-connect 启动服务
Step 6: 飞书群添加机器人，发送测试消息
```

### SOP 3：Codex Skill 创建模板

```
输入：「帮我创建一个飞书自动化 Skill：名称 feishu-daily-report，
功能：每天 18:00 自动收集飞书消息、日历、任务，生成日报文档发送到群，
使用 lark-cli 完成所有操作」

输出：Codex 自动生成 Skill 文件并注册
```

## 四、安全注意事项

1. App Secret 必须存入 `.env.personal`，不入版本控制
2. 生产环境使用飞书应用商店发布的应用
3. 定期轮换 App Secret（90 天）
4. 遵循最小权限原则
5. cc-connect yolo 模式仅限可信本地环境
6. 敏感操作（删除/踢人/修改权限）需人工确认
