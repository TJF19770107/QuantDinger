# 交易复盘索引

> 龙虾AI量化交易 · 交易复盘内容地图 · 自动汇总

## 概述

本索引覆盖龙虾AI量化体系的交易复盘记录，包括交易概况、盈亏分析、策略执行评估、心理状态分析和改进计划。所有复盘文件按日期归档，支持 Dataview 自动汇总。

---

## Dataview 自动汇总

### 所有复盘记录（按日期倒序）

```dataview
TABLE date AS "复盘日期", asset AS "标的", period AS "周期"
FROM "共享知识库" OR "quant_data"
WHERE file_type = "验收报告" OR type = "review"
SORT date DESC
```

### 盈亏汇总统计

```dataview
TABLE date AS "日期", profit_loss AS "盈亏", win_rate AS "胜率"
FROM "共享知识库" OR "quant_data"
WHERE type = "review"
SORT date DESC
```

### 策略执行评估

```dataview
TABLE date AS "日期", strategy_name AS "策略", execution_score AS "执行评分"
FROM "共享知识库" OR "quant_data"
WHERE type = "review"
SORT date DESC
```
