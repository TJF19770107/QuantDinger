# 量化交易总索引

> 龙虾AI量化全链路体系 · 内容地图索引 · 自动汇总

## 概述

本索引覆盖龙虾AI量化交易体系的全链路资产，包括策略库、行情数据、交易复盘、心理分析、系统运维等核心领域。通过 Dataview 实现动态自动汇总。

## Dataview 自动汇总

### 全部量化资产文件

```dataview
TABLE file_type AS "类型", file.ctime AS "创建时间", file.mtime AS "修改时间"
FROM "共享知识库"
WHERE contains(tags, "量化交易")
SORT file.mtime DESC
```

### 按文件类型统计

```dataview
TABLE length(rows) AS "数量"
FROM "共享知识库"
WHERE contains(tags, "量化交易")
GROUP BY file_type
```

### 最近更新的10个文件

```dataview
TABLE file_type AS "类型", file.mtime AS "最后修改"
FROM "共享知识库"
WHERE contains(tags, "量化交易")
SORT file.mtime DESC
LIMIT 10
```

### 标签导航

```dataview
LIST
FROM "共享知识库"
WHERE contains(tags, "量化交易")
GROUP BY tags
```
