# 行情数据索引

> 龙虾AI量化交易 · 行情数据内容地图 · 自动汇总

## 概述

本索引覆盖 DOGE/USDT 及相关标的的行情数据资产，包含日线完整数据、周线数据和关键节点数据。所有数据以 CSV 格式存储，可直接用于策略回测和分析。

---

## Dataview 自动汇总

### 所有行情数据文件

```dataview
TABLE file.size AS "大小", file.ctime AS "创建时间", file.mtime AS "最后修改"
FROM "quant_data"
WHERE file_type = "行情数据"
SORT file.mtime DESC
```

### 行情数据统计

```dataview
TABLE length(rows) AS "文件数", sum(file.size) AS "总大小(Bytes)"
FROM "quant_data"
WHERE file_type = "行情数据"
```
