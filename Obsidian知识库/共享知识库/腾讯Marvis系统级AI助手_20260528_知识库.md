## 核心知识点总结

### 1. 基本定位
- **名称**：Marvis（马维斯），名字致敬钢铁侠Jarvis
- **推出时间**：2026年5月20日正式上线
- **开发团队**：腾讯应用宝团队打造
- **核心定位**：操作系统级AI助手，主打"用自然语言操控整台电脑/手机"
- **品牌理念**：科技为人、务实减负、安全共生

### 2. 核心架构：1+5智能体（6个AI"牛马"）

| 序号 | Agent名称 | 核心职责 | 具体能力 |
|------|-----------|----------|----------|
| 1 | 主Agent（调度） | 理解用户指令、拆解任务、分配给专项Agent | 自然语言理解、任务规划、资源调度 |
| 2 | File Agent | 文件管理 | 搜索、整理、转格式、内容理解（Word/Excel/PDF/图片OCR） |
| 3 | Computer Agent | 系统运维 | 查配置、改设置、清垃圾、优化启动项、关Windows广告 |
| 4 | App Agent | 应用操控 | 打开/关闭软件、点按钮、填表单、自动化流程 |
| 5 | Browser Agent | 网页交互 | 查资料、填网页、刷数据、截图整理 |
| 6 | Search Agent | 信息检索 | 联网查资料、整理摘要、参考文献 |

### 3. 核心能力详解

#### 3.1 系统级操控（最独特能力）
**一句话查询**：
- 电脑配置、电池健康、网速
- 能不能玩某款游戏（硬件兼容性检查）

**一句话修改**：
- 关广告、调分辨率、清C盘
- 优化开机、卸载软件、调整系统设置

#### 3.2 文件深度智能
**不只是文件名搜索**：
- 读文档内容（Word/Excel/PDF）
- 识别图片文字（OCR）
- 按内容/场景/人像分类

**批量操作**：
- 批量转格式、合并PDF
- 整理合同、做数据汇总
- 文件归类与智能整理

#### 3.3 办公自动化
- 写周报、做PPT大纲
- 整理会议纪要、翻译文档
- 查文献、数据分析和报告生成

#### 3.4 跨端协同
- 手机远程控制电脑
- 看电脑屏幕、传文件
- 跨设备接力任务

#### 3.5 隐私保护（端侧模式）
- 开启后数据不上云、断网可用
- 基于腾讯自研Qwen端侧模型
- 适合财务/法务/敏感文件处理

### 4. 与普通AI的区别对比

| 对比维度 | 普通聊天AI（豆包、元宝） | 腾讯Marvis |
|----------|-------------------------|------------|
| 能力范围 | 只能对话、生成内容 | 直接操控电脑系统和文件 |
| 权限级别 | 应用层权限 | 系统中间层，接管电脑 |
| 任务执行 | 提供建议和内容 | 真正"干活"，执行具体操作 |
| 交互方式 | 纯对话交互 | 自然语言指令+系统操作 |
| 安全机制 | 内容安全审核 | 关键操作必须用户确认 |

### 7. 高级功能与使用技巧

#### 7.1 构建个人本地知识库
1. 打开Marvis设置 → 本地知识库
2. 添加需要索引的文件夹（支持文档、图片、代码等）
3. Marvis自动扫描并向量化文件内容
4. 用自然语言查询知识库中的任何信息

**查询示例**：
- "根据我所有的技术笔记，总结一下STM32定时器的使用方法"
- "在我的项目文档中，找到关于数据库设计的部分"

#### 7.2 创建定时任务
1. 进入任务中心 → 定时任务
2. 设置执行时间、重复周期和任务指令

**定时任务示例**：
- "每天早上9点，自动整理昨天的下载文件"
- "每周五下午5点，备份我的工作文档到D盘"

#### 7.3 工作流编排
对于复杂的重复性工作，可以创建自定义工作流：

**示例工作流**："发布CSDN文章"
1. 打开指定的Markdown文件
2. 检查格式和错别字
3. 生成标题、摘要和5个关键词
4. 自动打开CSDN创作中心
5. 粘贴内容并设置文章属性

#### 7.4 常用快捷键
- `Ctrl+Shift+M`：全局唤醒Marvis
- `Ctrl+Enter`：发送指令
- `Ctrl+Shift+S`：截图并发送给Marvis分析
- `Ctrl+Shift+F`：快速搜索本地文件

### 8. 注意事项与最佳实践

#### 8.1 隐私保护
- 处理敏感数据时务必切换到隐私模式
- 确保数据不上云，端侧处理
- 定期清理对话历史

#### 8.2 内容审核
- Marvis生成的内容需要人工审核
- 特别是技术文章和代码，确保准确性
- 重要决策不能完全依赖AI生成

#### 8.3 权限管理
- 不要授予不必要的权限
- 定期在设置中查看和管理权限
- 关键操作必须手动确认

#### 8.4 性能影响
- 隐私模式会占用一定的CPU和内存资源
- 低配电脑建议使用效率模式
- 定期清理缓存和临时文件

#### 8.5 更新维护
- 定期更新Marvis客户端
- 获取最新功能和安全修复
- 关注官方公告和更新日志
