## 核心问题

微信生态中公众号文章存在三大痛点：
- **搜不到**：微信搜索无法检索公众号历史文章
- **存不住**：文章在腾讯服务器上，不在用户本地
- **整理不了**：收藏夹形同虚设，无法打标签、建链接、全文搜索

## 解决方案

Hermes（本地 AI Agent）+ Docker 抓取服务 → 公众号文章自动同步到 Obsidian 本地知识库。

### 技术架构（三层）

| 层级 | 作用 | 实现方式 |
|------|------|----------|
| 抓取层 | 定期拉取公众号文章列表及正文、元数据 | Docker 容器 + 微信授权账号内容获取路径 |
| 存储层 | 每篇文章存为带 YAML 元数据的 Markdown 文件 | Obsidian vault 目录，文件名含日期和来源 |
| 操作层 | 自然语言指令控制抓取/格式化/写入全流程 | Hermes Agent Profile 预配置工具和工作流 |

### 存储格式

```yaml
---
title: 文章标题
date: 2026-05-26
source: 来源公众号
url: https://mp.weixin.qq.com/s/xxxxx
tags: [标签1, 标签2]
---
# 正文内容...
```

## 日常使用场景

1. **批量下载**：出门前一句指令下载指定号近期文章，通勤时翻完
2. **全文检索**：Obsidian 内秒级搜索历史文章，引用不再丢失
3. **专题研究**：批量下载数月历史文章集中阅读，信息密度远超随机刷
4. **清空收藏夹**：积压文章一键导入知识库

## 上手流程

1. 安装 Docker（Mac/Windows/Linux 均有文档）
2. 解压 wechat-curator 文件夹到 Hermes 的 profiles 目录
3. 复制环境变量模板，填入知识库路径等参数
4. 运行 add_account.sh，微信扫码授权，搜索公众号添加
5. 用自然语言告诉 Agent 下载哪个号、最近几天
