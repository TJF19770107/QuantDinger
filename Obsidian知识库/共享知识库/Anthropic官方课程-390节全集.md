**前置要求**：Basic familiarity with a code editor and the command line; A Claude account (Pro, Max, or Enterprise) or an API key

**目标受众**：New developers learning AI-assisted workflows and experienced engineers exploring coding agents

## 8. Model Context Protocol: Advanced Topics

**课程链接**：https://anthropic.skilljar.com/model-context-protocol-advanced-topics

**课程简介**：
Examines advanced features and implementation patterns for MCP development, focusing on server-client communication, transport mechanisms, and production deployment.

**学习目标**：
- **Sampling implementation** — How MCP servers request language model calls through connected clients
- **Progress and logging notifications** — Real-time feedback systems using context objects, logging callbacks
- **Roots-based file access** — Permission systems granting MCP servers access to specific directories
- **JSON message architecture** — Complete MCP message specification, distinguishing request-result pairs from notifications
- **Stdio transport** — Communication through standard input/output streams with initialization handshake
- **StreamableHTTP transport** — Server-Sent Events (SSE) enabling server-to-client communication over HTTP
- **HTTP transport limitations** — Configuration flags affecting server-initiated requests and streaming
- **Production scaling** — Stateless HTTP for horizontal scaling with load balancers
- **Transport selection** — Choosing appropriate transport methods based on deployment requirements

**前置要求**：Experience with Python async programming; Familiarity with JSON/HTTP/SSE

**目标受众**：Working with MCP implementations; Engineers building MCP servers and clients

## 10. Introduction to subagents

**课程链接**：https://anthropic.skilljar.com/introduction-to-subagents

**课程简介**：
Sub-agents are one of the most practical ways to get more out of longer Claude Code sessions. They let you delegate tasks to isolated assistants that do their work separately and return just the information you need — keeping your main context window clean and your conversations focused.

**课时结构（4课时）**：

| # | 课时名称 | 内容概要 |
|---|---------|---------|
| 1 | **What are subagents?** | 子代理本质：独立上下文窗口、任务委托机制、输入流入与摘要回传原理 |

- **Designing effective sub-agents** — Patterns for reliability: structured output formats, obstacle reporting, limiting tool access

## 19. 多Agent五模式协调体系（Anthropic 2026官方）

> 来源：Anthropic《Multi-agent coordination patterns》2026
> 学习轮次：R45

### 五种模式概览

| 模式 | 核心机制 | 适用场景 | 致命缺陷 |
|------|---------|---------|---------|
| Generator-Verifier | 生成→验证→修改循环 | 代码审查、事实核查、合规审查 | 验证者形同虚设（标准不明确时） |
| Orchestrator-Subagent | 主编排→子Agent→汇总 | PR审查、客服、调研 | 编排者成信息瓶颈；串行限制吞吐 |
| Agent Teams | Worker持久化+任务队列 | 框架迁移、多服务独立部署 | 独立性硬要求，Worker间无法共享发现 |
| Message Bus | 发布/订阅事件路由 | 安全运营、事件驱动管道 | 追踪困难；路由准确性是命门 |
| Shared State | 共享存储去中心化 | 研究综合、协作调查 | 反应性循环（无限Token消耗） |

### 模式演进决策矩阵

| 场景特征 | 推荐模式 |
|---------|---------|
| 输出质量关键，有明确评估标准 | Generator-Verifier |
| 任务拆分明确，子任务有界 | Orchestrator-Subagent |
| 并行工作负载，独立长时间子任务 | Agent Teams |
| 事件驱动管道，Agent生态不断增长 | Message Bus |
| 协作式研究，Agent需要共享发现 | Shared State |
| 要求无单点故障 | Shared State |

### 核心原则

- 从最简单模式开始，观察它在哪里挣扎，再演进
- 单Agent能解决的不盲目上多Agent（Token消耗3-10倍）
- 多Agent本质是横向扩展Token预算的工程手段

## 20. Claude Code七层Harness架构（Anthropic 2026）

> 来源：Anthropic《Claude Code大型代码库最佳实践》2026
> 学习轮次：R45

### 七层架构（从底到顶）

```
CLAUDE.md → Hooks → Skills → Plugins → LSP → MCP Servers → Subagents
```

| 层级 | 职责 | 关键洞察 |
|------|------|---------|
| CLAUDE.md | 项目级全局约定 | 克制内容；专业知识放Skills |
| Hooks | 硬约束+自我进化 | Stop Hook反思→提议更新CLAUDE.md；27个Hook事件 |
| Skills | 按需加载知识包 | 文件夹（非文件）；渐进式披露；9种分类 |
| Plugins | 持久工具扩展 | 独立存储路径 `${CLAUDE_PLUGIN_DATA}` |
| LSP | 代码智能 | IDE级语义理解 |
| MCP Servers | 外部系统连接 | Tools/Resources/Prompts三层原语 |
| Subagents | 上下文隔离执行 | 独立窗口+精炼回报 |

### Hooks/Skills/Agents职责三定律

> Hooks管"不能做什么"（硬约束）
> Skills管"应该怎么做"（能力包）
> Agents管"谁来做"（角色担当）

### Skills九种分类

| # | 类型 | 典型应用 |
|---|------|---------|
| 1 | 库和API参考 | 内部库使用指南+边界情况+踩坑清单 |

| 8 | Runbooks | 症状→多工具调查→结构化报告 |

### Skill工程最佳实践

- Gotchas部分信噪比最高（记录Claude实际踩过的坑）
- description字段是模型触发条件，不是功能摘要
- 给Claude信息，不给Claude剧本（留判断权给模型）
- 先在7天内验证Skill价值再决定保留

### 多Agent研究系统核心数据

- 多Agent（Opus 4 Lead + Sonnet 4 Subagent）比单Agent强**90.2%**
- Token用量解释**80%**性能方差
- 开放性压缩本质：海量信息→横向扩展Token→并行提炼洞见
