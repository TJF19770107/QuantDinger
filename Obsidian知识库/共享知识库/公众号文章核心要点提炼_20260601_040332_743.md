## 一、核心命题

**问题**：AI Agent 再聪明，也只停留在"给建议"，无法真正进入协作系统把事情办完。

**方案**：飞书 CLI（lark-cli）作为飞书官方开源命令行工具，为 Codex 等 AI Agent 提供标准化执行入口。

**结果**：Codex + 飞书 CLI = 一句话处理飞书所有数据。

---

## 二、关键洞察

1. **补全执行闭环**：AI 从"理解需求→生成建议"升级为"理解需求→读取上下文→调用工具→执行操作→落地到飞书"

2. **低门槛接入**：Node.js + 一条命令安装，10 分钟跑通，无需审批

3. **覆盖全业务域**：文档/消息/日历/多维表格/邮箱/妙记/通讯录/知识库/搜索

4. **AI 专用优化**：错误提示告诉 AI 如何修复、缺权限自动引导补授权、Token 消耗优化、成功率远高于直接调 API

## 四、关键命令卡片

```
# 一键安装
npx @larksuite/cli@latest install

# Skills 加载
npx skills add larksuite/cli -y -g

# 初始化应用
lark-cli config init --new

# 用户授权
lark-cli auth login --recommend

# 验证状态
lark-cli auth status
```

## 六、最佳实践原则

1. **先装 Skill 再授权**：CLI + Skills 装完后必须重启 Agent
2. **授权选最小权限**：个人使用选"仅个人使用"
3. **遇到问题先 auth status**：检查 identity 和 tokenStatus
4. **自然语言驱动**：不需要记命令，直接用自然语言描述需求
5. **cc-connect 做群聊桥接**：需要飞书群内交互时使用
