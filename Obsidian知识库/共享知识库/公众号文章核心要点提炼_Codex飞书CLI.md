## 核心要点提炼

### 1. 架构范式：对话即API
Codex 通过 MCP（Model Context Protocol）协议将飞书开放平台 API 封装为可对话调用的工具集。用户无需编写代码，通过自然语言即可驱动飞书文档/表格/消息/日历/会议/审批操作。

### 2. 接入五步法
1. **飞书应用创建**：开放平台创建企业自建应用 + 权限配置
2. **Token 管理**：tenant_access_token 获取与缓存（2小时有效期）
3. **MCP Server 注册**：将飞书 API 封装为 MCP 工具集
4. **Codex Session 对接**：启动带飞书 MCP 的会话
5. **对话验证**：自然语言驱动操作

### 3. 六大自动化场景
- **飞书文档**：CRUD、块级追加、批量更新
- **多维表格**：记录查询/新增/更新/批量操作
- **消息推送**：富文本/卡片消息、群消息
- **日历管理**：忙闲查询、日程创建/更新
- **会议调度**：创建/结束/录制查询
- **审批流程**：实例创建/查询/审批处理

### 4. 关键技术点
- **MCP 协议**：标准化工具暴露接口，实现 Agent ↔ API 解耦
- **Hook 机制**：定时调度（cron）、事件触发自动化
- **Skill 封装**：将工具组合为可复用的技能模块
- **错误处理**：限流重试、Token 刷新、降级策略
