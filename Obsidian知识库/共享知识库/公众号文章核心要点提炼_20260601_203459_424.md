## 二、核心技术点拆解

### 2.1 飞书 CLI（larksuite/cli）—— 为 AI Agent 设计的命令行工具

- **GitHub**：https://github.com/larksuite/cli（5.5k+ Star）
- **核心设计**：不是传统 API SDK，而是专门为 AI Agent 优化的命令行界面
- **三层架构**：Shortcuts → API Commands → Raw API（2500+ OpenAPI）

### 2.2 Codex 接入飞书的两种路径

| 路径 | 工具 | 适用场景 |
|------|------|---------|
| MCP 注入 | `lark-mcp` + Codex config.toml | 深度集成，自然语言驱动 |
| CLI 调用 | `lark-cli` 命令行 | 脚本/自动化/简单集成 |

### 2.3 最小闭环三步走

1. 安装 CLI：`npm install -g @larksuite/cli`
2. 安装 Skills：`npx skills add larksuite/cli -y -g`
3. 初始化配置：`lark-cli config init --new` → 扫码授权 → 重启 AI 工具

## 三、可复用 SOP 模板提炼

### SOP-1：AI 调研 → 飞书文档自动落地

```
输入：调研主题
输出：飞书文档链接

步骤：
1. AI 多源搜索 + 内容提炼 → 生成结构化 Markdown
2. 调用 lark-cli docs +create --title "主题" --content "<Markdown>"
3. 返回文档链接
```

### SOP-2：数据整理 → 飞书多维表格

```
输入：CSV/JSON/手工数据
输出：飞书 Base 表格链接

步骤：
1. 解析数据结构
2. 逐条调用 lark-cli base record-create
3. 返回表格链接
```

### SOP-3：群消息智能总结

```
输入：飞书群 ID
输出：结构化总结消息/文档

步骤：
1. lark-cli im +messages-summary 获取消息
2. LLM 提炼关键点（待办/决策/讨论）
3. 发送总结到群或创建飞书文档
```

### SOP-4：日程智能管理

```
输入：自然语言需求（如"下周哪天有空"）
输出：日程创建完成 + 确认消息

步骤：
1. lark-cli calendar +freebusy 查忙闲
2. 找可用时段
3. lark-cli calendar +event-create 创建日程
4. 发送确认消息
```

### SOP-5：Codex Triggers 事件驱动自动化（R28 新增）

```
输入：GitHub Issue / Webhook 事件
输出：飞书通知 + 自动 PR

步骤：
1. Codex Triggers 监听 GitHub 事件
2. Codex 自动分析 Issue 内容 → 生成修复代码
3. 开 Pull Request
4. 飞书 CLI 发送通知到团队群
```

## 四、关键权限配置清单

| 权限域 | 用途 | 开通建议 |
|--------|------|---------|
| `doc:doc:readonly/write` | 读写文档 | 必开 |
| `im:message:send` | 发送消息 | 必开 |
| `calendar:calendar:readonly/write` | 读写日历 | 按需 |
| `base:app:readonly/write` | 读写多维表格 | 按需 |
| `mail:mail:readonly/write` | 读写邮件 | 按需 |
| `contact:contact:readonly` | 读通讯录 | 按需 |
| `task:task:readonly/write` | 读写任务 | 按需 |
