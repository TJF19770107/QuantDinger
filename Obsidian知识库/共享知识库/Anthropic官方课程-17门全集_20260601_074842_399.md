### 13. Introduction to Agent Skills

| 属性 | 内容 |
|------|------|
| **链接** | https://anthropic.skilljar.com/introduction-to-agent-skills |
| **时长** | 约 2 小时 |
| **难度** | 中级 |
| **证书** | 有 |

**核心内容**：Agent Skills 的构建、配置和分享。Skills 是可复用的 Markdown 指令，Claude 在任务中根据上下文自动应用。

**Skill 架构**：
```
skill-folder/
├── SKILL.md          # 核心指令（YAML frontmatter + Markdown 指令）
├── scripts/          # 可执行 Python/Bash 脚本
├── references/       # 按需加载的参考文档
└── templates/        # 模板文件（可选）
```

**核心原则**：

| 原则 | 说明 |
|------|------|
| **原子化** | 一个 Skill = 一个明确定义的任务 |
| **精确触发** | 避免 Skill 之间的触发冲突 |
| **渐进式信息披露** | 仅在触发时加载详细指令，节省 70-90% Token |
| **脚本确定性** | 需要一致结果的任务使用脚本保证可靠性 |
| **跨平台兼容** | 同一 Skill 格式适用于 Claude.ai / Claude Code / API |

**学习目标**：
- 理解 Agent 的感知-行动-反思循环
- Skill 架构设计（触发器/指令/上下文）
- 完整的 Skill 开发工作流
- 测试与迭代优化
- 发布到 Skill 市场

**Agent Skills 是 Agent 的「能力集」**——将特定任务逻辑封装为可复用技能，让 Claude 成为能执行特定操作的"数字员工"。这是从「提示词工程」到「Agent 协作工程」的关键一步。

### 14. Introduction to Subagents

| 属性 | 内容 |
|------|------|
| **链接** | https://anthropic.skilljar.com/introduction-to-subagents |
| **时长** | 约 2 小时（4 个短视频 + 测验） |
| **难度** | 中级-高级 |
| **证书** | 有 |

**核心内容**：在 Claude Code 中使用和创建 Subagents——上下文管理、任务委派、与 Skills 协同、构建专业化工作流。

**Subagent 设计五要素**：

| 要素 | 规范 |
|------|------|
| 输入格式 | 明确字段定义（项目名、目标平台、字数上限等） |
| 输出格式 | 强制 JSON 模式，含 title/intro/steps |
| 失败返回 | `{"error":"描述"}` 标准化错误结构 |
| 超时策略 | 设置超时阈值，超时后重试 |
| 重试策略 | 空响应时增加重试并检查输入格式 |

**学习目标**：
- 创建带有 Skills 的 Subagents
- 构建多 Agent 系统
- 管理隔离的上下文窗口
- 并行启动子代理处理跨平台任务

**子代理最佳实践**：

| 要点 | 详情 |
|------|------|
| 上下文隔离 | 每个子代理独立上下文窗口，主Agent只接收精炼结果 |
| 委派标准 | 可独立完成 + 结果可验证 + 值得开销 |
| 精准回报 | 子代理只返回关键信息，不返回完整执行过程 |
| Skills 协同 | Skills 注入自定义子代理实现专家级任务委派 |
| 并行处理 | 无依赖任务同时启动，主代理收集结果统一格式 |
| 冲突调和 | 并行结果冲突时主代理以优先级规则或合并模板调和 |

## 八、核心技能深度提炼

### 8.1 子代理 (Subagents) 核心技能

**设计原则**：
- **单一职责**：每个子代理只处理一个明确定义的任务
- **明确输入输出**：Spec 模板强制 JSON 格式，字段明确
- **上下文隔离**：独立上下文窗口，不污染主对话线程
- **精准回报**：只返回关键精炼结果

**错误处理模式**：
| 问题 | 应对 |
|------|------|
| 空响应 | 增加重试 + 检查输入格式 |
| 输出格式错位 | Spec 强制 JSON 模式 + 示例 |
| 并行结果冲突 | 主代理优先级规则/合并模板调和 |

---

### 8.2 多 Agent 协作 (Agent Teams) 核心技能

**三层 Agent 架构 (Level 1-3)**：

| 层级 | 名称 | 通信 | 适用场景 | 比喻 |
|------|------|------|---------|------|
| **Level 1** | Subagents | 向主 Agent 汇报，彼此不通信 | 可重复任务（审查/测试/文档） | 承包商 |
| **Level 2** | Agent View | 全屏 Dashboard 管理 | 3-10 个独立任务 | 任务看板 |
| **Level 3** | Agent Teams | 成员互相通信，共享任务列表 | 跨文件相互依赖任务 | 工程团队 |

**7 步构建 Agent 战队**：
1. 理解 3 个层级能力边界
